# Cairn v0.9.0 — Design Spec

> **Status:** finalized 2026-05-26. Single release, no split. Branch discipline per the v0.7-v0.8 retrospective: all work lands on `release/v0.9.0`, not `main`. Single PR to main at smoke + release time.

**Theme:** power features + 1.0-readiness — finishes every remaining feature on the pre-1.0 roadmap except the AI cluster (set aside for the third time).

**Scope:** 38 features, 43 plans, 9 plan groups, 15 new migrations (0034-0048).

**Prior context:** v0.7.0 shipped MCP + automation + connectors + pgvector hybrid search. v0.8.0 shipped offline-Yjs sync + virtualized sidebar/db-table + code-split editor + inbox + onboarding + palette expand + settings hub + notifications + themes + covers + native PDF + new blocks. The v0.7-v0.8 retrospective (`docs/superpowers/retrospective-v0.7-v0.8.md`) is required reading before writing or implementing any v0.9 plan.

---

## 1. Release shape

- **Version:** `0.9.0`. Single release. No `0.10` split.
- **Branching:** `release/v0.9.0` created off `main` at start. Every P-plan + every fix-on-fix commits to the branch. A single smoke plan opens one PR `release/v0.9.0 → main`. Tag fires off the merge commit.
- **Plan groups:** 9 (G1-G9). G9 = combined smoke + release.
- **Plan count:** **43**.
- **Migration ledger:** 15 migrations, `0034` through `0048`.
- **Non-goals (explicit):** in-app AI assistant / AI writing tools / AI DB autofill; mobile native app; payments/billing; SaaS multi-tenancy; SAML/OIDC at the `cairn-collab` layer.

## 2. Feature scope (38)

### G1 — Security + identity (5 features → 10 plans)

**#2 SSO bundle.** SAML 2.0 (`samlify`), OIDC (Auth.js native), SCIM 2.0 provisioning endpoint, admin IdP-config UI. SCIM v2 `/Users` + `/Groups` with `userName eq`/`meta.lastModified gt` filter support only (complex filters deferred). JIT user provisioning explicitly skipped — SCIM is the provisioning surface. New tables: `idp_configurations`, `external_identities`, `scim_tokens`. 4 plans.

**#4 + #5 E2E encryption.** Per-user X25519 keypair (private encrypted under a passphrase-derived KEK, stored server-side as ciphertext). Per-page mode: a symmetric DEK encrypts content, wrapped under every page-member's public key. Workspace-wide mode: a workspace key wrapped under every member's public key, all pages in the workspace use it. Server never sees plaintext or unwrapped keys. New tables: `user_keypairs`, `page_encryption_keys`, `workspace_encryption_keys`. New column: `pages.encrypted boolean`. Three plans: crypto core, per-page mode, workspace-wide mode.

**#20 MFA — WebAuthn + step-up + admin-enforce.** `@simplewebauthn/server` + `@simplewebauthn/browser`. Passkeys complement (do not replace) v0.6 P19 TOTP. Step-up flow re-auths before sensitive ops (workspace delete, admin role grant). Workspace admin can require MFA enrolment for all members. New tables: `user_webauthn_credentials`, `workspace_mfa_policies`. New audit actions: `mfa.passkey_added/removed/used`, `mfa.stepup_required`. 1 plan.

**#15 PAT quotas + scope rate-limits + admin dashboard.** Extend `personal_access_tokens` with `daily_request_limit`, `monthly_request_limit`, `scope_rate_limits jsonb`. New `pat_quota_usage` rollup table. Admin observability dashboard with live quota usage + reset action. 2 plans: quota engine, admin UI.

### G2 — Workspace structure (4 features → 4 plans)

**#7 Spaces.** Flat `spaces` table under each workspace. `pages.space_id` nullable FK. `space_members` for per-space ACLs; permission check chains workspace role + space role. Sidebar groups pages by space. No nesting (parent FK column reserved but unused). 1 plan.

**#38 Workspace-pinned pages.** New `workspace_pins` table (workspace_id, page_id, position, pinned_by). Distinct from v0.8 per-user favorites. Admin UI manages pins; pinned items render workspace-wide in a separate sidebar section above per-user favorites. 1 plan.

**#18 Trash retention + auto-purge.** `workspaces.trash_retention_days` (defaults to `CAIRN_TRASH_RETENTION_DAYS` env). Admin settings UI to override. Cron sweep purges per workspace value. Manual "empty trash now" button with confirm modal + audit. 1 plan.

**#23 Page lock / freeze.** `pages.locked_at`, `locked_by`, `locked_until`. Lock refuses ALL writes including from owners with edit perms (full freeze). Admin can override-unlock with audit. Optional `locked_until` for time-boxed locks; cron auto-unlocks at expiry with audit entry. New audit actions: `page.locked`, `page.unlocked`, `page.auto_unlocked`. 1 plan.

### G3 — New blocks (9 features → 8 plans)

**#6 Diagram blocks expansion.** Add PlantUML + drawio alongside v0.8's Mermaid. PlantUML via `plantuml-encoder` client-side WASM (no server runtime). drawio via iframe embed (extend `EMBED_FRAME_HOSTS` + drift-guard). 1 plan.

**#9 Image gallery + lightbox.** TipTap gallery node (n-image grid) + portal modal viewer with prev/next/zoom. 1 plan.

**#10 PDF annotation + inline viewer.** `pdfjs-dist` inline viewer + annotation overlay. New `pdf_annotations` table (page_id, file_id, page_number, rect jsonb, kind, content, created_by). v0.9 annotations are per-user, no Yjs sync (deferred). 1 plan.

**#11 Citation / footnote blocks.** TipTap footnote anchor + citation block + bibliography aggregator at page-end. Pairs with #34. 1 plan.

**#22 Flashcards block.** Per-user persistent SM-2 spaced repetition. New tables: `flashcard_cards` (page_id, block_id, front, back, deck_tag), `flashcard_reviews` (card_id, user_id, ease, interval, due_at, last_reviewed_at). "Review due" sidebar counter + study-session route + v0.8 notification-bell entries + v0.6 email digest. 1 plan.

**#31 Date/time block with timezone.** TipTap node + `luxon` for TZ-aware rendering. First-class block (vs raw text date). 1 plan.

**#34 DOI / PubMed citation lookup.** Paste DOI or PubMed ID → server-side fetch from `api.crossref.org` / `eutils.ncbi.nlm.nih.gov` → APA/MLA/Chicago formatted citation inserted via the #11 citation block. 1 plan.

**#25 Bulk file drag-drop + #36 Audio/video block.** Multi-file uploader UI (drag a folder of files at once → parallel upload + insert blocks). Audio TipTap node alongside v0.8 video; extend `/api/upload` MIME allowlist with `audio/mpeg`, `audio/wav`, `audio/ogg`, `audio/flac`. 1 plan.

### G4 — Content lifecycle (5 features → 4 plans)

**#1 Tasks hub ("My Tasks").** `/my-tasks` route that aggregates every task-list checkbox across pages where the signed-in user is assigned or mentioned. Built via a materialized view over existing task-block content. 1 plan.

**#8 Page approval / sign-off.** New `page_approvals` table tying a snapshot version (v0.5 P4) to an approver + HMAC-signed audit entry. Approval UI on pages in `status='review'`. Couples with #29 lifecycle. 1 plan.

**#28 Save-as-template + sharing controls.** "Save as template" page-action menu item. New `page_templates.visibility` column: `private` (creator only), `workspace` (every member), `public` (anyone with `/templates/gallery`). Hook into v0.8 P10 gallery. 1 plan.

**#29 Page lifecycle + #19 Parallel translations.** New `pages.status text` enum: `draft` (visible only to author + admins), `review` (visible to workspace, gates approval UI), `published` (visible to workspace + reachable in search), `archived` (hidden from sidebar/search, retrievable). Existing `pages.published` boolean → distinct concept (public-share toggle). New `pages.translation_of_page_id` self-FK + `pages.translation_locale` text — paired translation pages link bidirectionally. 1 plan.

### G5 — Search + discovery (4 features → 4 plans)

**#12 "See also" related pages.** Vector-powered similarity panel using v0.7 P11-P13 embeddings. Surfaces in the editor's right-rail (when present) + on `/p/<slug>` reader view. Skips `pages.encrypted=true`. 1 plan.

**#16 Page outline / TOC sidebar.** Sticky right-rail panel auto-built from page headings. Per-user pref controls visibility (default off). The inline TOC block from v0.6 P6 coexists. 1 plan.

**#32 Search operators + chip UI + saved templates.** Parser converts `foo from:alice before:2026-01-01 tag:bug` to the v0.6 P22 filter structure. Chip-builder UI above the search input renders typed operators as removable chips. Named operator templates (`@bugs` resolves to `tag:bug type:page status:open`). 1 plan.

**#33 Federated multi-workspace + cross-instance search.** Membership-scoped cross-workspace search (user's `?q=` queries every workspace they belong to). Admin opt-in cross-workspace search (admin queries non-member workspaces with audit). New `peer_instances` table for cross-instance federation; HMAC-signed query envelope using `CAIRN_FEDERATION_SHARED_SECRET`. 1 plan.

### G6 — Polish + UX (4 features → 3 plans)

**#3 i18n framework + en + es.** String-key audit lifts every hardcoded English string into `src/lib/copy/messages.ts` (v0.8 P13 registry). New Biome rule to refuse new hardcoded strings in `src/`. Ship `es` translations (native-speaker pass). Other languages deferred to community contributions. 1 plan.

**#17 Side-by-side version diff.** Pick snapshot A + B from v0.5 P4 version history; render block-level ProseMirror diff with green/red highlighting and collapse-identical-sections. No 3-way diff. No revert-from-diff. 1 plan.

**#30 Focus/reader + #35 Share password.** Focus toggle on `/pages/<id>` hides sidebar/header/comments (editor stays editable). Reader mode is read-only with prose styling matching `/p/<slug>`. Two distinct buttons. Share-password: wire `pages.link_password_hash` (column already exists) — settings UI to set/clear, `/p/<slug>` 401 + password prompt, bcrypt verify, audit on entry. 1 plan.

### G7 — Export + interop (4 features → 5 plans)

**#13 Static-site export (MkDocs + Docusaurus).** 2 plans:
- Plan A: shared export pipeline + CLI (`pnpm exec cairn-export --target ... --workspace ...`) + workspace-admin UI button + MkDocs target (mkdocs.yml + assets + frontmatter profile).
- Plan B: Docusaurus target on the same pipeline (docusaurus.config.js + sidebars + `id`/`slug`/`sidebar_position` frontmatter profile).

Scheduled S3/GitHub-Pages export skipped (deferred).

**#14 Chat bridge (Slack + Discord).** 2 plans:
- Plan A: Slack/Discord app install + bot tokens (`@slack/bolt`, `discord.js`); outbound page-event notifications via existing v0.5 P2 webhook infrastructure; inbound message-reply creates a Cairn comment.
- Plan B: slash commands (`/cairn search`, `/cairn create page`) + channel↔page sync mode (channel messages append to a linked page, page comments post to the channel).

**#27 OpenAPI + Swagger UI.** Generator that introspects existing `/api/**` route handlers + Zod schemas via `zod-to-openapi`. Publishes `/openapi.json` + a Swagger UI page at `/api-docs`. 1 plan.

**#37 MD frontmatter** — folded into #13's plans (per-format frontmatter profiles). No separate plan.

### G8 — Operations + observability (3 features → 4 plans)

**#21 SIEM forwarder.** 2 plans:
- Plan A: core engine + syslog (RFC 5424) + generic HTTP webhook targets. New tables: `siem_forwarders`, `siem_delivery_log`.
- Plan B: native Splunk HEC + Datadog Logs API + periodic S3 NDJSON archive.

**#24 Self-hosted upgrade tooling.** 2 plans:
- Plan A: `cairn-upgrade` CLI (`preview` / `apply` / `rollback` / `healthcheck`) bundled into runtime image. `apply` does pg_dump snapshot → migrate in txn → restart → healthcheck → on fail, restore. Docker Compose-aware (drives compose stack lifecycle).
- Plan B: release-watch daemon (inline cron tick) polls `CAIRN_RELEASE_FEED_URL` for new tags + emits an in-app admin notification. Admin UI at `/admin/upgrade` shows current/available versions + one-click apply. Auto-apply remains off by default.

**#26 Encrypted workspace backups.** AES-256-GCM envelope around the existing v0.5 P5 S3 backup pipeline. Key derived from `CAIRN_BACKUP_ENCRYPTION_PASSPHRASE` via Argon2id. Separate from #4/#5 E2E (different keys, different threat model: backup encryption protects the *backup blob* against the S3 provider; E2E protects *live page content* against the Cairn server). 1 plan.

### G9 — Smoke + release (1 plan)

`scripts/smoke-v0.9.0.sh` + README/SECURITY/CHANGELOG/version bump + tag. Mirrors v0.8 P26 + retrospective rules: PR `release/v0.9.0 → main`, tag from merge commit. T6 (the tag itself) stays controller-authorized (mirrors v0.8 self-tag authorization).

### Runtime impact — E2E

Server is blind to encrypted page content. Knock-on effects (every consumer must check `pages.encrypted`):

- FTS + pgvector: skip encrypted pages server-side; UI shows "encrypted" badge in search results.
- Embeddings: skip pipeline; `see also` (#12) silently excludes them.
- Public sharing: REFUSED with explicit error.
- Templates: snapshot-from-encrypted-page allowed (template stays encrypted); instantiation into a non-encrypted workspace requires explicit re-key.
- Backups: pass through (already encrypted).
- Webhook/automation: events fire with `body: null` for content fields + `page.encrypted` flag for consumers.
- Hocuspocus collab: doc updates already opaque blobs, works unchanged.

No new infra services. No worker process. Existing `cairn` + `cairn-collab` + `db` compose stays.

## 5. Non-goals + deferred + risks

### Explicit non-goals for v0.9.0

- No in-app AI assistant / AI writing / AI DB autofill (third explicit set-aside).
- No mobile native app.
- No payments / billing / SaaS multi-tenancy.
- No SAML/OIDC at `cairn-collab` Hocuspocus layer (Auth.js JWT at Next layer only).
- No mobile companion for chat bridge.
- No real-time multi-cursor for encrypted pages (Yjs awareness stays unencrypted in v0.9).

### Deferred to v1.0.0

- AI cluster (re-evaluate at v1.0 brainstorm — ship or drop permanently).
- Mobile native app.
- Encrypted multi-cursor awareness.
- SCIM 2.0 group-nesting + complex filter expressions (basic only in v0.9).
- Real-time collaborative PDF annotation (annotations are per-user in v0.9).
- Chat bridge for Teams / Mattermost / Zulip.
- Per-page DEK rotation (DEK is set-once in v0.9).

### Risks (highest → lowest)

1. **E2E encryption blindness across half the product.** Every consumer of `pages.content_text` / `pages.content` must check `pages.encrypted`. One missed consumer leaks plaintext. **Mitigation:** plan-review subagent verifies the encryption flag at every consumer call site.

2. **SAML real-world IdP interop.** `samlify` mock covers unit tests; document a HUMAN-RUN smoke checklist against Okta + Keycloak (minimum) as a release-block gate.

3. **Federated cross-instance search.** New cross-instance trust model + abuse surface. **Mitigation:** off by default; HMAC-signed envelope; per-peer rate-limit; audit every cross-instance request.

4. **Page-status migration on existing rows.** Backfill all to `status='published'`. Wrap in a single transaction; verify count matches pre-migration count before commit.

5. **WebAuthn RP-ID misconfiguration.** Permanent credential invalidation. **Mitigation:** startup-time RP-ID sanity check against `NEXTAUTH_URL`; admin warning on mismatch.

6. **Chat bridge inbound webhook abuse.** Slack signing-secret + Discord ed25519 sig validation; per-workspace rate-limit; XSS sanitizer reuses v0.5.1 T3.

7. **`cairn-upgrade apply` on production data.** `apply` requires `--confirm`; runs `pg_dump` first; `rollback` restores. `preview` is read-only.

8. **i18n hardcoded-string sweep.** Tedious. **Mitigation:** Biome rule + automated codemod + native-speaker pass on `es`.

9. **Plan count (43).** Branch discipline contains the blast radius — stalled state stays off `main`.

### v1.0.0 implications

v0.9.0 ships every remaining pre-1.0 feature on the original roadmap minus the AI cluster. v1.0.0 should be: stabilization sweep, security audit, performance regression catch-up, docs polish, AI cluster decision.
