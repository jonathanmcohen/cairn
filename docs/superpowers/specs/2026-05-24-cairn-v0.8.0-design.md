# Cairn v0.8.0 — Experience & 1.0-readiness

> Status: **design approved**. Single large release after v0.7.0; explicitly NOT split. The theme is "experience polish + 1.0-readiness" — most items are deltas on shipped v0.6 / v0.7 surfaces, plus six genuinely-new top-level capabilities (performance, themes, quick capture, onboarding, covers, settings hub polish). Follows the v0.6.0 / v0.7.0 spec → numbered plans → subagent-driven execution pattern.

---

## 1. Goals & non-goals

**Goals.** Finish the experience strokes that get Cairn to 1.0: full-doc offline editing, gesture-first mobile, a notification center, themes, quick capture, first-run onboarding, server-side PDF, page covers + richer embeds, a Notion-class command palette, and a measured performance pass. Sweep WCAG over the v0.7 new-route surfaces. Settle the small leftover block-type gaps.

**Non-goals (deferred to v1.0 stabilization).**
- Frozen public API + OpenAPI spec.
- BYO-LLM AI assist features.
- Native iOS/Android apps (PWA covers mobile through 1.0).
- Cross-page synced blocks, per-block ACLs, graph view of page links, recurring tasks, SSO/SAML/SCIM, passkeys, distributed scheduling, arbitrary iframe embeds, third-party email SaaS, comment reactions.

---

## 2. Decisions (the six design points settled in brainstorm)

Each is a binding constraint for the plans below.

### 2.1 Overlap-as-delta — keep all 16 items, no rebuilds

Ten of the sixteen items overlap with shipped v0.6/v0.7 work. Each ships a **specific delta** on top of what's there; the spec calls out the delta per item. The six genuinely-new items get full specs.

### 2.2 Offline editing — full Yjs-over-IndexedDB sync (no queue)

Drop v0.6 P13's bounded-cache restriction. Every page the user opens is mirrored to IndexedDB via `y-indexeddb` for the lifetime of the workspace session. Offline edits land in the local Yjs doc; the existing `HocuspocusProvider` auto-reconnects + Yjs CRDT merges with the server doc on rejoin. No edit queue, no manual conflict resolution, no "offline mode" toggle — the provider's connection state already drives the UI indicator. Trade-off: IndexedDB footprint grows with workspace-session breadth; eviction is FIFO, capped by `CAIRN_OFFLINE_DOC_LIMIT_MB` (default 256MB).

### 2.3 Performance pass — bounded triage (three targets + CI budget)

Three measured targets, each with a Plan:

1. **Virtualize the page-tree sidebar + db-table view.** Both currently DOM-render every row. Use `@tanstack/react-virtual` (lightweight, no theme assumptions). Sustains 10k+ row workspaces without sidebar jank.
2. **Code-split heavy editor extensions.** TipTap math (KaTeX), syncedBlock, and embed extensions all load on first paint today. Lazy-load each via `dynamic(() => import(...))` so they only enter the bundle when a page actually uses them.
3. **DB query audit.** Drive selection via v0.6 P20 `db_query_duration_seconds` — pick the top 5 routes by p99 latency, run `EXPLAIN ANALYZE`, add missing indexes (or rewrite the query). Document the 5 in `docs/operations.md`.

CI gate: **Lighthouse CI budget** on the public `/p/<id>` route (no auth required, predictable load) — fail the build if performance score drops > 5 points, or any of LCP/FCP/TTI regress > 10%.

### 2.4 Quick capture — PWA-native (in-tab hotkey + share_target + inbox page)

- **In-tab hotkey** registered via v0.6 P15 shortcut registry: default `Cmd+Shift+N` / `Ctrl+Shift+N` opens an "Add to inbox" modal anywhere in the app.
- **PWA `share_target`** manifest entry registers Cairn as an OS-level share destination (Android share sheet, ChromeOS, Windows/macOS Chromium Share). The OS POSTs the shared payload to `/api/inbox` and Cairn opens the triage view.
- **Inbox as workspace-scoped system page.** New `workspaces.inbox_page_id` column (nullable; lazily created on first capture). Captured items are normal child pages of the inbox page, tagged `inbox = true` (jsonb metadata) until triaged (moved or marked done).

No native binary, no browser extension. `share_target` is a one-line manifest addition; the rest reuses existing primitives.

### 2.5 PDF/print export — Playwright server-side PDF (env-gated)

Promote `@playwright/test` from dev-dep to runtime-dep (it's already pulled in for the v0.6 P14 a11y gate). New `pageToPdf(page): Promise<Buffer>` renders `pageToPdfHtml` through a headless Chromium instance and returns real `application/pdf` bytes. Wired into existing `/api/pages/[pageId]/export?format=pdf`. Browser-print path stays as `?format=pdf-print-html` fallback. Gated behind `CAIRN_NATIVE_PDF=1` env so operators who don't need PDF keep a slim ~150MB-smaller image.

### 2.6 Notification center — bell drawer + /notifications page (both)

- **Bell drawer:** global-header bell icon with unread count; click opens a right-side drawer with grouped notifications (today / this week / older), per-row deep link, mark-read, mark-all-read, "see all" link.
- **`/notifications` page:** full inbox-style view with filter (type, date range, status) + pagination.

Shared list query + pagination; two render contexts. Email digest path from v0.6 P11 stays untouched. The `notifications` table already has a `read` column.

## 3. Feature areas (10 plan groups, ~26 numbered plans)

Each group is independently shippable; G1–G9 cover the 16 features, G10 is smoke + release.

### G1. PWA + mobile polish (items #1, #2)

**Plans (3):**

- **P1** — Drop bounded-cache restriction in `y-indexeddb` mirror; persist every opened doc for the workspace session; FIFO eviction at `CAIRN_OFFLINE_DOC_LIMIT_MB` (default 256MB). Update the offline-status banner to reflect actively-syncing vs queued-pending.
- **P2** — Mobile gesture polish: swipe-back on detail pages, long-press → context menu on db rows + sidebar pages, pull-to-refresh on the list/timeline views. Touch-target audit per WCAG 2.5.5 (44×44 minimum) across new v0.7 surfaces (dev settings, automation, connectors).
- **P3** — Reconnect-and-merge smoke: integration test seeds a doc, simulates offline edits via the IndexedDB provider, simulates reconnect, asserts CRDT merge produces the expected text + structure. Stop divergence at the contract boundary.

### G2. Performance pass (item #4)

**Plans (4):**

- **P4** — Add `@tanstack/react-virtual` dep; virtualize `<PageTreeSidebar>` (replaces the recursive DOM render with a windowed flat list — page tree is pre-flattened at the server). Performance test: render 10k pages in < 200ms.
- **P5** — Virtualize the db-table view (`<DatabaseTableView>`). Sticky headers + virtualized row body. Performance test: 10k rows in < 200ms.
- **P6** — Code-split TipTap math (KaTeX), syncedBlock, embed extensions via `dynamic()` + per-extension `loading: () => null`. Measure: initial editor bundle reduced by ≥ 200 KB.
- **P7** — DB query audit. Use the v0.6 P20 `db_query_duration_seconds` metric to pick top-5 routes by p99 latency; run `EXPLAIN ANALYZE`; add indexes or rewrite. Document 5 audits in `docs/operations.md`. Add a Lighthouse CI budget on `/p/<id>` as a regression gate (`@lhci/cli` GitHub Action).

### G3. Quick capture + onboarding (items #9, #10)

**Plans (3):**

- **P8** — Migration `0029`: `workspaces.inbox_page_id uuid REFERENCES pages(id) ON DELETE SET NULL`. PWA manifest `share_target` entry. `POST /api/inbox` accepts title + body + optional URL; lazily creates the inbox page if absent; inserts a child page tagged `{inbox: true, capturedAt}`. Triage UI on the inbox page: drag-to-folder + "mark done" action.
- **P9** — In-tab hotkey via v0.6 P15 registry: `Cmd+Shift+N` opens the `<QuickCaptureModal>` from anywhere. Form: title + optional body + optional URL; submits to `/api/inbox`.
- **P10** — First-run onboarding: detect a brand-new workspace (no pages yet) → render a guided 3-step setup (name + theme + sample-content opt-in). Bundle a `welcome.zip` template archive (4 sample pages + 1 sample database) at `public/templates/welcome.zip`; instantiate via the v0.5 P3 template instantiator on opt-in. Template gallery at `/templates/gallery` lists the welcome template + any user-saved templates.

### G4. Command palette + settings hub (items #3, #16)

**Plans (3):**

- **P11** — Expand the cmdk action set: add "open settings", "switch workspace", "create page", "create database row", "open recent (× 10)", "search across workspace (FTS+semantic)", "MCP token info" actions. Each action is a registry entry with `id`, `label`, `icon`, `shortcut?`, `handler`. Recent-commands stored in `localStorage`; surfaces above the search results.
- **P12** — Settings hub restructure: replace the existing flat `/settings/*` route tree with a sidebar-nav layout under `/settings` (Account / Workspace / Admin / Developer / Notifications / Security). All existing settings pages move under the new nav with redirect from old paths. No backend change — pure UI reshape.
- **P13** — Microcopy + empty-state polish: per-feature empty states (search no-results, no-databases-yet, no-notifications-yet, no-tokens-yet, no-connectors-yet) with friendly copy + a primary action. Polish setup wizard copy + button labels.

### G5. A11y v0.7 new-route sweep (item #6)

**Plans (1):**

- **P14** — Extend the v0.6 P14 `pnpm test:a11y` Playwright suite to cover the v0.7 surfaces: `/settings/developer`, `/settings/automation`, `/settings/connectors`, `/settings/admin/webhooks/[id]/deliveries`, `/healthz`. Add axe assertions for keyboard nav + focus management on the new modals (mint-PAT dialog, automation-rule form, connector OAuth flow). Fix any failures inline.

### G6. Notification center + favorites + backlinks delta (items #13, #8, #12)

**Plans (4):**

- **P15** — `<NotificationBell>` global-header component: unread count badge, click opens `<NotificationDrawer>` (right side, focus-trapped). Grouped today/this-week/older. Per-row deep link + mark-read. "See all" link to `/notifications`.
- **P16** — `/notifications` full inbox page: filter by type / date / status, paginated with keyset cursor (mirrors v0.6 P18 audit viewer). Shared list query helper with the drawer.
- **P17** — Favorites refinements: drag-to-reorder via `@dnd-kit/sortable`; new `favorites.position integer` column (migration `0030`); keyboard nav (arrow-up/down + Enter to open); per-favorite remove action.
- **P18** — Backlinks delta: inline transclusion preview — hovering a `[[page-link]]` in the editor opens a popover with the first paragraph of the linked page + outbound link. Unlinked-mentions sidebar section in the existing linked-references panel (FTS for page title across the workspace, deduped against existing linked references).

### G7. Themes + page covers + icons (items #14, #7)

**Plans (3):**

- **P19** — Migration `0031`: `user_theme_prefs` table (`user_id`, `accent` text, `font_family` text, `page_width` text, `created_at`, `updated_at`; PK `user_id`). `<ThemePicker>` in `/settings/account` lets the user pick: accent color (8 presets + custom hex), font family (system / serif / mono — 3 choices), page width (narrow / wide / full). Applied via CSS custom properties on `<html data-theme-*>` — reuses Tailwind v4 `@theme` design tokens.
- **P20** — Page covers: `pages.cover jsonb NOT NULL DEFAULT '{}'` (migration `0032`); shape: `{kind: 'color' | 'unsplash' | 'upload', value: string}`. UI: cover picker on the page header with three tabs — solid color (16 presets), Unsplash (gated behind `CAIRN_UNSPLASH_ACCESS_KEY` env; client-side search + insert URL), upload (reuses existing file-upload path). Cover renders as a 200px-tall banner above the page title.
- **P21** — Page-icon polish: emoji picker (already exists per v0.5) gets a search + recently-used row. Custom upload icon via the file-upload path. Default-icon randomizer for new pages (rotates through a curated set of 32 emojis).

### G8. Embeds/unfurl delta + block-type gaps (items #5, #15)

**Plans (3):**

- **P22** — Expand embed allowlist: Loom, Codepen, Spotify, Vimeo Showcase, Mermaid (via `mermaid.js` lazy-loaded), Excalidraw (embedded iframe pointing at `excalidraw.com/embed?...`). Each provider has its own URL-pattern regex + CSP `frame-src` allowlist addition. Drift-guarded by `tests/lib/security/embed-allowlist.test.ts`.
- **P23** — Richer link unfurls: extract OpenGraph image + description from the existing v0.6 P5 `/api/unfurl` response (currently returns title + favicon only). Cap image fetch at 256KB; SSRF guard already in place. Bookmark card shows the image + first 200 chars of description.
- **P24** — Block-type gaps: ship the small ones that are still missing — `divider` (`<hr>`-style horizontal rule), `button` (CTA with optional URL action), `video` (uploaded MP4 / WebM via existing file-upload path). Each is a TipTap node extension + read-only renderer for public pages.

### G9. Native PDF (item #11)

**Plans (1):**

- **P25** — Promote `@playwright/test` to runtime dep (move from `devDependencies` to `dependencies`). New `src/lib/export/pdf-native.ts#pageToPdf(page): Promise<Buffer>`: launches headless Chromium, navigates to a server-rendered preview URL, `page.pdf()` to Buffer. Wire into the existing `/api/pages/[pageId]/export?format=pdf` route — emit native bytes when `CAIRN_NATIVE_PDF=1`, else fall through to existing browser-print HTML path. New `?format=pdf-print-html` explicit fallback. Smoke: assert returned bytes start with `%PDF-1.`.

### G10. Combined smoke + release (item #16 polish folds in via P13)

**Plans (1):**

- **P26** — Combined cross-feature smoke (`scripts/smoke-v0.8.0.sh`): boots stack, walks the v0.8 deltas (PWA offline edit + rejoin + merge, quick capture via in-tab hotkey, notification bell unread count, native PDF response shape, page cover save+restore, theme apply). ## 6. Risks

1. **Offline-doc growth** unbounded if users open many pages in a session. Mitigated by `CAIRN_OFFLINE_DOC_LIMIT_MB` FIFO eviction (P1).
2. **Playwright runtime adds ~150MB to image.** Gated env (P25); operators opt in.
3. **Theme + CSS-custom-property + Tailwind v4 interplay** — Tailwind v4 already uses `@theme` design tokens; per-user accent overrides need to override the right tokens at runtime. Verified pattern: set custom properties on `<html data-accent="...">` and Tailwind utility classes inherit. Tested in P19.
4. **`share_target` browser support gaps** — Firefox + Safari don't implement it. Documented as "Chromium PWA-only" for v0.8; explicit warning in onboarding when target browser doesn't support.
5. **Lighthouse CI flakiness** on shared CI runners (LCP variance). Mitigation: median of 3 runs; budget regression threshold relaxed to 10% (default 5%).
6. **Native-PDF Chromium launch latency** (~1.5s cold start). Mitigated by keeping a singleton browser instance alive per process; lazy-launched on first PDF request.
7. **Mermaid + Excalidraw embeds** are full third-party iframes. CSP `frame-src` allowlist gets two more entries; drift-test catches accidental allowlist removal.

## 8. Verification

After v0.8.0 ships:
- Editing offline → reconnect → CRDT merge round-trip works on a real PWA install.
- Quick capture via `Cmd+Shift+N` and Android share sheet land in the inbox page; triage works.
- First-run onboarding seeds a welcome workspace; users can opt out.
- Notification bell + `/notifications` page show unread + history; deep links work.
- Themes persist across sessions; per-user; render correctly on `/p/<id>` published pages.
- Page covers + custom icons persist + render on the editor + on `/p/<id>`.
- New embed providers render in sandbox iframes; OG-rich unfurls show image + description.
- Server-side PDF responds with `application/pdf` bytes when `CAIRN_NATIVE_PDF=1`.
- Performance budget on `/p/<id>` holds (Lighthouse CI green).
- A11y sweep passes on all v0.7 routes (axe + Playwright).

Final gate: `pnpm lint && pnpm typecheck && pnpm test && pnpm build && pnpm build:entrypoint` all exit 0; cross-feature smoke green; CI green on `main`; tag fires the GHA-hosted release workflow.
