## 2. Data model & migrations

Next migration number: **0058**. Append extensions/triggers/self-FKs by hand per project convention.

- **0058 — workflow condition tree (J, AND/OR).** Add jsonb `condition_tree` to the automation row (chosen over a normalized group table — matches the existing `src/lib/databases/filter.ts` jsonb-compile pattern, avoids join-heavy eval). Node shape: `{ logic: 'and'|'or', children: Array<ConditionNode | GroupNode> }`, `ConditionNode = { field, op, value }`. Backfill: wrap each existing automation's flat sequential conditions as one implicit `{logic:'and', children:[...]}`. Reversible. Dispatcher gains a recursive evaluator with a depth cap (e.g. 5).
- **0059 — action ordering (J).** Add `sort_order` int to automation actions table if absent; backfill by current array index. Builder persists order on drag.
- **0060 — chat OAuth installs (F).** `chat_oauth_installs` (id, workspace_id FK, platform enum `slack|discord`, external_team_id, bot_token_encrypted, scopes text[], installed_by FK users, installed_at, revoked_at nullable). Bot tokens encrypted via `src/lib/crypto/secret-box.ts`; never logged (extend secret-leak suite). Unique (workspace_id, platform, external_team_id).
- **0061 — automation run history (J).** `automation_runs` (id, automation_id FK, status enum `success|error|skipped`, started_at, finished_at, trigger_digest text, error text nullable). Pruned by retention (cap N most-recent per automation, e.g. 100) in the dispatcher or a CLI sweep.

No migration: A/B routing, C/D/K UI, G `router.refresh`, I client, E env flag, L test, H (reads existing columns).

## 5. Risks & guards

- **Stale-deploy root cause** (C/A/B/E/D): source already correct; fixes are verification + targeted improvement. User must redeploy `ghcr…:v0.9.8` post-merge — documented in CHANGELOG + spec.
- **E2EE stays default-off** — zero lockout / search-break risk this release.
- **Condition-tree migration (0058)** is the one real backfill risk: reversible, single implicit AND group, tested against existing automations before/after.
- **Chat OAuth tokens** are sensitive: encrypted at rest, never logged, SSRF-guarded redirect URIs, secret-leak test coverage.
- **SSO route move** must redirect all old `/admin/sso*` deep links (avoid breaking bookmarks); API routes untouched.
- **CI flake awareness** (self-hosted runners): build OOM mitigated by skipping in-build TS phase (v0.9.7); embed-smoke/test shards can flake (137/255/SIGKILL) → re-run, not "fix."
