# Cairn v0.9.6 — Audit-Driven Hotfix Release (Design)

**Date:** 2026-05-30
**Type:** Hotfix / polish release (NOT a feature push). Closes named GitHub issues from the v0.9.4 live browser audit (#129–#149 + the dialog epic #138).
**Process discipline:** single branch `patches/v0.9.6`, single PR at the end, **no direct landing on `main`**. Subagent-driven execution, hold for explicit "go" before building.

Resolve the v0.9.4 deploy-audit findings: production-broken surfaces (embeddings, dialogs, block insertion), non-functional UI (connectors, admin, covers, suggestions badge), and discoverability/polish gaps (slash aliases, swagger, DB views). Every plan closes named issues.

## Plan groups

Plans are grouped by theme. Each group is a sequence of bite-sized TDD plans. The themed-dialog epic (G1) is its own large group.

### G1 — Themed dialog epic + native-control sweep (A) — closes #138, #135, #38
Absorbs the in-flight work on branch `feat/themed-confirm-dialogs` (PR #140: `ConfirmProvider`/`useConfirm` + 12 `confirm()` sites + `InputDialog`/`usePrompt` + 4 `prompt()` sites, all tested). v0.9.6 incorporates those commits, then completes:
- **Editor dialog bridge**: TipTap slash commands can't call React hooks. Add an imperative store (`src/components/editor/editor-dialog-bus.ts`) + a React `<EditorDialogs>` host mounted near the editor. The 9 `slash-extension.ts` prompts (footnote text; citation DOI/PubMed/author/title/year; flashcard front/back/deck) dispatch to the bus → host opens `InputDialog` (single-field) or a small multi-field form dialog (citation, flashcard).
- **`<AlertDialog>`** one-button info dialog for completeness (no current `alert()` sites, but ship the primitive for the ban).
- **Biome `noRestrictedGlobals`**: ban `confirm`/`alert`/`prompt` (repo uses Biome v2, **not ESLint**). Enable only after `src/` is clean. CI lint gate enforces going forward.
- **Native form-control sweep (#38)**: after the dialog work, grep `src/` for any remaining native `<select>`, `<input type="date|color|range|file">` used as a control, and any other unthemed native UI; convert to the existing themed primitives (`Select`, `DateField`, etc.). #38 closes when the sweep is clean (it's the cross-cutting umbrella the dialog epic is part of). #135 is a duplicate of #138 — closed by this group.
- **Acceptance:** `rg 'window\.(confirm|alert|prompt)' src` returns 0 (excluding the dialog impls); Biome rule green; no unthemed native form controls remain.

### G2 — Editor block empty-states + slash aliases (H, I) — closes #139, #148, #149

Seed: equation→math; embed→iframe,youtube; image→img,picture,photo; code→snippet; subpage→page; divider→hr,line; citation→cite,ref; footnote→note; mermaid→diagram,flowchart; flashcard→anki,card; tasklist→check,todo; bookmark→link.

### G8 — MFA WebAuthn + Sessions (N) — closes #70
- WebAuthn/passkey **registration + login** flows alongside TOTP (`@simplewebauthn` already in the stack from v0.9.0 G1 P8). The passkeys page exists (surfaced v0.9.4) — wire the actual ceremony.
- **Active-sessions list + sign-out-all (#70)**: add a **session store** (migration `0055` — an `auth_sessions` table). On sign-in the jwt callback writes a `sid` claim and an `auth_sessions` row (user, workspace, UA, IP, created/last-seen, revoked_at); the proxy/auth middleware rejects tokens whose `sid` is revoked. Settings → Security gets an active-sessions table (this device marked) + "Sign out everywhere" (revoke all but current / revoke all). This keeps the jwt strategy (no full DB session adapter) while making sessions listable + revocable.

## Architecture notes

- **Editor dialog bus** (G1): a tiny pub/sub module (no React) that slash commands call; `<EditorDialogs>` subscribes and renders the themed dialogs. Keeps TipTap commands hook-free while reusing `InputDialog`. This bus also powers G2's block-data entry (citation lookup, flashcard fields).
- **No new migrations expected** except possibly admin/connectors persistence already covered by existing tables (audit_log, idp/connector config, siem_forwarders). Confirm during planning; if a migration is needed it is `0055+`.
- **Empty-state NodeViews** (G2) follow the existing callout/code-block NodeView pattern (`src/components/editor/blocks/*-view.tsx`).
- **Reuse over rebuild**: connectors/admin/SIEM/MFA all have **backend** from v0.7–v0.9; v0.9.6 is almost entirely the missing **UI layer** + the bug fixes.
