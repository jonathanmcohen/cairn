## Code migrations applied

- Node 24: 3 discord-sig test helpers cast `generateKey` result through `unknown` (webcrypto now infers `CryptoKey`).
- pdfjs 5: `pdf-renderer.tsx` passes the now-required `canvas` to `page.render()`.
- pnpm 11: `pnpm-workspace.yaml` `allowBuilds` allowlist for native build scripts.
- `previewAccepted` (RSC fix): JSON round-trip to strip null-prototype attrs.

## Notable

- **Lighthouse CI**: was red every run since v0.9.0 (`/p/<slug>` 500). Now fixed + reproduced green locally.
- **No DB migrations**: `0034`–`0053` unchanged from v0.9.0. Upgraders redeploy without `db:migrate` changes.
- gitleaks-action@v2 runs on deprecated Node 20 (forced to 24 by 2026-06-02 per GitHub) — non-fatal warning, tracked for a future CI follow-up.

## Release flow (next steps)

1. Open PR `release/v0.9.1 → main`. CI runs full suite (lint + typecheck + test + build + a11y + security).
2. Wait for CI green — **including Lighthouse CI** (the fix this release targets).
3. Merge + tag `v0.9.1` → `release.yml` builds multi-arch image to `ghcr.io/jonathanmcohen/cairn:0.9.1` + GitHub Release.
4. Controller does NOT merge/tag without explicit user go.
