## HUMAN-RUN smoke tests required before/after tag

These cannot run in automated CI; must be exercised by an operator on a staging deploy:

1. **SSO IdP interop matrix** (P2/P3/P4) — Real OIDC roundtrip against Okta + Keycloak; SAML SP-init + IdP-init against Okta + Keycloak; SCIM user provisioning from Okta.
2. **WebAuthn enrollment + step-up** (P8) — Hardware key (e.g. YubiKey) + platform authenticator (TouchID) enrollment; step-up modal triggers workspace-delete; passkey list + revoke.
3. **E2E encrypt + decrypt roundtrip** (P5–P7) — Per-page encrypt → reload → decrypt with passphrase; workspace-wide enable + sweep; member-add rewrap; rekey rotation; verify encrypted pages refuse public-share, search, embedding, federated-search, export.
4. **Chat bridge live install** (P36/P37) — Install Cairn Slack app in a test workspace; verify outbound notification post; reply in channel → see comment on page; `/cairn create <title>` slash; channel↔page sync.
5. **Encrypted backup roundtrip** (P43) — Run `cairn-backup --target s3` with `CAIRN_BACKUP_ENCRYPTION_PASSPHRASE` set; verify `.enc` magic; restore on fresh instance with same passphrase.
6. **Upgrade dry-run + apply + rollback** (P41/P42) — On a non-prod instance with v0.8.0 deployed: `cairn-upgrade preview --to-version=0.9.0`; `cairn-upgrade apply --workspace-id=...`; verify auto-rollback on simulated migration failure.
7. **Federated search peer pairing** (P30) — Two instances with peer config; cross-instance search returns only public/shared pages; HMAC mismatch rejects with generic 400.

- P41 upgrade snapshot/preview/apply tests require `pg_dump`/`psql` on PATH; locally fail on dev boxes without `libpq` brew install. CI runner image ships `postgresql17-client`. Follow-up: add `hasPgDump16` skip-guard to those tests (matching the P43 backup integration test pattern).
- P42 notification UI (`upgrade_available` type) falls back to generic notification card — no first-class render in the v0.8 notification bell/drawer. Functional but not polished. Follow-up: extend the discriminated-union renderer.
- P31 i18n audit has 796 baselined hardcoded-string findings. Future i18n sweep should chip away at the baseline.
- Migration ledger experienced two re-shuffles during execution (P5/P6 added `0035`/`0036` post-P14, then P23 added `0046` post-shift). Plan-index migration ledger updated in-flight; final state at `docs/superpowers/plans/v0.9.0/2026-05-26-cairn-v0.9.0-plans-index.md`.

## Release flow (next steps)

1. **Open PR** `release/v0.9.0 → main`. CI runs full suite on the PR (CI doesn't fire on `release/*` push by design — only on `pull_request` + `push: branches: [main]`).
2. **Wait for CI green** (lint + typecheck + test + build + a11y + security on the PR).
3. **Merge PR** (squash or merge commit per repo norm; this run is too large to squash — use merge commit).
4. **Tag `v0.9.0`** on the merge commit. `release.yml` workflow fires automatically: multi-arch image build (linux/amd64 + linux/arm64) → push to `ghcr.io/jonathanmcohen/cairn:0.9.0` + `cairn-collab:0.9.0` → GitHub Release with auto-generated notes.
5. **Run HUMAN-RUN smokes** (above) against a staging deploy.
6. **Update v1.0.0 spec** to reflect what's now shipped vs deferred.
