# Cairn v0.3.0 Plan 1 — Collab infrastructure

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the real-time collaboration backbone that the rest of v0.3.0 builds on: the `0008` migration adding `page_yjs`, a shared short-lived collab-token mint/verify lib, a Next route (`GET /api/collab/token`) that hands the browser a page+role-scoped token, and a second container `cairn-collab` running [Hocuspocus](https://tiptap.dev/hocuspocus) that persists each page's Yjs document to `page_yjs` and authorizes connections with the shared token. No editor wiring yet — that is Plan 2. This plan ends with a WebSocket connect smoke test, not collaborative editing.

**Architecture:** The Next app stays stateless. The stateful WebSocket layer lives in a dedicated `cairn-collab` service (spec §2.1) sharing the same Postgres and the same `AUTH_SECRET`. The Next app mints a compact HMAC-signed token (claims: `userId`, `pageId`, `role`, `exp` ~5 min) via `/api/collab/token`, gated by `requirePageAccess(pageId, 'viewer')` so the token's role mirrors the caller's real page permission. The collab server's `onAuthenticate` verifies that token with the *same* `verifyCollabToken` (the lib is shared, not duplicated) and checks the token's `pageId` matches the requested document name; the decision is extracted into a pure `authorizeCollab(token, documentName, secret)` so it is unit-testable without a live socket. Hocuspocus's database extension fetches/stores the `state` bytea keyed by `page_id` (= document name). The Yjs→ProseMirror materializer (`yjsStateToProseDoc`) is added now as a tested stub but is only *wired* in Plan 2.

**Tech Stack:** `@hocuspocus/server`, `@hocuspocus/extension-database`, `yjs`, `y-prosemirror` (new deps), `postgres` (already present, used directly by the collab server), Node `crypto` (HMAC, mirroring `src/lib/files/signing.ts`), Drizzle, Zod, Vitest + Testcontainers.

**Spec:** `docs/superpowers/specs/2026-05-21-cairn-v0.3.0-design.md` (§2 decisions 1–3, §4 `page_yjs`, §5 architecture, §6 security).

## Design choices made explicit (read before starting)

1. **Token format — compact HMAC, not a JWT library.** A token is `base64url(JSON payload) + "." + hex(HMAC-SHA256 over that base64url segment)`. Payload = `{ userId, pageId, role, exp }` where `exp` is a unix-seconds expiry (~5 min ahead). This reuses the exact HMAC/`timingSafeEqual` approach from `src/lib/files/signing.ts` — no new dep (`jsonwebtoken`/`jose`), and the same `AUTH_SECRET` signs it. Verify is constant-time, checks the signature first, then `exp`. It is a "JWT-ish" token, deliberately minimal.
2. **`COLLAB_URL` is an optional env, default `ws://localhost:1234`.** 1234 is the Hocuspocus default port. It is browser-facing (the Next route returns it to the client), so in a real deploy it points at the public WS endpoint (e.g. `wss://cairn.example.com/collab`). Optional + defaulted so existing `.env` files keep parsing.
3. **The collab server reuses the ROOT `node_modules` / root `package.json`.** No separate `collab/package.json` and no second `pnpm install`. The new deps (`@hocuspocus/server`, `@hocuspocus/extension-database`, `yjs`, `y-prosemirror`) go in the root `package.json` so (a) the shared libs `src/lib/collab/token.ts` and `src/lib/collab/authorize.ts` are importable by both processes, and (b) there is one lockfile/CI install. `collab/server.ts` is plain TypeScript run with `tsx` (already a devDep); `Dockerfile.collab` installs root deps and runs it. This keeps the lib genuinely shared rather than copied.
4. **Collab server writes/reads `page_yjs` via a thin `postgres`-js client, not Drizzle.** Hocuspocus's `@hocuspocus/extension-database` hands you raw `fetch`/`store` callbacks; we run two parameterized SQL statements (`SELECT state ... WHERE page_id=$1`, `INSERT ... ON CONFLICT (page_id) DO UPDATE`). Drizzle is not needed inside the collab process and pulling the schema graph in would bloat the image. (Materialization to `pages.content` is Plan 2; this plan only persists Yjs binary.)
5. **`page_id` is the Hocuspocus document name.** The client connects to document = the page UUID; `authorizeCollab` enforces `token.pageId === documentName`.
6. **`page_yjs` is added by `db:generate` for the table, but the `bytea` type + the PK-as-FK-cascade may need a hand-edit.** Drizzle models `bytea` via a `customType`; verify the generated SQL has `"state" bytea NOT NULL` and the `page_id` PK + cascade FK. Hand-edit per the CLAUDE.md precedent if it doesn't.

```ts
import { customType, pgTable, timestamp, uuid } from 'drizzle-orm/pg-core';
import { pages } from './pages';

// Postgres bytea <-> Node Buffer. Drizzle doesn't ship a bytea helper.
export const bytea = customType<{ data: Buffer; default: false }>({
  dataType() {
    return 'bytea';
  },
});

export const pageYjs = pgTable('page_yjs', {
  pageId: uuid('page_id')
    .primaryKey()
    .references(() => pages.id, { onDelete: 'cascade' }),
  state: bytea('state').notNull(),
  updatedAt: timestamp('updated_at', { withTimezone: true }).notNull().defaultNow(),
});

export type PageYjs = typeof pageYjs.$inferSelect;
export type NewPageYjs = typeof pageYjs.$inferInsert;
```

```ts
import { createHmac, timingSafeEqual } from 'node:crypto';
import type { MemberRole } from '@/lib/auth/require-role';

export type CollabClaims = {
  userId: string;
  pageId: string;
  role: MemberRole;
  exp: number; // unix seconds
};

export type MintInput = {
  userId: string;
  pageId: string;
  role: MemberRole;
  secret: string;
  /** unix seconds; defaults to now + 5 min */
  expiresAt?: number;
};

const DEFAULT_TTL_SECONDS = 5 * 60;

function sign(payloadB64: string, secret: string): string {
  return createHmac('sha256', secret).update(payloadB64).digest('hex');
}

export function mintCollabToken(input: MintInput): string {
  const exp = input.expiresAt ?? Math.floor(Date.now() / 1000) + DEFAULT_TTL_SECONDS;
  const claims: CollabClaims = {
    userId: input.userId,
    pageId: input.pageId,
    role: input.role,
    exp,
  };
  const payloadB64 = Buffer.from(JSON.stringify(claims)).toString('base64url');
  const sig = sign(payloadB64, input.secret);
  return `${payloadB64}.${sig}`;
}

/** Returns the claims if the token is well-formed, correctly signed, and unexpired; else null. */
export function verifyCollabToken(token: string, secret: string): CollabClaims | null {
  if (typeof token !== 'string') return null;
  const parts = token.split('.');
  if (parts.length !== 2) return null;
  const [payloadB64, sig] = parts;
  if (!payloadB64 || !sig) return null;

  const expected = sign(payloadB64, secret);
  const a = Buffer.from(expected, 'hex');
  const b = Buffer.from(sig, 'hex');
  if (a.length !== b.length || a.length === 0) return null;
  if (!timingSafeEqual(a, b)) return null;

  let claims: CollabClaims;
  try {
    claims = JSON.parse(Buffer.from(payloadB64, 'base64url').toString('utf8'));
  } catch {
    return null;
  }
  if (
    typeof claims?.userId !== 'string' ||
    typeof claims?.pageId !== 'string' ||
    typeof claims?.role !== 'string' ||
    typeof claims?.exp !== 'number'
  ) {
    return null;
  }
  if (claims.exp < Math.floor(Date.now() / 1000)) return null;
  return claims;
}
```

import { env } from '@/lib/env';

export async function GET(req: Request): Promise<Response> {

  const pageId = url.searchParams.get('pageId');
  if (!pageId) {
    return NextResponse.json({ error: 'pageId is required' }, { status: 400 });
  }

      role: ctx.role,
      secret: env().AUTH_SECRET,
    });
    return NextResponse.json({ token, collabUrl: env().COLLAB_URL });
  } catch (err) {
    if (err instanceof HttpError) {
      return NextResponse.json({ error: err.message }, { status: err.status });
    }
    throw err;
  }
}

```ts
import type { MemberRole } from '@/lib/auth/require-role';
import { verifyCollabToken } from './token';

export type CollabAuthResult =
  | { ok: true; userId: string; pageId: string; role: MemberRole }
  | { ok: false };

/**
 * Pure authorization decision for a collab WS connect. Verifies the token's
 * signature + expiry and that its pageId matches the requested document name
 * (the document name IS the page id). No I/O — the page-permission check was
 * already done by /api/collab/token at mint time and is encoded in the role claim.
 */
export function authorizeCollab(
  token: string,
  documentName: string,
  secret: string,
): CollabAuthResult {
  const claims = verifyCollabToken(token, secret);
  if (!claims) return { ok: false };
  if (claims.pageId !== documentName) return { ok: false };
  return { ok: true, userId: claims.userId, pageId: claims.pageId, role: claims.role };
}
```

- [x] **Step 8: Write `collab/server.ts`**

Standalone Node service. Reads `DATABASE_URL`, `AUTH_SECRET`, and `COLLAB_PORT` (default 1234). Persists Yjs binary to `page_yjs` via raw `postgres` SQL; authorizes with the shared `authorizeCollab`. No HTTP surface beyond the WS endpoint (spec §6).

```ts
import { Database } from '@hocuspocus/extension-database';
import { Server } from '@hocuspocus/server';
import postgres from 'postgres';
import { authorizeCollab } from '../src/lib/collab/authorize.js';

const DATABASE_URL = process.env.DATABASE_URL;
const AUTH_SECRET = process.env.AUTH_SECRET;
const PORT = Number(process.env.COLLAB_PORT ?? 1234);

if (!DATABASE_URL) throw new Error('DATABASE_URL is required');
if (!AUTH_SECRET) throw new Error('AUTH_SECRET is required');

const sql = postgres(DATABASE_URL);
const secret = AUTH_SECRET;

const server = new Server({
  port: PORT,
  // documentName is the page id (uuid).
  async onAuthenticate({ token, documentName }) {
    const result = authorizeCollab(token, documentName, secret);
    if (!result.ok) {
      // Throwing rejects the connection.
      throw new Error('Unauthorized');
    }
    // Expose claims to later hooks (used in Plan 2 for materialize attribution).
    return { user: { id: result.userId, role: result.role } };
  },
  extensions: [
    new Database({
      async fetch({ documentName }) {
        const rows = await sql<{ state: Buffer }[]>`
          SELECT state FROM page_yjs WHERE page_id = ${documentName} LIMIT 1
        `;
        return rows[0]?.state ?? null;
      },
      async store({ documentName, state }) {
        const buf = Buffer.from(state);
        await sql`
          INSERT INTO page_yjs (page_id, state, updated_at)
          VALUES (${documentName}, ${buf}, now())
          ON CONFLICT (page_id) DO UPDATE SET state = EXCLUDED.state, updated_at = now()
        `;
      },
    }),
  ],
});

server.listen();
// eslint-disable-next-line no-console
console.log(`cairn-collab listening on ws://0.0.0.0:${PORT}`);
```

> Implementation note for the worker: `@hocuspocus/server`'s exact `Server` construction API and the `Database` extension callback shapes (`fetch` returning `Uint8Array | null`, `store` receiving `state: Uint8Array`) should be confirmed against the installed version's types — adjust signatures to match. The *contract* (auth via `authorizeCollab`, persist `state` bytea keyed by `page_id`) is what must hold. If `documentName` needs to be cast to a uuid in SQL, use `${documentName}::uuid`.

import { yDocToProsemirrorJSON } from 'y-prosemirror';
import * as Y from 'yjs';

/**
 * Convert a Yjs document binary (Hocuspocus-managed `page_yjs.state`) into
 * ProseMirror JSON suitable for writing to `pages.content`.
 *
 * LIMITATION: fidelity depends on the ProseMirror schema passed in. The full

 */
export function yjsStateToProseDoc(

  _schema?: Schema,
  fragment = 'default',
): Record<string, unknown> {
  const ydoc = new Y.Doc();
  Y.applyUpdate(ydoc, state);
  return yDocToProsemirrorJSON(ydoc, fragment) as Record<string, unknown>;
}
