# Cairn v0.9.1 — Dependency Upgrade & Node 24 Migration Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan group-by-group. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move every dependency to its latest version (incl. safe majors), migrate the codebase to support the new APIs, bump the runtime to Node 24 LTS, and capture a light+dark feature screenshot set for the README — shipping as v0.9.1.

**Architecture:** A patch-release dependency sweep, not a feature release. No new migrations, no new env vars, no schema changes. Work proceeds in ordered groups (runtime → package manager → safe bumps → breaking majors → screenshots → release), each gated by `pnpm lint && pnpm typecheck && pnpm test` (+ `pnpm build` where the change is build-observable) before moving on. Mirrors the prior v0.2.x "Upgrade Group A–J" pattern. Screenshots reuse the existing Playwright a11y harness, which already boots the standalone app, seeds the DB, and defines `light`/`dark` projects — a screenshots spec runs in both themes automatically.

**Tech Stack:** pnpm 11, Node 24 LTS, Next 16, React 19, TypeScript 6, Vitest 4, Biome 2, Drizzle 0.45, TipTap 3, Tailwind 4.

**Branch:** `release/v0.9.1` off `main` (after PR #3 lands). Single `release/v0.9.1 → main` PR at the end. Controller does NOT merge or tag without explicit user "go" (release-branch discipline from v0.7/v0.8 retrospective).

A capture spec dropped in `tests/a11y/` runs once per project, so each surface is shot in BOTH themes from one spec with zero extra theme plumbing. A bare `next dev` instance has no seed data and no auth session — worse screenshots, more work.

- [ ] **Step 2: Write the capture spec**

Create `tests/a11y/screenshots.spec.ts`. Pattern (one block per surface):

```ts
import { mkdirSync } from 'node:fs';
import { join } from 'node:path';
import { test } from './fixtures';

const OUT = join(process.cwd(), 'docs', 'screenshots');

test.beforeAll(() => {
  mkdirSync(OUT, { recursive: true });
});

// `test.info().project.name` is 'light' or 'dark' — name files by theme so the
// two projects don't clobber each other.
function shotPath(name: string, theme: string): string {
  return join(OUT, `${name}-${theme}.png`);
}

test('editor hero', async ({ page, signIn }, testInfo) => {
  await signIn();
  await page.goto('/pages/<seeded-rich-page-id>');
  await page.waitForLoadState('networkidle');
  await page.screenshot({ path: shotPath('editor', testInfo.project.name), fullPage: true });
});

// ...one test per surface in the list above, navigating to the seeded route.
```
Notes:
- `signIn` comes from `tests/a11y/fixtures.ts` (already used by the other specs).
- For the ⌘K palette / focus-mode / diff shots, drive the UI (`page.keyboard.press('Meta+k')`, click the focus toggle, open the version-diff route) then screenshot — full-page or element-clipped as fits.
- Use stable seeded IDs from `seed.ts` (export them from the fixture if not already).
