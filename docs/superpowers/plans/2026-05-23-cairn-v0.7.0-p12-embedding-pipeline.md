# Cairn v0.7.0 — Plan P12: Embedding update pipeline (on-write + reindex CLI + opt-in backfill)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire the P11 `EmbeddingProvider` into the live application: (1) on every page write (`src/lib/pages/update.ts` + `src/lib/pages/create.ts`), `setImmediate` an `embedPage(pageId)` call that hashes the page's `content_text`, skips if the hash matches the row already in `page_embeddings`, else computes a new vector and upserts. (2) A new `reindex-embeddings` CLI subcommand walks pages with stale or absent embeddings in batches of 16, computing + upserting. (3) On first boot post-upgrade, if `CAIRN_BACKFILL_EMBEDDINGS=1` is set, `entrypoint.ts` kicks the same reindex in the background once — single-instance ceiling documented (consistent with v0.6 P21 / P22 schedulers).

**Architecture:** A single source-of-truth helper `src/lib/search/embed-page.ts#embedPage(db, pageId)` reads `pages.content_text` + `workspace_id`, computes `sha256(content_text ?? '')`, looks up `page_embeddings` by `page_id`. If the row exists and `content_hash` matches, it's a no-op (returns `{ status: 'skipped' }`). Otherwise it calls `getEmbeddingProvider().embed(text)` and writes via `INSERT ... ON CONFLICT (page_id) DO UPDATE`. The write helpers (`update.ts`, `create.ts`) call `setImmediate(() => embedPage(db, pageId).catch(err => logger.warn({ err, pageId }, 'embedPage failed')))` AFTER the DB transaction commits — exactly the v0.6 P11 email-send pattern. The CLI subcommand `pnpm cli reindex-embeddings [--workspace <id>]` dispatches to `src/lib/search/reindex-cli.ts#reindexEmbeddings(opts)`, which streams `pages` rows (optionally filtered by workspace) where the joined `page_embeddings.content_hash` is `NULL` or stale, processes them in batches of 16 with `Promise.all`, and logs progress. The entrypoint backfill is a one-line `if (env.CAIRN_BACKFILL_EMBEDDINGS) setImmediate(() => reindexEmbeddings({}))` near the existing scheduler bootstrap. **Single-instance ceiling:** two app processes both run the backfill — same v0.6 P21 ceiling; documented in `docs/operations.md` (extended here, not re-introduced).

**Tech Stack:** Drizzle 0.45 (`INSERT ... ON CONFLICT` via `.onConflictDoUpdate`), Postgres 16, Node `crypto.createHash('sha256')`, the P11 `EmbeddingProvider`, the existing `cli.ts`/`cli-internal.ts` dispatch pattern (no top-level `@/` imports in the CLI module — heavy work loads through the entrypoint dynamic-import seam, matching v0.6 P21 §Conventions). Vitest 4 + Testcontainers.

**Spec:** `docs/superpowers/specs/2026-05-23-cairn-v0.7.0-design.md` — §3 G4 "Embedding update pipeline" (the three bullets — on-write fire-and-forget, reindex CLI, opt-in backfill), §5.2 (single-instance ceiling extended to the backfill), §5.4 (`embedding_generation_total{provider, outcome}` mounts here in P9), §5.6 (`CAIRN_BACKFILL_EMBEDDINGS` env). P11 is the prerequisite (provider + table + extension).

```ts
import { createHash } from 'node:crypto';
import * as schema from '@/db/schema';
import { eq } from 'drizzle-orm';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import { getEmbeddingProvider } from '@/lib/search/embed';

type Db = PostgresJsDatabase<typeof schema>;

export type EmbedPageResult =
  | { status: 'embedded'; pageId: string }
  | { status: 'skipped'; pageId: string }
  | { status: 'missing'; pageId: string };

/**
 * Compute and persist a single page's embedding. Idempotent: when the
 * SHA-256 of content_text matches the stored row's content_hash, no
 * provider call is made and the function returns status='skipped'. When
 * the page itself does not exist (deleted between enqueue and execution),
 * returns status='missing' — the on-write hook in update.ts swallows it.
 *
 * The provider is loaded via `getEmbeddingProvider()`; in tests the
 * factory's singleton can be reset via __resetEmbeddingProviderForTests
 * exported from the provider module.
 */
export async function embedPage(db: Db, pageId: string): Promise<EmbedPageResult> {
  const [page] = await db
    .select({
      id: schema.pages.id,
      workspaceId: schema.pages.workspaceId,
      contentText: schema.pages.contentText,
    })
    .from(schema.pages)
    .where(eq(schema.pages.id, pageId));
  if (!page) return { status: 'missing', pageId };

  const text = page.contentText ?? '';
  const hash = createHash('sha256').update(text).digest('hex');

  const [existing] = await db
    .select({ contentHash: schema.pageEmbeddings.contentHash })
    .from(schema.pageEmbeddings)
    .where(eq(schema.pageEmbeddings.pageId, pageId));
  if (existing && existing.contentHash === hash) {
    return { status: 'skipped', pageId };
  }

  const provider = getEmbeddingProvider();
  const vec = await provider.embed(text);
  // Drizzle's vector customType (P11) accepts number[] on input; convert
  // the Float32Array via Array.from to land on the JS-array contract.
  const embedding = Array.from(vec);

  await db
    .insert(schema.pageEmbeddings)
    .values({
      pageId,
      workspaceId: page.workspaceId,
      embedding,
      contentHash: hash,
    })
    .onConflictDoUpdate({
      target: schema.pageEmbeddings.pageId,
      set: {
        embedding,
        contentHash: hash,
        updatedAt: new Date(),
      },
    });

  return { status: 'embedded', pageId };
}
```

```ts
import * as schema from '@/db/schema';
import { and, eq, isNull, or, sql as rawSql } from 'drizzle-orm';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import { embedPage } from '@/lib/search/embed-page';

type Db = PostgresJsDatabase<typeof schema>;

export type ReindexSummary = {
  processed: number;
  embedded: number;
  skipped: number;
  errors: number;
};

export type ReindexOpts = {
  /** Restrict to one workspace; if undefined, walks every workspace. */
  workspaceId?: string;
  /** Page-fetch batch size; defaults to 16 (matches the embed call parallelism). */
  batchSize?: number;
};

/**
 * Walk every page where the embedding is missing OR stale, embed in
 * batches of 16, log progress, return counters. Idempotent — re-running
 * after a clean pass returns {processed: N, embedded: 0, skipped: N}.
 *
 * "Stale" is detected by embedPage itself (the hash compare); reindex
 * just enumerates candidates. The query is a LEFT JOIN — pages with no
 * page_embeddings row OR with a row whose content_hash != sha256(content_text)
 * are both fetched. We push the hash compare to Postgres via `encode(digest(...))`
 * to avoid loading every page's text into Node when nothing has changed.
 */
export async function reindexEmbeddings(db: Db, opts: ReindexOpts = {}): Promise<ReindexSummary> {
  const batchSize = opts.batchSize ?? 16;
  const summary: ReindexSummary = { processed: 0, embedded: 0, skipped: 0, errors: 0 };

  // Build the candidate id query: pages where deleted_at is null AND
  // (no embedding row OR row.hash != sha256(coalesce(content_text, ''))).
  // Postgres's `digest()` is in the `pgcrypto` extension — Cairn enables it
  // in 0001 for gen_random_uuid(); confirm via psql or grep if uncertain.
  const candidates = (await db.execute(rawSql`
    SELECT p.id
    FROM pages p
    LEFT JOIN page_embeddings e ON e.page_id = p.id
    WHERE p.deleted_at IS NULL
      ${opts.workspaceId ? rawSql`AND p.workspace_id = ${opts.workspaceId}::uuid` : rawSql``}
      AND (
        e.page_id IS NULL
        OR e.content_hash <> encode(digest(coalesce(p.content_text, ''), 'sha256'), 'hex')
      )
    ORDER BY p.workspace_id, p.id
  `)) as unknown as { id: string }[];

  for (let i = 0; i < candidates.length; i += batchSize) {
    const batch = candidates.slice(i, i + batchSize);
    const results = await Promise.allSettled(batch.map((c) => embedPage(db, c.id)));
    for (const r of results) {
      summary.processed++;
      if (r.status === 'rejected') {
        summary.errors++;
        // Best-effort: log to stderr; the CLI driver logs the final summary too.
        console.warn('reindex error:', r.reason);
        continue;
      }
      if (r.value.status === 'embedded') summary.embedded++;
      else if (r.value.status === 'skipped') summary.skipped++;
      // 'missing' status counts as processed but neither embedded nor skipped.
    }
    if ((i + batchSize) % 64 === 0 || i + batchSize >= candidates.length) {
      console.log(
        `reindex: ${summary.processed}/${candidates.length} processed ` +
          `(embedded=${summary.embedded}, skipped=${summary.skipped}, errors=${summary.errors})`,
      );
    }
  }

  return summary;
}
```

> The raw-SQL candidate query relies on `pgcrypto.digest()` — Cairn enables `pgcrypto` in migration `0001` for `gen_random_uuid()`. If that's missing in some env (it shouldn't be — `gen_random_uuid()` is universal in this codebase), the fallback is to fetch all `(id, content_text)` and hash in Node. Don't pre-emptively change this; if a test surfaces it, add the fallback.

### Embedding backfill (one-time, opt-in)

Setting `CAIRN_BACKFILL_EMBEDDINGS=1` on the first boot after upgrading to v0.7.0 kicks a one-time
