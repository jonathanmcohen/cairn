# Cairn v0.9.0 — Plan P43: Encrypted workspace backups — AES-256-GCM envelope around v0.5 S3 pipeline

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking. **Every commit lands on `release/v0.9.0` — never on `main`** (retrospective §1).

**Goal:** Wrap the v0.5 P5 backup pipeline (archiver-streamed zip → S3) with an AES-256-GCM envelope so backup archives at rest are unreadable without the operator's passphrase. Argon2id-derived 256-bit key, random 96-bit nonce per archive, GCM authentication tag for tamper detection. The encryption layer is opt-in via `CAIRN_BACKUP_ENCRYPTION_PASSPHRASE`; when unset, the backup CLI behaves exactly as v0.5 P5 (raw zip → S3) and a clear deprecation note in the README warns about pre-1.0 backups. Restore path adds a `--decrypt --passphrase` flag pair. **Distinct from P5 (E2E crypto core) and P7 (workspace-wide E2E)** — those encrypt page content in the DB; this encrypts the backup archive on disk. Both can coexist (a workspace with E2E on still benefits from encrypted backups: the DB is already ciphertext but the workspace-key wrap rows in the same dump are not, so the envelope adds the second layer).

**Architecture:** Library at `src/lib/backups/encryption.ts` exposes a `Transform` stream that wraps any `Readable` (archiver's zip stream, in production) with AES-256-GCM. Envelope format: `[magic][salt][nonce][ciphertext][tag]`:
- magic: 16 bytes `CAIRN-ENC-BAK-v1\n` — version identifier
- salt: 16 bytes random — Argon2id input
- nonce: 12 bytes random — GCM IV
- ciphertext: arbitrary length — input bytes XOR'd against AES-CTR keystream
- tag: 16 bytes — GCM authentication tag (written at the end of the stream)

Argon2id parameters: `m=64MB`, `t=3`, `p=1` (matches `@node-rs/argon2` defaults; balanced enough for once-per-backup invocation). Decryption reverses byte-for-byte; wrong passphrase / tampered ciphertext / wrong magic all surface as distinct error reasons.

The v0.5 P5 backup CLI (`src/server/cli-backup.ts` or wherever it lives) is modified to pipe through `encryptBackup` when the env is set. Restore CLI accepts `--decrypt --passphrase $PASS` and pipes the downloaded blob through `decryptBackup` before handing it to `unzipper`.

**Tech Stack:** Node `node:crypto` (`createCipheriv('aes-256-gcm')` + `createDecipheriv`), `@node-rs/argon2` (already a dep — see `package.json`), `node:stream` Transform, Vitest with streaming test fixtures.

**Spec:** `docs/superpowers/specs/2026-05-26-cairn-v0.9.0-design.md` §3 G8 P43 + §5.2 new env var (`CAIRN_BACKUP_ENCRYPTION_PASSPHRASE`, opt-in; added to `FORBIDDEN_KEYS` v0.7 secret-leak suite + `pino` redact list).

```ts
/**
 * Backup envelope format v1:
 *   [magic: 16][salt: 16][nonce: 12][ciphertext: variable][auth tag: 16]
 *
 * The magic identifies the envelope version and discriminates encrypted
 * backups from raw zips (which start with PK\x03\x04). The salt feeds
 * Argon2id KDF (see encryption.ts). The nonce is the GCM IV. The auth tag is
 * written by the GCM cipher at the end of the stream.
 */

export const ENVELOPE_MAGIC = Buffer.from('CAIRN-ENC-BAK-v1\n', 'utf8');
export const SALT_LEN = 16;
export const NONCE_LEN = 12;
export const TAG_LEN = 16;
export const HEADER_LEN = ENVELOPE_MAGIC.length + SALT_LEN + NONCE_LEN; // 44

if (ENVELOPE_MAGIC.length !== 16) {
  throw new Error('envelope magic must be exactly 16 bytes');
}

export function buildEnvelopeHeader(salt: Buffer, nonce: Buffer): Buffer {
  if (salt.length !== SALT_LEN) throw new Error(`salt must be ${SALT_LEN} bytes`);
  if (nonce.length !== NONCE_LEN) throw new Error(`nonce must be ${NONCE_LEN} bytes`);
  return Buffer.concat([ENVELOPE_MAGIC, salt, nonce]);
}

export function parseEnvelopeHeader(buf: Buffer): { salt: Buffer; nonce: Buffer } {
  if (buf.length < HEADER_LEN) {
    throw new Error(`envelope header length: expected ≥ ${HEADER_LEN}, got ${buf.length}`);
  }
  if (!buf.subarray(0, ENVELOPE_MAGIC.length).equals(ENVELOPE_MAGIC)) {
    throw new Error('envelope magic mismatch (not a CAIRN-ENC-BAK-v1 stream)');
  }
  return {
    salt: Buffer.from(buf.subarray(ENVELOPE_MAGIC.length, ENVELOPE_MAGIC.length + SALT_LEN)),
    nonce: Buffer.from(buf.subarray(ENVELOPE_MAGIC.length + SALT_LEN, ENVELOPE_MAGIC.length + SALT_LEN + NONCE_LEN)),
  };
}
```

async function collect(s: NodeJS.ReadableStream): Promise<Buffer> {

  return Buffer.concat(chunks);

    Readable.from([plaintext]).pipe(enc);

```ts
import { createCipheriv, createDecipheriv, randomBytes, type Cipher, type Decipher } from 'node:crypto';
import { Transform, type TransformCallback } from 'node:stream';
import { hash as argon2hash, Algorithm } from '@node-rs/argon2';
import {
  ENVELOPE_MAGIC,
  HEADER_LEN,
  NONCE_LEN,
  SALT_LEN,
  TAG_LEN,
  buildEnvelopeHeader,
  parseEnvelopeHeader,
} from './encryption-envelope';

const KEY_LEN = 32; // AES-256
const ARGON2_PARAMS = {
  algorithm: Algorithm.Argon2id,
  memoryCost: 64 * 1024, // 64 MB
  timeCost: 3,
  parallelism: 1,
  outputLen: KEY_LEN,
} as const;

async function deriveKey(passphrase: string, salt: Buffer): Promise<Buffer> {
  // @node-rs/argon2 returns the *encoded hash string* from its top-level hash()
  // helper. We need the raw bytes, which the library exposes via the lower
  // level hashRaw call. If hashRaw is unavailable in the pinned version, fall
  // back to PBKDF2-SHA256 with 600_000 iterations (NIST 2024 minimum). The
  // plan-review pass confirms which API is available.
  // eslint-disable-next-line @typescript-eslint/no-explicit-any
  const lib = (await import('@node-rs/argon2')) as any;
  if (typeof lib.hashRaw === 'function') {
    const out = await lib.hashRaw(Buffer.from(passphrase, 'utf8'), {
      ...ARGON2_PARAMS,
      salt,
    });
    return Buffer.from(out as Uint8Array);
  }
  // Fallback — should not happen with the dep currently in package.json (^2.0.2)
  // but documented for plan-review:
  const { pbkdf2Sync } = await import('node:crypto');
  return pbkdf2Sync(passphrase, salt, 600_000, KEY_LEN, 'sha256');
}

/** Transform stream: plaintext bytes → encrypted envelope bytes. */
export function encryptBackup(passphrase: string): Transform {
  const salt = randomBytes(SALT_LEN);
  const nonce = randomBytes(NONCE_LEN);
  let cipher: Cipher | null = null;
  let headerWritten = false;
  let keyReady: Promise<void> | null = null;

  return new Transform({
    async transform(chunk, _enc, cb: TransformCallback) {
      try {
        if (!keyReady) {
          keyReady = (async () => {
            const key = await deriveKey(passphrase, salt);
            cipher = createCipheriv('aes-256-gcm', key, nonce);
          })();
        }
        await keyReady;
        if (!headerWritten) {
          this.push(buildEnvelopeHeader(salt, nonce));
          headerWritten = true;
        }
        const out = cipher!.update(chunk);
        if (out.length > 0) this.push(out);
        cb();
      } catch (err) {
        cb(err as Error);
      }
    },
    async flush(cb: TransformCallback) {
      try {
        if (!keyReady) {
          // No data was written; still emit a valid envelope with empty ciphertext.
          keyReady = (async () => {
            const key = await deriveKey(passphrase, salt);
            cipher = createCipheriv('aes-256-gcm', key, nonce);
          })();
        }
        await keyReady;
        if (!headerWritten) {
          this.push(buildEnvelopeHeader(salt, nonce));
          headerWritten = true;
        }
        const tail = cipher!.final();
        if (tail.length > 0) this.push(tail);
        this.push(cipher!.getAuthTag());
        cb();
      } catch (err) {
        cb(err as Error);
      }
    },
  });
}

/** Transform stream: encrypted envelope bytes → plaintext bytes. */
export function decryptBackup(passphrase: string): Transform {
  let buffered = Buffer.alloc(0);
  let header: { salt: Buffer; nonce: Buffer } | null = null;
  let decipher: Decipher | null = null;
  // We must hold back the trailing TAG_LEN bytes from the cipher so we can
  // call setAuthTag() before final(). Strategy: keep a sliding window —
  // anything older than TAG_LEN is safe to feed into the cipher; the last
  // TAG_LEN bytes are the tag.
  let body = Buffer.alloc(0);

  async function ensureHeader(): Promise<void> {
    if (header) return;
    if (buffered.length < HEADER_LEN) return;
    header = parseEnvelopeHeader(buffered.subarray(0, HEADER_LEN));
    body = Buffer.from(buffered.subarray(HEADER_LEN));
    buffered = Buffer.alloc(0);
    const key = await deriveKey(passphrase, header.salt);
    decipher = createDecipheriv('aes-256-gcm', key, header.nonce);
  }

  return new Transform({
    async transform(chunk, _enc, cb: TransformCallback) {
      try {
        if (!header) {
          buffered = Buffer.concat([buffered, chunk]);
          await ensureHeader();
        } else {
          body = Buffer.concat([body, chunk]);
        }
        if (header && body.length > TAG_LEN) {
          const consume = body.subarray(0, body.length - TAG_LEN);
          body = Buffer.from(body.subarray(body.length - TAG_LEN));
          const out = decipher!.update(consume);
          if (out.length > 0) this.push(out);
        }
        cb();
      } catch (err) {
        cb(err as Error);
      }
    },
    flush(cb: TransformCallback) {
      try {
        if (!header) {
          throw new Error('envelope incomplete: header missing');
        }
        if (body.length !== TAG_LEN) {
          throw new Error(`envelope incomplete: expected ${TAG_LEN}-byte auth tag, got ${body.length}`);
        }
        decipher!.setAuthTag(body);
        const tail = decipher!.final();
        if (tail.length > 0) this.push(tail);
        cb();
      } catch (err) {
        // Surface a clear message: GCM final() throws "Unsupported state or
        // unable to authenticate data" on tamper / wrong passphrase. Wrap so
        // tests can match on /auth|tag|passphrase/.
        const msg = (err as Error).message || '';
        if (/authenticate|state/i.test(msg)) {
          cb(new Error(`decryption failed: auth tag mismatch (wrong passphrase or tampered ciphertext): ${msg}`));
        } else {
          cb(err as Error);
        }
      }
    },
  });
}
```

import { join } from 'node:path';
import { describe, expect, it } from 'vitest';
import { encryptBackup, decryptBackup } from '@/lib/backups/encryption';

describe('encrypted backup roundtrip (file-level)', () => {
  it('produces a file with the CAIRN-ENC-BAK-v1 magic and roundtrips', async () => {
    const dir = mkdtempSync(join(tmpdir(), 'cairn-bk-'));
    const plainPath = join(dir, 'plain.zip');
    const encPath = join(dir, 'plain.zip.enc');
    const restorePath = join(dir, 'restored.zip');

    // Fake "zip" payload — for the test we just need bytes.
    const payload = Buffer.alloc(1024 * 50, 0xab);
    writeFileSync(plainPath, payload);

    await new Promise<void>((resolve, reject) => {
      const { createWriteStream } = require('node:fs');
      const out = createWriteStream(encPath);
      createReadStream(plainPath).pipe(encryptBackup('test-pass-123')).pipe(out);
      out.on('finish', () => resolve());
      out.on('error', reject);
    });

    const head = readFileSync(encPath).subarray(0, 16).toString('utf8');
    expect(head).toBe('CAIRN-ENC-BAK-v1\n');

    await new Promise<void>((resolve, reject) => {
      const { createWriteStream } = require('node:fs');
      const out = createWriteStream(restorePath);
      createReadStream(encPath).pipe(decryptBackup('test-pass-123')).pipe(out);
      out.on('finish', () => resolve());
      out.on('error', reject);
    });

    expect(readFileSync(restorePath).equals(payload)).toBe(true);
  });
});
```

```markdown
## Encrypted backup passphrase rotation

Cairn's backup pipeline (v0.5 P5) optionally wraps each S3 archive in an
AES-256-GCM envelope when `CAIRN_BACKUP_ENCRYPTION_PASSPHRASE` is set
(v0.9.0 G8 P43). The passphrase is the ONLY thing that can decrypt
archives — there is no recovery path if you lose it. Rotation should be
treated as a planned operation.

### Procedure

1. **Snapshot current state.** Confirm the new passphrase is stored in your
   secret manager (1Password, AWS Secrets Manager, etc.) BEFORE rotating.
2. **Decrypt all existing archives with the old passphrase** to a local
   directory. For each `s3://your-bucket/path/<file>.zip.enc`:

   ```sh
   aws s3 cp s3://your-bucket/path/<file>.zip.enc - \
     | node dist/server/cli-backup.js decrypt-stream \
       --passphrase "$OLD_PASSPHRASE" \
     > /tmp/rotation/<file>.zip
   ```

3. **Re-encrypt with the new passphrase** and upload back. The CLI's
   `encrypt-stream` subcommand emits envelope-wrapped output on stdout:

   ```sh
   cat /tmp/rotation/<file>.zip \
     | node dist/server/cli-backup.js encrypt-stream \
       --passphrase "$NEW_PASSPHRASE" \
     | aws s3 cp - s3://your-bucket/path/<file>.zip.enc
   ```

4. **Update the env var** (`CAIRN_BACKUP_ENCRYPTION_PASSPHRASE`) on the
   Cairn host to the new passphrase. Restart the standalone server so
   future backups encrypt with the new key.
5. **Verify** a fresh backup round-trip on the new passphrase before
   destroying the local plaintext copies in `/tmp/rotation/`.

### Failure modes

- **Wrong passphrase on decrypt.** The CLI exits non-zero with
  `decryption failed: auth tag mismatch (wrong passphrase or tampered
  ciphertext)`. No partial plaintext is written.
- **Tampered envelope.** Same failure mode — GCM's auth tag detects any
  flipped bit in the ciphertext.
- **Missing magic.** `decryption failed: envelope magic mismatch (not a
  CAIRN-ENC-BAK-v1 stream)`. You are likely pointing the CLI at a raw zip
  from before the encryption env was set; restore that one without
  `--decrypt`.

### Notes

- The passphrase is in `FORBIDDEN_KEYS` (the v0.7 P5 secret-leak suite) +
  `pino`'s redact list. Cairn will not log or expose it via any API surface.
- This procedure is independent of v0.9.0 P5/P7 E2E encryption — the
  workspace key-wrap rows live inside the DB dump and are protected by
  the SAME envelope, giving you defense-in-depth.
```
