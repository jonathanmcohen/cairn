# Cairn v0.9.0 — Plan P13: Trash retention migration `0040` + admin UI + auto-purge cron + manual empty-trash

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trash is currently a soft-delete graveyard with no purge job — `pages.deleted_at` rows accumulate forever, and the workspace settings page has no knob for retention. P13 adds:

1. Migration `0040_workspace_settings_batch.sql` — three new columns on `workspaces`: `trash_retention_days int default 30`, `default_page_status text default 'published'`, `enable_federated_search boolean default false`. (P13 only wires `trash_retention_days`; P26 wires `default_page_status`; P30 wires `enable_federated_search`. Batched into one migration so we don't burn three migration slots for three trivial settings columns.)
2. Library `src/lib/trash/purge.ts` — `purgeWorkspaceTrash({workspaceId, retentionDays, reason})` deletes trash pages older than the cutoff, cascades file-blob removal via the existing `FileStorage` interface, and writes audit rows.
3. Cron entry — daily at 03:00 workspace local via the v0.7 P14 `cron_schedules` table; CLI command `node dist/server/cli.js trash:purge --workspace-id=<id>` invoked by the scheduler.
4. Admin UI at `/settings/workspace/trash` — retention-days input (env default surfaced as placeholder, override per-workspace) + "Empty trash now" button with confirm modal.
5. Audit actions — `trash.purged_auto` (per cron run, count + bytes) + `trash.purged_manual` (per admin click, count + bytes).

**Architecture:** v0.7 P14 already ships `cron_schedules` + `src/server/scheduler.ts` (singleton-tick) + a CLI shim. P13 registers a per-workspace `trash:purge` row at workspace creation (and on settings-change if retention is enabled), and the scheduler spawns the CLI which calls `purgeWorkspaceTrash`. Cron rows for trash purge use the standard cron string `0 3 * * *` (workspace local — UTC for now; per-workspace TZ shifting is out of scope for P13). `CAIRN_TRASH_RETENTION_DAYS` env var stays the GLOBAL default; the per-workspace column overrides it when non-null.

**Spec:** Section 3 G2 P13 (workspace settings batch). Status row in plans index: `G2 P13 — Trash retention + auto-purge`.

**Tech Stack:** Drizzle migration + Drizzle ORM schema, Postgres jsonb audit_log (existing), Next.js 16 App Router server-action for the admin form, shadcn `<Button>` + `<AlertDialog>` for confirm, Vitest + Testcontainers for purge/cron/audit roundtrip.

```ts
import { sql } from 'drizzle-orm';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import * as schema from '@/db/schema';
import { getFileStorage } from '@/lib/files/storage';

export type PurgeReason = 'auto' | 'manual';

export type PurgeResult = {
  purgedCount: number;
  purgedPageIds: string[];
  bytesReclaimed: number;
};

export async function purgeWorkspaceTrash(
  db: PostgresJsDatabase<typeof schema>,
  input: { workspaceId: string; retentionDays: number; reason: PurgeReason },
): Promise<PurgeResult> {
  const { workspaceId, retentionDays, reason } = input;

  // 1. Find candidate page ids — trashed roots older than the cutoff. Cascade
  //    happens implicitly via the existing pages.deleted_root semantics: a root
  //    in trash carries its descendants with it, but we still need to delete
  //    descendant rows explicitly here since `deleted_root` only flags the
  //    root for the listing UI.
  const rootRows = (await db.execute(sql`
    SELECT id FROM pages
    WHERE workspace_id = ${workspaceId}
      AND deleted_at IS NOT NULL
      AND deleted_root = true
      AND deleted_at < now() - (${retentionDays} || ' days')::interval
  `)) as unknown as Array<{ id: string }>;

  if (rootRows.length === 0) {
    return { purgedCount: 0, purgedPageIds: [], bytesReclaimed: 0 };
  }

  const rootIds = rootRows.map((r) => r.id);

  // 2. Collect every descendant id for blob cleanup.
  const allIds = (await db.execute(sql`
    WITH RECURSIVE descendants AS (
      SELECT id FROM pages WHERE id = ANY(${rootIds}::uuid[])
      UNION
      SELECT p.id FROM pages p JOIN descendants d ON p.parent_id = d.id
    )
    SELECT id FROM descendants
  `)) as unknown as Array<{ id: string }>;
  const allPageIds = allIds.map((r) => r.id);

  // 3. Resolve files attached to those pages so we can delete blobs after the
  //    DB rows are gone (DB row delete is the source of truth — if blob delete
  //    fails we still want the rows gone; orphan blobs are picked up by the
  //    weekly orphan sweeper from v0.6 P9).
  const fileRows = (await db.execute(sql`
    SELECT id, storage_key, byte_size FROM files WHERE page_id = ANY(${allPageIds}::uuid[])
  `)) as unknown as Array<{ id: string; storage_key: string; byte_size: number }>;
  const bytesReclaimed = fileRows.reduce((acc, f) => acc + Number(f.byte_size ?? 0), 0);

  // 4. Delete descendant pages (children first via reverse recursion already
  //    captured in `allPageIds`; Postgres handles row order under a single
  //    DELETE since there are no DB-level FK cascades against pages).
  await db.execute(sql`DELETE FROM pages WHERE id = ANY(${allPageIds}::uuid[])`);

  // 5. Delete blobs out-of-band (best-effort).
  const storage = getFileStorage();
  for (const file of fileRows) {
    try {
      await storage.delete(file.storage_key);
    } catch (err) {
      console.warn('[trash:purge] blob delete failed', { fileId: file.id, err });
    }
  }

  // 6. Audit row — one summary per purge invocation.
  const action = reason === 'auto' ? 'trash.purged_auto' : 'trash.purged_manual';
  await db.execute(sql`
    INSERT INTO audit_log (id, workspace_id, action, payload, created_at)
    VALUES (
      gen_random_uuid(),
      ${workspaceId},
      ${action},
      ${JSON.stringify({ count: rootIds.length, descendantsCount: allPageIds.length, bytesReclaimed, retentionDays })}::jsonb,
      now()
    )
  `);

  return { purgedCount: rootIds.length, purgedPageIds: rootIds, bytesReclaimed };
}
```

- [ ] **Step 4: Implement `src/server/cron-register.ts`**

```ts
import { CronExpressionParser } from 'cron-parser';
import { and, eq, sql } from 'drizzle-orm';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import * as schema from '@/db/schema';

const TRASH_PURGE_CRON = '0 3 * * *';

/**
 * Registers (or updates) the per-workspace trash:purge cron row. Idempotent —
 * one row per (workspaceId, kind='trash_purge').
 */
export async function registerTrashPurgeCron(
  db: PostgresJsDatabase<typeof schema>,
  input: { workspaceId: string },
): Promise<void> {
  const nextRunAt = CronExpressionParser.parse(TRASH_PURGE_CRON, { tz: 'UTC' })
    .next()
    .toDate();
  const command = `trash:purge --workspace-id=${input.workspaceId}`;

  const existing = await db
    .select({ id: schema.cronSchedules.id })
    .from(schema.cronSchedules)
    .where(
      and(
        eq(schema.cronSchedules.workspaceId, input.workspaceId),
        eq(schema.cronSchedules.kind, 'trash_purge'),
      ),
    )
    .limit(1);

  if (existing[0]) {
    await db
      .update(schema.cronSchedules)
      .set({ command, cron: TRASH_PURGE_CRON, enabled: true, nextRunAt })
      .where(eq(schema.cronSchedules.id, existing[0].id));
    return;
  }

  await db.insert(schema.cronSchedules).values({
    workspaceId: input.workspaceId,
    kind: 'trash_purge',
    command,
    cron: TRASH_PURGE_CRON,
    enabled: true,
    nextRunAt,
  });
}
```

**Goal:** Server-rendered settings page at `/settings/workspace/trash` with two controls: (a) retention-days input (number, min 0, max 3650; empty means "use env default"), (b) "Empty trash now" button that fires `purgeWorkspaceTrash` with `reason: 'manual'` after a confirm dialog.
```ts
'use server';

import { revalidatePath } from 'next/cache';
import { eq } from 'drizzle-orm';
import { z } from 'zod';
import { db } from '@/db';
import * as schema from '@/db/schema';
import { requireRole } from '@/lib/auth/require-role';
import { purgeWorkspaceTrash } from '@/lib/trash/purge';

const retentionSchema = z.object({
  retentionDays: z.coerce.number().int().min(0).max(3650),
});

export async function updateRetention(formData: FormData): Promise<void> {
  const { ctx } = await requireRole('admin');
  const { retentionDays } = retentionSchema.parse({
    retentionDays: formData.get('retentionDays'),
  });
  await db
    .update(schema.workspaces)
    .set({ trashRetentionDays: retentionDays })
    .where(eq(schema.workspaces.id, ctx.workspaceId));
  revalidatePath('/settings/workspace/trash');
}

export async function emptyTrashNow(): Promise<void> {
  const { ctx } = await requireRole('admin');
  const ws = await db
    .select({ retention: schema.workspaces.trashRetentionDays })
    .from(schema.workspaces)
    .where(eq(schema.workspaces.id, ctx.workspaceId))
    .limit(1);
  // Manual purge — retention 0 means "everything in trash, regardless of age".
  await purgeWorkspaceTrash(db, {
    workspaceId: ctx.workspaceId,
    retentionDays: 0,
    reason: 'manual',
  });
  void ws; // (unused here, but kept for symmetry; see test expectations)
  revalidatePath('/settings/workspace/trash');
  revalidatePath('/trash');
}
```
