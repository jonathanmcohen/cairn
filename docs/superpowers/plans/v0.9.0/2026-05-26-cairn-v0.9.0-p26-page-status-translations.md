# Page lifecycle status + parallel translations (migration `0044`) — Cairn v0.9.0 G4 P26

> **For agentic workers:** REQUIRED SUB-SKILLS: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a four-state lifecycle to every page (`draft` | `review` | `published` | `archived`) and a bidirectional translation link between pages (`translation_of_page_id` self-FK + `translation_locale`). Migration `0044_page_lifecycle_translations.sql` adds the three columns and backfills every existing row to `status='published'` inside a single transaction with a pre-vs-post row-count check. A `transitionStatus(pageId, to, byUserId)` library function enforces the allowed-transition matrix; the sidebar/search/public-share consumers all gain a status filter; new audit actions `page.status_changed` + `page.translation_linked` record activity.

**Architecture:** Three additive columns on `pages` — no data loss. `status` is enforced by a Postgres CHECK constraint (cheap, no enum churn — matches the spec's `text` choice). `translation_of_page_id` is a self-FK to `pages.id` with `ON DELETE SET NULL`. Symmetric linkage: when a page A is linked to canonical C, the UI surfaces every other page B that also points at C. The canonical is whichever page's `translation_of_page_id IS NULL` *or* the first ancestor in the chain — the helper resolves it.

Existing `pages.published boolean` is a **distinct concept** (public-share toggle reachable at `/p/<slug>`). It stays. Public-share now requires BOTH `published=true` AND `status='published'` — `draft`/`review`/`archived` pages refuse to render at `/p/<slug>` even if `published=true` (e.g. left-over from before status was set).

**Tech Stack:** Drizzle ORM (`ALTER TABLE` via hand-edited migration — Drizzle's generator can express the columns + CHECK; we add the backfill + count-verify by hand), Zod v4 enum, Vitest 4 + Testcontainers v12, Biome v2.

**Spec:** `docs/superpowers/specs/2026-05-26-cairn-v0.9.0-design.md` — §2 G4 #29 + #19 (page lifecycle + translations), §3 row 0044, §5 risk #4 ("Page-status migration on existing rows" — backfill + count-verify in a single transaction). Retrospective rules: §1 (release branch), §2 (plan-review), §3 (verify before commit), §7 (coupling — sidebar + search + public-share all touched in this single plan, not chained).

**Branch:** `release/v0.9.0` (per retrospective; do NOT commit to `main`)

```ts
    title: text('title').notNull().default('Untitled'),
    icon: text('icon'),

    expiresAt: timestamp('expires_at', { withTimezone: true }),
    allowDuplication: boolean('allow_duplication').notNull().default(false),
    content: jsonb('content')
      .$type<unknown>()
      .notNull()
      .default({
        type: 'doc',
        content: [{ type: 'paragraph' }],
      }),
    metadata: jsonb('metadata').$type<Record<string, unknown>>().notNull().default({}),
    contentText: text('content_text').notNull().default(''),
    contentTsv: tsvector('content_tsv'),
    // v0.9.0 G4 P26 — lifecycle status. CHECK constraint added by hand in the
    // migration SQL (Drizzle generator has no CHECK builder). Backfill in the
    // migration sets every existing row to 'published'.

    // requires AnyPgColumn cast (Drizzle callback form can't reference the
    // table being declared).
    translationOfPageId: uuid('translation_of_page_id').references(
      (): AnyPgColumn => pages.id,
      { onDelete: 'set null' },
    ),
    translationLocale: text('translation_locale'),
    createdBy: uuid('created_by')
      .notNull()
      .references(() => users.id, { onDelete: 'restrict' }),
    createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
    updatedAt: timestamp('updated_at', { withTimezone: true }).notNull().defaultNow(),
    deletedAt: timestamp('deleted_at', { withTimezone: true }),
    deletedRoot: boolean('deleted_root').notNull().default(false),
  },
  (t) => ({
    workspaceIdx: index('pages_workspace_idx').on(t.workspaceId),
    parentIdx: index('pages_parent_idx').on(t.parentId),
    tsvIdx: index('pages_content_tsv_idx').using('gin', t.contentTsv),
    statusIdx: index('pages_status_idx').on(t.status),
    translationOfIdx: index('pages_translation_of_idx').on(t.translationOfPageId),
  }),
);

export type Page = typeof pages.$inferSelect;
export type NewPage = typeof pages.$inferInsert;
```

- [ ] **Step 3: Hand-augment the migration SQL**

Open `drizzle/migrations/0044_page_lifecycle_translations.sql` and replace its contents with the augmented version (preserve the Drizzle-emitted statements; wrap them + add CHECK + count-verify):

```sql
BEGIN;

-- Capture pre-migration row count so the COMMIT can refuse if backfill miscounts.
DO $$
DECLARE
  pre_count bigint;
  post_count bigint;
BEGIN
  SELECT count(*) INTO pre_count FROM "pages";

  -- v0.9.0 G4 P26 — additive lifecycle columns. Default = 'published' so every
  -- existing row is implicitly backfilled at ADD COLUMN time (Postgres rewrites
  -- the rows lazily; the column is non-null with a default → no NULL rows).
  ALTER TABLE "pages" ADD COLUMN "status" text DEFAULT 'published' NOT NULL;
  ALTER TABLE "pages" ADD COLUMN "translation_of_page_id" uuid;
  ALTER TABLE "pages" ADD COLUMN "translation_locale" text;

  ALTER TABLE "pages"
    ADD CONSTRAINT "pages_translation_of_page_id_pages_id_fk"
    FOREIGN KEY ("translation_of_page_id")
    REFERENCES "pages"("id") ON DELETE set null;

  ALTER TABLE "pages"
    ADD CONSTRAINT "pages_status_check"
    CHECK ("status" IN ('draft','review','published','archived'));

  CREATE INDEX "pages_status_idx" ON "pages" ("status");
  CREATE INDEX "pages_translation_of_idx" ON "pages" ("translation_of_page_id");

  -- Confirm every existing row landed on 'published' (per spec §5 risk #4).
  SELECT count(*) INTO post_count FROM "pages" WHERE "status" = 'published';
  IF post_count <> pre_count THEN
    RAISE EXCEPTION 'page-status backfill miscount: pre=% post=%', pre_count, post_count;
  END IF;
END $$;

COMMIT;
```

(Statement-breakpoint markers Drizzle's migrator uses are unnecessary inside the single `DO $$` block — the migrator splits on `--> statement-breakpoint` only at top level. Wrapping in `DO $$` runs the whole body atomically inside `BEGIN/COMMIT`.)

## Task 4: `transitionStatus` library — allowed-transition matrix + audit

**Goal:** A single function that gates every status change. Matrix:

```ts
import { eq } from 'drizzle-orm';
import { drizzle } from 'drizzle-orm/postgres-js';

import { afterAll, beforeAll, beforeEach, describe, expect, it } from 'vitest';

let sql: ReturnType<typeof postgres>;

beforeAll(async () => {
  const uri = await startPostgres();
  await runMigrations(uri);
  sql = postgres(uri);
  db = drizzle(sql, { schema });
});

afterAll(async () => {
  await sql.end();
  await stopPostgres();
});

  await sql`TRUNCATE audit_log, pages, workspace_members, workspaces, users RESTART IDENTITY CASCADE`;

async function seedPage(status: schema.PageStatus = 'published') {
  const [u] = await db
    .insert(schema.users)
    .values({ email: `u-${Date.now()}@example.com`, name: 'U', passwordHash: 'x' })
    .returning({ id: schema.users.id });
  const [w] = await db
    .insert(schema.workspaces)
    .values({ name: 'W', slug: `w-${Date.now()}-${Math.random().toString(36).slice(2, 6)}` })

    .insert(schema.pages)
    .values({ workspaceId: w!.id, title: 'P', status, createdBy: u!.id } as never)
    .returning();

}

describe('transitionStatus — allowed-transition matrix', () => {
  const matrix: Array<[schema.PageStatus, schema.PageStatus, boolean]> = [
    ['draft', 'review', true],
    ['draft', 'archived', true],
    ['draft', 'published', false],
    ['review', 'draft', true],
    ['review', 'published', true],
    ['review', 'archived', false],
    ['published', 'review', true],
    ['published', 'archived', true],
    ['published', 'draft', false],
    ['archived', 'draft', true],
    ['archived', 'review', false],
    ['archived', 'published', false],
  ];

  for (const [from, to, allowed] of matrix) {
    it(`${from} → ${to}: ${allowed ? 'allowed' : 'refused'}`, async () => {
      const { userId, pageId } = await seedPage(from);
      if (allowed) {
        const out = await transitionStatus(db, { pageId, to, byUserId: userId });

      .select()
      .from(schema.auditLog)
      .where(eq(schema.auditLog.targetId, pageId));

    expect(rec!.metadata).toMatchObject({ from: 'draft', to: 'review' });
    expect(rec!.workspaceId).toBe(workspaceId);
  });

  it('no-op transition (same status) is treated as illegal', async () => {
    const { userId, pageId } = await seedPage('published');
```

```ts
import { eq } from 'drizzle-orm';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import * as schema from '@/db/schema';
import { recordAudit } from '@/lib/audit/record';

type Db = PostgresJsDatabase<typeof schema>;

export class IllegalStatusTransition extends Error {
  constructor(
    public readonly from: schema.PageStatus,
    public readonly to: schema.PageStatus,
  ) {
    super(`illegal status transition ${from} → ${to}`);
    this.name = 'IllegalStatusTransition';
  }
}

/**
 * Allowed-transition matrix (spec §2 G4 #29). All other transitions throw
 * IllegalStatusTransition. Note `published` cannot go directly back to `draft`
 * — it must pass through `review` (audit-trail discipline).
 */
const ALLOWED: Record<schema.PageStatus, ReadonlySet<schema.PageStatus>> = {
  draft: new Set(['review', 'archived']),
  review: new Set(['draft', 'published']),
  published: new Set(['review', 'archived']),
  archived: new Set(['draft']),
};

export function canTransition(from: schema.PageStatus, to: schema.PageStatus): boolean {
  return ALLOWED[from]?.has(to) ?? false;
}

/**
 * Transition the page's status. Audit-and-mutate in a single transaction so
 * the audit can never drift from the mutation (spec §2.27).
 *
 * Throws:
 *   - IllegalStatusTransition if the (from→to) pair is not in the matrix
 *     (including same-status no-ops).
 *   - Error('page not found') if pageId doesn't match a row.
 */
export async function transitionStatus(
  db: Db,
  input: { pageId: string; to: schema.PageStatus; byUserId: string },
): Promise<{ status: schema.PageStatus }> {
  return db.transaction(async (tx) => {
    const [row] = await tx
      .select({
        id: schema.pages.id,
        status: schema.pages.status,
        workspaceId: schema.pages.workspaceId,
      })
      .from(schema.pages)
      .where(eq(schema.pages.id, input.pageId));
    if (!row) throw new Error('page not found');

    const from = row.status as schema.PageStatus;
    if (!canTransition(from, input.to)) {
      throw new IllegalStatusTransition(from, input.to);
    }

    await tx
      .update(schema.pages)
      .set({ status: input.to, updatedAt: new Date() })
      .where(eq(schema.pages.id, input.pageId));

    await recordAudit(tx, {
      workspaceId: row.workspaceId,
      actorUserId: input.byUserId,
      action: 'page.status_changed',
      targetType: 'page',
      targetId: input.pageId,
      metadata: { from, to: input.to },
    });

    return { status: input.to };
  });
}
```

```ts
import { and, eq, isNotNull, ne, or } from 'drizzle-orm';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import * as schema from '@/db/schema';
import { recordAudit } from '@/lib/audit/record';

type Db = PostgresJsDatabase<typeof schema>;

/**
 * Link `pageId` as a translation of `canonicalPageId` with the BCP-47 locale
 * code. Refuses:
 *   - self-link (cycle of length 1)
 *   - cross-workspace canonical
 *   - missing page or missing canonical
 *
 * Always writes `page.translation_linked` audit with {locale, canonicalPageId}.
 * The locale string is not validated against a BCP-47 grammar — UI uses a
 * select-from-known-locales control, callers in tests pass plain strings.
 */
export async function linkTranslation(
  db: Db,
  input: { pageId: string; canonicalPageId: string; locale: string; byUserId: string },
): Promise<void> {
  if (input.pageId === input.canonicalPageId) {
    throw new Error('cannot link a page as a translation of itself');
  }
  return db.transaction(async (tx) => {
    const [page] = await tx
      .select({ id: schema.pages.id, workspaceId: schema.pages.workspaceId })
      .from(schema.pages)
      .where(eq(schema.pages.id, input.pageId));
    const [canonical] = await tx
      .select({ id: schema.pages.id, workspaceId: schema.pages.workspaceId })
      .from(schema.pages)
      .where(eq(schema.pages.id, input.canonicalPageId));
    if (!page) throw new Error('page not found');
    if (!canonical) throw new Error('canonical page not found');
    if (page.workspaceId !== canonical.workspaceId) {
      throw new Error('translation must be in the same workspace as the canonical');
    }

    await tx
      .update(schema.pages)
      .set({
        translationOfPageId: input.canonicalPageId,
        translationLocale: input.locale,
        updatedAt: new Date(),
      })
      .where(eq(schema.pages.id, input.pageId));

    await recordAudit(tx, {
      workspaceId: page.workspaceId,
      actorUserId: input.byUserId,
      action: 'page.translation_linked',
      targetType: 'page',
      targetId: input.pageId,
      metadata: { locale: input.locale, canonicalPageId: input.canonicalPageId },
    });
  });
}

/**
 * Resolve the canonical for a page and return every OTHER page also linked to
 * that canonical (symmetric "Translations" picker). If `canonicalPageId`
 * itself points at a canonical, we walk one step up — translation chains are
 * at most one level deep in practice (the UI links to the canonical, not to a
 * sibling), but a one-step resolution makes the helper safe regardless.
 */
export async function listLinkedTranslations(
  db: Db,
  args: { canonicalPageId: string },
): Promise<schema.Page[]> {
  // Step 1: walk up one step if the given id is itself a translation.
  const [self] = await db
    .select()
    .from(schema.pages)
    .where(eq(schema.pages.id, args.canonicalPageId));
  if (!self) return [];
  const trueCanonicalId = self.translationOfPageId ?? self.id;

  // Step 2: return every row pointing at trueCanonicalId, plus trueCanonical
  // itself if the caller was a sibling (not the canonical). Exclude the
  // caller from the result.
  const linked = await db
    .select()
    .from(schema.pages)
    .where(
      and(
        or(
          eq(schema.pages.translationOfPageId, trueCanonicalId),
          eq(schema.pages.id, trueCanonicalId),
        ),
        ne(schema.pages.id, args.canonicalPageId),
        isNotNull(schema.pages.id),
      ),
    );
  return linked;
}
```
