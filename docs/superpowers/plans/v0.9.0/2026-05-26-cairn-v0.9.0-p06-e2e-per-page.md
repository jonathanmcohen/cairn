# Cairn v0.9.0 — Plan P6: E2E per-page mode — selective encryption

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. **Plan-review subagent runs before implementer dispatch (v0.7-v0.8 retrospective §2).** Spec ref: `docs/superpowers/specs/2026-05-26-cairn-v0.9.0-design.md` §2 G1 #4+#5, §4 "Runtime impact — E2E". Branch: `release/v0.9.0` — every commit lands on the branch, NOT `main`.

**Goal:** Ship the per-page encryption UX + server flow + consumer audit. A workspace admin can flip `CAIRN_ENABLE_E2E_ENCRYPTION` server-side; once enabled, page authors get an "Encrypt page" action in the page menu. The client (a) generates a 32-byte DEK, (b) encrypts the serialized TipTap JSON via AES-256-GCM under the DEK, (c) wraps the DEK under every page-member's public key (looked up from `user_keypairs.public_key`), (d) POSTs ciphertext + wrapped DEK rows to `/api/pages/[pageId]/encrypt`. The server writes ciphertext to a new `pages.content_encrypted bytea` column, sets `pages.encrypted = true`, blanks `content_text` + `content_tsv` to prevent leaks, and inserts the wrapped-DEK rows in `page_encryption_keys`. Decryption is client-side via `unwrapDek` + AES-GCM.

**Consumer audit (load-bearing — retrospective §2 risk #1):** every existing code path that reads `pages.content` / `pages.content_text` MUST check `pages.encrypted = false` first. This plan touches:
- FTS query (`src/lib/pages/search.ts`) — skip encrypted rows.
- Embedding pipeline (`src/lib/search/embed-page.ts`) — early-return for encrypted pages.
- Public share (`src/app/p/[slug]/page.tsx` or `src/app/api/public/...`) — refuse with HTTP 403 "Encrypted pages cannot be publicly shared".
- Webhook emit on page events — set `body: null` and add `page.encrypted: true` flag.

**Architecture:**
- New `pages.content_encrypted bytea null` column (added in **this plan's migration**, not P5 — P5's `0035` migration added only the three E2E tables + `pages.encrypted boolean`).
- API route `/api/pages/[pageId]/encrypt` (POST) — admin/editor with page write access; idempotent (calling it again rotates the DEK).
- API route `/api/pages/[pageId]/encryption-bundle` (GET) — returns `{ contentEncrypted, wrappedDekForMe }` for the calling user (404s if they're not a member).
- Client component `EncryptPageAction` calls the v0.9 crypto helpers from P5's `src/lib/e2e/crypto.ts`.

**Tech Stack:** Existing Next 16 + Drizzle + crypto core from P5. New Drizzle migration (likely `0036` numerically since P8 hasn't landed yet — accept Drizzle's emission). Vitest for server-side guards + a jsdom client roundtrip test.

**Spec ref:** `docs/superpowers/specs/2026-05-26-cairn-v0.9.0-design.md` §2 G1 #4+#5, §4 "Runtime impact — E2E" bullet list.

- [ ] **Step 3: Implement `src/lib/e2e/page-cipher.ts`**

```ts
import { createCipheriv, createDecipheriv, randomBytes } from 'node:crypto';

const IV = 12;
const TAG = 16;

export function encryptPageContent(content: unknown, dek: Buffer): Buffer {
  if (dek.byteLength !== 32) throw new Error('DEK must be 32 bytes');
  const iv = randomBytes(IV);
  const cipher = createCipheriv('aes-256-gcm', dek, iv);
  const pt = Buffer.from(JSON.stringify(content), 'utf8');
  const ct = Buffer.concat([cipher.update(pt), cipher.final()]);
  const tag = cipher.getAuthTag();
  return Buffer.concat([iv, ct, tag]);
}

export function decryptPageContent(blob: Buffer, dek: Buffer): unknown {
  if (dek.byteLength !== 32) throw new Error('DEK must be 32 bytes');
  if (blob.byteLength < IV + TAG) throw new Error('blob too short');
  const iv = blob.subarray(0, IV);
  const tag = blob.subarray(blob.length - TAG);
  const ct = blob.subarray(IV, blob.length - TAG);
  const decipher = createDecipheriv('aes-256-gcm', dek, iv);
  decipher.setAuthTag(tag);
  const pt = Buffer.concat([decipher.update(ct), decipher.final()]);
  return JSON.parse(pt.toString('utf8'));
}
```

## Task 3: `POST /api/pages/[pageId]/encrypt` route

**Goal:** Workspace member (with page write access) submits `{ contentEncrypted: base64, wrappedDeks: Array<{ memberUserId, wrappedDek: base64 }> }`. Server validates: caller has write access; every `memberUserId` is a current workspace member with a registered `user_keypairs` row; the `wrappedDeks` set covers every current page-member exactly once. On success: in one transaction, update `pages` (set `encrypted=true`, write `content_encrypted`, blank `content_text`, set `content` to a sentinel `{"type":"doc","content":[]}` so existing readers don't choke), upsert the rows in `page_encryption_keys`, record `e2e.page.encrypted` audit. Idempotent: a second call replaces existing wrapped-DEK rows + ciphertext (DEK rotation).

```ts
import { and, eq, inArray } from 'drizzle-orm';
import { NextResponse } from 'next/server';
import { z } from 'zod';
import { db } from '@/db/client';
import { pageEncryptionKeys, pages, userKeypairs, workspaceMembers } from '@/db/schema';
import { recordAudit } from '@/lib/audit/record';
import { requirePageAccess } from '@/lib/pages/access';

export const runtime = 'nodejs';

const Body = z.object({
  contentEncrypted: z.string().min(1),
  wrappedDeks: z
    .array(
      z.object({
        memberUserId: z.string().uuid(),
        wrappedDek: z.string().min(1),
      }),
    )
    .min(1),
});

export async function POST(
  req: Request,
  { params }: { params: Promise<{ pageId: string }> },
): Promise<Response> {
  const { pageId } = await params;
  const access = await requirePageAccess(pageId, 'editor');
  if (access instanceof NextResponse) return access; // 403 / 404
  const { page, ctx } = access;

  const parsed = Body.safeParse(await req.json().catch(() => null));
  if (!parsed.success) return NextResponse.json({ error: 'bad request' }, { status: 400 });
  const { contentEncrypted, wrappedDeks } = parsed.data;

  // Page-members = workspace-members (v0.9 baseline; per-page ACLs from v0.7
  // P5 may further restrict, but we ALWAYS wrap to every workspace member to
  // avoid a removed-but-cached-ACL leak. The wrapped-DEK row count must
  // exactly equal current workspace member count.)
  const members = await db
    .select({ userId: workspaceMembers.userId })
    .from(workspaceMembers)
    .where(eq(workspaceMembers.workspaceId, page.workspaceId));
  const memberIds = new Set(members.map((m) => m.userId));
  const payloadIds = new Set(wrappedDeks.map((w) => w.memberUserId));
  if (memberIds.size !== payloadIds.size || ![...memberIds].every((id) => payloadIds.has(id))) {
    return NextResponse.json({ error: 'wrapped DEKs must cover every workspace member exactly once' }, { status: 400 });
  }

  // Every covered member must have a registered keypair.
  const keypairs = await db
    .select({ userId: userKeypairs.userId })
    .from(userKeypairs)
    .where(inArray(userKeypairs.userId, [...memberIds]));
  if (keypairs.length !== memberIds.size) {
    return NextResponse.json({ error: 'one or more members have no registered keypair' }, { status: 409 });
  }

  const ctBuf = Buffer.from(contentEncrypted, 'base64');

  await db.transaction(async (tx) => {
    await tx
      .update(pages)
      .set({
        encrypted: true,
        contentEncrypted: ctBuf,
        contentText: '',
        content: { type: 'doc', content: [] },
      })
      .where(eq(pages.id, pageId));
    // Idempotent: wipe + reinsert for this page.
    await tx.delete(pageEncryptionKeys).where(eq(pageEncryptionKeys.pageId, pageId));
    await tx.insert(pageEncryptionKeys).values(
      wrappedDeks.map((w) => ({
        pageId,
        memberUserId: w.memberUserId,
        wrappedDek: Buffer.from(w.wrappedDek, 'base64'),
      })),
    );
    await recordAudit(tx, {
      workspaceId: page.workspaceId,
      actorUserId: ctx.userId,
      action: 'e2e.page.encrypted',
      targetType: 'page',
      targetId: pageId,
      metadata: { memberCount: wrappedDeks.length },
    });
  });

  return NextResponse.json({ ok: true });
}
```

import { and, eq } from 'drizzle-orm';
import { NextResponse } from 'next/server';
import { db } from '@/db/client';
import { pageEncryptionKeys, pages } from '@/db/schema';
import { requirePageAccess } from '@/lib/pages/access';

export const runtime = 'nodejs';

export async function GET(
  _req: Request,
  { params }: { params: Promise<{ pageId: string }> },
): Promise<Response> {
  const { pageId } = await params;
  const access = await requirePageAccess(pageId, 'viewer');
  if (access instanceof NextResponse) return access;
  const { page, ctx } = access;
  if (!page.encrypted || !page.contentEncrypted) {
    return NextResponse.json({ contentEncrypted: null, wrappedDekForMe: null });
  }
  const [row] = await db
    .select()
    .from(pageEncryptionKeys)
    .where(and(eq(pageEncryptionKeys.pageId, pageId), eq(pageEncryptionKeys.memberUserId, ctx.userId)));
  if (!row) return NextResponse.json({ error: 'no wrapped DEK for caller' }, { status: 403 });
  return NextResponse.json({
    contentEncrypted: Buffer.from(page.contentEncrypted).toString('base64'),
    wrappedDekForMe: Buffer.from(row.wrappedDek).toString('base64'),
  });
}

```tsx
'use client';

import { useState } from 'react';
import { Button } from '@/components/ui/button';

/**
 * "Encrypt page" menu action. Performs every cryptographic step CLIENT-SIDE:
 *   1. Fetch the workspace member roster + their public keys from
 *      GET /api/workspaces/[id]/keypair-roster (added in this same task —
 *      see route below).
 *   2. Unlock the caller's private key from `localStorage` (cached at login
 *      time after the user enters their passphrase — out of scope for this
 *      plan to wire end-to-end; for v0.9 the action prompts for the
 *      passphrase if the unlocked key isn't in memory).
 *   3. Generate a DEK; encrypt the current TipTap doc JSON via
 *      `encryptPageContent`; wrap the DEK under every member's public key
 *      via `wrapDek`.
 *   4. POST to /api/pages/[id]/encrypt with the bundle.
 *
 * The actual crypto helpers from `src/lib/e2e/crypto.ts` +
 * `src/lib/e2e/page-cipher.ts` are isomorphic — they use `node:crypto` which
 * Next 16 polyfills in the browser bundle. (Confirmed via build: see Step 6.)
 */
export function EncryptPageAction({
  pageId,
  workspaceId,
  currentDoc,
}: {
  pageId: string;
  workspaceId: string;
  currentDoc: unknown;
}) {
  const [busy, setBusy] = useState(false);
  const [err, setErr] = useState<string | null>(null);

  async function run() {
    setBusy(true);
    setErr(null);
    try {
      const { encryptPageContent } = await import('@/lib/e2e/page-cipher');
      const { generateDek, wrapDek, unlockUserKeypair } = await import('@/lib/e2e/crypto');

      // 1. Roster.
      const rosterRes = await fetch(`/api/workspaces/${workspaceId}/keypair-roster`);
      if (!rosterRes.ok) throw new Error('roster fetch failed');
      const roster = (await rosterRes.json()) as Array<{ memberUserId: string; publicKey: string }>;

      // 2. Caller passphrase prompt (v0.9 minimal — passphrase manager is a
      // post-1.0 polish item).
      const sealedJson = window.localStorage.getItem('cairn.e2e.sealedKeypair');
      if (!sealedJson) throw new Error('no sealed keypair on this device — register first');
      const sealed = JSON.parse(sealedJson) as {
        publicKey: string;
        encryptedPrivateKey: string;
        kdfSalt: string;
        kdfIters: number;
      };
      const passphrase = window.prompt('Enter your E2E passphrase to encrypt this page');
      if (!passphrase) throw new Error('cancelled');
      const me = await unlockUserKeypair(
        {
          publicKey: Buffer.from(sealed.publicKey, 'base64'),
          encryptedPrivateKey: Buffer.from(sealed.encryptedPrivateKey, 'base64'),
          kdfSalt: Buffer.from(sealed.kdfSalt, 'base64'),
          kdfIters: sealed.kdfIters,
        },
        passphrase,
      );

      // 3. Encrypt + wrap.
      const dek = generateDek();
      const ct = encryptPageContent(currentDoc, dek);
      const wrappedDeks = roster.map((r) => ({
        memberUserId: r.memberUserId,
        wrappedDek: Buffer.from(wrapDek(dek, Buffer.from(r.publicKey, 'base64'))).toString('base64'),
      }));

      // 4. POST.
      const res = await fetch(`/api/pages/${pageId}/encrypt`, {
        method: 'POST',
        headers: { 'content-type': 'application/json' },
        body: JSON.stringify({ contentEncrypted: ct.toString('base64'), wrappedDeks }),
      });
      if (!res.ok) throw new Error(`encrypt failed: ${res.status}`);
      window.location.reload();
    } catch (e) {
      setErr((e as Error).message);
    } finally {
      setBusy(false);
    }
  }

  return (
    <div>
      <Button onClick={run} disabled={busy}>
        {busy ? 'Encrypting…' : 'Encrypt page'}
      </Button>
      {err ? <p className="text-sm text-destructive">{err}</p> : null}
    </div>
  );
}
```

import { eq } from 'drizzle-orm';
import { NextResponse } from 'next/server';
import { db } from '@/db/client';
import { userKeypairs, workspaceMembers } from '@/db/schema';
import { requireRole } from '@/lib/auth/require-role';

export const runtime = 'nodejs';

export async function GET(
  _req: Request,
  { params }: { params: Promise<{ workspaceId: string }> },
): Promise<Response> {
  const { workspaceId } = await params;
  const gate = await requireRole(workspaceId, 'viewer');
  if (gate instanceof NextResponse) return gate;
  const rows = await db
    .select({ memberUserId: workspaceMembers.userId, publicKey: userKeypairs.publicKey })
    .from(workspaceMembers)
    .innerJoin(userKeypairs, eq(userKeypairs.userId, workspaceMembers.userId))
    .where(eq(workspaceMembers.workspaceId, workspaceId));
  return NextResponse.json(
    rows.map((r) => ({
      memberUserId: r.memberUserId,
      publicKey: Buffer.from(r.publicKey).toString('base64'),
    })),
  );
}
