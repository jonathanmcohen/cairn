# Cairn v0.9.0 — Plan P36: Chat bridge — Slack + Discord, outbound notifications + inbound comment replies

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land the outbound + inbound paths of the chat bridge for both Slack and Discord. Slash commands and channel↔page sync mode are deferred to the sibling P37.

- **Outbound.** Page events (`page.created`, `page.updated`, `comment.created`) post a message to a configured workspace channel. Reuses the existing v0.5 P2 webhook infrastructure (`src/lib/webhooks/dispatch.ts`, `webhook_deliveries` table, HMAC sign, retries) — Slack incoming-webhook URLs and Discord webhook URLs are stored as workspace config and registered as standard webhooks with a new `kind` discriminator (`slack` / `discord`). The dispatch path translates the canonical Cairn payload into platform-specific message shapes before POSTing.
- **Inbound.** A user replies in-thread on a Slack message that Cairn posted (or replies to a Cairn message in Discord). Cairn receives the platform's events webhook at `/api/chat/slack/events` or `/api/chat/discord/events`, validates the signature (`x-slack-signature` HMAC v0; Discord ed25519 via `x-signature-ed25519`), resolves the thread's `thread_ts` / `message_id` back to the originating Cairn page + parent comment via a small posted-message log, sanitizes the reply body via the v0.5.1 T3 XSS pipeline, and creates a Cairn comment.
- **Admin UI.** A new admin route `/admin/chat-bridge` shows install status per platform with set/clear buttons for the platform webhook URL + signing secret / bot token. Install ergonomics (real OAuth) are deferred to P37 — P36 ships a manual paste-the-incoming-webhook-URL flow.

**Architecture:**

- **Reuse webhooks infra.** v0.5 P2 already gives us `webhooks` + `webhook_deliveries` with HMAC sign + retry + admin UI. We add a `webhooks.kind text default 'generic'` column (values: `generic` | `slack` | `discord`) and a `webhooks.platform_metadata jsonb` column (Slack/Discord-specific fields like `bot_token_encrypted`, `signing_secret_encrypted`, `app_id`, `team_id`). Outbound dispatch reads `kind` and chooses a translator:
  - `slack`: POST `chat.postMessage`-style payload `{text: ..., blocks: [...]}` to the configured webhook URL.
  - `discord`: POST `{content: ..., embeds: [...]}` to the configured webhook URL.
  - `generic`: existing canonical-body path (unchanged).
- **Posted-message log.** New table `chat_posted_messages` maps `(workspace_id, platform, channel_id, thread_ts or message_id) → (page_id, parent_comment_id?)`. Each outbound success writes one row so inbound replies can resolve back. (This is the load-bearing data structure — without it, inbound replies have nothing to bind a comment to.)
- **Inbound auth.** Slack: HMAC-SHA256 over `v0:${timestamp}:${rawBody}`, compared to `x-slack-signature` (`v0=<sig>`) with the workspace's `signing_secret`. Discord: ed25519 verify via `x-signature-ed25519` + `x-signature-timestamp` against the registered application's public key. Both reject if the timestamp is older than 5 minutes (anti-replay).
- **No migration shared with P37.** P36 lands its OWN migration `chat_bridge_p36.sql`: the two new columns on `webhooks` + the `chat_posted_messages` table. P37 lands `chat_bridge_installs` + `chat_channel_links` (mapped to ledger row 0047) for slash commands + sync mode. Splitting the migration keeps each plan self-contained and avoids the v0.8 P26 fix-on-fix pattern.

**Spec:** `docs/superpowers/specs/2026-05-26-cairn-v0.9.0-design.md` §2 G7 #14 plan A (outbound + inbound). §4 new env vars: `CAIRN_SLACK_CLIENT_ID/SECRET/SIGNING_SECRET`, `CAIRN_DISCORD_CLIENT_ID/SECRET/BOT_TOKEN`. Risks §6 (inbound webhook abuse — sig validation + per-workspace rate-limit + XSS sanitizer reuse).

**Branch:** `release/v0.9.0` (per retrospective §1; do NOT commit to `main`).

**Tech Stack:** `@slack/bolt` (used only for its `verifyRequestSignature` helper in P36 — full receiver lifecycle is deferred to P37), `discord.js` (used only for `verifyKey` from `discord-interactions` style API — `discord.js` ships its own crypto helpers), `crypto.subtle` ed25519 (Node 22 native — fallback path if discord.js's helper unavailable), existing Drizzle migration toolchain, Vitest 4 + Testcontainers v12 Postgres, Next.js 16 Route Handlers.

```ts
export const chatPostedMessages = pgTable(
  'chat_posted_messages',
  {
    id: uuid('id').primaryKey().defaultRandom(),
    workspaceId: uuid('workspace_id')
      .notNull()
      .references(() => workspaces.id, { onDelete: 'cascade' }),
    platform: text('platform').notNull(), // 'slack' | 'discord'

    messageId: text('message_id').notNull(),
    threadTs: text('thread_ts'),

      .references(() => pages.id, { onDelete: 'cascade' }),
    parentCommentId: uuid('parent_comment_id').references(() => comments.id, {
      onDelete: 'set null',
    }),
    metadata: jsonb('metadata').$type<Record<string, unknown>>(),
    createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),

  (t) => [

    uniqueIndex('chat_posted_messages_thread_unique').on(t.platform, t.channelId, t.threadTs),
    index('chat_posted_messages_message_idx').on(t.platform, t.channelId, t.messageId),
    index('chat_posted_messages_workspace_idx').on(t.workspaceId),
  ],
);

export type ChatPostedMessage = typeof chatPostedMessages.$inferSelect;
export type NewChatPostedMessage = typeof chatPostedMessages.$inferInsert;
```

- [x] **Step 3: Implement `src/lib/chat/translate-slack.ts`**

```ts
export type CairnChatEvent =
  | {
      event: 'page.created' | 'page.updated';
      data: {
        page: { id: string; title: string; publicUrl?: string | null };
        actor?: { name?: string | null } | null;
      };
    }
  | {
      event: 'comment.created';
      data: {
        page: { id: string; title: string; publicUrl?: string | null };
        comment: { id: string; body: string; authorName?: string | null };
      };
    };

export type SlackMessage = {
  text: string;
  blocks?: Array<Record<string, unknown>>;
};

function truncate(s: string, n: number): string {
  return s.length <= n ? s : `${s.slice(0, n - 1)}…`;
}

export function translateToSlack(input: CairnChatEvent): SlackMessage {
  const link = (txt: string, url: string | null | undefined): string =>
    url ? `<${url}|${txt}>` : txt;

  switch (input.event) {
    case 'page.created':
    case 'page.updated': {
      const verb = input.event === 'page.created' ? 'created' : 'updated';
      const actor = input.data.actor?.name ?? 'Someone';
      const pageLink = link(input.data.page.title, input.data.page.publicUrl);
      const text = `${actor} ${verb} ${pageLink}`;
      return {
        text,
        blocks: [
          {
            type: 'section',
            text: { type: 'mrkdwn', text },
          },
        ],
      };
    }
    case 'comment.created': {
      const actor = input.data.comment.authorName ?? 'Someone';
      const pageLink = link(input.data.page.title, input.data.page.publicUrl);
      const body = truncate(input.data.comment.body, 400);
      const text = `${actor} commented on ${pageLink}`;
      return {
        text,
        blocks: [
          { type: 'section', text: { type: 'mrkdwn', text } },
          { type: 'section', text: { type: 'mrkdwn', text: `> ${body.replace(/\n/g, '\n> ')}` } },
        ],
      };
    }
  }
}
```

```ts
import { translateToSlack } from '@/lib/chat/translate-slack';
import { translateToDiscord } from '@/lib/chat/translate-discord';

function bodyForKind(
  kind: string,
  event: WebhookEvent,
  payload: unknown,
): { contentType: string; body: string } {
  switch (kind) {
    case 'slack':
      return {
        contentType: 'application/json',
        body: JSON.stringify(translateToSlack({ event, data: payload } as Parameters<typeof translateToSlack>[0])),
      };
    case 'discord':
      return {
        contentType: 'application/json',
        body: JSON.stringify(translateToDiscord({ event, data: payload } as Parameters<typeof translateToDiscord>[0])),
      };
    default:
      return {
        contentType: 'application/json',
        body: canonicalBody(event, payload),
      };
  }
}
```

```ts
  input: { platform: 'slack' | 'discord'; channelId: string; threadTs?: string | null; messageId?: string | null },
```

```ts
import { createHmac, timingSafeEqual } from 'node:crypto';

/**
 * Slack Events API signature check (HMAC-SHA256 over `v0:${ts}:${rawBody}`).
 * Rejects if ts is >5 min old (anti-replay) or if the sig doesn't match.
 */
export function verifySlackSignature(input: {
  signingSecret: string;
  timestamp: string;
  signature: string;
  rawBody: string;
  nowSec?: number;
}): boolean {
  const now = input.nowSec ?? Math.floor(Date.now() / 1000);
  const ts = Number(input.timestamp);
  if (!Number.isFinite(ts) || Math.abs(now - ts) > 5 * 60) return false;
  const baseString = `v0:${input.timestamp}:${input.rawBody}`;
  const expected = `v0=${createHmac('sha256', input.signingSecret).update(baseString).digest('hex')}`;
  const a = Buffer.from(expected);
  const b = Buffer.from(input.signature);
  if (a.length !== b.length) return false;
  return timingSafeEqual(a, b);
}
```

```ts
import { webcrypto } from 'node:crypto';

/**
 * Discord interaction signature check — Ed25519 over `${timestamp}${rawBody}`,
 * verified against the application's public key (hex-encoded).
 */
export async function verifyDiscordSignature(input: {
  publicKeyHex: string;
  timestamp: string;
  signature: string;
  rawBody: string;
}): Promise<boolean> {
  try {
    const pubKey = Buffer.from(input.publicKeyHex, 'hex');
    const sig = Buffer.from(input.signature, 'hex');
    const msg = Buffer.from(`${input.timestamp}${input.rawBody}`);
    const key = await webcrypto.subtle.importKey('raw', pubKey, { name: 'Ed25519' }, false, ['verify']);
    return await webcrypto.subtle.verify({ name: 'Ed25519' }, key, sig, msg);
  } catch {
    return false;
  }
}
```

```ts
import { and, eq } from 'drizzle-orm';
import { NextResponse } from 'next/server';
import { getDb } from '@/db/client';
import * as schema from '@/db/schema';
import { recordAudit } from '@/lib/audit/record';
import { ingestInboundReply } from '@/lib/chat/inbound';
import { verifySlackSignature } from '@/lib/chat/verify-slack';

export async function POST(req: Request): Promise<Response> {
  const raw = await req.text();
  const ts = req.headers.get('x-slack-request-timestamp') ?? '';
  const sig = req.headers.get('x-slack-signature') ?? '';

  // Slack url_verification challenge happens BEFORE signing-secret is known — accept it.
  let body: { type?: string; challenge?: string; team_id?: string; event?: Record<string, unknown> };
  try {
    body = JSON.parse(raw);
  } catch {
    return NextResponse.json({ error: 'invalid json' }, { status: 400 });
  }
  if (body.type === 'url_verification' && typeof body.challenge === 'string') {
    return NextResponse.json({ challenge: body.challenge });
  }

  // Look up the workspace by team_id via webhooks.platform_metadata.
  const team = body.team_id;
  if (!team) return NextResponse.json({ ok: true });
  const [hook] = await getDb()
    .select()
    .from(schema.webhooks)
    .where(and(eq(schema.webhooks.kind, 'slack')))
    .limit(50);
  // Among matching workspaces, find the one whose platform_metadata.team_id matches.
  // (In a multi-workspace install, we'd index this; v0.9 ships with a small N.)
  const candidates = await getDb()
    .select()
    .from(schema.webhooks)
    .where(eq(schema.webhooks.kind, 'slack'));
  const match = candidates.find((h) => (h.platformMetadata as { team_id?: string } | null)?.team_id === team);
  if (!match) return NextResponse.json({ ok: true });
  const signingSecret = (match.platformMetadata as { signing_secret?: string } | null)?.signing_secret ?? '';
  void hook;

  if (!verifySlackSignature({ signingSecret, timestamp: ts, signature: sig, rawBody: raw })) {
    await recordAudit(getDb(), {
      workspaceId: match.workspaceId,
      actorUserId: null,
      action: 'chat.signature_rejected',
      metadata: { platform: 'slack' },
    });
    return NextResponse.json({ error: 'invalid signature' }, { status: 401 });
  }

  const ev = body.event as { type?: string; text?: string; user?: string; channel?: string; thread_ts?: string } | undefined;
  if (ev?.type === 'message' && ev.thread_ts && typeof ev.text === 'string' && ev.channel) {
    await ingestInboundReply(getDb(), {
      platform: 'slack',
      channelId: ev.channel,
      threadTs: ev.thread_ts,
      body: ev.text,
      authorPlatformHandle: ev.user ?? 'unknown',
    });
  }
  return NextResponse.json({ ok: true });
}
```
