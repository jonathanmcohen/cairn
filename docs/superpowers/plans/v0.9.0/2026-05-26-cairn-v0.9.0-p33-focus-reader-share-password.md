# Cairn v0.9.0 — Plan P33: Focus mode + reader mode + share-password verify wiring

> **Implementation note (post-landing):** the controller scoped this plan down at
> execution time to drop the new migration entirely. Focus + reader prefs are
> persisted client-side in `localStorage` under the key `cairn:page-mode`

> no `getPageModePrefs/setPageModePrefs` helper. Tasks 1 + 2 were therefore
> skipped; Tasks 3-7 landed as written (with the shell wired to localStorage in

> changes (Tasks 5-6) landed unmodified.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Three page-shell-layer UX features. (1) **Focus mode** toggle hides sidebar + workspace header + comments rail on `/pages/[pageId]`, leaving the editor editable; the toggle persists per-user across navigations. (2) **Reader mode** renders the page read-only with the same prose styling as the public `/p/<slug>` route; it is a separate button from focus and forces the TipTap editor into `editable: false`. (3) **Share-password verify polish** — the verify flow already exists end-to-end on `main` (`src/lib/pages/share.ts` + `src/app/p/[slug]/verify/route.ts` + `gate-form.tsx`); P33 narrows the cookie TTL to **5 minutes**, splits the existing `page.share_changed` audit into the spec-prescribed actions `share.password_set` / `share.password_cleared` / `share.password_used`, and adds a "Rotate password" affordance to `SharePanel` (re-hash without first clearing).

**Architecture:**

- **Focus + reader prefs.** Two booleans live on the existing per-user-prefs table `user_theme_prefs` (`src/db/schema/user-theme-prefs.ts`) — no new table needed. New columns `last_focus_mode boolean default false`, `last_reader_mode boolean default false`. The page-shell server component (`src/app/(app)/pages/[pageId]/page.tsx`) reads them via a tiny helper and threads the booleans into a new `<PageModeShell>` Client Component that wraps the existing `<PageDetailShell>` markup. Toggle buttons sit in the header bar next to `<PageMenu>`; each click PATCHes `/api/users/me/page-mode-prefs` (new) and updates local state optimistically. Focus mode toggles a workspace-layout-level class via a shared `usePageMode()` hook reading a `localStorage`-mirrored signal so the sidebar and topbar (rendered in `src/app/(app)/layout.tsx`) can react without a server roundtrip. Reader mode flips a prop on `<Editor>` that swaps `editable={true}` → `false`.
- **Share-password.** `pages.link_password_hash` already exists (added in v0.6); `setShareSettings` already argon2id-hashes it; the verify route is at `src/app/p/[slug]/verify/route.ts` with default TTL `12 * 60 * 60`. P33: change `DEFAULT_TTL_SECONDS` to `5 * 60`, **and** extend `setShareSettings` to emit fine-grained audit actions `share.password_set` / `share.password_cleared` in addition to (or replacing for the password path) the legacy `page.share_changed`. Verify route additionally writes `share.password_used` on success. New audit actions are added to `AUDIT_ACTIONS` in `src/lib/audit/actions.ts`. SharePanel gains a "Rotate" button that posts a new password directly (no clear-then-set round-trip).
- **No new migration** for share-password — the column already exists. **One new migration `0044?`** for the two prefs columns. NOTE: at write-time the next free migration slot is 0044; if Drizzle emits a different number because P26 / P25 / P30 land before P33, accept it and rename helpful. Per the plan-index migration ledger 0044 is currently owned by P26 (page lifecycle + translations) — coordinate by landing P33's migration AFTER P26, so this migration takes whatever number Drizzle emits next (likely 0049 if all earlier plans landed). The exact number is decided at generation time.

```ts
import { eq, sql } from 'drizzle-orm';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import * as schema from '@/db/schema';

export type PageModePrefs = { focus: boolean; reader: boolean };

const DEFAULTS: PageModePrefs = { focus: false, reader: false };

export async function getPageModePrefs(
  db: PostgresJsDatabase<typeof schema>,
  userId: string,
): Promise<PageModePrefs> {
  const [row] = await db
    .select({
      focus: schema.userThemePrefs.lastFocusMode,
      reader: schema.userThemePrefs.lastReaderMode,
    })
    .from(schema.userThemePrefs)
    .where(eq(schema.userThemePrefs.userId, userId))
    .limit(1);
  if (!row) return DEFAULTS;
  return { focus: row.focus, reader: row.reader };
}

export async function setPageModePrefs(
  db: PostgresJsDatabase<typeof schema>,
  userId: string,
  patch: Partial<PageModePrefs>,
): Promise<void> {
  // Upsert: insert a defaults row if missing, then merge.
  await db
    .insert(schema.userThemePrefs)
    .values({
      userId,
      accent: 'default',
      fontFamily: 'system',
      pageWidth: 'wide',
      lastFocusMode: patch.focus ?? false,
      lastReaderMode: patch.reader ?? false,
    })
    .onConflictDoUpdate({
      target: schema.userThemePrefs.userId,
      set: {
        ...(patch.focus !== undefined ? { lastFocusMode: patch.focus } : {}),
        ...(patch.reader !== undefined ? { lastReaderMode: patch.reader } : {}),
        updatedAt: sql`now()`,
      },
    });
}
```

- [x] **Step 6: Implement `src/app/api/users/me/page-mode-prefs/route.ts`**

```ts
import { NextResponse } from 'next/server';
import { z } from 'zod';
import { getDb } from '@/db/client';
import { auth } from '@/lib/auth/config';
import { setPageModePrefs } from '@/lib/pages/page-mode-prefs';

const Body = z.object({
  focus: z.boolean().optional(),
  reader: z.boolean().optional(),
});

export async function PATCH(req: Request): Promise<Response> {
  const session = await auth();
  if (!session?.user?.id) {
    return NextResponse.json({ error: 'unauthorized' }, { status: 401 });
  }
  let body: z.infer<typeof Body>;
  try {
    body = Body.parse(await req.json());
  } catch {
    return NextResponse.json({ error: 'invalid body' }, { status: 400 });
  }
  await setPageModePrefs(getDb(), session.user.id, body);
  return NextResponse.json({ ok: true });
}
```

```tsx
'use client';

import {
  createContext,
  type ReactNode,
  useCallback,
  useContext,
  useEffect,
  useMemo,
  useState,
} from 'react';

type ModeCtx = {
  focus: boolean;
  reader: boolean;
  setFocus: (v: boolean) => void;
  setReader: (v: boolean) => void;
};

const Ctx = createContext<ModeCtx | null>(null);

export function usePageMode(): ModeCtx {
  const ctx = useContext(Ctx);
  if (!ctx) throw new Error('usePageMode must be used inside <PageModeShell>');
  return ctx;
}

async function patchPrefs(body: { focus?: boolean; reader?: boolean }): Promise<void> {
  try {
    await fetch('/api/users/me/page-mode-prefs', {
      method: 'PATCH',
      headers: { 'content-type': 'application/json' },
      body: JSON.stringify(body),
    });
  } catch {
    // Best-effort; failed sync is non-fatal — local state still flips.
  }
}

type Props = {
  initialFocus: boolean;
  initialReader: boolean;
  toggles: ReactNode;
  children: ReactNode;
};

/**
 * Client wrapper around the page-detail body. Owns the focus + reader toggle
 * state and surfaces it both as a context (child components read via
 * `usePageMode()`) and as a `cairn-focus-mode` class on the document root so
 * the workspace layout can collapse the sidebar + topbar via CSS without a
 * re-render of those server-rendered shells.
 */
export function PageModeShell({ initialFocus, initialReader, toggles, children }: Props) {
  const [focus, setFocusState] = useState(initialFocus);
  const [reader, setReaderState] = useState(initialReader);

  useEffect(() => {
    document.documentElement.classList.toggle('cairn-focus-mode', focus);
    return () => {
      document.documentElement.classList.remove('cairn-focus-mode');
    };
  }, [focus]);

  const setFocus = useCallback((v: boolean) => {
    setFocusState(v);
    void patchPrefs({ focus: v });
  }, []);
  const setReader = useCallback((v: boolean) => {
    setReaderState(v);
    void patchPrefs({ reader: v });
  }, []);

  const value = useMemo(() => ({ focus, reader, setFocus, setReader }), [focus, reader, setFocus, setReader]);

  return (
    <Ctx.Provider value={value}>
      <div data-page-mode-shell="" data-focus={focus} data-reader={reader}>
        <div className="flex justify-end gap-1">{toggles}</div>
        {children}
      </div>
    </Ctx.Provider>
  );
}
```
