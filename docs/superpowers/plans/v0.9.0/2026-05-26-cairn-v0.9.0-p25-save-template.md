# Save-as-template UI + sharing controls (uses migration `0045` from P24) — Cairn v0.9.0 G4 P25

> **For agentic workers:** REQUIRED SUB-SKILLS: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the existing minimal `Save as template` button (live in `PageMenu` — fires a fire-and-forget call) with a real modal that captures (a) template name, (b) icon, (c) sharing **visibility**: `private` (creator only), `workspace` (any member), `public` (anyone reaching `/templates/gallery`). On save, snapshot `pages.content` + `pages.cover` + icon into a `templates` row with the new `visibility` column added by **P24's migration `0045`** (shared migration; this plan adds NO migration of its own). The v0.8 P10 gallery (`/templates/gallery` + `src/components/templates/templates-gallery.tsx`) is updated to honor the visibility filter, and a server-side ACL guard refuses cross-visibility access.

**Architecture:** The `templates` table (already in the schema as `src/db/schema/templates.ts`) gains a `visibility text` column via P24's migration (`0045_approvals_and_template_sharing.sql`). The save modal collects the three fields and POSTs to a new `/api/templates/save-from-page` route which delegates to a refactored `savePageAsTemplate(db, {...})` in `src/lib/templates/save.ts` — extended to accept `visibility` + `icon`. The gallery server component filters rows by visibility against the caller's user/workspace identity. The public route `/templates/gallery` (existing v0.8 P10 surface) keeps the same path but the loader changes: `private` shows only the caller's, `workspace` shows the caller's-workspace templates plus their `private`, `public` adds globally-visible templates regardless of workspace membership. **Encrypted-page snapshot:** `pages.encrypted=true` snapshots are allowed (template stays encrypted via stored ciphertext) — instantiation into a non-encrypted workspace requires explicit re-key (re-key flow itself lives in P5/P6 — this plan only refuses instantiation when source-encrypted and target-workspace lacks the key).

**Tech Stack:** Drizzle ORM (uses existing `templates` table schema; visibility column added by P24), Next.js 16 RSC + Client Components for the modal (Client) + gallery (RSC), Zod v4 for input validation, Vitest 4 + Testcontainers v12, Biome v2.

**Spec:** `docs/superpowers/specs/2026-05-26-cairn-v0.9.0-design.md` — §2 G4 #28 (Save-as-template + sharing controls), §3 row 0045 (shared with P24). Retrospective rules: §1 (release branch), §2 (plan-review), §7 (coupling — the migration is owned by P24; this plan only **consumes** the new column and adds NO migration of its own).

```ts
import { workspaces } from './workspaces';

/**
 * Template payload registry. v0.5 introduced this; v0.8 P10 added the gallery
 * UI consumer; v0.9 P25 added visibility + icon + cover-snapshot + source-page
 * tracking via the shared P24/P25 migration 0045.

export const templates = pgTable(
  'templates',
  {
    id: uuid('id').primaryKey().default(sql`gen_random_uuid()`),
    workspaceId: uuid('workspace_id').references(() => workspaces.id, { onDelete: 'cascade' }), // null = built-in/global

    kind: text('kind').notNull(), // 'page' | 'database'

    //

    //                 caller's userId against templates.created_by … *but* the

    //                 caller must have page-read on the source page, else 404.
    //                 The access.ts ACL is the canonical contract.
    //   'workspace' — every member of templates.workspace_id sees it.
    //   'public'    — every signed-in user sees it under /templates/gallery's
    //                 "Public" tab.
    visibility: text('visibility').notNull().default('workspace'),
    icon: text('icon'),
    cover: jsonb('cover').$type<unknown>().notNull().default({}),
    // Snapshot lineage — null for legacy templates and for database-kind rows.
    sourcePageId: uuid('source_page_id').references(() => pages.id, { onDelete: 'set null' }),
    createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
  },
  (t) => ({
    byWorkspaceKindIdx: index('templates_workspace_id_kind_idx').on(t.workspaceId, t.kind),
    byVisibilityIdx: index('templates_visibility_idx').on(t.visibility),
  }),
);

export type NewTemplate = typeof templates.$inferInsert;
```

```ts
import { eq } from 'drizzle-orm';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import { z } from 'zod';
import * as schema from '@/db/schema';
import { recordAudit } from '@/lib/audit/record';
import { captureDatabase, capturePage } from './capture';

type Db = PostgresJsDatabase<typeof schema>;

const VISIBILITY = z.enum(['private', 'workspace', 'public']);

export type SavePageAsTemplateInput = {
  workspaceId: string;
  actorUserId: string;
  rootPageId: string;
  name: string;
  visibility: schema.TemplateVisibility;
  /** Override the source page's icon (defaults to it when omitted). */
  icon?: string | null;
};

/**
 * Capture a page subtree as a reusable template. Persists name + payload +
 * visibility + (icon, cover) snapshot of the source page. The insert + the
 * `template.created` audit row are written in a single transaction so the
 * audit can never drift (spec §2.27).
 */
export async function savePageAsTemplate(
  db: Db,
  input: SavePageAsTemplateInput,
): Promise<schema.Template> {
  // Validate visibility up front so a bad string blows up before the heavy
  // capturePage() walk. Cheap fail-fast.
  VISIBILITY.parse(input.visibility);

  const payload = await capturePage(db, {
    workspaceId: input.workspaceId,
    rootPageId: input.rootPageId,
  });

  // Pull icon + cover from the source page for the template-card preview.
  // capturePage doesn't return the row directly (only the rewritten tree), so
  // we re-fetch the single row — cheap relative to the capture walk.
  const [src] = await db
    .select({ icon: schema.pages.icon, cover: schema.pages.cover })
    .from(schema.pages)
    .where(eq(schema.pages.id, input.rootPageId));
  if (!src) throw new Error('source page not found');

  return db.transaction(async (tx) => {
    const [row] = await tx
      .insert(schema.templates)
      .values({
        workspaceId: input.workspaceId,
        name: input.name,
        kind: 'page',
        payload,
        builtIn: false,
        visibility: input.visibility,
        icon: input.icon === undefined ? src.icon : input.icon,
        cover: src.cover ?? {},
        sourcePageId: input.rootPageId,
      })
      .returning();
    if (!row) throw new Error('failed to save template');
    await recordAudit(tx, {
      workspaceId: input.workspaceId,
      actorUserId: input.actorUserId,
      action: 'template.created',
      targetType: 'template',
      targetId: row.id,
      metadata: { name: input.name, kind: 'page', visibility: input.visibility },
    });
    return row;
  });
}

/**
 * Capture a database as a reusable template. Database templates always default
 * to visibility='workspace' (matches v0.5/v0.8 behaviour); v0.9 didn't extend
 * the database-template UX.
 */
export async function saveDatabaseAsTemplate(
  db: Db,
  input: {
    workspaceId: string;
    actorUserId: string;
    databaseId: string;
    name: string;
    withSampleRows?: boolean;
  },
): Promise<schema.Template> {
  const payload = await captureDatabase(db, {
    workspaceId: input.workspaceId,
    databaseId: input.databaseId,
    withSampleRows: input.withSampleRows,
  });
  return db.transaction(async (tx) => {
    const [row] = await tx
      .insert(schema.templates)
      .values({
        workspaceId: input.workspaceId,
        name: input.name,
        kind: 'database',
        payload,
        builtIn: false,
        visibility: 'workspace',
      })
      .returning();
    if (!row) throw new Error('failed to save template');
    await recordAudit(tx, {
      workspaceId: input.workspaceId,
      actorUserId: input.actorUserId,
      action: 'template.created',
      targetType: 'template',
      targetId: row.id,
      metadata: { name: input.name, kind: 'database', visibility: 'workspace' },
    });
    return row;
  });
}
```

```ts
import { and, eq, inArray, or } from 'drizzle-orm';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import * as schema from '@/db/schema';

type Db = PostgresJsDatabase<typeof schema>;

/**
 * Visibility ACL for templates. The viewer carries an explicit workspace
 * identity (their currently-active workspace) — gallery loaders pass it from
 * the requireWorkspace context. We never trust the workspace stored on the
 * template row alone; the caller must also be a member of that workspace for
 * 'workspace' visibility.
 *
 * 'private': visible iff template.workspace_id matches the viewer's workspace
 *            AND the viewer is a member of that workspace. (When P24 adds a
 *            created_by column on templates, this tightens to "viewer ===
 *            creator". Until then, 'private' is workspace-scoped membership
 *            + a UI affordance — the row is still hidden from cross-workspace
 *            access.)
 * 'workspace': visible iff viewer is a member of template.workspace_id.
 * 'public':  visible to any caller (no workspace gate; gallery surfaces it
 *            under a "Public" tab).
 */

export async function canReadTemplate(
  db: Db,
  args: { templateId: string; viewerUserId: string; viewerWorkspaceId: string },
): Promise<boolean> {
  const [tpl] = await db
    .select({
      visibility: schema.templates.visibility,
      workspaceId: schema.templates.workspaceId,
    })
    .from(schema.templates)
    .where(eq(schema.templates.id, args.templateId));
  if (!tpl) return false;
  if (tpl.visibility === 'public') return true;

  // 'private' + 'workspace' both require workspace membership on the template's
  // workspace. Built-in (workspaceId === null) is never private/workspace —
  // built-ins are always 'public' by convention.
  if (!tpl.workspaceId) return false;

  const [member] = await db
    .select({ id: schema.workspaceMembers.workspaceId })
    .from(schema.workspaceMembers)
    .where(
      and(
        eq(schema.workspaceMembers.workspaceId, tpl.workspaceId),
        eq(schema.workspaceMembers.userId, args.viewerUserId),
      ),
    );
  if (!member) return false;

  // 'workspace': any member sees it. 'private': member of THE template's
  // workspace sees it (current placeholder — tightens to created_by check
  // once that column exists; flag noted in module comment).
  return true;
}

/**
 * List every template visible to (viewerUserId, viewerWorkspaceId). Used by
 * the gallery server component.
 */
export async function listVisibleTemplates(
  db: Db,
  args: { viewerUserId: string; viewerWorkspaceId: string },
): Promise<schema.Template[]> {
  // 1. Public — every row regardless of workspace.
  // 2. Workspace + private — only rows where the viewer is a member of
  //    template.workspace_id. We pre-compute the viewer's workspace set in
  //    one query, then filter.
  const memberRows = await db
    .select({ workspaceId: schema.workspaceMembers.workspaceId })
    .from(schema.workspaceMembers)
    .where(eq(schema.workspaceMembers.userId, args.viewerUserId));
  const memberWorkspaces = memberRows.map((r) => r.workspaceId);

  const conditions = [eq(schema.templates.visibility, 'public')];
  if (memberWorkspaces.length > 0) {
    conditions.push(
      and(
        inArray(schema.templates.workspaceId, memberWorkspaces),
        inArray(schema.templates.visibility, ['workspace', 'private'] as const),
      )!,
    );
  }
  return db.select().from(schema.templates).where(or(...conditions));
}
```

```ts
import { NextResponse } from 'next/server';
import { z } from 'zod';
import { getDb } from '@/db/client';
import { auth } from '@/lib/auth/config';
import { requirePageAccess } from '@/lib/pages/access';
import { savePageAsTemplate } from '@/lib/templates/save';

export const runtime = 'nodejs';

const BodySchema = z.object({
  pageId: z.uuid(),
  name: z.string().min(1).max(120),
  icon: z.string().max(64).nullable().optional(),
  visibility: z.enum(['private', 'workspace', 'public']),
});

/**
 * Save a page as a template with the chosen visibility. Caller must be signed
 * in and have at least 'view' access on the source page (cross-workspace
 * returns 404, matching the existing requirePageAccess contract — never leak
 * page existence).
 */
export async function POST(req: Request): Promise<Response> {
  const session = await auth();
  if (!session?.user?.id) return NextResponse.json({ error: 'unauthorized' }, { status: 401 });

  let body: z.infer<typeof BodySchema>;
  try {
    body = BodySchema.parse(await req.json());
  } catch {
    return NextResponse.json({ error: 'invalid input' }, { status: 400 });
  }

  // requirePageAccess verifies (a) the page exists in some workspace the user
  // belongs to and (b) returns the page row + workspace context. Throws with a
  // 404 HttpError on cross-workspace / missing.
  let pageCtx;
  try {
    pageCtx = await requirePageAccess(body.pageId, 'view');
  } catch (err) {
    if ((err as { status?: number }).status === 404) {
      return NextResponse.json({ error: 'not found' }, { status: 404 });
    }
    if ((err as { status?: number }).status === 403) {
      return NextResponse.json({ error: 'forbidden' }, { status: 403 });
    }
    throw err;
  }

  const db = getDb();
  const tpl = await savePageAsTemplate(db, {
    workspaceId: pageCtx.ctx.workspaceId,
    actorUserId: session.user.id,
    rootPageId: body.pageId,
    name: body.name,
    visibility: body.visibility,
    icon: body.icon ?? undefined,
  });

  return NextResponse.json({ templateId: tpl.id });
}
```

```tsx
    byVisibility.get(v)?.push(tpl);
  }

  return (
    <div className="space-y-8">
      {ORDER.map((v) => {
        const rows = byVisibility.get(v) ?? [];
        if (rows.length === 0) return null;
        return (
          <section key={v} aria-labelledby={`tpl-${v}`}>
            <h2 id={`tpl-${v}`} className="mb-2 text-sm font-semibold uppercase tracking-wide text-muted-foreground">
              {v}
            </h2>
            <ul className="grid grid-cols-1 gap-3 sm:grid-cols-2 lg:grid-cols-3">
              {rows.map((tpl) => (
                <li
                  key={tpl.id}
                  className="rounded-lg border bg-card p-3 text-sm hover:bg-accent/50"
                >
                  <div className="flex items-center gap-2">
                    <span aria-hidden="true">{tpl.icon ?? '📄'}</span>
                    <span className="font-medium">{tpl.name}</span>
                  </div>
                  <div className="mt-1 text-xs text-muted-foreground">
                    {tpl.workspaceId === activeWorkspaceId ? 'In this workspace' : 'Shared'} · {tpl.kind}
                  </div>
                </li>
              ))}
            </ul>
          </section>
        );
      })}
    </div>
  );
}
```
