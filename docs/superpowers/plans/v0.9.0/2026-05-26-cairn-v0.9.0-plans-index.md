# Cairn v0.9.0 — Numbered Plans Index

> **For agentic workers:** REQUIRED SUB-SKILLS:
> 1. **`superpowers:subagent-driven-development`** — fresh subagent per plan.
> 2. **Plan-review subagent BEFORE implementer dispatch** — new per the v0.7-v0.8 retrospective. Verifies every referenced file path, schema column, migration number, and RSC-vs-Client-Component boundary against current HEAD.

**Spec:** `docs/superpowers/specs/2026-05-26-cairn-v0.9.0-design.md`
**Retrospective (required reading):** `docs/superpowers/retrospective-v0.7-v0.8.md`

**Theme of v0.9.0:** finish every remaining pre-1.0 roadmap feature except the AI cluster (set aside for the 3rd time). After v0.9.0, v1.0.0 is pure stabilization.

**Execution pattern:**

- Branch: `release/v0.9.0` (cut off `main` at start). **Every commit lands on the branch, NOT main.**
- Subagent-driven (fresh implementer per plan with full task text).
- Plan-review subagent dispatched before implementer dispatch.
- Controller reviews + commits + pushes to release branch between plans.
- Single PR `release/v0.9.0 → main` at G9 smoke + release time. Tag fires from merge commit.

**Conventions (carried from v0.8.0):**

- Prefix every shell command with `source ~/.zshenv && `.
- Conventional Commits, no `Co-Authored-By` trailer.
- Workflow-wide `NODE_OPTIONS=--max-old-space-size=6144` in CI.
- Migration numbers shift if Drizzle emits a different sequence — accept what generates, rename helpful, update meta journal.
- Per-runtime-dep bumps update **all five** consumers in one commit (docker-compose, tests/helpers/db.ts, ci.yml services, lighthouse.yml services, Dockerfile if relevant).
- Implementer marks `- [ ]` → `- [x]` in the plan doc as work lands.
- Implementer updates `docs/superpowers/roadmap-0.6-to-1.0.md` v0.9 checkbox row for the plan.

```
       G1 (P1-P10)         G2 (P11-P14)

                              ▼
                       G5 (P27-P30)      G6 (P31-P33)
                              │                │

                                       ▼
                                G7 (P34-P38)     G8 (P39-P43)
                                       │                │
                                       └────────┬───────┘
                                                ▼
                                          G9 P44 — release
```

**Most groups pairwise independent.** Hard dependencies:

- **P5 (E2E crypto core) is load-bearing.** P6, P7 depend on it. So does every consumer that needs to check `pages.encrypted`: P27 (see-also skip), P29 (search-operator filter passes through), P30 (federated search skip), P23 (tasks hub aggregator must check ACL).
- **P26 (page status enum) → P24** (approval workflow gates on `status='review'`).
- **P18 (citation block) ↔ P21 (DOI lookup)** ship together; either can technically land first.
- **P34 (static export pipeline) → P35** (Docusaurus target reuses pipeline).
- **P36 → P37** (slash commands extend the bot install).
- **P39 → P40** (Splunk/Datadog targets extend the forwarder kind enum).
- **P41 → P42** (release watch invokes CLI primitives).
- **G9 P44 requires every other plan landed + green CI on `release/v0.9.0`.**
