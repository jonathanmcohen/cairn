# Cairn v0.9.0 — Plan P15: Diagram blocks expansion — PlantUML + drawio (alongside v0.8 Mermaid)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** v0.8 P22 shipped Mermaid as a lazy-loaded block (renders inline SVG, no iframe). P15 extends the diagram surface with two new block types:

1. **PlantUML** — text-DSL diagrams rendered to PNG/SVG via either the public `www.plantuml.com/plantuml/svg/<encoded>` URL OR a self-hosted PlantUML server when `CAIRN_PLANTUML_SERVER` env is set. The text is encoded with the standard PlantUML deflate+base64 algorithm using the `plantuml-encoder` npm package (~3 KB, client-side). The rendered image is loaded as `<img>` — NO iframe.
2. **drawio** — a viewer-only iframe to `https://viewer.diagrams.net/?lightbox=1&...` carrying the user's diagram XML in the URL. The XML is gzipped + base64'd into the `data=` parameter (drawio's own URL contract). For pure-viewer mode the XML can also be loaded from a public URL via `url=`. CSP `frame-src` allowlist gains `https://viewer.diagrams.net` only.

Both blocks follow the v0.8 P6 / P22 Mermaid pattern: schema-only TipTap node under `src/components/editor/blocks/` + lazy-loaded React renderer + slash-command entry + extension registration in `extensions-lazy.ts`. The CSP drift-guard test at `tests/lib/security/headers.test.ts` is extended.

**Existing surface (read before editing):**
- `src/components/editor/blocks/mermaid-node.ts` + `mermaid.tsx` — the v0.8 P22 template. P15 follows this shape exactly.
- `src/components/editor/extensions-lazy.ts` — registers the lazy block extensions.
- `src/components/editor/extensions.ts` — schema-only registrations (parsed in SSR).
- `src/lib/editor/embed-allowlist.ts` — `EMBED_FRAME_HOSTS` constant.
- `src/lib/security/headers.ts` — the CSP builder; mirrors `EMBED_FRAME_HOSTS`.
- `tests/lib/security/headers.test.ts` — drift-guard.

**Architecture decisions:**
1. **PlantUML uses `<img>`, not iframe.** No CSP `frame-src` entry needed. CSP `img-src` already permits `https:` so public PlantUML server URLs Just Work; for self-hosted servers the operator's domain must be reachable from clients. We document this in the env var help text.
2. **drawio uses iframe.** Only `https://viewer.diagrams.net` is added to `EMBED_FRAME_HOSTS`. The "edit on drawio" UX is out of scope; this is viewer-only.
3. **Both blocks ship a `source` attribute** holding the diagram text. The renderer derives the URL each render; nothing is persisted server-side beyond the source string.

```tsx
'use client';

import type { NodeViewProps } from '@tiptap/react';
import { NodeViewWrapper } from '@tiptap/react';
import { useEffect, useState } from 'react';
import { Button } from '@/components/ui/button';
import { Textarea } from '@/components/ui/textarea';
import { env } from '@/lib/env';

/**
 * Build a PlantUML render URL. The encoder is dynamically imported by the
 * caller (so this is a synchronous URL builder once the encoder is loaded).
 * Exported separately for unit testing — the React view passes the loaded
 * `encode` function in.
 */
export function buildPlantUmlUrl(
  source: string,
  server: string | undefined,
  encodeFn?: (s: string) => string,
): string {
  const base = (server ?? 'https://www.plantuml.com/plantuml').replace(/\/$/, '');
  // The default (test-only) fallback emits a deterministic placeholder so
  // unit tests can assert URL shape without loading the encoder. In real
  // usage the React view always passes encodeFn.
  const encoded = encodeFn ? encodeFn(source) : Buffer.from(source).toString('base64url');
  return `${base}/svg/${encoded}`;
}

export function PlantUmlView({ node, editor, updateAttributes }: NodeViewProps) {
  const source = (node.attrs.source ?? '') as string;
  const [editing, setEditing] = useState(!source);
  const [draft, setDraft] = useState(source);
  const [url, setUrl] = useState<string | null>(null);
  const [err, setErr] = useState<string | null>(null);

  useEffect(() => {
    if (!source) {
      setUrl(null);
      return;
    }
    let cancelled = false;
    void import('plantuml-encoder').then((mod) => {
      if (cancelled) return;
      try {
        const server = env().NEXT_PUBLIC_CAIRN_PLANTUML_SERVER;
        setUrl(buildPlantUmlUrl(source, server, mod.default.encode));
        setErr(null);
      } catch (e) {
        setErr(e instanceof Error ? e.message : 'PlantUML encode failed');
        setUrl(null);
      }
    });
    return () => {
      cancelled = true;
    };
  }, [source]);

  if (editing && editor.isEditable) {
    return (
      <NodeViewWrapper className="my-3 rounded-md border p-3">
        <Textarea
          value={draft}
          onChange={(e) => setDraft(e.target.value)}
          placeholder={'@startuml\nAlice -> Bob: hello\n@enduml'}
          className="font-mono text-sm"
          rows={6}
        />
        <div className="mt-2 flex gap-2">
          <Button
            type="button"
            onClick={() => {
              updateAttributes({ source: draft });
              setEditing(false);
            }}
          >
            Render
          </Button>
          {source && (
            <Button type="button" variant="outline" onClick={() => setEditing(false)}>
              Cancel
            </Button>
          )}
        </div>
      </NodeViewWrapper>
    );
  }

  return (
    <NodeViewWrapper className="my-3">
      {err && (
        <div className="rounded-md border border-destructive/40 p-3 text-sm text-destructive">
          PlantUML error: {err}
        </div>
      )}
      {url && (
        <img
          src={url}
          alt="PlantUML diagram"
          className="max-w-full overflow-x-auto"
          loading="lazy"
        />
      )}
      {editor.isEditable && (
        <Button
          type="button"
          size="sm"
          variant="ghost"
          onClick={() => {
            setDraft(source);
            setEditing(true);
          }}
        >
          Edit diagram
        </Button>
      )}
    </NodeViewWrapper>
  );
}
```

```tsx
'use client';

import type { NodeViewProps } from '@tiptap/react';
import { NodeViewWrapper } from '@tiptap/react';
import { useState } from 'react';
import { Button } from '@/components/ui/button';
import { Input } from '@/components/ui/input';
import { Textarea } from '@/components/ui/textarea';

const VIEWER_ORIGIN = 'https://viewer.diagrams.net';

export function buildDrawioUrl(input: { source?: string; sourceUrl?: string }): string {
  const u = new URL(VIEWER_ORIGIN);
  u.searchParams.set('lightbox', '1');
  if (input.sourceUrl) {
    u.searchParams.set('url', input.sourceUrl);
    return u.toString();
  }
  if (input.source) {
    // drawio's `data=` accepts the raw XML (the viewer URL-decodes and
    // displays). For deflated XML use `xml=` instead; viewer-only mode
    // is happy with raw `data=`.
    u.searchParams.set('data', input.source);
    return u.toString();
  }
  return u.toString();
}

export function DrawioView({ node, editor, updateAttributes }: NodeViewProps) {
  const source = (node.attrs.source ?? '') as string;
  const sourceUrl = (node.attrs.sourceUrl ?? '') as string;
  const hasContent = Boolean(source || sourceUrl);
  const [editing, setEditing] = useState(!hasContent);
  const [draftSource, setDraftSource] = useState(source);
  const [draftUrl, setDraftUrl] = useState(sourceUrl);

  if (editing && editor.isEditable) {
    return (
      <NodeViewWrapper className="my-3 rounded-md border p-3">
        <div className="space-y-3">
          <div>
            <label className="text-xs font-medium text-muted-foreground">Diagram XML</label>
            <Textarea
              value={draftSource}
              onChange={(e) => setDraftSource(e.target.value)}
              placeholder="<mxGraphModel>...</mxGraphModel>"
              className="font-mono text-sm"
              rows={6}
            />
          </div>
          <div className="text-center text-xs text-muted-foreground">— or —</div>
          <div>
            <label className="text-xs font-medium text-muted-foreground">Public URL</label>
            <Input
              value={draftUrl}
              onChange={(e) => setDraftUrl(e.target.value)}
              placeholder="https://example.com/diagram.drawio"
            />
          </div>
          <div className="flex gap-2">
            <Button
              type="button"
              onClick={() => {
                updateAttributes({ source: draftSource, sourceUrl: draftUrl });
                setEditing(false);
              }}
            >
              Render
            </Button>
            {hasContent && (
              <Button type="button" variant="outline" onClick={() => setEditing(false)}>
                Cancel
              </Button>
            )}
          </div>
        </div>
      </NodeViewWrapper>
    );
  }

  return (
    <NodeViewWrapper className="my-3">
      <iframe
        src={buildDrawioUrl({ source, sourceUrl })}
        title="drawio diagram"
        className="aspect-video w-full rounded-md border"
        sandbox="allow-scripts allow-same-origin allow-popups"
        loading="lazy"
      />
      {editor.isEditable && (
        <Button
          type="button"
          size="sm"
          variant="ghost"
          onClick={() => {
            setDraftSource(source);
            setDraftUrl(sourceUrl);
            setEditing(true);
          }}
        >
          Edit diagram
        </Button>
      )}
    </NodeViewWrapper>
  );
}
```
