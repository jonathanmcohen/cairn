# Cairn v0.6.0 Plan P10 — Page links + backlinks + page mentions/embeds + per-database row templates

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn Cairn into a wiki: inline **page links** (`pageLink`), inline **page mentions** (`pageMention`), block **page embeds** (`pageEmbed`) — all inserted via a `[[` / `@page` autocomplete that queries the workspace's pages; a write-time `reindexPageLinks(tx, pageId, content)` that walks the saved ProseMirror JSON and upserts a `page_links` index; a **"Linked references"** (backlinks) panel that reads that index plus a read-time **unlinked-mentions** FTS search for the page title; and **per-database row templates** (`rowTemplates` jsonb config + a "new row from template" picker). Migration `0018` creates the `page_links` index table AND the `notification_email_prefs` table (the latter is consumed by **P11**, created here so P11 needs no migration). Every new node is Yjs round-trip audited.

**Architecture (per the v0.6.0 design — Key decisions #15, #16, #17, §4 migration `0018`, §5 "Collaboration" / "Database"):**
- **Link index, not read-time scans (#15).** Page links live as inline/block nodes in `pages.content`. On save, `reindexPageLinks(tx, pageId, content)` walks the ProseMirror JSON, extracts every `pageLink`/`pageMention`/`pageEmbed` target id, and does a **delete-then-insert per source** into `page_links(source_page_id, target_page_id, kind)`. "Linked references" is `SELECT … WHERE target_page_id = ?` (indexed). **Unlinked mentions** are a read-time FTS search for the page's title across other pages' `content_tsv` (no index) — exactly the existing `src/lib/pages/search.ts` FTS path, scoped to the workspace and excluding pages already in `page_links`.
- **Nodes mirror the v0.3.0 @mention extension (#16).** `pageMention` is inline (live page title + link, like the member `mention` node); `pageEmbed` is a block (read-only snapshot preview — title + first blocks via `publicExtensions()`, with a link through, **not** a live nested collab doc — live transclusion is deferred). `pageLink` is inline (a styled link with a label). All three are TipTap 3 custom nodes, get read-only variants in `publicExtensions()` for `/p/` + `/s/`, feed `reindexPageLinks`, and are Yjs round-trip audited (the v0.3.0 precedent).
- **Storage convention.** Each node stores `{ targetPageId, label }` (mirroring the `@[Name](userId)` mention convention's `{id,label}` shape). `reindexPageLinks` reads `node.attrs.targetPageId` — that is the single source of truth for the index; the label is for render/FTS legibility only.
- **Autocomplete (#16).** A single suggestion plugin handles BOTH triggers: `[[` opens the page picker (inserting a `pageLink`), `@` (page scope) inserts a `pageMention`. Both query `GET /api/workspaces/pages?q=` (a new thin route over a pure `searchWorkspacePages` helper, mirroring `searchWorkspaceMembers` from v0.3.0 P5). `pageEmbed` is inserted from the slash menu (`/embed page`) using the same picker UI.
- **Row templates (#17), no new table.** A database gains optional `rowTemplates: [{id, name, cellDefaults, contentTemplate?}]` in its existing config jsonb (on `databases.config` — **no schema change**). `src/lib/databases/row-templates.ts` does CRUD on that jsonb + `applyRowTemplate(template)` → the `{cells, content}` seed for a new row; the database toolbar's "New" button gains a template-picker dropdown.

**Migration `0018` (this plan owns it) — creates `page_links` AND `notification_email_prefs`:**

```
page_link_kind:           NEW enum ('link','mention','embed')          -- CREATE TYPE (transactional)
page_links:               source_page_id uuid REF pages(id) ON DELETE CASCADE,
                          target_page_id uuid REF pages(id) ON DELETE CASCADE,
                          kind page_link_kind NOT NULL,
                          PRIMARY KEY (source_page_id, target_page_id, kind)
                          + index page_links(target_page_id)            -- the backlinks query
notification_email_prefs: user_id uuid REF users(id) ON DELETE CASCADE,
                          workspace_id uuid REF workspaces(id) ON DELETE CASCADE,
                          notification_type text NOT NULL,
                          email_enabled boolean NOT NULL DEFAULT false,
                          digest_only   boolean NOT NULL DEFAULT false,
                          PRIMARY KEY (user_id, workspace_id, notification_type)
```

`0016`/`0017` already create new enums in-transaction; `0018` follows that precedent — `CREATE TYPE page_link_kind` runs **in** the transaction (it is a new type, not an `ALTER TYPE ADD VALUE`). Both tables are emitted by `pnpm db:generate` from the Drizzle schema (no self-FK or trigger here — the composite-PK + index are standard, so `db:generate` produces correct SQL; **still READ the generated SQL** before committing, per the CLAUDE.md gotcha, to confirm the FKs/PK/index are present and no extra `ALTER TYPE` slipped in).

```ts
import { index, pgEnum, pgTable, primaryKey, uuid } from 'drizzle-orm/pg-core';
import { pages } from './pages';

export const pageLinkKind = pgEnum('page_link_kind', ['link', 'mention', 'embed']);

/**
 * Write-time index of page-to-page references (link/mention/embed). Maintained by
 * reindexPageLinks(tx, pageId, content) as a delete-then-insert per source page.
 * "Linked references" reads WHERE target_page_id = ? (indexed); unlinked mentions
 * are a separate read-time FTS search (no index).
 */
export const pageLinks = pgTable(
  'page_links',
  {
    sourcePageId: uuid('source_page_id')
      .notNull()
      .references(() => pages.id, { onDelete: 'cascade' }),
    targetPageId: uuid('target_page_id')
      .notNull()
      .references(() => pages.id, { onDelete: 'cascade' }),
    kind: pageLinkKind('kind').notNull(),
  },
  (t) => [
    primaryKey({ columns: [t.sourcePageId, t.targetPageId, t.kind] }),
    index('page_links_target_idx').on(t.targetPageId),
  ],
);

export type PageLink = typeof pageLinks.$inferSelect;
```

```ts
import { drizzle } from 'drizzle-orm/postgres-js';
import postgres from 'postgres';
import { afterAll, beforeAll, beforeEach, describe, expect, it } from 'vitest';

import { startPostgres, stopPostgres } from '../../helpers/db';

let db: ReturnType<typeof drizzle<typeof schema>>;

beforeAll(async () => {
  const uri = await startPostgres();
  await runMigrations(uri);
  sql = postgres(uri);
  db = drizzle(sql, { schema });

afterAll(async () => {
  await sql.end();
  await stopPostgres();

async function makePage(workspaceId: string, userId: string, title: string) {
  const [page] = await db
    .insert(schema.pages)
    .values({ workspaceId, title, createdBy: userId, content: { type: 'doc', content: [] } as never })
    .returning();
  if (!page) throw new Error('page insert failed');
  return page;
}

const A = '11111111-1111-1111-1111-111111111111';
const C = '33333333-3333-3333-3333-333333333333';

function doc(...nodes: unknown[]) {
  return { type: 'doc', content: nodes };
}
const link = (id: string) => ({ type: 'pageLink', attrs: { targetPageId: id, label: 'X' } });
const mention = (id: string) => ({ type: 'pageMention', attrs: { targetPageId: id, label: 'X' } });
const embed = (id: string) => ({ type: 'pageEmbed', attrs: { targetPageId: id, label: 'X' } });

describe('extractPageLinks', () => {
  it('returns [] for a doc with no page-link nodes', () => {
    expect(extractPageLinks(doc({ type: 'paragraph', content: [{ type: 'text', text: 'hi' }] }))).toEqual([]);
  });

  it('extracts link/mention/embed targets and dedupes per (target, kind)', () => {
    const result = extractPageLinks(
      doc(
        { type: 'paragraph', content: [link(A), mention(C)] },
        link(A), // duplicate (A, link) — collapsed
        embed(A),
      ),
    );
    expect(result).toEqual(
      expect.arrayContaining([
        { targetPageId: A, kind: 'link' },
        { targetPageId: C, kind: 'mention' },
        { targetPageId: A, kind: 'embed' },
      ]),
    );
    expect(result).toHaveLength(3); // (A,link) appears once despite two nodes
  });

  it('ignores nodes with a missing/non-uuid targetPageId', () => {
    expect(
      extractPageLinks(
        doc({ type: 'pageLink', attrs: { label: 'no id' } }, { type: 'pageLink', attrs: { targetPageId: 'nope' } }),
      ),
    ).toEqual([]);
  });
});

    const u = await createTestWorkspaceWithUser(db);
    const src = await makePage(u.workspaceId, u.userId, 'Source');
    const t1 = await makePage(u.workspaceId, u.userId, 'Target 1');
    const t2 = await makePage(u.workspaceId, u.userId, 'Target 2');

    await db.transaction((tx) =>
      reindexPageLinks(tx, src.id, doc({ type: 'paragraph', content: [link(t1.id), mention(t2.id)] })),
    );
```

```ts
import { and, eq, inArray } from 'drizzle-orm';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import * as schema from '@/db/schema';

type Tx = Pick<PostgresJsDatabase<typeof schema>, 'select' | 'delete' | 'insert'>;

const UUID_RE = /^[0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{12}$/;

const NODE_KIND: Record<string, 'link' | 'mention' | 'embed'> = {
  pageLink: 'link',
  pageMention: 'mention',
  pageEmbed: 'embed',
};

export type PageLinkRef = { targetPageId: string; kind: 'link' | 'mention' | 'embed' };

/**
 * Walk a ProseMirror doc and collect every page reference, deduped per
 * (targetPageId, kind). Nodes with a missing or non-UUID `targetPageId` are
 * ignored. Self-references are allowed (a page may link to itself).
 */
export function extractPageLinks(content: unknown): PageLinkRef[] {
  const seen = new Set<string>();
  const out: PageLinkRef[] = [];
  const walk = (node: unknown): void => {
    if (!node || typeof node !== 'object') return;
    const n = node as { type?: string; attrs?: { targetPageId?: unknown }; content?: unknown[] };
    const kind = n.type ? NODE_KIND[n.type] : undefined;
    if (kind) {
      const id = n.attrs?.targetPageId;
      if (typeof id === 'string' && UUID_RE.test(id)) {
        const key = `${id}:${kind}`;
        if (!seen.has(key)) {
          seen.add(key);
          out.push({ targetPageId: id, kind });
        }
      }
    }
    if (Array.isArray(n.content)) for (const child of n.content) walk(child);
  };
  walk(content);
  return out;
}

/**
 * Re-index the page_links rows for a single source page: delete the existing
 * rows for `pageId`, then insert the references found in `content`. Targets that
 * no longer exist as pages are filtered out (so the FK never fails on a stale
 * reference). Runs inside the caller's transaction (the page-save txn).
 */
export async function reindexPageLinks(tx: Tx, pageId: string, content: unknown): Promise<void> {
  await tx.delete(schema.pageLinks).where(eq(schema.pageLinks.sourcePageId, pageId));

  const refs = extractPageLinks(content);
  if (refs.length === 0) return;

  const targetIds = [...new Set(refs.map((r) => r.targetPageId))];
  const existing = await tx
    .select({ id: schema.pages.id })
    .from(schema.pages)
    .where(inArray(schema.pages.id, targetIds));
  const live = new Set(existing.map((p) => p.id));

  const rows = refs
    .filter((r) => live.has(r.targetPageId))
    .map((r) => ({ sourcePageId: pageId, targetPageId: r.targetPageId, kind: r.kind }));
  if (rows.length > 0) await tx.insert(schema.pageLinks).values(rows);
}

/** Backlinks: pages that reference `pageId` (any kind). Used by the panel. */
export async function getBacklinks(
  db: PostgresJsDatabase<typeof schema>,
  targetPageId: string,
): Promise<{ sourcePageId: string; kind: 'link' | 'mention' | 'embed' }[]> {
  return db
    .select({ sourcePageId: schema.pageLinks.sourcePageId, kind: schema.pageLinks.kind })
    .from(schema.pageLinks)
    .where(eq(schema.pageLinks.targetPageId, targetPageId));
}

export { and }; // re-export kept tree-shake-safe; remove if unused after Task 4 wiring.
```

```ts
import { and, desc, eq, ilike, isNull } from 'drizzle-orm';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import * as schema from '@/db/schema';

export type PageSearchResult = { id: string; title: string; icon: string | null };

/**
 * Pages of `workspaceId` whose title matches `query` (ILIKE substring), excluding
 * soft-deleted pages. An empty query returns the most recently updated pages so
 * the [[ / @page picker can show something on the bare trigger. Workspace-scoped.
 */
export async function searchWorkspacePages(
  db: PostgresJsDatabase<typeof schema>,
  input: { workspaceId: string; query: string; limit?: number },
): Promise<PageSearchResult[]> {
  const limit = input.limit ?? 10;
  const q = input.query.trim();
  return db
    .select({ id: schema.pages.id, title: schema.pages.title, icon: schema.pages.icon })
    .from(schema.pages)
    .where(
      and(
        eq(schema.pages.workspaceId, input.workspaceId),
        isNull(schema.pages.deletedAt),
        q.length > 0 ? ilike(schema.pages.title, `%${q}%`) : undefined,
      ),
    )
    .orderBy(desc(schema.pages.updatedAt))
    .limit(limit);
}
```

```ts
function makeRenderer() {
  return () => {
    let component: ReactRenderer<PageLinkListRef, { items: PageItem[]; command: (i: PageItem) => void }>;
    let popup: Instance<TippyProps>;
    return {
      onStart: (props: { items: PageItem[]; command: (i: { id: string; title: string; icon: string | null }) => void; editor: unknown; clientRect?: (() => DOMRect | null) | null }) => {

          editor: props.editor as never,

        popup = tippy(document.body, {
          getReferenceClientRect: props.clientRect as () => DOMRect,
          appendTo: () => document.body,
          content: component.element,
          showOnCreate: true,
          interactive: true,
          trigger: 'manual',
          placement: 'bottom-start',
        });
      },
      onUpdate: (props: { items: PageItem[]; command: (i: PageItem) => void; clientRect?: (() => DOMRect | null) | null }) => {
```

```ts
import { and, eq, ilike, isNull, ne, notInArray, sql as rawSql } from 'drizzle-orm';

/**
 * Read-time "unlinked mentions": pages in the same workspace whose text contains
 * the target page's `title` but which are NOT already in page_links pointing at
 * `pageId`. Reuses the existing FTS column (content_tsv) with an ILIKE fallback
 * on content_text for robustness; excludes the target itself and soft-deleted
 * pages. No index — bounded by the workspace's page count, run on panel open.
 */
export async function findUnlinkedMentions(
  db: PostgresJsDatabase<typeof schema>,
  input: { workspaceId: string; pageId: string; title: string },
): Promise<{ id: string; title: string }[]> {
  const title = input.title.trim();
  if (title.length === 0) return [];

  // Sources already linking to this page — excluded from "unlinked".
  const linked = await db
    .select({ sourcePageId: schema.pageLinks.sourcePageId })
    .from(schema.pageLinks)
    .where(eq(schema.pageLinks.targetPageId, input.pageId));
  const linkedIds = [...new Set(linked.map((l) => l.sourcePageId))];

  const where = and(
    eq(schema.pages.workspaceId, input.workspaceId),
    isNull(schema.pages.deletedAt),
    ne(schema.pages.id, input.pageId),
    // FTS match on the title's words; plainto_tsquery handles multi-word titles.
    rawSql`${schema.pages.contentTsv} @@ plainto_tsquery('english', ${title})`,
    linkedIds.length > 0 ? notInArray(schema.pages.id, linkedIds) : undefined,
  );

  return db
    .select({ id: schema.pages.id, title: schema.pages.title })
    .from(schema.pages)
    .where(where)
    .limit(50);
}
```

If multi-word titles miss via `plainto_tsquery`, add an ILIKE fallback on `content_text` (`or(... , ilike(schema.pages.contentText, '%'+title+'%'))`).
```ts
import { randomUUID } from 'node:crypto';
import { eq } from 'drizzle-orm';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import { z } from 'zod';
import * as schema from '@/db/schema';

export const RowTemplateSchema = z.object({
  id: z.string(),
  name: z.string().min(1).max(120),
  cellDefaults: z.record(z.string(), z.unknown()).default({}),
  contentTemplate: z.unknown().optional(),
});
export type RowTemplate = z.infer<typeof RowTemplateSchema>;

type Db = PostgresJsDatabase<typeof schema>;

function readTemplates(config: unknown): RowTemplate[] {
  const parsed = z.object({ rowTemplates: z.array(RowTemplateSchema).default([]) }).safeParse(config ?? {});
  return parsed.success ? parsed.data.rowTemplates : [];
}

export async function listRowTemplates(db: Db, databaseId: string): Promise<RowTemplate[]> {
  const [row] = await db
    .select({ config: schema.databases.config })
    .from(schema.databases)
    .where(eq(schema.databases.id, databaseId))
    .limit(1);
  if (!row) throw new Error('database not found');
  return readTemplates(row.config);
}

async function writeTemplates(db: Db, databaseId: string, templates: RowTemplate[]): Promise<void> {
  const [row] = await db
    .select({ config: schema.databases.config })
    .from(schema.databases)
    .where(eq(schema.databases.id, databaseId))
    .limit(1);
  if (!row) throw new Error('database not found');
  const config = { ...((row.config as Record<string, unknown>) ?? {}), rowTemplates: templates };
  await db.update(schema.databases).set({ config: config as never }).where(eq(schema.databases.id, databaseId));
}

export async function addRowTemplate(
  db: Db,
  input: { databaseId: string; template: Omit<RowTemplate, 'id'> },
): Promise<RowTemplate> {
  const template = RowTemplateSchema.parse({ ...input.template, id: randomUUID() });
  const existing = await listRowTemplates(db, input.databaseId);
  await writeTemplates(db, input.databaseId, [...existing, template]);
  return template;
}

export async function removeRowTemplate(
  db: Db,
  input: { databaseId: string; templateId: string },
): Promise<void> {
  const existing = await listRowTemplates(db, input.databaseId);
  await writeTemplates(
    db,
    input.databaseId,
    existing.filter((t) => t.id !== input.templateId),
  );
}

/** The seed a "new row from template" produces: cell values + an optional doc. */
export function applyRowTemplate(template: RowTemplate): {
  cells: Record<string, unknown>;
  content?: unknown;
} {
  return { cells: { ...template.cellDefaults }, content: template.contentTemplate };
}
```
