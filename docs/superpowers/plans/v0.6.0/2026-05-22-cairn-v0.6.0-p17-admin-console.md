# Cairn v0.6.0 P17 — Workspace admin console + transfer/delete + settings

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the workspace admin console: a `requireRole('admin')`-gated route group (`/(app)/settings/admin`) with members/roles management, invites management, and workspace settings (name, icon, default-role, `require_2fa`, `home_page_id`). Add two owner-only server actions/routes that close the v0.2.0 sole-owner follow-ups — **transfer ownership** and **delete workspace** — each calling a `recordAudit(tx, …)` helper introduced here as a stub (P18 fully wires it). This plan **owns migration `0020`**, which lands all of `require_2fa`/`home_page_id` plus the `audit_log` and `user_totp` tables in ONE migration so that P18 (audit log + activity feed) and P19 (TOTP 2FA) add **no migration of their own**.

**Architecture:** The admin console lives under `src/app/(app)/settings/admin/*`, gated at the layout by `requireRole('admin')` (404/redirect for lower roles). Members/roles/invites reuse the existing membership helpers (`src/lib/workspaces/members.ts`, `list.ts`, the v0.2.0 invite path) plus two new role-mutation helpers (`setMemberRole`, `removeMember`) — all db-injected, unit-testable without HTTP. Workspace settings are one server action over `workspaces` columns (existing `name`/`icon`/`default_role` + the new `require_2fa`/`home_page_id`). **Transfer ownership** (`transferOwnership`) and **delete workspace** (`deleteWorkspace`) are new owner-only helpers in `src/lib/workspaces/*`: transfer demotes the current owner to `admin` and promotes a target member to `owner` in one transaction; delete cascades the whole workspace after a typed-confirmation. Both call `recordAudit(tx, …)` *inside their transaction*. `recordAudit` is introduced here as a thin insert into `audit_log` (P18 expands its action vocabulary, viewer, and per-page feed). The two helpers retire the SOLE_OWNER dead-end from `leaveWorkspace`: an owner who is alone now has a path (transfer then leave, or delete).

**Tech Stack:** Next.js 16 App Router (React 19 server actions + route handlers), Drizzle 0.45 (transactions, self-FK to `pages`), Zod 4, Auth.js v5 (`getAuthContext`/`requireRole`), Vitest 4 + Testcontainers 12, Biome 2, pnpm.

**Spec:** `docs/superpowers/specs/2026-05-22-cairn-v0.6.0-design.md` (§2.27 audit log, §2.29 TOTP table, §2.30 `require_2fa`, §2.40 `home_page_id`, §3 "Admin console", §4 migration `0020`, §5 "Admin / observability / ops").

## Resolved design decisions (made here, not left open)

1. **`recordAudit` is a real (if minimal) insert, not a no-op.** Even though P18 owns the viewer + the full action vocabulary, this plan writes genuine `audit_log` rows at the transfer/delete sites so the rows exist the moment those actions ship. The helper is intentionally thin: `recordAudit(tx, {workspaceId, actorUserId, action, targetType?, targetId?, metadata?, ip?})` → one insert. P18 extends *callers* and adds the read side; it does not need to change this signature. The metadata for transfer/delete carries only ids/role-names (`{fromUserId, toUserId}` / `{name}`) — **never secrets** (spec §2.27).

2. **Transfer ownership demotes the old owner to `admin` (does not remove them).** `transferOwnership(db, {workspaceId, fromUserId, toUserId})` requires `fromUserId` to currently be an `owner` and `toUserId` to be an existing member; in one transaction it sets `toUserId.role = 'owner'` and `fromUserId.role = 'admin'`. Rationale: the previous owner keeps high access and can still administer or leave afterward — and "transfer then leave" is now the documented escape from the v0.2.0 SOLE_OWNER block. Errors via a typed `TransferError` (`NOT_OWNER` / `TARGET_NOT_MEMBER` / `TARGET_ALREADY_OWNER`).

3. **Delete workspace is a hard cascade behind a typed-confirmation, owner-only.** `deleteWorkspace(db, {workspaceId, actorUserId, confirmName})` requires the caller to be an `owner` and `confirmName` to exactly equal the workspace's current `name` (the typed-confirm guard lives in the helper so the route stays thin and the rule is unit-tested). It records the audit row, then deletes the `workspaces` row; all child rows (`workspace_members`, `pages`, databases, invites, …) drop via their existing `ON DELETE CASCADE` FKs. Errors via a typed `DeleteError` (`NOT_OWNER` / `NAME_MISMATCH`).

4. **`audit_log.action` is a free-text column (no DB enum).** Spec §2.27 lists an "enum-like set" but stores `action text NOT NULL`; a TS union type (`AuditAction`) documents the values at the type layer without a migration-coupled Postgres enum (so P18+ can add actions without `ALTER TYPE`). This plan uses `workspace.ownership_transferred` and `workspace.deleted`.

5. **`require_2fa` toggle is gated, not enforced here.** This plan adds the column + the settings checkbox + persists it. Spec §2.30's enforcement at the auth/session boundary and the "owner must have 2FA enabled before enabling the requirement" guard are **P19's** job (they need `user_totp`, also created here). The settings form persists `require_2fa` as a plain boolean; no enforcement wiring in P17.

6. **`home_page_id` is a nullable self-reference to `pages`, validated to belong to the workspace.** The settings action, when `home_page_id` is non-null, verifies the page exists, is not soft-deleted, and is in this workspace (else 400) before persisting. `ON DELETE SET NULL` (spec §4) means deleting the home page silently clears the setting.

7. **Members/roles/invites helpers reuse v0.2.0, plus two mutations.** Listing reuses `listUserWorkspaces`/`searchWorkspaceMembers` shapes; this plan adds `listWorkspaceMembers(db, workspaceId)` (all members + user name/email/role, for the table), `setMemberRole(db, {workspaceId, actorUserId, targetUserId, role})` (admin+; cannot demote the last owner; cannot set `owner` via this path — promotion to owner goes through transfer), and `removeMember(db, {workspaceId, actorUserId, targetUserId})` (admin+; cannot remove an owner; cannot remove yourself — use leave). Invite create/revoke/list reuse the existing v0.2.0 invite helpers/routes; the admin UI is a new surface over them (no new invite helper unless the existing one lacks `listInvites`/`revokeInvite` — Task 3 reads the invite module first and only adds what's missing).

import { and, eq } from 'drizzle-orm';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import * as schema from '@/db/schema';

export type AdminMemberErrorCode =
  | 'CANNOT_SET_OWNER'
  | 'LAST_OWNER'
  | 'CANNOT_REMOVE_OWNER'
  | 'CANNOT_REMOVE_SELF'
  | 'TARGET_NOT_MEMBER';

export class AdminMemberError extends Error {
  constructor(
    public code: AdminMemberErrorCode,
    message: string,
  ) {
    super(message);
  }
}

export type WorkspaceMemberRow = {
  userId: string;
  name: string;
  email: string;
  image: string | null;
  role: schema.MemberRole;
  joinedAt: Date;
};

/** Every member of a workspace with their user identity + role (admin table). */
export async function listWorkspaceMembers(
  db: PostgresJsDatabase<typeof schema>,
  workspaceId: string,
): Promise<WorkspaceMemberRow[]> {
  return db
    .select({
      userId: schema.users.id,
      name: schema.users.name,
      email: schema.users.email,
      image: schema.users.image,
      role: schema.workspaceMembers.role,
      joinedAt: schema.workspaceMembers.joinedAt,
    })
    .from(schema.workspaceMembers)
    .innerJoin(schema.users, eq(schema.users.id, schema.workspaceMembers.userId))
    .where(eq(schema.workspaceMembers.workspaceId, workspaceId))
    .orderBy(schema.users.name);
}

/**
 * Change a member's role. Cannot set `owner` (promotion to owner goes through
 * transferOwnership), and cannot demote the last remaining owner.
 * Caller must already be authorized as admin+ at the route layer.
 */
export async function setMemberRole(
  db: PostgresJsDatabase<typeof schema>,
  input: { workspaceId: string; actorUserId: string; targetUserId: string; role: schema.MemberRole },
): Promise<void> {
  if (input.role === 'owner') {
    throw new AdminMemberError('CANNOT_SET_OWNER', 'Use transfer ownership to make someone an owner');
  }
  await db.transaction(async (tx) => {
    const members = await tx
      .select({ userId: schema.workspaceMembers.userId, role: schema.workspaceMembers.role })
      .from(schema.workspaceMembers)
      .where(eq(schema.workspaceMembers.workspaceId, input.workspaceId));

    const target = members.find((m) => m.userId === input.targetUserId);
    if (!target) throw new AdminMemberError('TARGET_NOT_MEMBER', 'Not a member of that workspace');

    if (target.role === 'owner') {
      const owners = members.filter((m) => m.role === 'owner');
      if (owners.length === 1) {
        throw new AdminMemberError('LAST_OWNER', 'Cannot demote the only owner; transfer ownership first');
      }
    }

    await tx
      .update(schema.workspaceMembers)
      .set({ role: input.role })
      .where(
        and(
          eq(schema.workspaceMembers.workspaceId, input.workspaceId),
          eq(schema.workspaceMembers.userId, input.targetUserId),
        ),
      );
  });
}

/**
 * Remove another member. Cannot remove an owner (transfer first) and cannot
 * remove yourself (use leaveWorkspace). Caller must be admin+ at the route layer.
 */
export async function removeMember(
  db: PostgresJsDatabase<typeof schema>,
  input: { workspaceId: string; actorUserId: string; targetUserId: string },
): Promise<void> {
  if (input.actorUserId === input.targetUserId) {
    throw new AdminMemberError('CANNOT_REMOVE_SELF', 'Use leave to remove your own membership');
  }
  await db.transaction(async (tx) => {
    const [target] = await tx
      .select({ role: schema.workspaceMembers.role })
      .from(schema.workspaceMembers)
      .where(
        and(
          eq(schema.workspaceMembers.workspaceId, input.workspaceId),
          eq(schema.workspaceMembers.userId, input.targetUserId),
        ),
      )
      .limit(1);
    if (!target) throw new AdminMemberError('TARGET_NOT_MEMBER', 'Not a member of that workspace');
    if (target.role === 'owner') {
      throw new AdminMemberError('CANNOT_REMOVE_OWNER', 'Cannot remove an owner; transfer ownership first');
    }
    await tx
      .delete(schema.workspaceMembers)
      .where(
        and(
          eq(schema.workspaceMembers.workspaceId, input.workspaceId),
          eq(schema.workspaceMembers.userId, input.targetUserId),
        ),
      );
  });
}

import { NextResponse } from 'next/server';
import { z } from 'zod';
import { getDb } from '@/db/client';
import { HttpError, requireRole } from '@/lib/auth/require-role';
import {
  AdminMemberError,
  removeMember,
  setMemberRole,
} from '@/lib/workspaces/admin-members';

const RoleBody = z.object({ role: z.enum(['viewer', 'editor', 'admin', 'owner']) });

function mapAdminError(err: AdminMemberError): Response {
  const status =
    err.code === 'TARGET_NOT_MEMBER'
      ? 404
      : err.code === 'CANNOT_SET_OWNER' || err.code === 'CANNOT_REMOVE_SELF'
        ? 400
        : 409; // LAST_OWNER / CANNOT_REMOVE_OWNER
  return NextResponse.json({ error: err.message, code: err.code }, { status });
}

export async function PATCH(
  req: Request,
  { params }: { params: Promise<{ id: string; userId: string }> },
): Promise<Response> {
  try {
    const { id, userId } = await params;
    const ctx = await requireRole('admin'); // active workspace + admin+
    if (ctx.workspaceId !== id) throw new HttpError(404, 'Workspace not found');
    const { role } = RoleBody.parse(await req.json().catch(() => ({})));
    await setMemberRole(getDb(), {
      workspaceId: id,
      actorUserId: ctx.userId,
      targetUserId: userId,
      role,
    });
    return NextResponse.json({ ok: true }, { status: 200 });
  } catch (err) {
    return toResponse(err);
  }
}

export async function DELETE(
  _req: Request,
  { params }: { params: Promise<{ id: string; userId: string }> },
): Promise<Response> {
  try {
    const { id, userId } = await params;
    const ctx = await requireRole('admin');
    if (ctx.workspaceId !== id) throw new HttpError(404, 'Workspace not found');
    await removeMember(getDb(), { workspaceId: id, actorUserId: ctx.userId, targetUserId: userId });
    return NextResponse.json({ ok: true }, { status: 200 });
  } catch (err) {
    return toResponse(err);
  }
}

function toResponse(err: unknown): Response {
  if (err instanceof AdminMemberError) return mapAdminError(err);
  if (err instanceof HttpError) return NextResponse.json({ error: err.message }, { status: err.status });
  if (err instanceof z.ZodError) return NextResponse.json({ error: 'validation', issues: err.issues }, { status: 400 });
  return NextResponse.json({ error: err instanceof Error ? err.message : 'unknown' }, { status: 500 });
}

import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import * as schema from '@/db/schema';

export type SettingsErrorCode = 'EMPTY_NAME' | 'HOME_PAGE_NOT_IN_WORKSPACE';

export class SettingsError extends Error {
  constructor(
    public code: SettingsErrorCode,
    message: string,
  ) {
    super(message);
  }
}

export type UpdateWorkspaceSettingsInput = {
  workspaceId: string;
  name?: string;
  icon?: string | null;
  defaultRole?: schema.MemberRole;
  requireTwofa?: boolean;
  // undefined = leave unchanged; null = clear; string = set (validated).
  homePageId?: string | null;
};

/**
 * Persist admin-editable workspace settings. Validates a non-empty name and that
 * any non-null home_page_id is a live page in THIS workspace. Does NOT enforce
 * require_2fa — that gate is P19 (it needs user_totp + the owner-has-2FA guard).
 */
export async function updateWorkspaceSettings(
  db: PostgresJsDatabase<typeof schema>,
  input: UpdateWorkspaceSettingsInput,
): Promise<void> {
  if (input.name !== undefined && input.name.trim().length === 0) {
    throw new SettingsError('EMPTY_NAME', 'Workspace name cannot be empty');
  }

  await db.transaction(async (tx) => {
    if (input.homePageId) {
      const [p] = await tx
        .select({ id: schema.pages.id })
        .from(schema.pages)
        .where(
          and(
            eq(schema.pages.id, input.homePageId),
            eq(schema.pages.workspaceId, input.workspaceId),
            isNull(schema.pages.deletedAt),
          ),
        )
        .limit(1);
      if (!p) throw new SettingsError('HOME_PAGE_NOT_IN_WORKSPACE', 'Home page must be a live page in this workspace');
    }

    const patch: Partial<typeof schema.workspaces.$inferInsert> = {};
    if (input.name !== undefined) patch.name = input.name.trim();

    if (input.defaultRole !== undefined) patch.defaultRole = input.defaultRole;
    if (input.requireTwofa !== undefined) patch.requireTwofa = input.requireTwofa;
    if (input.homePageId !== undefined) patch.homePageId = input.homePageId;
    if (Object.keys(patch).length === 0) return;

    await tx.update(schema.workspaces).set(patch).where(eq(schema.workspaces.id, input.workspaceId));
  });
}

import { and, eq } from 'drizzle-orm';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import * as schema from '@/db/schema';
import { recordAudit } from '@/lib/audit/record';

export type TransferErrorCode = 'NOT_OWNER' | 'TARGET_NOT_MEMBER' | 'TARGET_ALREADY_OWNER' | 'SAME_USER';

export class TransferError extends Error {
  constructor(
    public code: TransferErrorCode,
    message: string,
  ) {
    super(message);
  }
}

/**
 * Transfer ownership: promote `toUserId` to owner, demote `fromUserId` to admin,
 * atomically. Records an audit row inside the same transaction. This is the
 * documented escape from the v0.2.0 SOLE_OWNER block (transfer, then leave).
 */
export async function transferOwnership(
  db: PostgresJsDatabase<typeof schema>,
  input: { workspaceId: string; fromUserId: string; toUserId: string; ip?: string | null },
): Promise<void> {
  if (input.fromUserId === input.toUserId) {
    throw new TransferError('SAME_USER', 'Cannot transfer ownership to yourself');
  }
  await db.transaction(async (tx) => {
    const members = await tx
      .select({ userId: schema.workspaceMembers.userId, role: schema.workspaceMembers.role })
      .from(schema.workspaceMembers)
      .where(eq(schema.workspaceMembers.workspaceId, input.workspaceId));

    const from = members.find((m) => m.userId === input.fromUserId);
    if (!from || from.role !== 'owner') throw new TransferError('NOT_OWNER', 'Only an owner can transfer ownership');
    const to = members.find((m) => m.userId === input.toUserId);
    if (!to) throw new TransferError('TARGET_NOT_MEMBER', 'Target is not a member of this workspace');
    if (to.role === 'owner') throw new TransferError('TARGET_ALREADY_OWNER', 'Target is already an owner');

    await tx
      .update(schema.workspaceMembers)
      .set({ role: 'owner' })
      .where(and(eq(schema.workspaceMembers.workspaceId, input.workspaceId), eq(schema.workspaceMembers.userId, input.toUserId)));
    await tx
      .update(schema.workspaceMembers)
      .set({ role: 'admin' })
      .where(and(eq(schema.workspaceMembers.workspaceId, input.workspaceId), eq(schema.workspaceMembers.userId, input.fromUserId)));

    await recordAudit(tx, {
      workspaceId: input.workspaceId,
      actorUserId: input.fromUserId,
      action: 'workspace.ownership_transferred',
      targetType: 'workspace',
      targetId: input.workspaceId,
      metadata: { fromUserId: input.fromUserId, toUserId: input.toUserId },
      ip: input.ip ?? null,
    });
  });
}
