# Cairn v0.6.0 Plan 22 — Search filters + saved searches + reminders + bulk ops + workspace-home

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Layer a **structured search-filter compiler** (author / date-range / type / scope-to-database / search-within-page) onto the existing FTS+trigram query in `src/lib/pages/search.ts`; ship **per-user saved searches** (CRUD over the `saved_searches` table, surfaced in the ⌘K palette + sidebar); materialize **due-date reminders** from database date properties and a cron-able **`reminders:scan`** CLI subcommand that fires polled in-app notifications via the v0.3.0 path; add **bulk operations** (multi-select pages/rows → move / delete / duplicate / tag, plus bulk trash-restore) with a partial-failure report; and wire **workspace-home** (`workspaces.home_page_id`) as the default landing when set. **NO migration in this plan.**

**Architecture:** The filter compiler is a pure function `compileSearchFilters({author?, dateRange?, types?, scopeDatabaseId?})` returning extra SQL `WHERE` fragments that AND onto the existing FTS+trigram CTEs (author = `created_by`, date = `created_at`/`updated_at` range, type = page vs. db-row, scope = restrict to one database's rows) — config-only, no schema. Saved searches are rows in `saved_searches` (`name`, `query`, `filters` jsonb reusing the database filter vocabulary), per-user/private; CRUD lives in `src/lib/search/saved.ts`, exposed at `/api/search/saved` and rendered in the palette + a sidebar section. Reminders are materialized to `reminders` rows on row-create / date-property edit (driven by per-database reminder config in `db_properties.config`), and `scanReminders(now)` — invoked by `pnpm cli reminders:scan` or the opt-in single-instance interval ticker — finds due unfired rows (the partial index makes it cheap), inserts a notification via the v0.3.0 helper, and stamps `fired_at`. Bulk operations are a multi-select layer over the existing per-item helpers, run in **one transaction**, role-checked once up front, returning `{succeeded, failed:[{id, reason}]}`. Workspace-home is a read of `workspaces.home_page_id` in the landing resolver.

**Tech Stack:** Postgres FTS (`websearch_to_tsquery`) + `pg_trgm`, raw `db.execute(rawSql\`...\`)` for the keyset/CTE queries, Drizzle, Zod v4, Next.js 16 route handlers, `cmdk` palette, the v0.3.0 polled notifications path (`src/lib/notifications/`), the existing CLI runner, Vitest 4 + Testcontainers.

**Spec:** `docs/superpowers/specs/2026-05-22-cairn-v0.6.0-design.md` (§2.34 saved searches + filters, §2.35 reminders, §2.36 single-instance ticker ceiling, §2.39 bulk operations, §2.40 workspace-home; §3 "Search" / "Reminders" / "Bulk operations" / workspace-home; §5 "Search" / "Reminders").

```ts
import { sql as rawSql } from 'drizzle-orm';
import type { SQL } from 'drizzle-orm';
// ...existing imports...

const UUID_RE = /^[0-9a-f-]{36}$/i;

export type SearchFilters = {
  author?: string;
  dateRange?: { from?: string; to?: string };
  types?: ('page' | 'db_row')[];
  scopeDatabaseId?: string;
};

/**
 * Compile structured search filters into SQL fragments that AND onto the
 * existing FTS/trigram WHERE clauses. Pure + config-only — no schema change.
 * Every interpolated id is UUID-validated to defend the raw-SQL boundary
 * (mirrors getBreadcrumbs).
 */
export function compileSearchFilters(filters: SearchFilters): SQL[] {
  const frags: SQL[] = [];
  if (filters.author) {
    if (!UUID_RE.test(filters.author)) throw new Error(`invalid author uuid: ${filters.author}`);
    frags.push(rawSql`created_by = ${filters.author}::uuid`);
  }
  if (filters.dateRange?.from) {
    frags.push(rawSql`created_at >= ${filters.dateRange.from}::timestamptz`);
  }
  if (filters.dateRange?.to) {
    frags.push(rawSql`created_at <= ${filters.dateRange.to}::timestamptz`);
  }
  if (filters.types && filters.types.length > 0) {
    // 'db_row' = a page linked to a database row; 'page' = not. Adapt the
    // column to the real schema discovered in Step 1 (e.g. database_id).
    const wantsRow = filters.types.includes('db_row');
    const wantsPage = filters.types.includes('page');
    if (wantsRow && !wantsPage) frags.push(rawSql`database_id IS NOT NULL`);
    else if (wantsPage && !wantsRow) frags.push(rawSql`database_id IS NULL`);
  }
  if (filters.scopeDatabaseId) {
    if (!UUID_RE.test(filters.scopeDatabaseId)) {
      throw new Error(`invalid scopeDatabaseId uuid: ${filters.scopeDatabaseId}`);
    }
    frags.push(rawSql`database_id = ${filters.scopeDatabaseId}::uuid`);
  }
  return frags;
}

/** AND a list of fragments into a single clause (or TRUE when empty). */
function andAll(frags: SQL[]): SQL {
  if (frags.length === 0) return rawSql`true`;
  return frags.reduce((acc, f) => rawSql`${acc} AND ${f}`);
}
```

Add `filters?: SearchFilters` to `SearchPagesInput`, and inside `searchPages` build `const extra = andAll(compileSearchFilters(input.filters ?? {}));` then interpolate `AND ${extra}` into each CTE's `WHERE` (after the existing `workspace_id` / `deleted_at` / `@@`/`similarity` conditions). With no filters `extra` is `true`, leaving today's behavior unchanged.

```ts
import { and, desc, eq } from 'drizzle-orm';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import * as schema from '@/db/schema';
import type { SearchFilters } from '@/lib/pages/search';

type Db = PostgresJsDatabase<typeof schema>;

export type CreateSavedSearchInput = {
  workspaceId: string;
  userId: string;
  name: string;
  query: string;
  filters: SearchFilters;
};

export async function createSavedSearch(
  db: Db,
  input: CreateSavedSearchInput,
): Promise<schema.SavedSearch> {
  const [row] = await db
    .insert(schema.savedSearches)
    .values({
      workspaceId: input.workspaceId,
      userId: input.userId,
      name: input.name,
      query: input.query,
      filters: input.filters,
    })
    .returning();
  if (!row) throw new Error('failed to create saved search');
  return row;
}

export async function listSavedSearches(
  db: Db,
  input: { workspaceId: string; userId: string },
): Promise<schema.SavedSearch[]> {
  return db
    .select()
    .from(schema.savedSearches)
    .where(
      and(
        eq(schema.savedSearches.workspaceId, input.workspaceId),
        eq(schema.savedSearches.userId, input.userId),
      ),
    )
    .orderBy(desc(schema.savedSearches.createdAt));
}

export async function updateSavedSearch(
  db: Db,
  input: { id: string; userId: string; name?: string; query?: string; filters?: SearchFilters },
): Promise<schema.SavedSearch> {
  const patch: Partial<typeof schema.savedSearches.$inferInsert> = {};
  if (input.name !== undefined) patch.name = input.name;
  if (input.query !== undefined) patch.query = input.query;
  if (input.filters !== undefined) patch.filters = input.filters;
  const [row] = await db
    .update(schema.savedSearches)
    .set(patch)
    // owner-scoped: the userId predicate prevents cross-user mutation.
    .where(
      and(eq(schema.savedSearches.id, input.id), eq(schema.savedSearches.userId, input.userId)),
    )
    .returning();
  if (!row) throw new Error('saved search not found or not owned by user');
  return row;
}

export async function deleteSavedSearch(
  db: Db,
  input: { id: string; userId: string },
): Promise<void> {
  const deleted = await db
    .delete(schema.savedSearches)
    .where(
      and(eq(schema.savedSearches.id, input.id), eq(schema.savedSearches.userId, input.userId)),
    )
    .returning({ id: schema.savedSearches.id });
  if (deleted.length === 0) throw new Error('saved search not found or not owned by user');
}
```

```ts
import { and, eq } from 'drizzle-orm';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import * as schema from '@/db/schema';

type Db = PostgresJsDatabase<typeof schema>;

type ReminderConfig = { datePropertyId: string; leadTime: number };

/**
 * Materialize (create/update/remove) the reminders row(s) for a single db row,
 * driven by the per-database reminder config in db_properties.config jsonb.
 * Idempotent per (row_id, property_id): re-running on a date edit updates
 * remind_at in place; clearing the date deletes the reminder. No notification
 * is fired here — scanReminders (Task 4) does that.
 */
export async function materializeReminders(
  db: Db,
  input: { workspaceId: string; databaseId: string; rowId: string },
): Promise<void> {
  // 1. Load the date property whose config carries a reminder spec.
  const props = await db
    .select()
    .from(schema.dbProperties)
    .where(eq(schema.dbProperties.databaseId, input.databaseId));

  const reminderProps = props
    .map((p) => ({ p, cfg: (p.config as { reminder?: ReminderConfig } | null)?.reminder }))
    .filter((x): x is { p: schema.DbProperty; cfg: ReminderConfig } => Boolean(x.cfg));

  for (const { cfg } of reminderProps) {
    const [cell] = await db
      .select()
      .from(schema.dbCells)
      .where(
        and(
          eq(schema.dbCells.rowId, input.rowId),
          eq(schema.dbCells.propertyId, cfg.datePropertyId),
        ),
      );

    const raw = cell?.value as string | null | undefined;
    // No date → ensure no stale reminder remains.
    if (!raw) {
      await db
        .delete(schema.reminders)
        .where(
          and(
            eq(schema.reminders.rowId, input.rowId),
            eq(schema.reminders.propertyId, cfg.datePropertyId),
          ),
        );
      continue;
    }

    const remindAt = new Date(new Date(raw).getTime() - cfg.leadTime);
    const userId = await resolveTarget(db, input);

    // Upsert keyed on (row_id, property_id). Delete-then-insert keeps it simple
    // and correct (no partial unique index assumed across schema variants).
    await db
      .delete(schema.reminders)
      .where(
        and(
          eq(schema.reminders.rowId, input.rowId),
          eq(schema.reminders.propertyId, cfg.datePropertyId),
        ),
      );
    await db.insert(schema.reminders).values({
      workspaceId: input.workspaceId,
      databaseId: input.databaseId,
      propertyId: cfg.datePropertyId,
      rowId: input.rowId,
      userId,
      remindAt,
    });
  }
}

/** Assignee from a `person` property if present, else the row's page creator. */
async function resolveTarget(
  db: Db,
  input: { databaseId: string; rowId: string },
): Promise<string> {
  const props = await db
    .select()
    .from(schema.dbProperties)
    .where(eq(schema.dbProperties.databaseId, input.databaseId));
  const personProp = props.find((p) => p.type === 'person');
  if (personProp) {
    const [cell] = await db
      .select()
      .from(schema.dbCells)
      .where(
        and(eq(schema.dbCells.rowId, input.rowId), eq(schema.dbCells.propertyId, personProp.id)),
      );
    const assignee = cell?.value as string | null | undefined;
    if (assignee) return assignee;
  }
  // Fallback: the row's page creator (db rows are pages — read created_by).
  const [page] = await db
    .select({ createdBy: schema.pages.createdBy })
    .from(schema.pages)
    .where(eq(schema.pages.id, input.rowId));
  if (!page) throw new Error(`row ${input.rowId} has no backing page`);
  return page.createdBy;
}
```

```ts
import { and, eq, isNull, lte } from 'drizzle-orm';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import * as schema from '@/db/schema';

type Db = PostgresJsDatabase<typeof schema>;

/**
 * Fire polled in-app notifications for every due, unfired reminder, then stamp
 * fired_at so each reminder fires at most once. Served by the partial index
 * `reminders(remind_at) WHERE fired_at IS NULL` (P21's 0021).
 *
 * SINGLE-INSTANCE CEILING: there is no distributed lock for 1.0. Two instances
 * scanning concurrently can double-fire (same ceiling as the backup ticker and
 * single-instance collab — §2.36). Run the scan on exactly one instance, or via
 * external cron. Returns the number of reminders fired.
 */
export async function scanReminders(db: Db, now: Date = new Date()): Promise<number> {
  const due = await db
    .select()
    .from(schema.reminders)
    .where(and(lte(schema.reminders.remindAt, now), isNull(schema.reminders.firedAt)));
  if (due.length === 0) return 0;

  let fired = 0;
  for (const r of due) {
    await db.transaction(async (tx) => {
      await tx.insert(schema.notifications).values({
        userId: r.userId,
        workspaceId: r.workspaceId,
        // Reuse an existing notification type variant; reminder specifics live
        // in payload (no migration in this plan). Align the literal to the real
        // enum discovered in Step 1.
        type: 'reminder' as const,
        payload: {
          reminderId: r.id,
          databaseId: r.databaseId,
          rowId: r.rowId,
          propertyId: r.propertyId,
          remindAt: r.remindAt.toISOString(),
        },
      });
      await tx
        .update(schema.reminders)
        .set({ firedAt: now })
        .where(eq(schema.reminders.id, r.id));
    });
    fired += 1;
  }
  return fired;
}
```

```ts
import { and, eq, inArray, isNotNull, isNull } from 'drizzle-orm';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import * as schema from '@/db/schema';
import { hasMinRole, type MemberRole } from '@/lib/auth/require-role';

type Db = PostgresJsDatabase<typeof schema>;

export type BulkResult = { succeeded: string[]; failed: { id: string; reason: string }[] };
type BulkCtx = { workspaceId: string; userId: string; role: MemberRole; ids: string[] };

/**
 * Run a per-item mutation over a selection inside ONE transaction. Each item is
 * attempted independently; failures are collected (partial-failure report)
 * rather than aborting the batch. Permission is checked once up front via the
 * caller's role; per-item workspace ownership is verified in the predicate.
 */
async function runBulk(
  db: Db,
  ctx: BulkCtx,
  minRole: MemberRole,
  perItem: (tx: Db, id: string) => Promise<void>,
): Promise<BulkResult> {
  if (!hasMinRole(ctx.role, minRole)) {
    throw new Error(`requires role ${minRole}`);
  }
  const result: BulkResult = { succeeded: [], failed: [] };
  await db.transaction(async (tx) => {
    for (const id of ctx.ids) {
      try {
        await perItem(tx as Db, id);
        result.succeeded.push(id);
      } catch (err) {
        result.failed.push({ id, reason: err instanceof Error ? err.message : 'failed' });
      }
    }
  });
  return result;
}

/** Soft-delete (trash) each page that belongs to the workspace and is live. */
export async function bulkTrashPages(db: Db, ctx: BulkCtx): Promise<BulkResult> {
  return runBulk(db, ctx, 'editor', async (tx, id) => {
    const updated = await tx
      .update(schema.pages)
      .set({ deletedAt: new Date() })
      .where(
        and(
          eq(schema.pages.id, id),
          eq(schema.pages.workspaceId, ctx.workspaceId),
          isNull(schema.pages.deletedAt),
        ),
      )
      .returning({ id: schema.pages.id });
    if (updated.length === 0) throw new Error('not found, not in workspace, or already trashed');
  });
}

/** Restore each trashed page in the workspace. */
export async function bulkRestorePages(db: Db, ctx: BulkCtx): Promise<BulkResult> {
  return runBulk(db, ctx, 'editor', async (tx, id) => {
    const updated = await tx
      .update(schema.pages)
      .set({ deletedAt: null })
      .where(
        and(
          eq(schema.pages.id, id),
          eq(schema.pages.workspaceId, ctx.workspaceId),
          isNotNull(schema.pages.deletedAt),
        ),
      )
      .returning({ id: schema.pages.id });
    if (updated.length === 0) throw new Error('not found, not in workspace, or not trashed');
  });
}

/** Move each page under a new parent (or to root when parentId is null). */
export async function bulkMovePages(
  db: Db,
  ctx: BulkCtx & { parentId: string | null },
): Promise<BulkResult> {
  return runBulk(db, ctx, 'editor', async (tx, id) => {
    if (ctx.parentId && ctx.ids.includes(ctx.parentId)) {
      throw new Error('cannot move a page under itself');
    }
    const updated = await tx
      .update(schema.pages)
      .set({ parentId: ctx.parentId })
      .where(and(eq(schema.pages.id, id), eq(schema.pages.workspaceId, ctx.workspaceId)))
      .returning({ id: schema.pages.id });
    if (updated.length === 0) throw new Error('not found or not in workspace');
  });
}
```

```ts
import { and, asc, eq, isNull } from 'drizzle-orm';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import * as schema from '@/db/schema';

type Db = PostgresJsDatabase<typeof schema>;

/**
 * Resolve the page to land on when a workspace is opened:
 *   1. workspaces.home_page_id, if set AND the page is live + in-workspace;
 *   2. (when P19 recents exist) the user's last-visited page;
 *   3. the first (oldest live) page in the workspace;
 *   4. null when the workspace has no live pages.
 */
export async function resolveLandingPage(
  db: Db,
  input: { workspaceId: string; userId: string },
): Promise<string | null> {
  const [ws] = await db
    .select({ homePageId: schema.workspaces.homePageId })
    .from(schema.workspaces)
    .where(eq(schema.workspaces.id, input.workspaceId));

  if (ws?.homePageId) {
    const [home] = await db
      .select({ id: schema.pages.id })
      .from(schema.pages)
      .where(
        and(
          eq(schema.pages.id, ws.homePageId),
          eq(schema.pages.workspaceId, input.workspaceId),
          isNull(schema.pages.deletedAt),
        ),
      );
    if (home) return home.id;
  }

  // TODO(P19): if user_page_prefs.last_visited_at is available, prefer the
  // user's most-recently-visited live page here before the first-page fallback.

  const [first] = await db
    .select({ id: schema.pages.id })
    .from(schema.pages)
    .where(and(eq(schema.pages.workspaceId, input.workspaceId), isNull(schema.pages.deletedAt)))
    .orderBy(asc(schema.pages.createdAt))
    .limit(1);
  return first?.id ?? null;
}
```
