# Cairn v0.6.0 Plan 5 — Blocks pt.2: embed, bookmark, math, same-page synced block

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add four TipTap 3 custom nodes (design §2.4/§2.5, §5 "Editor / content blocks"), each Yjs-serializable, each with a node-view, a slash-menu entry, and a read-only/public variant:

- **`embed`** — an **allowlist-only** sandboxed iframe (YouTube / Vimeo / Figma / GitHub gist / CodeSandbox). Arbitrary iframes are refused (design key decision #4: "allowlist enforced under the CSP, no arbitrary iframes"). A pure URL→provider validator (`src/lib/editor/embed-allowlist.ts`) maps a user-pasted URL to a normalized embeddable `src` + provider id, or rejects it.
- **`bookmark`** — paste a URL → `GET /api/unfurl?url=` (SSRF-guarded by the existing `assertPublicUrl` from `src/lib/webhooks/ssrf.ts`) parses Open-Graph / `<title>` / favicon tags into `{title, description, favicon, image}` **cached in the node's attrs** at insert time (no schema, design §4: "the bookmark unfurl cache stores `{title, description, favicon, image}` in the node's attrs").
- **`math`** — KaTeX inline (`$…$`) + block (`$$…$$`) rendering. New dep `katex` (+ `@types/katex` — KaTeX ships its own types but the dep is added explicitly for clarity; if `pnpm` reports it bundled, drop the `@types` add).
- **`syncedBlock`** — **same-page only** (design key decision #5). A `syncedBlockId` identifies a group; the *source* instance is normal editable content, *mirror* instances (same Yjs doc) render the source's content **read-only and live**. **Cross-page synced blocks are DEFERRED** (need a shared sub-document model — documented limitation).

Each node is audited for Yjs round-trip like the v0.3.0 custom-node check (design §6 "Yjs-safety audit"; the `extensions.ts` header comment is the precedent). Security tests for the embed allowlist validator + the unfurl SSRF **extend the v0.5.1 security suite**.

**Architecture:** Pure, dependency-free validators live in `src/lib/editor/` (`embed-allowlist.ts`, `og-parse.ts`) so they unit-test without a browser or HTTP. The unfurl route `src/app/api/unfurl/route.ts` is a thin authenticated handler: it calls `assertPublicUrl(url)` (reused verbatim from `src/lib/webhooks/ssrf.ts` — DNS-resolves to defeat rebinding, blocks loopback/link-local/private/CGNAT/metadata), fetches with a byte cap + timeout + `redirect: 'manual'` (re-guarding any redirect target), then runs `parseOgTags(html)`. The four TipTap nodes live one-file-each under `src/components/editor/blocks/` with React node-views (the project already uses React node-views for `DatabaseNode`); each is registered in `baseExtensions()` (the editing surface) and a read-only variant set used by `/p/` + `/s/` (design §5: "register in `baseExtensions()` + `publicExtensions()`"). Because `publicExtensions()` does not yet exist in `src/components/editor/extensions.ts` at this point in the v0.6.0 sequence, this plan adds the four nodes to `baseExtensions()` (which the public renderer also consumes via `editable: false`) and gives each node-view an `editor.isEditable`-gated read-only branch — so the same node renders correctly editable in the app and read-only on public pages, with no separate extension list required yet. Slash-menu entries extend the existing `SlashCommand` items. **No migration** — all four nodes store their entire state in ProseMirror attrs (Yjs-safe by construction), so they live inside `pages.content` jsonb with nothing new in the schema.

**Tech Stack:** Next.js 16 (App Router, React 19, client node-views), TipTap 3 (`@tiptap/core` `Node.create`, `ReactNodeViewRenderer`), KaTeX, Node `fetch`/`URL`/`dns`, Zod v4 (route input), Vitest 4 (+ Testcontainers only where a route test needs the auth mock; the validators are pure unit tests). Biome v2.

**Spec:** `docs/superpowers/specs/2026-05-22-cairn-v0.6.0-design.md` — key decisions #4 + #5; §5 "Editor / content blocks"; §4 (bookmark unfurl cache in attrs); §6 (unfurl OG-parser + allowlist embed-URL validator + SSRF tests; Yjs round-trip audit); §8 ("Embeds + unfurl are an SSRF/XSS surface — embeds are allowlist-only and sandboxed; the unfurl endpoint reuses the v0.5.0 SSRF guard").
```ts
/**
 * Pure URL → embeddable-iframe-src resolver for the ALLOWLISTED embed providers.
 * Returns null for anything not on the allowlist (arbitrary iframes are refused,
 * per the v0.6.0 design: "allowlist enforced under the CSP, no arbitrary iframes").
 * No I/O, no React. The returned `src` is always https: and always on a host in
 * EMBED_FRAME_HOSTS, so the iframe can be locked to those origins by the CSP.
 */

export type EmbedProvider = 'youtube' | 'vimeo' | 'figma' | 'gist' | 'codesandbox';

export type ResolvedEmbed = {
  provider: EmbedProvider;
  /** Normalized https embed URL, host ∈ EMBED_FRAME_HOSTS. */
  src: string;
};

/** The exact iframe origins the embed node may load — also the CSP `frame-src` set. */
export const EMBED_FRAME_HOSTS = [
  'https://www.youtube.com',
  'https://player.vimeo.com',
  'https://www.figma.com',
  'https://gist.github.com',
  'https://codesandbox.io',
] as const;

const YT_ID = /^[\w-]{11}$/;

function parse(rawUrl: string): URL | null {
  try {
    const u = new URL(rawUrl);
    return u.protocol === 'https:' ? u : null;
  } catch {
    return null;
  }
}

function youtube(u: URL): ResolvedEmbed | null {
  const host = u.hostname.replace(/^www\./, '');
  let id: string | null = null;
  if (host === 'youtu.be') {
    id = u.pathname.slice(1).split('/')[0] ?? null;
  } else if (host === 'youtube.com') {
    if (u.pathname === '/watch') id = u.searchParams.get('v');
    else if (u.pathname.startsWith('/embed/')) id = u.pathname.slice('/embed/'.length).split('/')[0] ?? null;
    else if (u.pathname.startsWith('/shorts/')) id = u.pathname.slice('/shorts/'.length).split('/')[0] ?? null;
  }
  if (!id || !YT_ID.test(id)) return null;
  return { provider: 'youtube', src: `https://www.youtube.com/embed/${id}` };
}

function vimeo(u: URL): ResolvedEmbed | null {
  if (u.hostname.replace(/^www\./, '') !== 'vimeo.com') return null;
  const id = u.pathname.slice(1).split('/')[0] ?? '';
  if (!/^\d+$/.test(id)) return null;
  return { provider: 'vimeo', src: `https://player.vimeo.com/video/${id}` };
}

function figma(u: URL): ResolvedEmbed | null {
  const host = u.hostname.replace(/^www\./, '');
  if (host !== 'figma.com') return null;
  if (!/^\/(file|proto|design|board)\//.test(u.pathname)) return null;
  const src = `https://www.figma.com/embed?embed_host=cairn&url=${encodeURIComponent(u.toString())}`;
  return { provider: 'figma', src };
}

function gist(u: URL): ResolvedEmbed | null {
  if (u.hostname !== 'gist.github.com') return null;
  // /<user>/<id> → the .pibb embeddable form.
  const parts = u.pathname.split('/').filter(Boolean);
  if (parts.length < 2) return null;
  return { provider: 'gist', src: `https://gist.github.com${u.pathname}.pibb` };
}

function codesandbox(u: URL): ResolvedEmbed | null {
  if (u.hostname.replace(/^www\./, '') !== 'codesandbox.io') return null;
  const m = u.pathname.match(/^\/(?:s|embed)\/([\w-]+)/);
  if (!m?.[1]) return null;
  return { provider: 'codesandbox', src: `https://codesandbox.io/embed/${m[1]}` };
}

const RESOLVERS: Array<(u: URL) => ResolvedEmbed | null> = [youtube, vimeo, figma, gist, codesandbox];

/** Resolve a pasted URL to an embeddable provider/src, or null if not allowlisted. */
export function resolveEmbed(rawUrl: string): ResolvedEmbed | null {
  const u = parse(rawUrl);
  if (!u) return null;
  for (const r of RESOLVERS) {
    const hit = r(u);
    if (hit) return hit;
  }
  return null;
}
```

## Task 2: Embed node + sandboxed read-only iframe node-view

**Goal:** A TipTap 3 `embed` node — an atom (leaf, `atom: true`, `group: 'block'`) carrying `{ provider, src }` attrs only (Yjs-safe: all state is in attrs). Its React node-view renders a **sandboxed** iframe (`sandbox="allow-scripts allow-same-origin allow-popups"`, `referrerpolicy="no-referrer"`, `loading="lazy"`) whose `src` is the already-normalized allowlisted URL; an unresolved/empty node shows a paste-a-URL prompt (editable only — `editor.isEditable`). The same node-view renders on public pages (the editor is `editable: false` there), so the iframe is read-only by construction. Insertion uses `resolveEmbed` so the node never receives a non-allowlisted `src`.

```tsx
import { Node, mergeAttributes } from '@tiptap/core';
import { NodeViewWrapper, ReactNodeViewRenderer } from '@tiptap/react';
import { useState } from 'react';
import type { NodeViewProps } from '@tiptap/react';
import { resolveEmbed } from '@/lib/editor/embed-allowlist';

declare module '@tiptap/core' {
  interface Commands<ReturnType> {
    embed: {
      /** Insert an embed from a pasted URL; no-op if the URL is not allowlisted. */
      setEmbed: (rawUrl: string) => ReturnType;
    };
  }
}

function EmbedView({ node, editor, updateAttributes }: NodeViewProps) {
  const provider = node.attrs.provider as string | null;
  const src = node.attrs.src as string | null;
  const [draft, setDraft] = useState('');

  if (src && provider) {
    return (
      <NodeViewWrapper className="my-3" data-embed-provider={provider}>
        <div className="relative w-full overflow-hidden rounded-md border" style={{ aspectRatio: '16 / 9' }}>
          <iframe
            src={src}
            title={`${provider} embed`}
            className="absolute inset-0 h-full w-full"
            sandbox="allow-scripts allow-same-origin allow-popups allow-forms"
            referrerPolicy="no-referrer"
            loading="lazy"
            allow="fullscreen; clipboard-write; encrypted-media"
          />
        </div>
      </NodeViewWrapper>
    );
  }

  if (!editor.isEditable) {
    return (
      <NodeViewWrapper className="my-3 rounded-md border p-3 text-sm text-muted-foreground">
        Empty embed.
      </NodeViewWrapper>
    );
  }

  return (
    <NodeViewWrapper className="my-3 rounded-md border p-3">
      <div className="flex items-center gap-2">
        <input
          value={draft}
          onChange={(e) => setDraft(e.target.value)}
          placeholder="Paste a YouTube, Vimeo, Figma, gist, or CodeSandbox URL"
          className="flex-1 rounded border bg-background px-2 py-1 text-sm"
        />
        <button
          type="button"
          onClick={() => {
            const resolved = resolveEmbed(draft.trim());
            if (resolved) updateAttributes({ provider: resolved.provider, src: resolved.src });
          }}
          className="rounded bg-accent px-2 py-1 text-sm font-medium hover:bg-accent/80"
        >
          Embed
        </button>
      </div>
      <p className="mt-1 text-[11px] text-muted-foreground">
        Only allowlisted providers can be embedded.
      </p>
    </NodeViewWrapper>
  );
}

export const Embed = Node.create({
  name: 'embed',
  group: 'block',
  atom: true,
  selectable: true,
  draggable: true,

  addAttributes() {
    return {
      provider: { default: null },
      src: { default: null },
    };
  },

  parseHTML() {
    return [{ tag: 'div[data-embed-provider]' }];
  },

  renderHTML({ HTMLAttributes }) {
    return ['div', mergeAttributes(HTMLAttributes, { 'data-embed-provider': HTMLAttributes.provider })];
  },

  addNodeView() {
    return ReactNodeViewRenderer(EmbedView);
  },

  addCommands() {
    return {
      setEmbed:
        (rawUrl) =>
        ({ commands }) => {
          const resolved = resolveEmbed(rawUrl);
          if (!resolved) return false;
          return commands.insertContent({
            type: this.name,
            attrs: { provider: resolved.provider, src: resolved.src },
          });
        },
    };
  },
});
```

```ts
/**
 * Hand-rolled Open-Graph / <title> / favicon extractor. Pure (string in, object
 * out) so it unit-tests without a browser. Deliberately tolerant: it scans the
 * head with targeted regex rather than a full HTML parser to keep the dependency
 * surface zero and the byte cost predictable. The caller (the /api/unfurl route)
 * is responsible for the SSRF guard + byte cap before this ever sees a string.
 */

export type Unfurled = {
  title: string | null;
  description: string | null;
  image: string | null;
  favicon: string;
};

function decodeEntities(s: string): string {
  return s
    .replace(/&amp;/g, '&')
    .replace(/&lt;/g, '<')
    .replace(/&gt;/g, '>')
    .replace(/&quot;/g, '"')
    .replace(/&#0?39;/g, "'")
    .replace(/&#x27;/gi, "'")
    .replace(/&apos;/g, "'")
    .replace(/&nbsp;/g, ' ');
}

/** First `content` of a `<meta property|name="key">` (order: property then name). */
function meta(html: string, key: string): string | null {
  const re = new RegExp(
    `<meta[^>]+(?:property|name)=["']${key.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')}["'][^>]*>`,
    'i',
  );
  const tag = html.match(re)?.[0];
  if (!tag) return null;
  const content = tag.match(/content=["']([^"']*)["']/i)?.[1];
  return content ? decodeEntities(content.trim()) : null;
}

function resolve(href: string | null, baseUrl: string): string | null {
  if (!href) return null;
  try {
    return new URL(href, baseUrl).toString();
  } catch {
    return null;
  }
}

export function parseOgTags(html: string, baseUrl: string): Unfurled {
  const titleTag = html.match(/<title[^>]*>([\s\S]*?)<\/title>/i)?.[1];
  const title = meta(html, 'og:title') ?? (titleTag ? decodeEntities(titleTag.trim()) : null);
  const description = meta(html, 'og:description') ?? meta(html, 'description');
  const image = resolve(meta(html, 'og:image'), baseUrl);

  const iconHref = html
    .match(/<link[^>]+rel=["'][^"']*icon[^"']*["'][^>]*>/i)?.[0]
    ?.match(/href=["']([^"']*)["']/i)?.[1];
  const favicon = resolve(iconHref ?? null, baseUrl) ?? resolve('/favicon.ico', baseUrl) ?? baseUrl;

  return { title, description, image, favicon };
}
```

```ts
import { NextResponse } from 'next/server';
import { z } from 'zod';
import { getAuthContext } from '@/lib/auth/require-role';
import { parseOgTags } from '@/lib/editor/og-parse';
import { assertPublicUrl } from '@/lib/webhooks/ssrf';

export const runtime = 'nodejs';

const QuerySchema = z.object({ url: z.url() });

const MAX_BYTES = 512 * 1024; // 512 KiB head budget — bookmarks need only <head>.
const TIMEOUT_MS = 5_000;
const MAX_REDIRECTS = 3;

/** Fetch with a manual-redirect loop so EVERY hop is SSRF-re-checked. */
async function guardedFetch(rawUrl: string): Promise<{ html: string; finalUrl: string } | null> {
  let current = rawUrl;
  for (let hop = 0; hop <= MAX_REDIRECTS; hop += 1) {
    await assertPublicUrl(current); // throws on private/loopback/rebind/non-http(s)
    const controller = new AbortController();
    const timer = setTimeout(() => controller.abort(), TIMEOUT_MS);
    let res: Response;
    try {
      res = await fetch(current, {
        method: 'GET',
        redirect: 'manual',
        signal: controller.signal,
        headers: { accept: 'text/html', 'user-agent': 'cairn-unfurl/1.0' },
      });
    } finally {
      clearTimeout(timer);
    }
    if (res.status >= 300 && res.status < 400) {
      const loc = res.headers.get('location');
      if (!loc) return null;
      current = new URL(loc, current).toString();
      continue;
    }
    if (!res.ok) return null;
    const ctype = res.headers.get('content-type') ?? '';
    if (!ctype.includes('text/html') && !ctype.includes('application/xhtml')) return null;
    // Read at most MAX_BYTES.
    const reader = res.body?.getReader();
    if (!reader) return null;
    const chunks: Uint8Array[] = [];
    let total = 0;
    for (;;) {
      const { done, value } = await reader.read();
      if (done) break;
      if (value) {
        chunks.push(value);
        total += value.byteLength;
        if (total >= MAX_BYTES) {
          await reader.cancel();
          break;
        }
      }
    }
    const html = new TextDecoder('utf-8').decode(Buffer.concat(chunks.map((c) => Buffer.from(c))));
    return { html, finalUrl: current };
  }
  return null; // too many redirects
}

export async function GET(req: Request): Promise<Response> {
  // Authenticated workspace users only — not an anonymous proxy.
  const ctx = await getAuthContext();
  if (!ctx) return NextResponse.json({ error: 'unauthorized' }, { status: 401 });

  const parsed = QuerySchema.safeParse({ url: new URL(req.url).searchParams.get('url') });
  if (!parsed.success) return NextResponse.json({ error: 'invalid url' }, { status: 400 });

  try {
    const fetched = await guardedFetch(parsed.data.url);
    if (!fetched) return NextResponse.json({ error: 'could not fetch' }, { status: 422 });
    const meta = parseOgTags(fetched.html, fetched.finalUrl);
    return NextResponse.json({ url: parsed.data.url, ...meta });
  } catch (err) {
    // assertPublicUrl throws for blocked/internal hosts → refuse without leaking which.
    return NextResponse.json(
      { error: err instanceof Error ? err.message : 'refused' },
      { status: 400 },
    );
  }
}
```

The security contract is only: **reject anonymous callers, then SSRF-guard the URL.**

```tsx
        />
      </NodeViewWrapper>
    );
```

```tsx
  return (
    <NodeViewWrapper as={display ? 'div' : 'span'} className={display ? 'my-2 block text-center' : 'inline'}>

        dangerouslySetInnerHTML={{ __html: html }}
        onClick={() => editor.isEditable && setEditing(true)}
        className={editor.isEditable ? 'cursor-pointer' : undefined}
      />
    </NodeViewWrapper>
  );
```

## Task 5: Same-page synced block (source + live read-only mirror)

**Goal:** A `syncedBlock` node holding child content and a `syncedBlockId` attr. **Same-page only** (design key decision #5): the **first** instance of a given `syncedBlockId` in the document is the editable *source*; any **later** instance with the same id is a *mirror* that renders the source's current content **read-only** and updates live (they share one Yjs doc, so reading the source node's content each render is live by construction). Inserting a synced block mints a fresh `syncedBlockId`; "turn into mirror" / duplicating the node reuses the id. **Cross-page mirroring is NOT implemented** (deferred — would need a shared sub-document; the node-view shows a clear "mirror of a block on this page" affordance and never reaches across pages).

```tsx
import { Node, mergeAttributes } from '@tiptap/core';
import { NodeViewContent, NodeViewWrapper, ReactNodeViewRenderer } from '@tiptap/react';
import type { Node as PMNode } from '@tiptap/pm/model';
import type { NodeViewProps } from '@tiptap/react';

declare module '@tiptap/core' {
  interface Commands<ReturnType> {
    syncedBlock: {
      /** Insert a NEW synced source block (mints a fresh id). */
      setSyncedBlock: () => ReturnType;
    };
  }
}

function newId(): string {
  return globalThis.crypto?.randomUUID?.() ?? `sb_${Math.random().toString(36).slice(2)}`;
}

/** Find the FIRST node in the doc carrying `syncedBlockId` — that node is the source. */
function findSource(doc: PMNode, id: string, selfPos: number): { node: PMNode; pos: number } | null {
  let found: { node: PMNode; pos: number } | null = null;
  doc.descendants((node, pos) => {
    if (found) return false;
    if (node.type.name === 'syncedBlock' && node.attrs.syncedBlockId === id) {
      found = { node, pos };
      return false;
    }
    return true;
  });
  // A node is the source iff it is the first occurrence (its pos === the found pos).
  if (found && found.pos === selfPos) return null; // I am the source
  return found;
}

function SyncedBlockView({ node, editor, getPos }: NodeViewProps) {
  const id = node.attrs.syncedBlockId as string;
  const selfPos = typeof getPos === 'function' ? getPos() : -1;
  const source = id ? findSource(editor.state.doc, id, selfPos) : null;

  // I am a MIRROR if a source exists at an earlier position.
  if (source) {
    // Render the source's content read-only. We serialize the source node's content
    // to HTML via the editor schema so it reflects the live source on every render
    // (same Yjs doc → re-rendered when the source changes).
    const html = editor.storage; // placeholder access; real impl below
    return (
      <NodeViewWrapper className="my-2 rounded-md border border-dashed bg-muted/20 p-3">
        <div className="mb-1 text-[10px] uppercase tracking-wide text-muted-foreground">
          Synced (mirror)
        </div>
        <div
          className="prose-sm pointer-events-none select-text"
          // The mirror is a live read-only projection of the same-page source's content.
          // biome-ignore lint/security/noDangerouslySetInnerHtml: serialized from the local trusted doc.
          dangerouslySetInnerHTML={{ __html: serializeContent(editor, source.node) }}
        />
        <p className="mt-1 text-[10px] text-muted-foreground">
          Mirror of a synced block above. Edit the source to change both.
        </p>
        {/* satisfy linter for the unused storage access removed in final impl */}
        <span className="hidden">{String(Boolean(html))}</span>
      </NodeViewWrapper>
    );
  }

  // I am the SOURCE: editable content.
  return (
    <NodeViewWrapper className="my-2 rounded-md border-l-2 border-primary/50 bg-primary/5 pl-3">
      <div className="py-1 text-[10px] uppercase tracking-wide text-muted-foreground">Synced</div>
      <NodeViewContent />
    </NodeViewWrapper>
  );
}

/** Serialize a node's content to HTML using the editor's schema (read-only projection). */
function serializeContent(editor: NodeViewProps['editor'], source: PMNode): string {
  const fragmentDiv = document.createElement('div');
  const serializer = editor.view.someProp('clipboardSerializer') as
    | { serializeFragment?: (f: PMNode['content']) => DocumentFragment }
    | undefined;
  if (serializer?.serializeFragment) {
    fragmentDiv.appendChild(serializer.serializeFragment(source.content));
  } else {
    fragmentDiv.textContent = source.textContent;
  }
  return fragmentDiv.innerHTML;
}

export const SyncedBlock = Node.create({
  name: 'syncedBlock',
  group: 'block',
  content: 'block+',
  defining: true,

  addAttributes() {
    return {
      syncedBlockId: { default: null },
    };
  },

  parseHTML() {
    return [{ tag: 'div[data-synced-block-id]' }];
  },

  renderHTML({ HTMLAttributes }) {
    return [
      'div',
      mergeAttributes(HTMLAttributes, { 'data-synced-block-id': HTMLAttributes.syncedBlockId }),
      0,
    ];
  },

  addNodeView() {
    return ReactNodeViewRenderer(SyncedBlockView);
  },

  addCommands() {
    return {
      setSyncedBlock:
        () =>
        ({ commands }) =>
          commands.insertContent({
            type: this.name,
            attrs: { syncedBlockId: newId() },
            content: [{ type: 'paragraph' }],
          }),
    };
  },
});
```

> **Implementation cleanup for the implementer:** the `editor.storage` line + the hidden `<span>` above are a lint-satisfying placeholder — delete them and rely solely on `serializeContent(editor, source.node)`. The mirror re-renders whenever the shared doc changes (the node-view re-runs on transactions), so reading `source.node.content` each render gives the live source content. Keep the mirror `pointer-events-none` so it is non-editable, and never write back to the source from the mirror. If `someProp('clipboardSerializer')` typing is awkward under TS 6 strict, use `DOMSerializer.fromSchema(editor.schema).serializeFragment(source.content)` (import `DOMSerializer` from `@tiptap/pm/model`) — same result, fully typed. **Same-page only:** `findSource` walks `editor.state.doc` exclusively, so there is no cross-page reach (the deferred case).
