# Cairn v0.6.0 Plan P8 — Comments on databases + files

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generalize the v0.3.0 page-comments system to a **polymorphic comment target** so threads can anchor to a database row or an uploaded file as well as a page — workspace-scoped exactly like pages, cross-workspace → 404. Ships migration `0016` (a `comment_target` enum + `target_type`/`target_id` columns on `comments`, back-filling existing rows to `page`/`page_id`), the generalized `src/lib/comments/*` helper layer (create/list/resolve/delete all keyed on `(target_type, target_id)`), the `@mention` + notification fan-out preserved for every target type, new target-scoped API routes for row + file comments, the row/file comment UI, and the `comment.created` webhook firing for **all** target types. Reuses the v0.3.0 comment helpers and the `extractMentions`/`notifyMentions`/`notifyCommentReply` path verbatim.

**Architecture:** v0.3.0 comments anchored to a page via a `page_id` column. This plan adds a `(target_type ∈ {page, db_row, file}, target_id uuid)` polymorphic anchor (spec §2.12, §4 migration `0016`). The existing `page_id` column is **retained** (back-filled, kept NOT NULL for `page` targets and nullable for non-page targets — see the schema note) so v0.3.0's page-scoped queries, the `notifyCommentReply` "prior authors on this page" lookup, and FK cascade-on-page-delete keep working unchanged. For `db_row`/`file` targets, `target_id` references the row/file; `page_id` is the *owning* page of that row's database / that file's `pageId` (nullable for files with no page), denormalized at create time so notification fan-out + the activity model stay page-anchored. Helpers stay pure and db-injected (`db` first arg), mirroring `src/lib/pages/*`. Routes wrap helpers with `requireRole`/`requirePageAccess` and translate `HttpError` to status codes. The webhook `emit('comment.created', ...)` fires fire-and-forget from `createComment` for every target type, mirroring `row.created`/`page.created`.

**Target model (explicit):** `comments.target_type` is the new `comment_target` enum with values **`page` | `db_row` | `file`** (the migration §4 literal set; the spec prose §2.12/§3 calls them page/row/file — the enum string values are `page`/`db_row`/`file`). `comments.target_id uuid` is the id of the page / db_row / file. Resolution per target:
- `page`: `target_id = page_id`; validate `pages` row in the caller's workspace, not soft-deleted (the existing check).
- `db_row`: `target_id = db_rows.id`; validate the row's `databases.workspace_id` matches the caller's workspace; set `page_id = databases.page_id` of the owning database.
- `file`: `target_id = files.id`; validate `files.workspace_id`; set `page_id = files.page_id` (may be null).
Any target not found in the caller's workspace → throws (route → 404), never leaking existence.

**Anchor vs. target (do not conflate):** the existing nullable `anchor` jsonb (`{blockId}` / `{from,to}` / null) is the *intra-document* anchor for `page` targets and stays exactly as in v0.3.0. The new `(target_type, target_id)` is the *thread subject*. A `db_row`/`file` comment has `anchor = null` (no in-doc position); validation rejects a non-null `anchor` when `target_type !== 'page'`.

## Migration number (explicit)

The last migration on disk is `0012_icy_carnage.sql`; v0.6.0 P1–P7 consume `0013`–`0015` (per spec §4: `0013` content/db, `0014` share settings, `0015` public site). **This plan uses `0016`** for the polymorphic-comments change, matching spec §4. The change is **column additions + a new enum + a data back-fill** on the existing `comments` table:

1. `comment_target` is a **new enum** → `CREATE TYPE` is **transactional** (only `ALTER TYPE ADD VALUE` must run outside a txn — the `0011` precedent; this is a fresh `CREATE TYPE`, so no manual split needed).
2. `db:generate` will emit the `CREATE TYPE`, the two `ADD COLUMN`s (with the `DEFAULT 'page'` on `target_type`), and the index. **It will NOT emit the back-fill `UPDATE`** (Drizzle never generates data migrations) — you **append the back-fill SQL by hand** to the generated file (the same hand-edit pattern as the `pages` trigger / `pg_trgm`, per CLAUDE.md). Confirm the number is `0016`; if `db:generate` picks a higher number because an earlier plan added migrations, **use whatever it generates and note the actual number in the commit message**.

The generated + hand-appended `0016_*.sql` must contain, in order:

```sql
-- generated by db:generate (CREATE TYPE is transactional)
CREATE TYPE "public"."comment_target" AS ENUM('page', 'db_row', 'file');
--> statement-breakpoint
ALTER TABLE "comments" ADD COLUMN "target_type" "comment_target" DEFAULT 'page' NOT NULL;
--> statement-breakpoint
ALTER TABLE "comments" ADD COLUMN "target_id" uuid;
--> statement-breakpoint
CREATE INDEX "comments_target_idx" ON "comments" USING btree ("target_type","target_id");
--> statement-breakpoint
-- HAND-APPENDED back-fill: every pre-existing comment is a page comment whose
-- target is its own page. Idempotent (only touches rows still NULL).
UPDATE "comments" SET "target_id" = "page_id" WHERE "target_id" IS NULL;
```

> **Why `target_id` stays nullable in SQL** (not `NOT NULL`): adding a `NOT NULL` column with no default to a populated table fails. We add it nullable, back-fill, and enforce non-null **at the application layer** (`createComment` always sets it). Existing rows are back-filled to `page_id`; new rows always set it. A later migration could `SET NOT NULL` once confirmed clean — out of scope here.

```ts
import { index, jsonb, pgEnum, pgTable, text, timestamp, uuid } from 'drizzle-orm/pg-core';
import type { CommentAnchor } from '@/lib/comments/anchor';
import type { CommentTargetType } from '@/lib/comments/target';
import { pages } from './pages';
import { users } from './users';
import { workspaces } from './workspaces';

export const commentTarget = pgEnum('comment_target', ['page', 'db_row', 'file']);

export const comments = pgTable(
  'comments',
  {
    id: uuid('id').primaryKey().defaultRandom(),
    workspaceId: uuid('workspace_id')
      .notNull()
      .references(() => workspaces.id, { onDelete: 'cascade' }),
    // Retained from v0.3.0: the owning page for `page` targets (= target_id) and
    // the denormalized owning page for `db_row`/`file` targets (nullable for
    // page-less files). Cascade-on-page-delete preserved for page comments.
    pageId: uuid('page_id').references(() => pages.id, { onDelete: 'cascade' }),
    targetType: commentTarget('target_type').$type<CommentTargetType>().notNull().default('page'),
    // Nullable in SQL (back-filled); always set by the app layer. References the
    // page/db_row/file by id; no DB-level FK because it is polymorphic.
    targetId: uuid('target_id'),
    authorId: uuid('author_id')
      .notNull()
      .references(() => users.id, { onDelete: 'restrict' }),
    body: text('body').notNull(),
    anchor: jsonb('anchor').$type<CommentAnchor>(),
    resolvedAt: timestamp('resolved_at', { withTimezone: true }),
    createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
    updatedAt: timestamp('updated_at', { withTimezone: true }).notNull().defaultNow(),
  },
  (t) => ({
    pageIdx: index('comments_page_idx').on(t.pageId),
    workspaceIdx: index('comments_workspace_idx').on(t.workspaceId),
    targetIdx: index('comments_target_idx').on(t.targetType, t.targetId),
  }),
);

export type Comment = typeof comments.$inferSelect;
export type NewComment = typeof comments.$inferInsert;
```

The schema export `index.ts` already does `export * from './comments'`; `commentTarget` is re-exported automatically.

- [ ] **Step 3: Append `resolveTarget` to `src/lib/comments/target.ts`**

```ts
import { and, eq, isNull } from 'drizzle-orm';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import * as schema from '@/db/schema';
import { HttpError } from '@/lib/auth/require-role';

/** Validated target with the page id to denormalize onto the comment row. */
export type ResolvedTarget = { type: CommentTargetType; id: string; pageId: string | null };

/**
 * Validate that `target` exists in `workspaceId` and return the owning page id
 * (= the target id for pages, the owning database's page for rows, the file's
 * page for files — may be null). Cross-workspace / missing → HttpError(404),
 * mirroring requirePageAccess's existence-non-leak rule.
 */
export async function resolveTarget(
  db: PostgresJsDatabase<typeof schema>,
  workspaceId: string,
  target: CommentTarget,
): Promise<ResolvedTarget> {
  if (target.type === 'page') {
    const [page] = await db
      .select({ id: schema.pages.id })
      .from(schema.pages)
      .where(
        and(
          eq(schema.pages.id, target.id),
          eq(schema.pages.workspaceId, workspaceId),
          isNull(schema.pages.deletedAt),
        ),
      )
      .limit(1);
    if (!page) throw new HttpError(404, 'Target not found');
    return { type: 'page', id: page.id, pageId: page.id };
  }

  if (target.type === 'db_row') {
    const [row] = await db
      .select({ rowId: schema.dbRows.id, pageId: schema.databases.pageId })
      .from(schema.dbRows)
      .innerJoin(schema.databases, eq(schema.dbRows.databaseId, schema.databases.id))
```

```ts
import { and, eq, isNull } from 'drizzle-orm';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import * as schema from '@/db/schema';
import { extractMentions } from '@/lib/mentions/parse';
import { notifyCommentReply, notifyMentions } from '@/lib/notifications/create';
import { emit } from '@/lib/webhooks/dispatch';
import { type CommentAnchor, CommentAnchorSchema } from './anchor';
import { type CommentTarget, CommentTargetSchema, resolveTarget } from './target';

export type CreateCommentInput = {
  workspaceId: string;
  authorId: string;
  body: string;
  target: CommentTarget;
  anchor?: CommentAnchor | null;
};

export type CreateCommentResult = {
  comment: schema.Comment;
  mentionedUserIds: string[];
};

export async function createComment(
  db: PostgresJsDatabase<typeof schema>,
  input: CreateCommentInput,
): Promise<CreateCommentResult> {
  const body = input.body.trim();
  if (!body) throw new Error('comment body is required');
  const target = CommentTargetSchema.parse(input.target);

  // anchor only makes sense for an in-document (page) target.
  const anchor = input.anchor == null ? null : CommentAnchorSchema.parse(input.anchor);
  if (anchor != null && target.type !== 'page') {
    throw new Error('anchor is only valid for page comments');
  }

  const mentionedUserIds = extractMentions(body);

  const comment = await db.transaction(async (tx) => {
    // Validates the target in this workspace (throws 404 cross-workspace) and
    // returns the page id to denormalize.
    const resolved = await resolveTarget(tx, input.workspaceId, target);

    const [inserted] = await tx
      .insert(schema.comments)
      .values({
        workspaceId: input.workspaceId,
        pageId: resolved.pageId,
        targetType: resolved.type,
        targetId: resolved.id,
        authorId: input.authorId,
        body,
        anchor,
      })
      .returning();
    if (!inserted) throw new Error('failed to insert comment');

    // Mentions fan out for every target type.
    await notifyMentions(tx, {
      actorId: input.authorId,
      pageId: resolved.pageId ?? resolved.id,
      commentId: inserted.id,
      workspaceId: input.workspaceId,
      mentionedUserIds,
    });
    // Comment-reply fan-out is page-scoped; only meaningful when a page exists.
    if (resolved.pageId) {
      await notifyCommentReply(tx, {
        actorId: input.authorId,
        pageId: resolved.pageId,
        commentId: inserted.id,
        workspaceId: input.workspaceId,
      });
    }

    return inserted;
  });

  // Fire-and-forget for all target types, mirroring row.created/page.created.
  void emit('comment.created', input.workspaceId, {
    id: comment.id,
    targetType: comment.targetType,
    targetId: comment.targetId,
    pageId: comment.pageId,
  });

  return { comment, mentionedUserIds };
}
```

```ts
import { NextResponse } from 'next/server';
import { z } from 'zod';
import { getDb } from '@/db/client';
import { HttpError } from '@/lib/auth/require-role';
import { createComment } from '@/lib/comments/create';
import { listCommentsByTarget } from '@/lib/comments/list';
import { resolveTarget } from '@/lib/comments/target';
import { requirePageAccess } from '@/lib/pages/access';

type RouteCtx = { params: Promise<{ databaseId: string; rowId: string }> };

const PostInput = z.object({ body: z.string().min(1).max(10_000) });

export async function GET(_req: Request, { params }: RouteCtx): Promise<Response> {
  try {
    const { rowId } = await params;
    const db = getDb();
    // Resolve owning page WITHOUT a workspace yet — we need ctx first; instead,
    // gate via the page once known. Use a two-step: look up the row's workspace
    // through requireRole, then resolveTarget validates same-workspace.
    // Simpler: requireRole('viewer') to get ctx, then resolveTarget (404 cross-ws),
    // then requirePageAccess on the resolved page for the row's page-level role.
    const { ctx } = await requirePageAccessForRow(db, rowId, 'viewer');
    const comments = await listCommentsByTarget(db, { type: 'db_row', id: rowId }, ctx.workspaceId);
    return NextResponse.json(comments);
  } catch (err) {
    return errorToResponse(err);
  }
}

export async function POST(req: Request, { params }: RouteCtx): Promise<Response> {
  try {
    const { rowId } = await params;
    const db = getDb();
    const { ctx } = await requirePageAccessForRow(db, rowId, 'editor');
    const parsed = PostInput.parse(await req.json());
    const { comment } = await createComment(db, {
      workspaceId: ctx.workspaceId,
      authorId: ctx.userId,
      body: parsed.body,
      target: { type: 'db_row', id: rowId },
    });
    return NextResponse.json(comment, { status: 201 });
  } catch (err) {
    return errorToResponse(err);
  }
}

/**
 * Gate a row comment by its owning database's page. requireRole resolves the
 * caller's ctx (workspace + role); resolveTarget validates the row is in that
 * workspace (404 otherwise) and yields the page id; requirePageAccess enforces
 * the page-level role. Returns { ctx } with the page-resolved context.
 */
async function requirePageAccessForRow(
  db: ReturnType<typeof getDb>,
  rowId: string,
  role: 'viewer' | 'editor',
) {
  const { requireRole } = await import('@/lib/auth/require-role');
  const base = await requireRole('viewer'); // authenticate + resolve workspace
  const resolved = await resolveTarget(db, base.workspaceId, { type: 'db_row', id: rowId });
  if (resolved.pageId == null) throw new HttpError(404, 'Target not found');
  return requirePageAccess(resolved.pageId, role);
}

function errorToResponse(err: unknown): Response {
  if (err instanceof HttpError) return NextResponse.json({ error: err.message }, { status: err.status });
  if (err instanceof z.ZodError) return NextResponse.json({ error: 'validation', issues: err.issues }, { status: 400 });
  const message = err instanceof Error ? err.message : 'unknown';
  return NextResponse.json({ error: message }, { status: 500 });
}
```

```ts
import { NextResponse } from 'next/server';
import { z } from 'zod';
import { getDb } from '@/db/client';
import { HttpError, requireRole } from '@/lib/auth/require-role';
import { createComment } from '@/lib/comments/create';
import { listCommentsByTarget } from '@/lib/comments/list';
import { resolveTarget } from '@/lib/comments/target';
import { requirePageAccess } from '@/lib/pages/access';

type RouteCtx = { params: Promise<{ fileId: string }> };

const PostInput = z.object({ body: z.string().min(1).max(10_000) });

export async function GET(_req: Request, { params }: RouteCtx): Promise<Response> {
  try {
    const { fileId } = await params;
    const ctx = await gateFile(fileId, 'viewer');
    const comments = await listCommentsByTarget(getDb(), { type: 'file', id: fileId }, ctx.workspaceId);
    return NextResponse.json(comments);
  } catch (err) {
    return errorToResponse(err);
  }
}

export async function POST(req: Request, { params }: RouteCtx): Promise<Response> {
  try {
    const { fileId } = await params;
    const ctx = await gateFile(fileId, 'editor');
    const parsed = PostInput.parse(await req.json());
    const { comment } = await createComment(getDb(), {
      workspaceId: ctx.workspaceId,
      authorId: ctx.userId,
      body: parsed.body,
      target: { type: 'file', id: fileId },
    });
    return NextResponse.json(comment, { status: 201 });
  } catch (err) {
    return errorToResponse(err);
  }
}

/**
 * Gate a file comment: authenticate (requireRole) → resolveTarget (404 if the
 * file isn't in the caller's workspace) → if the file has a page, enforce the
 * page-level role; otherwise the workspace-level role from requireRole suffices.
 * Returns a ctx with { workspaceId, userId, role }.
 */
async function gateFile(fileId: string, role: 'viewer' | 'editor') {
  const base = await requireRole(role);
  const resolved = await resolveTarget(getDb(), base.workspaceId, { type: 'file', id: fileId });
  if (resolved.pageId != null) {
    const { ctx } = await requirePageAccess(resolved.pageId, role);
    return ctx;
  }
  return base;
}

function errorToResponse(err: unknown): Response {
  if (err instanceof HttpError) return NextResponse.json({ error: err.message }, { status: err.status });
  if (err instanceof z.ZodError) return NextResponse.json({ error: 'validation', issues: err.issues }, { status: 400 });
  const message = err instanceof Error ? err.message : 'unknown';
  return NextResponse.json({ error: message }, { status: 500 });
}
```
