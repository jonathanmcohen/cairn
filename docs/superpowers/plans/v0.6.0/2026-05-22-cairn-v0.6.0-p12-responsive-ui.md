# Cairn v0.6.0 Plan 12 — Responsive UI + sidebar drawer

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Cairn usable on a phone. A breakpoint pass on the editor + page header (touch targets, collapsing controls, tighter gutters under `md`); an off-canvas, **focus-trapped** sidebar **drawer** below the `md` breakpoint (a header hamburger toggles it, Escape + backdrop-click close it); and mobile layouts for the database views (table → horizontal scroll on touch, kanban stays swipeable, gallery → single column under `sm`). The reusable `useFocusTrap` hook introduced here is the **one focus-trap utility** the v0.6.0 accessibility plan (P14) reuses for modals/menus — so it is built first, isolated, and unit-tested. Everything else is **pure UI**, build-verified via Tailwind 4 responsive classes. **No migration, no schema, no new node types** — this is mobile presentation only.

**Architecture:** A new `src/lib/a11y/focus-trap.ts` exports `getFocusable(container)` (pure, DOM-query, unit-testable with jsdom) and a `useFocusTrap(active)` React hook that, while `active`, moves focus into a container, wraps `Tab`/`Shift+Tab` at the edges, and restores focus to the previously-focused element on deactivate (decision 24's "one focus-trap utility for modals/menus"). The sidebar (`src/components/sidebar.tsx`, a server component) is split: its body becomes a presentational `SidebarContent` rendered both inline (desktop, `md:` and up) and inside a new client `SidebarDrawer` (`aria-modal` off-canvas panel below `md`) toggled by a `SidebarToggle` hamburger in a thin mobile top bar. The app shell (`src/app/(app)/layout.tsx`) gates the desktop `aside` with `hidden md:flex` and renders the drawer + mobile bar `md:hidden`. The editor page header (`src/app/(app)/pages/[pageId]/page.tsx`) gets responsive gutters and the action cluster wraps under `md`; the editor prose width relaxes on small screens. Database views already use `overflow-x-auto` (table, kanban) and `grid-cols-1 sm:grid-cols-2 lg:grid-cols-3` (gallery) — the pass tightens touch targets and confirms the table scrolls rather than overflowing the viewport. All spacing uses Tailwind 4 logical-friendly classes (`px-`/`gap-`) so the later RTL work (P15) is unaffected.

**Tech Stack:** Next.js 16 (App Router, React 19, client + server components), Tailwind CSS v4 (`@theme` in `globals.css`, responsive `md:`/`sm:` variants), Vitest v4 (+ jsdom for the focus-trap hook/unit test), Biome v2, TypeScript 6 strict, pnpm.

**Spec:** `docs/superpowers/specs/2026-05-22-cairn-v0.6.0-design.md` — decision 24 (one focus-trap utility) + §3 "Mobile, a11y & i18n" (responsive UI: editor breakpoint pass, sidebar off-canvas drawer below `md`, database views adapt, touch targets ≥44px) + §5 "Mobile / PWA" (the sidebar becomes a focus-trapped `aria-modal` drawer below `md`; header hamburger toggles it) + §7 P12.
```ts
'use client';

import { useEffect, useRef } from 'react';

/**
 * Shared focus-trap primitive for modal surfaces (the sidebar drawer, dialogs,
 * menus). This is the SINGLE focus-trap utility — the v0.6.0 accessibility plan
 * (P14) reuses `useFocusTrap` for the share dialog, command palette, and other
 * modals rather than re-implementing trapping per component.
 */

const FOCUSABLE_SELECTOR = [
  'a[href]',
  'button:not([disabled])',
  'input:not([disabled])',
  'select:not([disabled])',
  'textarea:not([disabled])',
  '[tabindex]:not([tabindex="-1"])',
].join(',');

/** Tabbable elements inside `container`, in DOM order. Pure — no side effects. */
export function getFocusable(container: HTMLElement): HTMLElement[] {
  const nodes = container.querySelectorAll<HTMLElement>(FOCUSABLE_SELECTOR);
  return Array.from(nodes).filter(
    (el) => !el.hasAttribute('disabled') && el.getAttribute('aria-hidden') !== 'true',
  );
}

/**
 * While `active`, traps keyboard focus inside the returned ref's element:
 * focuses the first focusable child on activation, wraps Tab / Shift+Tab at the
 * edges, and restores focus to the previously-focused element on deactivation.
 * Attach the returned ref to the trap container.
 */
export function useFocusTrap<T extends HTMLElement = HTMLDivElement>(active: boolean) {
  const ref = useRef<T | null>(null);
  const previouslyFocused = useRef<HTMLElement | null>(null);

  useEffect(() => {
    if (!active) return;
    const container = ref.current;
    if (!container) return;

    previouslyFocused.current = (document.activeElement as HTMLElement | null) ?? null;

    const focusFirst = () => {
      const focusable = getFocusable(container);
      (focusable[0] ?? container).focus();
    };
    focusFirst();

    const onKeyDown = (event: KeyboardEvent) => {
      if (event.key !== 'Tab') return;
      const focusable = getFocusable(container);
      if (focusable.length === 0) {
        event.preventDefault();
        container.focus();
        return;
      }
      const first = focusable[0];
      const last = focusable[focusable.length - 1];
      const activeEl = document.activeElement;
      if (event.shiftKey && activeEl === first) {
        event.preventDefault();
        last?.focus();
      } else if (!event.shiftKey && activeEl === last) {
        event.preventDefault();
        first?.focus();
      }
    };

    container.addEventListener('keydown', onKeyDown);
    return () => {
      container.removeEventListener('keydown', onKeyDown);
      previouslyFocused.current?.focus?.();
    };
  }, [active]);

  return ref;
}
```

- [x] **Step 3: Create the client drawer `src/components/sidebar-drawer.tsx`**

A `'use client'` component holding the open/close state, the hamburger top bar, the backdrop, and the off-canvas panel. The panel uses `useFocusTrap(open)` and closes on Escape + backdrop click. It receives the already-rendered `SidebarContent` as `children` (a server component passed through), so no data is fetched here. Visible only below `md` (`md:hidden`).

```tsx
'use client';

import { Menu, X } from 'lucide-react';
import { type ReactNode, useEffect, useState } from 'react';
import { useFocusTrap } from '@/lib/a11y/focus-trap';

export function SidebarDrawer({ children }: { children: ReactNode }) {
  const [open, setOpen] = useState(false);
  const panelRef = useFocusTrap<HTMLDivElement>(open);

  // Close on Escape (the focus trap owns Tab; Escape is a separate global).
  useEffect(() => {
    if (!open) return;
    const onKeyDown = (e: KeyboardEvent) => {
      if (e.key === 'Escape') setOpen(false);
    };
    document.addEventListener('keydown', onKeyDown);
    return () => document.removeEventListener('keydown', onKeyDown);
  }, [open]);

  return (
    <div className="md:hidden">
      <div className="flex h-12 items-center gap-2 border-b bg-card px-2 text-card-foreground">
        <button
          type="button"
          aria-label="Open navigation menu"
          aria-expanded={open}
          onClick={() => setOpen(true)}
          className="flex h-11 w-11 items-center justify-center rounded hover:bg-accent"
        >
          <Menu className="h-5 w-5" />
        </button>
        <span className="text-sm font-medium">Cairn</span>
      </div>

      {open && (
        <>
          {/* biome-ignore lint/a11y/noStaticElementInteractions: dismiss backdrop; Escape + the in-panel close button provide keyboard dismissal */}
          <div
            className="fixed inset-0 z-40 bg-black/40"
            onClick={() => setOpen(false)}
            aria-hidden="true"
          />
          <div
            ref={panelRef}
            role="dialog"
            aria-modal="true"
            aria-label="Navigation"
            className="fixed inset-y-0 left-0 z-50 flex w-72 max-w-[85vw] flex-col border-r bg-card text-card-foreground shadow-lg"
          >
            <div className="flex items-center justify-end border-b p-2">
              <button
                type="button"
                aria-label="Close navigation menu"
                onClick={() => setOpen(false)}
                className="flex h-11 w-11 items-center justify-center rounded hover:bg-accent"
              >
                <X className="h-5 w-5" />
              </button>
            </div>
            <div className="min-h-0 flex-1 overflow-y-auto">{children}</div>
          </div>
        </>
      )}
    </div>
  );
}
```
