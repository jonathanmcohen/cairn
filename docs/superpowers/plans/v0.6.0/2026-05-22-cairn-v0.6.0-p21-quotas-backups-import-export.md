# Cairn v0.6.0 P21 — Quotas + Scheduled Backups + Import/Export Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Three operability capabilities, plus the migration both this plan and P22 build on. (1) **Per-workspace storage quotas**: a `workspace_quotas` table (one lazily-created row per workspace), `checkStorageQuota`/`incrementStorageUsed`/`decrementStorageUsed` enforced at the file-upload choke point (reject when `used + incoming > limit`), and a `reconcileQuota` recompute from `FileStorage` truth via a CLI subcommand. (2) **Scheduled backups**: the v0.5.0 backup CLI gains `--retention-days N` (prune old bundles) and `--target local|s3` (push to the S3/MinIO `FileStorage`), emitting an `audit_log` row; the scheduling *mechanism* (external cron OR an opt-in single-instance `CAIRN_BACKUP_INTERVAL` ticker) is documented, not a hosted daemon. (3) **Import/export**: an `export` subcommand producing a re-importable workspace archive (pages + databases + files + manifest, secrets excluded), an `import` subcommand for Notion ZIP/HTML/Markdown + Markdown-folder + workspace-archive (best-effort, reusing the templates id-rewrite pass, writing an `import_jobs` row + report), and PDF + per-page/per-database UI export (Markdown/CSV/JSON download buttons reusing the read-only renderers). This plan **owns migration `0021`** (creating ALL THREE tables — `workspace_quotas`, `saved_searches`, `reminders`) and migration **`0022`** (`import_jobs`).

**Architecture:** Migration `0021` creates `workspace_quotas`, `saved_searches`, and `reminders` together; **P22 depends on `saved_searches` + `reminders` and adds no migration of its own** — they are created here so P21 and P22 can ship independently against one applied migration. Migration `0022` adds the small `import_jobs` bookkeeping table. `src/lib/quotas/quota.ts` holds pure, db-injected helpers: `ensureQuotaRow(tx, workspaceId)` (lazy upsert), `checkStorageQuota(tx, {workspaceId, incomingBytes})` (reads the row; `null` limit = unlimited; throws `QuotaExceededError` when `used + incoming > limit`), `incrementStorageUsed`/`decrementStorageUsed` (counter maintained transactionally), and `reconcileQuota(db, storage, workspaceId)` (sums actual `files.size` for the workspace and writes it back as the canonical `storage_bytes_used`). The upload helper `src/lib/files/upload.ts` calls `checkStorageQuota` then `incrementStorageUsed` **inside the same insert transaction**; the existing delete/trash-purge path decrements. The CLI (`src/server/cli.ts` + `src/server/cli-internal.ts`) is extended **without `@/` runtime imports** (it compiles as a standalone entrypoint — see Conventions): new flags parse in `cli-internal.ts`; `export`/`import`/`reconcile`/`backup --retention-days/--target` dispatch in `cli.ts`. Import logic lives in `src/lib/import/notion.ts` + `src/lib/import/markdown-folder.ts` + `src/lib/import/workspace-archive.ts` (md→ProseMirror via the existing `marked` path, intra-export links rewritten with the **same `buildRemap`/`rewriteRefs` id-rewrite pass** the templates system uses in `src/lib/templates/rewrite.ts`, producing a structured `ImportReport`); these are pure `@/`-importable libs invoked by the CLI through the entrypoint's dynamic-import seam (the CLI shells the work into the running app process, never importing `@/` at module top-level). Export logic lives in `src/lib/export/workspace-archive.ts` (uses `archiver`) + `src/lib/export/pdf.ts` (renders the read-only page) + `src/lib/export/renderers.ts` (MD/CSV/JSON). PDF + per-page/db UI export are download buttons over those renderers. **No app cron daemon** — scheduling is external cron or an opt-in, OFF-by-default, explicitly single-instance interval ticker (two instances double-fire — documented ceiling, consistent with the single-instance collab ceiling).

**Tech Stack:** Drizzle (`workspace_quotas`/`saved_searches`/`reminders`/`import_jobs` tables; `sum()` aggregate for reconcile; partial index `reminders(remind_at) where fired_at is null`), Postgres 16, `archiver` (already present) for the workspace-archive ZIP + a streaming PDF (reuse the read-only node-views from the blocks plans; render via the existing prosemirror-JSON walker → printable HTML → PDF), `marked` (already present) for md→ProseMirror import, the templates id-rewrite (`src/lib/templates/rewrite.ts`), the v0.5.0 S3/MinIO `FileStorage` (`getStorage()`/`FILE_BACKEND`) for `--target s3`, Next.js 16 route handlers + server components for the UI export buttons, Vitest 4 + Testcontainers (Postgres for quotas/import/export round-trip; the CLI arg parser is a pure unit test).

**Spec:** `docs/superpowers/specs/2026-05-22-cairn-v0.6.0-design.md` — §2 decisions 33 (quotas), 36 (scheduled backups), 37 (Notion import), 38 (workspace export + PDF); §3 "Admin, observability, ops & import" (quotas / scheduled backups / import-export) + the deferred billing/Notion-fidelity/distributed-scheduling items; §4 migrations `0021` (`workspace_quotas`, `saved_searches`, `reminders`) + `0022` (`import_jobs`); §5 "Quotas" / "Scheduling mechanism" / "Backups/import/export"; §6 quota math + import id-rewrite/fidelity-gap + PDF/MD/CSV/JSON renderer tests + the export→import round-trip integration; §8 the quota-counter-drift, Notion-fidelity, and single-instance-scheduling risks.

```ts
import { QuotaExceededError } from '@/lib/quotas/errors';
import {
  checkStorageQuota,
  decrementStorageUsed,
  ensureQuotaRow,
  incrementStorageUsed,
  reconcileQuota,

import { eq } from 'drizzle-orm';
import { beforeAll, beforeEach, describe, expect, it } from 'vitest';
import { makeTestDb, seedWorkspaceUserPage } from '../../helpers/db';

describe('workspace storage quota', () => {
  let db: Awaited<ReturnType<typeof makeTestDb>>['db'];
  let workspaceId: string;
  let userId: string;

  beforeAll(async () => {
    ({ db } = await makeTestDb());
  });
  beforeEach(async () => {
    await db.execute(
      schema.sql`truncate workspace_quotas, files, pages, workspace_members, workspaces, users restart identity cascade`,
    );
    ({ workspaceId, userId } = await seedWorkspaceUserPage(db));
  });

  it('lazily creates a quota row with a zero counter and no limit', async () => {
    const q = await ensureQuotaRow(db, workspaceId);
    expect(q.storageBytesUsed).toBe(0);
    expect(q.storageBytesLimit).toBeNull();
  });

  it('allows any upload when the limit is null (unlimited)', async () => {
    await ensureQuotaRow(db, workspaceId);
    await expect(
      checkStorageQuota(db, { workspaceId, incomingBytes: 10_000_000 }),
    ).resolves.toBeUndefined();
  });

  it('rejects when used + incoming would exceed the limit', async () => {
    await ensureQuotaRow(db, workspaceId);
    await db
      .update(schema.workspaceQuotas)
      .set({ storageBytesLimit: 1000, storageBytesUsed: 900 })
      .where(eq(schema.workspaceQuotas.workspaceId, workspaceId));
    await expect(
      checkStorageQuota(db, { workspaceId, incomingBytes: 200 }),
    ).rejects.toBeInstanceOf(QuotaExceededError);
    // exactly at the limit is allowed
    await expect(
      checkStorageQuota(db, { workspaceId, incomingBytes: 100 }),
    ).resolves.toBeUndefined();
  });

  it('increments and decrements the counter (never below zero)', async () => {
    await ensureQuotaRow(db, workspaceId);
    await incrementStorageUsed(db, workspaceId, 500);
    await incrementStorageUsed(db, workspaceId, 250);
    let [q] = await db
      .select()
      .from(schema.workspaceQuotas)
      .where(eq(schema.workspaceQuotas.workspaceId, workspaceId));
    expect(q?.storageBytesUsed).toBe(750);
    await decrementStorageUsed(db, workspaceId, 1000); // over-decrement clamps to 0
    [q] = await db
      .select()
      .from(schema.workspaceQuotas)
      .where(eq(schema.workspaceQuotas.workspaceId, workspaceId));
    expect(q?.storageBytesUsed).toBe(0);
  });

  it('reconciles the counter from the actual files.size sum', async () => {
    await ensureQuotaRow(db, workspaceId);
    // drift: counter says 9999, but real files total 300
    await incrementStorageUsed(db, workspaceId, 9999);
    await db.insert(schema.files).values([
      { workspaceId, name: 'a.txt', mimeType: 'text/plain', size: 100, path: `${workspaceId}/a`, uploadedBy: userId },
      { workspaceId, name: 'b.txt', mimeType: 'text/plain', size: 200, path: `${workspaceId}/b`, uploadedBy: userId },
    ]);
    const used = await reconcileQuota(db, workspaceId);
    expect(used).toBe(300);
    const [q] = await db
      .select()
      .from(schema.workspaceQuotas)
      .where(eq(schema.workspaceQuotas.workspaceId, workspaceId));
    expect(q?.storageBytesUsed).toBe(300);
  });
});
```

- [ ] **Step 4: Implement `src/lib/quotas/quota.ts`**

```ts
import * as schema from '@/db/schema';
import { eq, sql } from 'drizzle-orm';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import { QuotaExceededError } from './errors';

type Db = PostgresJsDatabase<typeof schema>;

/** Lazily create (idempotent) and return the quota row for a workspace. */
export async function ensureQuotaRow(db: Db, workspaceId: string): Promise<schema.WorkspaceQuota> {
  await db
    .insert(schema.workspaceQuotas)
    .values({ workspaceId })
    .onConflictDoNothing({ target: schema.workspaceQuotas.workspaceId });
  const [row] = await db
    .select()
    .from(schema.workspaceQuotas)
    .where(eq(schema.workspaceQuotas.workspaceId, workspaceId));
  if (!row) throw new Error('quota row missing after ensure');
  return row;
}

/**
 * Throw QuotaExceededError when used + incoming > limit. A null limit is
 * unlimited. Lazily ensures the row first so a brand-new workspace never blocks.
 */
export async function checkStorageQuota(
  db: Db,
  args: { workspaceId: string; incomingBytes: number },
): Promise<void> {
  const row = await ensureQuotaRow(db, args.workspaceId);
  if (row.storageBytesLimit === null) return; // unlimited
  if (row.storageBytesUsed + args.incomingBytes > row.storageBytesLimit) {
    throw new QuotaExceededError({
      limit: row.storageBytesLimit,
      used: row.storageBytesUsed,
      incoming: args.incomingBytes,
    });
  }
}

export async function incrementStorageUsed(db: Db, workspaceId: string, bytes: number): Promise<void> {
  await ensureQuotaRow(db, workspaceId);
  await db
    .update(schema.workspaceQuotas)
    .set({
      storageBytesUsed: sql`${schema.workspaceQuotas.storageBytesUsed} + ${bytes}`,
      updatedAt: new Date(),
    })
    .where(eq(schema.workspaceQuotas.workspaceId, workspaceId));
}

/** Decrement, clamped at zero (a counter must never go negative). */
export async function decrementStorageUsed(db: Db, workspaceId: string, bytes: number): Promise<void> {
  await ensureQuotaRow(db, workspaceId);
  await db
    .update(schema.workspaceQuotas)
    .set({
      storageBytesUsed: sql`GREATEST(${schema.workspaceQuotas.storageBytesUsed} - ${bytes}, 0)`,
      updatedAt: new Date(),
    })
    .where(eq(schema.workspaceQuotas.workspaceId, workspaceId));
}

/**
 * Recompute storage_bytes_used from the canonical files.size sum and write it
 * back. Returns the reconciled value. The fix for counter drift (§8) — the CLI
 * `reconcile` subcommand calls this per workspace.
 */
export async function reconcileQuota(db: Db, workspaceId: string): Promise<number> {
  await ensureQuotaRow(db, workspaceId);
  const [{ total } = { total: 0 }] = await db
    .select({ total: sql<number>`coalesce(sum(${schema.files.size}), 0)::bigint` })
    .from(schema.files)
    .where(eq(schema.files.workspaceId, workspaceId));
  const used = Number(total);
  await db
    .update(schema.workspaceQuotas)
    .set({ storageBytesUsed: used, updatedAt: new Date() })
    .where(eq(schema.workspaceQuotas.workspaceId, workspaceId));
  return used;
}
```

> The `::bigint` cast keeps `sum()` an integer; `Number(total)` is safe for homelab-scale totals (well under `Number.MAX_SAFE_INTEGER` ≈ 9 PB). If `files.size` does not exist or is named differently, read `src/db/schema/files.ts` and use the real column.

```ts
export interface CliArgs {
  command: 'backup' | 'restore' | 'export' | 'import' | 'reconcile';
  out?: string;
  in?: string;
  force: boolean;
  retentionDays?: number;
  target?: 'local' | 's3';
  workspace?: string;
  source?: 'notion' | 'markdown-folder' | 'workspace-archive';
  file?: string;
}

export function parseArgs(argv: string[]): CliArgs {
  const [command, ...rest] = argv;
  const known = ['backup', 'restore', 'export', 'import', 'reconcile'] as const;
  if (!known.includes(command as (typeof known)[number])) {
    throw new Error(`Unknown command: ${command ?? '(none)'} (expected ${known.join('|')})`);
  }
  const cmd = command as CliArgs['command'];
  let out: string | undefined;
  let inBundle: string | undefined;
  let force = false;
  let retentionDays: number | undefined;
  let target: 'local' | 's3' | undefined;
  let workspace: string | undefined;
  let source: CliArgs['source'];
  let file: string | undefined;
  for (let i = 0; i < rest.length; i++) {
    const a = rest[i];
    if (a === '--out') out = rest[++i];
    else if (a === '--in') inBundle = rest[++i];
    else if (a === '--force') force = true;
    else if (a === '--retention-days') {
      const n = Number(rest[++i]);
      if (!Number.isInteger(n) || n < 0) throw new Error('--retention-days requires a non-negative integer');
      retentionDays = n;
    } else if (a === '--target') {
      const t = rest[++i];
      if (t !== 'local' && t !== 's3') throw new Error("--target must be 'local' or 's3'");
      target = t;
    } else if (a === '--workspace') workspace = rest[++i];
    else if (a === '--source') {
      const s = rest[++i];
      if (s !== 'notion' && s !== 'markdown-folder' && s !== 'workspace-archive') {
        throw new Error("--source must be 'notion' | 'markdown-folder' | 'workspace-archive'");
      }
      source = s;
    } else if (a === '--file') file = rest[++i];
    else throw new Error(`Unknown flag: ${a}`);
  }
  if (cmd === 'backup' && !out) throw new Error('backup requires --out <dir>');
  if (cmd === 'restore' && !inBundle) throw new Error('restore requires --in <bundle>');
  if (cmd === 'export' && (!workspace || !out)) throw new Error('export requires --workspace <id> --out <dir>');
  if (cmd === 'import' && (!source || !file || !workspace)) {
    throw new Error('import requires --source <kind> --file <path> --workspace <id>');
  }
  return {
    command: cmd,
    out,
    in: inBundle,
    force,
    retentionDays,
    target: cmd === 'backup' ? (target ?? 'local') : target,
    workspace,
    source,
    file,
  };
}
```

```ts
import { getDb } from '@/db/client';
import { HttpError } from '@/lib/auth/require-role';
import { pageToJson, pageToMarkdown } from '@/lib/export/renderers';
import { pageToPdf } from '@/lib/export/pdf';
import { requirePageAccess } from '@/lib/pages/access';
import { NextResponse } from 'next/server';

type Ctx = { params: Promise<{ pageId: string }> };

export async function GET(req: Request, { params }: Ctx): Promise<Response> {
  try {
    const { pageId } = await params;
    const { page } = await requirePageAccess(pageId, 'viewer');
    const format = new URL(req.url).searchParams.get('format') ?? 'md';
    if (format === 'md') {
      return new NextResponse(pageToMarkdown(page), {
        headers: { 'content-type': 'text/markdown; charset=utf-8',
          'content-disposition': `attachment; filename="${page.id}.md"` },
      });
    }
    if (format === 'json') {
      return NextResponse.json(pageToJson(page), {
        headers: { 'content-disposition': `attachment; filename="${page.id}.json"` },
      });
    }
    if (format === 'pdf') {
      const pdf = await pageToPdf(page);
      // @ts-expect-error Node Buffer → web Response body (Next 16 runtime-ok; see CLAUDE.md)
      return new NextResponse(pdf, {
        headers: { 'content-type': 'application/pdf',
          'content-disposition': `attachment; filename="${page.id}.pdf"` },
      });
    }
    return NextResponse.json({ error: 'unsupported format' }, { status: 400 });
  } catch (err) {
    if (err instanceof HttpError) return NextResponse.json({ error: err.message }, { status: err.status });
    return NextResponse.json({ error: err instanceof Error ? err.message : 'unknown' }, { status: 500 });
  }
}
```
