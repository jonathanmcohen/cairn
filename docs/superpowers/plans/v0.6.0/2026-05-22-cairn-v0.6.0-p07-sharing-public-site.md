# Cairn v0.6.0 Plan 7 — Per-page share settings + public site

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend v0.2.0's publish path (`/p/<slug>`) with **per-page share settings** — an optional link password (Argon2id), an optional expiry timestamp, and an "allow duplication" toggle — and add a workspace-level **public site** at `/s/<workspace-slug>` that renders a navigable, read-only mini-site of that workspace's already-published pages. A protected `/p/<slug>` shows a password gate; a correct password sets a short-lived **HMAC-signed access cookie** (`cairn_pub_<pageId>`) using the v0.5.0 signer — **no new secret, no client-stored password**. Expired / unpublished / wrong-password always resolve to **404, never 403** (the existence-non-leak rule). When duplication is allowed, an authenticated visitor can deep-copy the page subtree into their own workspace.

**Architecture:** Sharing stays a thin layer over the existing publish row (no `page_acls` table, no per-block grain — the **page is the unit**). Migration `0014` adds `link_password_hash text NULL` (Argon2id), `expires_at timestamptz NULL`, and `allow_duplication boolean NOT NULL DEFAULT false` to that row. Migration `0015` adds `public_site_slug text UNIQUE NULL` + `public_site_enabled boolean NOT NULL DEFAULT false` to `workspaces`. Pure, db-injected helpers do the work (`setShareSettings`, `verifyShareAccess`, `issueAccessCookie`/`verifyAccessCookie`, `requirePublicPageAccess`, `duplicatePublicPage`, `setPublicSite`, `getPublicSitePages`) so they're unit-testable without HTTP. The `cairn_pub_<pageId>` cookie carries `{pageId, exp}` HMAC-signed (SHA-256) with `AUTH_SECRET` via the existing `src/lib/files/signing.ts` primitive (reused, **no new secret class**). The render route `/p/[slug]` and the new public-site route `/s/[slug]` both reuse the v0.2.0 read-only renderer (`ReadOnlyView` + `resignDocumentImages`). Security tests extend the v0.5.1 suite: forged cookie, expired cookie, wrong password, gated-existence non-leak. Sharing is **per-page, never per-block**.

**Tech Stack:** Next.js 16 App Router (server + client components, `src/proxy.ts` auth gate), TypeScript 6 strict, Postgres 16 + Drizzle 0.45, Node `crypto` HMAC (reuse `signFileUrl`/`verifyFileUrl`), **Argon2id via `@node-rs/argon2`** (maintained, native, no node-gyp — preferred over the unmaintained `argon2` build), TipTap 3 (`editable: false`), Vitest 4 + Testcontainers, Biome 2, pnpm.

**Spec:** `docs/superpowers/specs/2026-05-22-cairn-v0.6.0-design.md` — Key decisions #8 (password links), #9 (expiry + allow-duplication), #10 (extends publish row, not a new ACL), #11 (public site); §4 migrations `0014` + `0015`; §5 "Sharing".

## Design choices resolved in this plan (read before starting)

- **No new secret.** The access cookie is signed with the **same `AUTH_SECRET`-derived HMAC** the file-URL signer uses. We add one tiny module `src/lib/pages/share-cookie.ts` that reuses `signFileUrl`/`verifyFileUrl` semantics with a `pageId` payload (`fileId := pageId`, `expiresAt := exp`). This deliberately rides the audited v0.5.0 primitive rather than introducing a JWT or a second key.
- **Cookie name + scope.** `cairn_pub_<pageId>` (one cookie per page so multiple protected pages don't collide), value `<exp>.<sig>`, `HttpOnly`, `SameSite=Lax`, `Secure` (in prod), `Path=/p/<slug>`, `Max-Age` = the cookie TTL (default 12h, capped to `expires_at` if sooner). The payload signed is the string `<pageId>.<exp>`; verification recomputes the HMAC and timing-safe compares, then checks `exp` is in the future.
- **Argon2id package.** `@node-rs/argon2` (Rust/NAPI, actively maintained, prebuilt binaries, no node-gyp toolchain). API: `hash(password)` / `verify(hash, password)`. The legacy `argon2` package needs node-gyp at install and is less reliably maintained — **do not use it.**
- **404 vs 403 (the non-leak rule).** `requirePublicPageAccess` returns a discriminated result `{ ok: true, page } | { ok: 'gate', page } | { ok: false }`. `{ ok: false }` covers unpublished, soft-deleted, unknown slug, AND **expired** — the route maps all of them to `notFound()`. A *wrong password* on a protected, otherwise-valid page returns `{ ok: 'gate' }` (re-render the gate with an error), which is indistinguishable in the unprotected-vs-protected sense from a page that simply requires a password — and a non-existent page never reaches the gate at all (it 404s first). We **never** emit 403.
- **Expiry independent of password.** Both toggles are independent (spec #9): a page can have a password and/or an expiry. Expiry is checked server-side on every public render; expired → `{ ok: false }` → 404.
- **Duplication.** When `allow_duplication = true`, the public render shows a "Duplicate to my workspace" button. The action requires an authenticated session (anon → redirect to sign-in with a return URL). `duplicatePublicPage` deep-copies the published page **and its published-or-not descendants** into the caller's chosen workspace (default: their first owned/admin workspace), minting fresh ids via a parent-id remap pass (the templates id-rewrite precedent), copying `content`/`title`/`icon`/hierarchy but **NOT** share settings, `published`, or `public_slug` (the copy starts private). Files referenced by `fileId` are left pointing at the originals' signed-URL path is **not** copied; instead we copy the ProseMirror content verbatim (fileId refs resolve against the original workspace's storage only inside that workspace) — **D: v0.6.0 duplication copies text/structure; embedded file blobs are NOT re-hosted into the new workspace** (documented limitation; matches the Notion-import "external link" fallback). Re-hosting blobs is deferred.
- **Public site lists only already-published pages** (spec #11): enabling the site does NOT bulk-publish. The nav tree is the hierarchy of pages that have `published = true AND deleted_at IS NULL` within the workspace, built with the existing recursive-CTE raw-SQL pattern. **Per-page password/expiry still gate a page inside the site** — clicking a protected page in the nav lands on its `/p/<slug>` gate (the site links through to `/p/<slug>`, it does not bypass the per-page gate).

```ts
import { signFileUrl, verifyFileUrl } from '@/lib/files/signing';

/** One cookie per page so multiple protected pages do not collide. */
export function cookieNameFor(pageId: string): string {
  return `cairn_pub_${pageId}`;
}

type IssueInput = {
  pageId: string;
  secret: string;
  /** Seconds from now. Ignored if `expiresAt` (an absolute unix-seconds) is given. */
  ttlSeconds?: number;
  expiresAt?: number;
};

/**
 * Mint the cookie *value* `<exp>.<sig>` where `sig = HMAC(secret, "<pageId>.<exp>")`.
 * We deliberately reuse the audited file-URL HMAC (`signFileUrl`) with `fileId := pageId`
 * and `expiresAt := exp` — so this introduces NO new secret and NO new crypto.
 */
export function issueAccessCookieValue(input: IssueInput): string {
  const exp =
    input.expiresAt ?? Math.floor(Date.now() / 1000) + (input.ttlSeconds ?? 12 * 60 * 60);
  const sig = signFileUrl({ fileId: input.pageId, expiresAt: exp, secret: input.secret });
  return `${exp}.${sig}`;
}

type VerifyInput = { pageId: string; value: string; secret: string };

/** True iff `value` is a well-formed, signature-valid, unexpired cookie for `pageId`. */
export function verifyAccessCookieValue(input: VerifyInput): boolean {
  const dot = input.value.indexOf('.');
  if (dot <= 0) return false;
  const expStr = input.value.slice(0, dot);
  const sig = input.value.slice(dot + 1);
  if (!/^\d+$/.test(expStr) || sig.length === 0) return false;
  const exp = Number(expStr);
  // verifyFileUrl checks BOTH the time gate (exp in the future) AND the timing-safe HMAC.
  return verifyFileUrl({ fileId: input.pageId, expiresAt: exp, sig, secret: input.secret });
}
```

```ts
import { hash, verify } from '@node-rs/argon2';
import { and, eq, isNull } from 'drizzle-orm';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import * as schema from '@/db/schema';

type Scope = { pageId: string; workspaceId: string };

type ShareSettings = Scope & {
  /** undefined = leave unchanged; null = clear; string = (re)hash. */
  password?: string | null;
  /** undefined = leave unchanged; null = clear; Date = set. */
  expiresAt?: Date | null;
  allowDuplication?: boolean;
};

async function loadScoped(db: PostgresJsDatabase<typeof schema>, scope: Scope) {
  const [page] = await db
    .select()
    .from(schema.pages)
    .where(and(eq(schema.pages.id, scope.pageId), eq(schema.pages.workspaceId, scope.workspaceId)))
    .limit(1);
  if (!page) throw new Error('page not found in workspace');
  return page;
}

/** Persist per-page share settings. Argon2id-hashes a provided password; null clears it. */
export async function setShareSettings(
  db: PostgresJsDatabase<typeof schema>,
  s: ShareSettings,
): Promise<void> {
  await loadScoped(db, s);
  const patch: Partial<typeof schema.pages.$inferInsert> = {};
  if (s.password !== undefined) {
    patch.linkPasswordHash = s.password === null ? null : await hash(s.password);
  }
  if (s.expiresAt !== undefined) patch.expiresAt = s.expiresAt;
  if (s.allowDuplication !== undefined) patch.allowDuplication = s.allowDuplication;
  if (Object.keys(patch).length > 0) {
    await db.update(schema.pages).set(patch).where(eq(schema.pages.id, s.pageId));
  }
}

/** Argon2id-verify a candidate password against a page's stored hash. */
export async function verifyShareAccess(
  page: Pick<schema.Page, 'linkPasswordHash'>,
  candidate: string,
): Promise<boolean> {
  if (!page.linkPasswordHash) return false;
  try {
    return await verify(page.linkPasswordHash, candidate);
  } catch {
    return false;
  }
}

export type PublicAccess =
  | { ok: true; page: schema.Page }
  | { ok: 'gate'; page: schema.Page }
  | { ok: false };

/**
 * The single public-render authorization gate. Resolves a slug to a published,
 * non-deleted, non-expired page. Expired/unpublished/deleted/unknown → { ok: false }
 * (the route maps ALL of these to notFound() — never 403). A password-protected page
 * without a valid access cookie → { ok: 'gate' }. Otherwise { ok: true }.
 */
export async function requirePublicPageAccess(
  db: PostgresJsDatabase<typeof schema>,
  slug: string,
  hasValidCookie: boolean,
): Promise<PublicAccess> {
  const [page] = await db
    .select()
    .from(schema.pages)
    .where(
      and(
        eq(schema.pages.publicSlug, slug),
        eq(schema.pages.published, true),
        isNull(schema.pages.deletedAt),
      ),
    )
    .limit(1);
  if (!page) return { ok: false };
  if (page.expiresAt && page.expiresAt.getTime() <= Date.now()) return { ok: false };
  if (page.linkPasswordHash && !hasValidCookie) return { ok: 'gate', page };
  return { ok: true, page };
}
```

```ts
import { and, eq, isNull } from 'drizzle-orm';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import { sql as rawSql } from 'drizzle-orm';
import * as schema from '@/db/schema';

type Args = { sourcePageId: string; intoWorkspaceId: string; actorUserId: string };

/**
 * Deep-copy a published page's subtree into another workspace. Only allowed when the
 * source page is published and `allow_duplication = true`. Mints fresh ids and remaps
 * parent_id; copies title/icon/content/hierarchy but NOT share settings, published, or
 * public_slug (the copy starts private). Returns the new root page id.
 *
 * NOTE (v0.6.0 limitation): embedded file blobs (cairnImage/fileAttachment fileId refs)
 * are NOT re-hosted into the new workspace — content is copied verbatim. Documented.
 */
export async function duplicatePublicPage(
  db: PostgresJsDatabase<typeof schema>,
  { sourcePageId, intoWorkspaceId, actorUserId }: Args,
): Promise<string> {
  return db.transaction(async (tx) => {
    const [root] = await tx
      .select()
      .from(schema.pages)
      .where(
        and(
          eq(schema.pages.id, sourcePageId),
          eq(schema.pages.published, true),
          eq(schema.pages.allowDuplication, true),
          isNull(schema.pages.deletedAt),
        ),
      )
      .limit(1);
    if (!root) throw new Error('page not duplicable');

    // Recursive-CTE descendant fetch (the established raw-SQL pattern).
    const rows = (await tx.execute(rawSql`
      WITH RECURSIVE sub AS (
        SELECT * FROM pages WHERE id = ${sourcePageId}
        UNION ALL
        SELECT p.* FROM pages p JOIN sub s ON p.parent_id = s.id WHERE p.deleted_at IS NULL
      )
      SELECT id, parent_id, title, icon, content FROM sub
    `)) as unknown as Array<{
      id: string;
      parent_id: string | null;
      title: string;
      icon: string | null;
      content: unknown;
    }>;

    // Insert in order; remap old id -> new id (parents always precede children in the CTE).
    const idMap = new Map<string, string>();
    for (const r of rows) {
      const remappedParent = r.parent_id ? (idMap.get(r.parent_id) ?? null) : null;
      const [inserted] = await tx
        .insert(schema.pages)
        .values({
          workspaceId: intoWorkspaceId,
          parentId: r.id === sourcePageId ? null : remappedParent,
          title: r.title,
          icon: r.icon,
          content: r.content as schema.Page['content'],
          createdBy: actorUserId,
          // share state intentionally omitted -> defaults: published=false, no slug.
        })
        .returning({ id: schema.pages.id });
      idMap.set(r.id, inserted!.id);
    }
    return idMap.get(sourcePageId)!;
  });
}
```

```ts
import { NextResponse } from 'next/server';
import { getDb } from '@/db/client';
import { env } from '@/lib/env';
import { getPublishedPageBySlug } from '@/lib/pages/public';
import { verifyShareAccess } from '@/lib/pages/share';
import { cookieNameFor, issueAccessCookieValue } from '@/lib/pages/share-cookie';

type Ctx = { params: Promise<{ slug: string }> };

export async function POST(req: Request, { params }: Ctx): Promise<Response> {
  const { slug } = await params;
  const page = await getPublishedPageBySlug(getDb(), slug);
  // Always behave identically for "no such page" and "wrong password": 401, no leak.
  if (!page || !page.linkPasswordHash) {
    return NextResponse.json({ error: 'unauthorized' }, { status: 401 });
  }
  const { password } = (await req.json().catch(() => ({}))) as { password?: unknown };
  if (typeof password !== 'string' || !(await verifyShareAccess(page, password))) {
    return NextResponse.json({ error: 'unauthorized' }, { status: 401 });
  }

  // TTL = 12h, capped to the page's expiry if sooner.
  const nowSec = Math.floor(Date.now() / 1000);
  const cap = page.expiresAt ? Math.floor(page.expiresAt.getTime() / 1000) : nowSec + 12 * 3600;
  const exp = Math.min(nowSec + 12 * 3600, cap);
  const value = issueAccessCookieValue({ pageId: page.id, expiresAt: exp, secret: env().AUTH_SECRET });

  const res = NextResponse.json({ ok: true });
  res.cookies.set(cookieNameFor(page.id), value, {
    httpOnly: true,
    sameSite: 'lax',
    secure: process.env.NODE_ENV === 'production',
    path: `/p/${slug}`,
    maxAge: Math.max(0, exp - nowSec),
  });
  return res;
}
```

```ts
import { and, eq, isNull } from 'drizzle-orm';
import { sql as rawSql } from 'drizzle-orm';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import * as schema from '@/db/schema';

type SetArgs = { workspaceId: string; slug: string; enabled: boolean };

/** Persist the workspace's public-site slug + enabled flag. Unique slug enforced by the DB. */
export async function setPublicSite(
  db: PostgresJsDatabase<typeof schema>,
  { workspaceId, slug, enabled }: SetArgs,
): Promise<void> {
  // The 0015 UNIQUE(public_site_slug) constraint surfaces collisions as a thrown error.
  await db
    .update(schema.workspaces)
    .set({ publicSiteSlug: slug, publicSiteEnabled: enabled })
    .where(eq(schema.workspaces.id, workspaceId));
}

export type PublicSitePage = { id: string; title: string; icon: string | null; slug: string; parentId: string | null };
export type PublicSite = { workspaceId: string; slug: string; pages: PublicSitePage[] };

/**
 * Resolve an ENABLED public site by its slug and return its published, non-deleted
 * pages as a flat list (caller builds the tree from parentId). Disabled / unknown → null.
 */
export async function getPublicSitePages(
  db: PostgresJsDatabase<typeof schema>,
  workspaceSlug: string,
): Promise<PublicSite | null> {
  const [ws] = await db
    .select()
    .from(schema.workspaces)
    .where(
      and(
        eq(schema.workspaces.publicSiteSlug, workspaceSlug),
        eq(schema.workspaces.publicSiteEnabled, true),
      ),
    )
    .limit(1);
  if (!ws) return null;

  const pages = (await db.execute(rawSql`
    SELECT id, title, icon, public_slug AS slug, parent_id
    FROM pages
    WHERE workspace_id = ${ws.id} AND published = true AND deleted_at IS NULL
    ORDER BY title ASC
  `)) as unknown as Array<{
    id: string;
    title: string;
    icon: string | null;
    slug: string;
    parent_id: string | null;
  }>;

  return {
    workspaceId: ws.id,
    slug: workspaceSlug,
    pages: pages.map((p) => ({
      id: p.id,
      title: p.title,
      icon: p.icon,
      slug: p.slug,
      parentId: p.parent_id,
    })),
  };
}
```

```tsx
  params,
}: {
```
