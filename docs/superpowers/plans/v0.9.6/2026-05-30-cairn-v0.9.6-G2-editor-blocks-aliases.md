# Editor Block Empty-States + Slash Aliases Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Give every MEDIA/ADVANCED editor block a visible, interactive empty-state node-view and make the slash menu discoverable by synonyms.

**Architecture:** Two media atoms (`cairnImage`, `fileAttachment`) are registered schema-only, so an empty insert renders an invisible `<img>`/`<a>` — we add React node-views with upload/URL CTAs (mirroring the existing `bookmark.tsx`/`video.tsx` pattern). The slash catalog gains a `keywords: string[]` field on every `SlashItem`, and the suggestion `items()` filter + `slash-menu.tsx` search match title OR any keyword. Blocks that already ship empty-states (Embed/Bookmark/Video/Mermaid/Gallery/Citation/Toggle) are left intact; this plan closes only the genuine gaps.

**Tech Stack:** TipTap 3 (`@tiptap/react` `ReactNodeViewRenderer`/`NodeViewWrapper`), React 19, TypeScript 6 strict, Vitest 4 (jsdom for components), Biome v2.

**Closes:** #139, #148, #149

## Background (read before starting)

Findings from the source audit (do not re-derive):

- **Slash insertion is NOT broken for most blocks.** `/citation` and `/file` both insert correctly: `/file` opens a native `<input type=file>` immediately and only inserts on file-choose (a cancelled picker is a legitimate no-op, not a bug); `/citation` (via `citationMenuItem.run`) inserts a `citation` node after the prompts. The real defect (#139) is that `cairnImage` and `fileAttachment` are registered **schema-only** in `src/components/editor/extensions.ts` (lines 84–85) — no `addNodeView()`. So when one is inserted **empty** (e.g. via block-convert, a future paste path, or a slash entry that inserts before upload), it renders as a bare `<img>` with `src=null` / an empty `<a>` — invisible. The fix is to give them empty-state node-views like every other media block already has.
- **Already have empty-states (leave alone):** `blocks/bookmark.tsx` ("Paste a link to bookmark"), `blocks/embed.tsx` ("Paste a … URL"), `blocks/video.tsx` (`VideoUploadButton`), `blocks/mermaid.tsx` ("Edit diagram"), `blocks/math.tsx` (click-to-edit), `blocks/gallery.tsx` ("Drop images here"), `blocks/toggle-view.tsx` ("Empty — add content…"), `extensions/citation.tsx` ("Add citation"). Synced-block has a source-picker. These need NO new work for empty-states.
- **Slash filter** lives in two places: `slash-extension.ts` `addOptions().suggestion.items` (line ~666, `items.filter((i) => i.title.toLowerCase().includes(...))`) and the type `SlashItem` in `slash-menu.tsx`. There is **no** `keywords` field today.
- **`SlashItem`** shape: `{ title, description, category, command, icon? }` (`slash-menu.tsx` lines 17–23). `toSlashItem()` in `slash-extension.ts` builds items from `CitationSlashEntry`.

Every task is TDD: write the failing test, run it (red), implement minimally, run it (green), commit. Shell commands must be prefixed with `source ~/.zshenv &&`. Do NOT push — the controller pushes.

```ts
export function matchesSlashQuery(item: SlashItem, query: string): boolean {
  const q = query.trim().toLowerCase();
  if (q === '') return true;
  if (item.title.toLowerCase().includes(q)) return true;
  return item.keywords.some((k) => k.toLowerCase().includes(q));
```

```tsx
'use client';

import type { NodeViewProps } from '@tiptap/react';
import { NodeViewWrapper } from '@tiptap/react';
import { useState } from 'react';

/**
 * #139 — empty-state node-view for the `cairnImage` atom. When the node has a
 * resolved `src` it renders the image; when empty + editable it offers an
 * upload picker AND a paste-URL affordance (mirrors blocks/bookmark.tsx). For
 * viewers an empty node is a muted notice. `updateAttributes` keeps the doc /
 * Yjs state the single source of truth — no node-local persisted state.
 */
export function ImageView({ node, editor, updateAttributes }: NodeViewProps) {
  const src = node.attrs.src as string | null;
  const alt = (node.attrs.alt as string | null) ?? '';
  const [mode, setMode] = useState<'cta' | 'url'>('cta');
  const [url, setUrl] = useState('');
  const [uploading, setUploading] = useState(false);

  async function upload(file: File) {
    setUploading(true);
    try {
      const fd = new FormData();
      fd.set('file', file);
      const res = await fetch('/api/upload', { method: 'POST', body: fd });
      if (!res.ok) return;
      const { signedUrl, file: meta } = (await res.json()) as {
        signedUrl: string;
        file: { id: string; name: string };
      };
      updateAttributes({ src: signedUrl, alt: meta.name, fileId: meta.id });
    } finally {
      setUploading(false);
    }
  }

  function pickFile() {
    const input = document.createElement('input');
    input.type = 'file';
    input.accept = 'image/*';
    input.onchange = () => {
      const file = input.files?.[0];
      if (file) void upload(file);
    };
    input.click();
  }

  if (src) {
    return (
      <NodeViewWrapper className="my-3" data-cairn-image="">
        {/* biome-ignore lint/performance/noImgElement: TipTap node-view emits a raw <img>; next/image is not appropriate inside ProseMirror node views. */}
        <img src={src} alt={alt} className="max-w-full rounded-md" loading="lazy" />
      </NodeViewWrapper>
    );
  }

  if (!editor.isEditable) {
    return (
      <NodeViewWrapper className="my-3 rounded-md border p-3 text-sm text-muted-foreground">
        Empty image.
      </NodeViewWrapper>
    );
  }

  return (
    <NodeViewWrapper className="my-3 rounded-md border p-3" data-empty>
      {mode === 'cta' ? (
        <div className="flex items-center gap-2">
          <button
            type="button"
            disabled={uploading}
            onClick={pickFile}
            className="rounded bg-accent px-2 py-1 text-sm font-medium hover:bg-accent/80 disabled:opacity-50"
          >
            {uploading ? 'Uploading…' : 'Upload an image'}
          </button>
          <button
            type="button"
            onClick={() => setMode('url')}
            className="rounded border px-2 py-1 text-sm hover:bg-accent/40"
          >
            Embed a URL
          </button>
        </div>
      ) : (
        <div className="flex items-center gap-2">
          <input
            value={url}
            onChange={(e) => setUrl(e.target.value)}
            placeholder="Paste an image URL"
            className="flex-1 rounded border bg-background px-2 py-1 text-sm"
          />
          <button
            type="button"
            disabled={url.trim().length === 0}
            onClick={() => updateAttributes({ src: url.trim(), alt: '' })}
            className="rounded bg-accent px-2 py-1 text-sm font-medium hover:bg-accent/80 disabled:opacity-50"
          >
            Embed
          </button>
        </div>
      )}
    </NodeViewWrapper>
  );
}
```

```tsx
    return (
      <NodeViewWrapper className="my-3" data-cairn-file="">
        <a
          href={href}
          target="_blank"
          rel="noopener noreferrer"
          className="file-attachment inline-flex items-center gap-2 rounded-md border px-3 py-2 text-sm no-underline hover:bg-accent/30"
        >
          <Paperclip aria-hidden className="size-4 shrink-0 text-muted-foreground" />
          <span className="truncate">{name}</span>
        </a>
      </NodeViewWrapper>
    );
  }

  if (!editor.isEditable) {
    return (
      <NodeViewWrapper className="my-3 rounded-md border p-3 text-sm text-muted-foreground">
        Empty file.
      </NodeViewWrapper>
    );
  }

  return (
    <NodeViewWrapper className="my-3 rounded-md border p-3" data-empty>
      <button
        type="button"
        disabled={uploading}
        onClick={pickFile}
        className="inline-flex items-center gap-2 rounded bg-accent px-2 py-1 text-sm font-medium hover:bg-accent/80 disabled:opacity-50"
      >
        <Paperclip aria-hidden className="size-4 shrink-0" />
        {uploading ? 'Uploading…' : 'Upload a file'}
      </button>
    </NodeViewWrapper>
  );
}
```
