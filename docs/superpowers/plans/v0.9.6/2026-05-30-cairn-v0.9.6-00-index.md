## Notes / known facts (baked into plans)

- **G1 absorbs PR #140** (`feat/themed-confirm-dialogs`): ConfirmProvider/useConfirm + 12 confirm() + InputDialog/usePrompt + 4 prompt() sites already done & tested. G1 completes the 9 `slash-extension` prompts via the editor bus + the Biome `noRestrictedGlobals` ban (repo has **no ESLint**).
- **G2 diagnosis:** `/citation` and `/file` slash insertions are NOT broken; the real gap is `cairnImage` + `fileAttachment` lack NodeViews (invisible `<img>`/`<a>`). Only those two node-views are added.
- **G3 #130 root cause:** `emoji-picker-element` defaults to the jsdelivr CDN (CSP-blocked); wire `picker.dataSource` to the same-origin `public/emoji-data.json`.
- **G4:** WASM (`onnxruntime-web`) backend removes the native `.so` dependency entirely (no glibc/musl issue). Collab #137 is operator-side `AUTH_SECRET` mismatch — code change = better `onAuthenticate` logging + README note.
- **G5:** backends all exist (audit query, members mgmt, SIEM CRUD, chat-bridge install, `workspaces.icon`, `CAIRN_ENFORCE_2FA`) — G5 is UI/nav wiring + the OpenAPI `publicOrigin()`/version fix.
- **G6 glow (#110/#133):** `@layer base` global `:focus-visible` ring (saturated per-accent `--ring`) leaks onto `.ProseMirror` + the slash tippy popup; scope the base rule with `:not()`.
- **G6c (#150):** the row `<Link>` covered only icon+title (`flex-1`); padding band + always-mounted action cluster were non-navigating dead zones, and 44px buttons bled over the 32px row. Fix: full-bleed `absolute inset-0` Link overlay + `pointer-events-none` content layer + `relative z-10` action cluster.
- **G8b is the only migration** (`0055_auth_sessions`). Keeps the jwt strategy; adds a `sid` claim + revocation check so sessions become listable/revocable without a full DB session adapter.
