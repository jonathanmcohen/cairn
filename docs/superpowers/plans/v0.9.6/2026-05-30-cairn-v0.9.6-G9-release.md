# G9 — Release Implementation Plan
> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Tie off the v0.9.6 audit-driven hotfix by bumping the version 0.9.5→0.9.6, writing the `[0.9.6]` CHANGELOG section (summarizing G1–G8 + every closed issue), running the combined release gate (the full `pnpm lint` incl. G1's new Biome `confirm`/`alert`/`prompt` ban + `typecheck` + `build`), and opening the single PR `patches/v0.9.6 → main` with the complete `Closes` list.

**Architecture:** This plan ships **no feature code** — G1–G8 already landed every fix on `patches/v0.9.6`. It edits exactly two files (`package.json` version, `CHANGELOG.md`), runs the combined gate as a verification ritual, then opens one PR. The runtime app version is read from `package.json` at request time via `appVersion()` in `src/lib/version.ts` (candidate-path `JSON.parse` of the nearest `package.json`, surfaced at `/api/health` and `/healthz`), so the **only** version reference to change is `package.json` — there is no hardcoded version string in source, Dockerfile, README, or compose to touch.

**Tech Stack:** pnpm 11, Node 24 LTS, Next 16, React 19, TypeScript 6, Vitest 4, Biome 2 (the lint gate now includes the `noRestrictedGlobals` ban added in G1), Drizzle 0.45. `gh` CLI for the PR.

**Closes:** release (the v0.9.6 milestone — the PR carries the full `Closes #38, #70, #124, #129, #130, #131, #132, #133, #134, #135, #136, #137, #138, #139, #141, #142, #143, #144, #145, #146, #147, #148, #149` list).

## Conventions (carried from CLAUDE.md + the v0.9.0/v0.9.1 release plans)

- **Prefix every shell command with `source ~/.zshenv && `** — the Bash tool's shell does not auto-source `~/.zshenv`, so `pnpm`/`node`/`docker`/`gh` are off PATH without it (it also sets `DOCKER_HOST` for Colima + `TESTCONTAINERS_DOCKER_SOCKET_OVERRIDE`). `colima start` if the Docker daemon is down (the test gate needs Testcontainers Postgres).
- **Branch:** every commit lands on `patches/v0.9.6`, NEVER on `main` (single-branch / single-PR discipline from the spec §0). The PR to `main` fires only in Task 4.
- **Conventional Commits**, one logical change each. **Every commit message ends with the trailer line** (spec G9 mandate):
  ```
  Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>
  ```
- **Do NOT push** from plan steps — the controller pushes and authorizes the merge. Task 4 *prepares* the PR command but the controller runs it (or the subagent runs `gh pr create` against the already-pushed branch only after the controller has pushed). Do not run `git push`, `git tag`, or `gh pr merge`.
- **Combined gate before the release commits:** `source ~/.zshenv && pnpm lint && pnpm typecheck && pnpm build`. `pnpm lint` is `biome check .` and now enforces G1's `noRestrictedGlobals` ban on `confirm`/`alert`/`prompt`. Run `pnpm test` too where Docker is available — but the gate that MUST be green to ship is lint + typecheck + build (the per-group plans already gated their own Testcontainers tests).

### Added
- **Themed editor dialogs (#138, #135, #38).** An imperative editor-dialog bus (`src/components/editor/editor-dialog-bus.ts`) + a React `<EditorDialogs>` host let TipTap slash commands open themed `InputDialog` / multi-field form dialogs (footnote, citation DOI/PubMed/author/title/year, flashcard front/back/deck) without React hooks. - **Empty-state NodeViews + slash aliases (#139, #148, #149).** Every MEDIA/ADVANCED block renders an interactive empty state on insert (File "Upload a file", Citation "Paste DOI / lookup", Image/Gallery/Video/Audio upload-or-URL, Embed/Bookmark "Paste URL", Mermaid/Math "Edit", Flashcard front/back, Toggle/Footnote/Synced placeholders). Slash descriptors gain a `keywords` alias list and the slash search matches title OR any keyword (equation→math, embed→iframe/youtube, image→img/picture/photo, code→snippet, and the rest).
- **Admin sub-pages (#132).** Audit-log viewer (read-only table over `audit_log`), user management (list / invite / role-change / deactivate), and SIEM config UI (form over the v0.9.0 SIEM forwarder config), wired into the Admin nav.
- **Connectors create-flow (#146, #147).** "Add connector" now opens a Slack / Discord connector-type picker + create flow over the v0.9.0 chat-bridge backend; a "Connectors" sub-entry on the Developer settings nav, a themed empty state, and the primary-button style unified with "Create key".
- **Page covers (#108).** "+ Add cover" opens a cover picker (image upload + URL input) writing `pages.cover`.
- **Suggestions panel (#85, #145).** The tab-strip "N open" badge opens a suggestions drawer listing open suggestions with accept / reject.
- **🔒 Locked indicator (#134).** A locked page renders a `🔒 Locked until <time>` badge in place of the hidden edit affordances.
- **Move-to picker (#124).** A searchable page-tree / workspace-root destination picker wired into the page row-action menu + action panels, calling the existing `POST /api/pages/[id]/move`.
- **DB view + empty-state polish (#142, #143, #144).** Tooltips on disabled Calendar / Timeline view types, per-view-type icons on the "+ Add view" dropdown, an "Add your first row" CTA + row-count indicator, and reduced dead vertical space.
- **MFA WebAuthn + sessions (#70).** Passkey registration + login ceremonies alongside TOTP; an active-sessions list (this-device marked) + "Sign out everywhere" backed by a new `auth_sessions` session store (migration `0055`) — the jwt callback writes a `sid` claim + a session row, and the proxy/auth middleware rejects revoked sessions. Recovery-codes management (view-used + regenerate) finished.
- **Workspace icon picker + Swagger polish (#141).** A workspace icon-picker UI over the `workspaces.icon` column; `/api-docs` Swagger `servers` resolved via `publicOrigin()`, `info.version` from the build-time app version, a back-to-Cairn header link, and a dark Swagger stylesheet.

### Fixed
- **Emoji picker (#129, #130, #131).** Root-caused the empty grid — the self-hosted `/emoji-data.json` wiring was broken; the picker points at the same-origin dataset again. Collapsed the two nested search inputs into one, and moved the picker into the themed radix `Popover` for Escape + click-outside dismiss.
- **Embeddings on portable images (#136).** Switched the embedder off the native `onnxruntime-node` path to the `onnxruntime-web` (WASM) backend, so the image carries no `.so` and runs portably across base images + arm64/amd64. CI gains an image-boot smoke that runs `embedPage` on a stub page and asserts a vector is written with no "Failed to load external module".
- **Collab auth diagnostics (#137).** `onAuthenticate` now logs the rejection reason (bad-signature / expired / page-mismatch) + the token's `pageId`/`exp` (never the secret) instead of a bare `Unauthorized`; README troubleshooting documents the operator-side `AUTH_SECRET` mismatch between `cairn` and `cairn-collab` as the root cause.
- **Viewport edge glow (#133).** Fixed the intermittent orange/red edge glow that appeared after rapid slash-menu interaction — a stuck focus/error state class on a full-width container.

### Changed
- **Sidebar search (#84).** The "Search or jump to…" input is relabeled to match its palette behavior; `⌘K` remains the palette entry — clarified, not restricted.
