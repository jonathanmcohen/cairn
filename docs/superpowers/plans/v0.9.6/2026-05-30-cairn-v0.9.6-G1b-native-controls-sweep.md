# G1b — Native Form-Control Sweep Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Replace every remaining unthemed native `<select>` and `<input type="date|time">` UI control in `src/` with the themed primitives (`Select`, `DateField`), then lock the sweep with a CI source-scan guard so #38 stays closed.

**Architecture:** The dialog epic (G1a, #138) handled `window.confirm/prompt/alert`. THIS plan handles the *form-control* half of the #38 umbrella. The themed `Select` (`src/components/ui/select.tsx`, a radix wrapper: `Select`/`SelectTrigger`/`SelectValue`/`SelectContent`/`SelectItem`) and `DateField` (`src/components/ui/date-field.tsx`, a radix `Popover` + self-rendered `Calendar`, value/onChange are ISO `YYYY-MM-DD` strings) already exist and are proven at call sites like `view-switcher.tsx`. Each task converts one file's controls and adds a jsdom component test. A final task adds a source-walking Vitest guard (mirroring `tests/components/editor/bundle-budget.test.ts`) that fails if a raw `<select` or native date/time input reappears under `src/` (excluding the `ui/` primitives and `calendar.tsx`).

**Tech Stack:** React 19 / Next 16 / TS6 strict, radix-ui (`Select`, `Popover`), Tailwind v4, Biome v2 (NOT ESLint), Vitest 4 (jsdom for components), `@testing-library/react`.

**Closes:** #38 (the cross-cutting native-form-control umbrella; the dialog half closed by G1a/#138)

**Explicitly OUT OF SCOPE (no themed primitive exists for them; #38 scope per the v0.9.6 design names only `Select`/`DateField`-class controls):**
- `type="checkbox"`, `type="radio"`, `type="file"` — there is no `src/components/ui/checkbox.tsx`/`switch.tsx`/`radio.tsx`/file primitive to convert to. Converting these would be net-new primitive work, not a sweep. They stay native.
- `type="number"` / `type="text"` native inputs (the `Input` primitive exists but these are tiny inline cell editors; not part of #38's "select/date" mandate).
- `editor/extensions/datetime.tsx`'s native `type="time"` has NO themed time primitive — keep `type="time"` but adopt the `Input` primitive's classes so it is themed. The guard must therefore allow `type="time"` (see Task 12).

> **The number of conversion tasks below is driven by this real audit.** A subagent must NOT skip a file because "it's similar to another" — every file's exact code is given.

**radix `Select` gotcha (applies to EVERY conversion):** `SelectItem value=""` throws at runtime (`A <Select.Item /> must have a value prop that is not an empty string`). Any native `<option value="">…</option>` sentinel ("All", "—", "Target database…") must become a `SelectItem value="__all"` (or `"__none"`) and be mapped back to `''` in `onValueChange`/`value`. Each task that has such a sentinel spells this out.

import { readdirSync, readFileSync, statSync } from 'node:fs';
import { join } from 'node:path';
import { describe, expect, it } from 'vitest';

const SRC = join(process.cwd(), 'src');
// The themed primitives themselves contain these strings (in JSDoc/comments and
// calendar.tsx's intentional native-date reference). Exclude that one dir.
const EXCLUDE_DIRS = new Set([join(SRC, 'components', 'ui')]);

function walk(dir: string, out: string[] = []): string[] {
  if (EXCLUDE_DIRS.has(dir)) return out;
  for (const ent of readdirSync(dir)) {
    const full = join(dir, ent);
    if (statSync(full).isDirectory()) {
      walk(full, out);
    } else if (full.endsWith('.tsx') || full.endsWith('.ts')) {
      out.push(full);
    }
  }
  return out;
}

describe('native form-control guard (#38)', () => {
  const files = walk(SRC);

  it('has no raw <select element under src/ (outside ui primitives)', () => {
    const offenders = files.filter((f) => /<select[\s>]/.test(readFileSync(f, 'utf8')));
    expect(
      offenders.map((f) => f.replace(`${process.cwd()}/`, '')),
      'convert these to the themed <Select> primitive',
    ).toEqual([]);
  });

  it('has no native <input type="date"|"datetime-local"> under src/ (outside ui primitives)', () => {
    const offenders = files.filter((f) =>
      /type="(date|datetime-local)"/.test(readFileSync(f, 'utf8')),
    );
    expect(
