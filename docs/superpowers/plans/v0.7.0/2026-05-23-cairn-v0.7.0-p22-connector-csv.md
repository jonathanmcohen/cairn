# Cairn v0.7.0 — Plan P22: CSV connector adapter + connector-secret leak suite

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the third (and final) v0.7.0 connector adapter — a **CSV file** adapter that reads/writes a CSV under a configured mount (`CAIRN_CONNECTOR_CSV_PATH`). Poll-only — no push (no `subscribe`); the P19 sync engine drives it via the cron entry per connector. **Also extends the v0.5.1 / v0.6 secret-leak suite** to cover all three connector adapters' secret classes (Sheets OAuth refresh token, Airtable PAT, Airtable webhook MAC secret, CSV path — the path is not a secret but is a sensitive operational config we still verify isn't leaked into API responses or audit metadata).

**Architecture:** Single adapter file (`src/lib/connectors/csv/adapter.ts`) implementing `ConnectorAdapter` from P19. `fetchAll` parses the configured CSV file under `CAIRN_CONNECTOR_CSV_PATH` (joined with a per-connector relative path from `sync_config`); `applyChanges` rewrites the entire file in place (CSV is small + simple; we don't try to do partial rewrites). No `subscribe` — the adapter explicitly omits it, signaling "poll-only" to the P19 sync engine. A config-form UI under the P19 connector shell collects the relative-path + delimiter + encoding + property → column-name map. The leak suite extension lives in `tests/security/secret-leak.test.ts` as a new `describe('secret-leak: connector secrets')` block that walks the four surfaces (API responses, audit metadata, token-usage log, workspace-archive export) and asserts each connector secret class is absent.

**Tech Stack:** `csv-parse` + `csv-stringify` (small, mature node-csv packages — no version pin). No new env vars beyond `CAIRN_CONNECTOR_CSV_PATH`. Path resolution uses `path.resolve` and a check that the resolved final path stays under `CAIRN_CONNECTOR_CSV_PATH` (prevents `..`-escape).

**Spec:** `docs/superpowers/specs/2026-05-23-cairn-v0.7.0-design.md` §2.7 (poll-only for sources without push — CSV is the canonical case), §3 G7 "CSV" (file path on a configured mount; mapping = relative path, delimiter, encoding, property → column-name map), §5.1 (the secret-leak suite extension is the explicit cross-cutting deliverable — PAT + OAuth refresh token + MAC secret never appear in API responses / audit metadata / token-usage log / workspace export; `database_connectors.auth_config` bytea contains no plaintext substrings).

- [x] **Step 2: Implement the adapter**

```ts
import { readFile, writeFile } from 'node:fs/promises';
import { resolve, sep } from 'node:path';
import { parse } from 'csv-parse/sync';
import { stringify } from 'csv-stringify/sync';
import type {
  AckedChange,
  ConnectorAdapter,
  ConnectorState,
  Diff,
  ExternalRow,
} from '@/lib/connectors/adapter';
import { env } from '@/lib/env';

type CsvSyncConfig = {
  relativePath: string;
  delimiter: string;                       // ',' or ';' or '\t'
  encoding: BufferEncoding;                // 'utf8' default
  columnMap: Record<string, string>;       // cairn property id → CSV column header
  externalIdProperty: string;
};

function resolveCsvPath(syncConfig: CsvSyncConfig): string {
  const mount = env().CAIRN_CONNECTOR_CSV_PATH;
  if (!mount) throw new Error('CSV connector mount not configured');
  const mountAbs = resolve(mount);
  const target = resolve(mountAbs, syncConfig.relativePath);
  if (!target.startsWith(mountAbs + sep) && target !== mountAbs) {
    throw new Error('path escapes mount');
  }
  return target;
}

export const CsvAdapter: ConnectorAdapter = {
  kind: 'csv',
  authConfigSchema: undefined as never, // empty for CSV — no auth

  async fetchAll(state) {
    const cfg = state.syncConfig as CsvSyncConfig;
    const path = resolveCsvPath(cfg);
    const raw = await readFile(path, { encoding: cfg.encoding });
    const records = parse(raw, {
      delimiter: cfg.delimiter,
      columns: true,        // first row is the header
      skip_empty_lines: true,
      trim: true,
    }) as Array<Record<string, string>>;

    const out: ExternalRow[] = [];
    for (const rec of records) {
      const cells: Record<string, unknown> = {};
      for (const [propId, header] of Object.entries(cfg.columnMap)) {
        cells[propId] = rec[header] ?? null;
      }
      const externalId = String(cells[cfg.externalIdProperty] ?? '');
      if (!externalId) continue; // skip rows with no external id
      out.push({ externalId, cells });
    }
    return out;
  },

  async applyChanges(state, diff: Diff) {
    const cfg = state.syncConfig as CsvSyncConfig;
    const path = resolveCsvPath(cfg);

    // Load the current file → row map keyed by externalId.
    const raw = await readFile(path, { encoding: cfg.encoding }).catch(() => '');
    const records = raw
      ? parse(raw, { delimiter: cfg.delimiter, columns: true, skip_empty_lines: true, trim: true })
      : [];
    const idHeader = cfg.columnMap[cfg.externalIdProperty];
    const byId = new Map<string, Record<string, string>>();
    for (const rec of records) byId.set(String(rec[idHeader] ?? ''), rec);

    // Apply deletes.
    for (const d of diff.deletes) byId.delete(d.externalId);

    // Apply upserts.
    for (const u of diff.upserts) {
      const existing = byId.get(u.externalId) ?? {};
      for (const [propId, header] of Object.entries(cfg.columnMap)) {
        if (propId in u.cells) existing[header] = String(u.cells[propId] ?? '');
      }
      existing[idHeader] = u.externalId;
      byId.set(u.externalId, existing);
    }

    // Serialize back.
    const headers = Object.values(cfg.columnMap);
    const out = stringify(Array.from(byId.values()), {
      header: true,
      columns: headers,
      delimiter: cfg.delimiter,
    });
    await writeFile(path, out, { encoding: cfg.encoding });

    const acked: AckedChange[] = [];
    for (const u of diff.upserts) acked.push({ externalId: u.externalId });
    for (const d of diff.deletes) acked.push({ externalId: d.externalId });
    return { ack: acked };
  },

  // subscribe intentionally omitted — poll-only.
};
```

import { useState } from 'react';
import { Button } from '@/components/ui/button';
import { Input } from '@/components/ui/input';

type Property = { id: string; name: string; type: string };

  connectorId: string;
  properties: Property[];
  initial?: {
    relativePath?: string;
    delimiter?: string;
    encoding?: string;
    columnMap?: Record<string, string>;
    externalIdProperty?: string;
  };

export function CsvConfigForm({ connectorId, properties, initial }: Props) {
  const [relativePath, setRelativePath] = useState(initial?.relativePath ?? '');
  const [delimiter, setDelimiter] = useState(initial?.delimiter ?? ',');
  const [encoding, setEncoding] = useState(initial?.encoding ?? 'utf8');

      headers: { 'content-type': 'application/json' },
      body: JSON.stringify({
        syncConfig: { relativePath, delimiter, encoding, columnMap, externalIdProperty },
        enabled: true,
      }),
    });
    setBusy(false);
  }

  return (
    <form onSubmit={onSubmit} className="space-y-4">
      <div className="space-y-1">
        <Label htmlFor="relativePath">Relative file path (under mount)</Label>
        <Input id="relativePath" required value={relativePath} onChange={(e) => setRelativePath(e.target.value)} placeholder="projects.csv" />

      </div>
      <div className="grid grid-cols-2 gap-3">
        <div className="space-y-1">
          <Label htmlFor="delimiter">Delimiter</Label>
          <select id="delimiter" value={delimiter} onChange={(e) => setDelimiter(e.target.value)} className="w-full rounded border px-2 py-1">
            <option value=",">Comma (,)</option>
            <option value=";">Semicolon (;)</option>
            <option value="\t">Tab</option>
          </select>
        </div>
        <div className="space-y-1">
          <Label htmlFor="encoding">Encoding</Label>
          <select id="encoding" value={encoding} onChange={(e) => setEncoding(e.target.value)} className="w-full rounded border px-2 py-1">
            <option value="utf8">UTF-8</option>
            <option value="latin1">Latin-1 (ISO-8859-1)</option>
            <option value="utf16le">UTF-16 LE</option>
          </select>
        </div>
      </div>
      <div className="space-y-1">
        <Label htmlFor="externalIdProperty">External-ID property</Label>
        <select id="externalIdProperty" value={externalIdProperty} onChange={(e) => setExternalIdProperty(e.target.value)} className="w-full rounded border px-2 py-1">

            />
          </div>
        ))}
      </div>
      <Button type="submit" disabled={busy}>{busy ? 'Saving…' : 'Save connector'}</Button>
    </form>
  );
