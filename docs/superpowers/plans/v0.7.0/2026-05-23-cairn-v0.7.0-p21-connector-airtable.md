# Cairn v0.7.0 — Plan P21: Airtable connector adapter

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the second concrete two-way DB connector adapter on top of P19's `ConnectorAdapter` interface + sync engine + conflict inbox: an **Airtable** adapter. Authentication is by user-pasted Airtable **Personal Access Token** (no OAuth dance — the user mints a PAT in their Airtable account and pastes it; we store it encrypted via P19's `connectors/auth.ts`). Push is via Airtable's native webhooks (validated by HMAC). Pull is via the Records API `list` + batched `create`/`update`/`delete` (≤10 records per Airtable request, the platform's hard limit).

**Architecture:** Single adapter file (`src/lib/connectors/airtable/adapter.ts`) implementing `ConnectorAdapter`. One webhook receiver (`src/app/api/connectors/airtable/webhook/route.ts`) for Airtable's push notifications — Airtable signs each webhook body with HMAC-SHA256 keyed by the per-webhook MAC secret returned at registration; we store that secret alongside the PAT inside the connector's encrypted `auth_config` and validate against it on every receipt. The adapter's `fetchAll` paginates through the Records API; `applyChanges` chunks upserts/deletes into 10-record batches. A config-form UI mirrors P20's shape: paste-your-PAT field + baseId + tableId + property → field-name map.

**Tech Stack:** Either the official `airtable` npm package or pure `fetch` against `api.airtable.com/v0`. Both ship in one tiny dependency-class. The plan uses pure `fetch` (no SDK pin needed; the Airtable API is stable + well-documented; saves an extra dep). The HMAC validation is `crypto.createHmac('sha256', secret)` against the raw request body — pure Node, no extra dep. No new DB schema; all storage lands in P19's `database_connectors.auth_config`.

**Spec:** `docs/superpowers/specs/2026-05-23-cairn-v0.7.0-design.md` §2.7 (hybrid push+poll, LWW per-cell, conflict-review inbox), §3 G7 "Airtable" (PAT pasted + encrypted; Airtable webhooks; Records API; mapping = baseId + tableId + property → field-name map), §5.1 (PAT is a secret class, encrypted at rest, never echoed; webhook HMAC secret in the same class).

## Task 1: AirtableAdapter (`src/lib/connectors/airtable/adapter.ts`)

**Goal:** Implement `ConnectorAdapter` for Airtable. Three methods:
- `fetchAll(state)` → paginates through `GET /v0/{baseId}/{tableIdOrName}` (Records API `list`), maps each record → `ExternalRow`.
- `applyChanges(state, diff)` → chunks upserts to ≤10 per `PATCH` (with `performUpsert.fieldsToMergeOn` if the external id is mapped to an Airtable field), and deletes to ≤10 per `DELETE`.
- `subscribe(state, onChange)` → calls `POST /v0/bases/{baseId}/webhooks` to register a Cairn webhook URL for the table; persists the returned MAC secret into the connector's `auth_config` so the receiver can verify HMAC.

- [x] **Step 2: Implement the adapter**

```ts
import type {
  AckedChange,
  ConnectorAdapter,
  ConnectorState,
  Diff,
  ExternalRow,
} from '@/lib/connectors/adapter';
import { decryptAuthConfig, encryptAuthConfig } from '@/lib/connectors/auth';

const AIRTABLE_API = 'https://api.airtable.com/v0';
const BATCH_LIMIT = 10; // Airtable's hard cap on records-per-request

type AirtableAuthConfig = {
  pat_encrypted: string;
  webhook_mac_secret_encrypted?: string;
  webhook_id?: string;
};

type AirtableSyncConfig = {
  baseId: string;
  tableId: string;
  fieldMap: Record<string, string>;            // cairn property id → Airtable field name
  externalIdProperty: string;
};

async function pat(state: ConnectorState) {
  return decryptAuthConfig((state.authConfig as AirtableAuthConfig).pat_encrypted);
}

function chunk<T>(xs: T[], n: number): T[][] {
  const out: T[][] = [];
  for (let i = 0; i < xs.length; i += n) out.push(xs.slice(i, i + n));
  return out;
}

function recordToCells(rec: { id: string; fields: Record<string, unknown> }, cfg: AirtableSyncConfig) {
  const cells: Record<string, unknown> = {};
  for (const [propId, fieldName] of Object.entries(cfg.fieldMap)) {
    cells[propId] = rec.fields[fieldName] ?? null;
  }
  return cells;
}

function cellsToFields(cells: Record<string, unknown>, cfg: AirtableSyncConfig) {
  const fields: Record<string, unknown> = {};
  for (const [propId, fieldName] of Object.entries(cfg.fieldMap)) {
    if (propId in cells) fields[fieldName] = cells[propId];
  }
  return fields;
}

export const AirtableAdapter: ConnectorAdapter = {
  kind: 'airtable',
  authConfigSchema: undefined as never, // registered in P19 elsewhere

  async fetchAll(state) {
    const cfg = state.syncConfig as AirtableSyncConfig;
    const token = await pat(state);
    const headers = { Authorization: `Bearer ${token}` };
    let url = `${AIRTABLE_API}/${cfg.baseId}/${cfg.tableId}?pageSize=100`;
    const out: ExternalRow[] = [];
    while (true) {
      const res = await fetch(url, { headers });
      if (!res.ok) throw new Error(`airtable.list ${res.status}`);
      const body = await res.json() as { records: Array<{ id: string; fields: Record<string, unknown> }>; offset?: string };
      for (const r of body.records) {
        const cells = recordToCells(r, cfg);
        out.push({ externalId: r.id, cells });
      }
      if (!body.offset) break;
      url = `${AIRTABLE_API}/${cfg.baseId}/${cfg.tableId}?pageSize=100&offset=${encodeURIComponent(body.offset)}`;
    }
    return out;
  },

  async applyChanges(state, diff: Diff) {
    const cfg = state.syncConfig as AirtableSyncConfig;
    const token = await pat(state);
    const headers = { Authorization: `Bearer ${token}`, 'Content-Type': 'application/json' };
    const acked: AckedChange[] = [];

    // Upserts → batched PATCH (Airtable supports performUpsert when external id maps to a field).
    for (const group of chunk(diff.upserts, BATCH_LIMIT)) {
      const body = {
        performUpsert: { fieldsToMergeOn: [cfg.fieldMap[cfg.externalIdProperty]] },
        records: group.map((u) => ({
          fields: cellsToFields(u.cells, cfg),
        })),
      };
      const res = await fetch(`${AIRTABLE_API}/${cfg.baseId}/${cfg.tableId}`, {
        method: 'PATCH',
        headers,
        body: JSON.stringify(body),
      });
      if (!res.ok) throw new Error(`airtable.patch ${res.status}`);
      for (const u of group) acked.push({ externalId: u.externalId });
    }

    // Deletes → batched DELETE (?records[]=id&records[]=id...).
    for (const group of chunk(diff.deletes, BATCH_LIMIT)) {
      const qs = group.map((d) => `records[]=${encodeURIComponent(d.externalId)}`).join('&');
      const res = await fetch(`${AIRTABLE_API}/${cfg.baseId}/${cfg.tableId}?${qs}`, {
        method: 'DELETE',
        headers: { Authorization: `Bearer ${token}` },
      });
      if (!res.ok) throw new Error(`airtable.delete ${res.status}`);
      for (const d of group) acked.push({ externalId: d.externalId });
    }

    return { ack: acked };
  },

  async subscribe(state, _onChange) {
    const cfg = state.syncConfig as AirtableSyncConfig;
    const token = await pat(state);
    const webhookUrl = `${process.env.PUBLIC_URL ?? ''}/api/connectors/airtable/webhook?w=${state.workspaceId}&c=${state.connectorId}`;

    const res = await fetch(`${AIRTABLE_API}/bases/${cfg.baseId}/webhooks`, {
      method: 'POST',
      headers: { Authorization: `Bearer ${token}`, 'Content-Type': 'application/json' },
      body: JSON.stringify({
        notificationUrl: webhookUrl,
        specification: {
          options: {
            filters: { dataTypes: ['tableData'], recordChangeScope: cfg.tableId },
          },
        },
      }),
    });
    if (!res.ok) throw new Error(`airtable.webhook.register ${res.status}`);
    const body = await res.json() as { id: string; macSecretBase64: string };

    // Persist webhook id + MAC secret encrypted on the connector's auth_config.
    // The caller in P19's sync engine handles the DB update via the returned shape:
    state.authConfig = {
      ...(state.authConfig as AirtableAuthConfig),
      webhook_id: body.id,
      webhook_mac_secret_encrypted: await encryptAuthConfig(body.macSecretBase64),
    } as AirtableAuthConfig;

    return async () => {
      try {
        await fetch(`${AIRTABLE_API}/bases/${cfg.baseId}/webhooks/${body.id}`, {
          method: 'DELETE',
          headers: { Authorization: `Bearer ${token}` },
        });
      } catch {
        /* webhook may already be expired */
      }
    };
  },
};
```

- [x] **Step 2: Implement the route**

```ts
import { createHmac, timingSafeEqual } from 'node:crypto';
import { and, eq } from 'drizzle-orm';
import { NextResponse, type NextRequest } from 'next/server';
import { db } from '@/db/client';
import { databaseConnectors } from '@/db/schema';
import { decryptAuthConfig } from '@/lib/connectors/auth';
import { syncConnector } from '@/lib/connectors/sync';

export async function POST(req: NextRequest) {
  const url = new URL(req.url);
  const workspaceId = url.searchParams.get('w');
  const connectorId = url.searchParams.get('c');
  if (!workspaceId || !connectorId) {
    return NextResponse.json({ error: 'missing identifiers' }, { status: 400 });
  }

  const macHeader = req.headers.get('x-airtable-content-mac');
  if (!macHeader) return NextResponse.json({ error: 'missing mac' }, { status: 401 });

  // Read the raw body (HMAC is computed over the raw bytes; we must not re-serialize).
  const raw = await req.text();

  const [conn] = await db
    .select({ id: databaseConnectors.id, authConfig: databaseConnectors.authConfig })
    .from(databaseConnectors)
    .where(
      and(
        eq(databaseConnectors.id, connectorId),
        eq(databaseConnectors.workspaceId, workspaceId),
      ),
    );
  if (!conn) {
    // Existence-non-leak.
    return NextResponse.json({ error: 'not found' }, { status: 404 });
  }

  const macEncrypted = (conn.authConfig as { webhook_mac_secret_encrypted?: string }).webhook_mac_secret_encrypted;
  if (!macEncrypted) return NextResponse.json({ error: 'no mac configured' }, { status: 401 });
  const macSecretB64 = await decryptAuthConfig(macEncrypted);

  // Header form: "hmac-sha256=<base64>"
  const m = /^hmac-sha256=(.+)$/.exec(macHeader);
  if (!m) return NextResponse.json({ error: 'bad mac header' }, { status: 401 });

  const expected = createHmac('sha256', Buffer.from(macSecretB64, 'base64')).update(raw).digest('base64');
  let ok = false;
  try {
    ok = timingSafeEqual(Buffer.from(expected, 'base64'), Buffer.from(m[1], 'base64'));
  } catch {
    ok = false;
  }
  if (!ok) return NextResponse.json({ error: 'invalid mac' }, { status: 401 });

  setImmediate(() => {
    syncConnector(connectorId).catch(() => {
      /* logged inside syncConnector */
    });
  });
  return NextResponse.json({ ok: true });
}
```

  const [fieldMap, setFieldMap] = useState<Record<string, string>>(initial?.fieldMap ?? {});
  const [busy, setBusy] = useState(false);

  function setField(propId: string, fieldName: string) {
    setFieldMap((m) => ({ ...m, [propId]: fieldName.trim() }));
  }

  async function onSubmit(e: React.FormEvent) {
    e.preventDefault();
    setBusy(true);
    await fetch(`/api/connectors/${connectorId}`, {
      method: 'PATCH',
      headers: { 'content-type': 'application/json' },
      body: JSON.stringify({
        // The server route encrypts pat into authConfig.pat_encrypted on save.
        authConfig: pat ? { pat } : undefined,
        syncConfig: { baseId, tableId, fieldMap, externalIdProperty },
        enabled: true,
      }),
    });
    setBusy(false);
    setPat(''); // clear after save — never round-trip the plaintext through the UI
  }

  return (
    <form onSubmit={onSubmit} className="space-y-4">
      <div className="space-y-1">
        <Label htmlFor="pat">Airtable Personal Access Token</Label>
        <Input id="pat" type="password" autoComplete="off" placeholder={initial?.baseId ? '(unchanged)' : 'pat…'} value={pat} onChange={(e) => setPat(e.target.value)} />
        <p className="text-muted-foreground text-xs">Stored encrypted at rest. Leave blank to keep the existing token.</p>
      </div>
      <div className="grid grid-cols-2 gap-3">
        <div className="space-y-1">
          <Label htmlFor="baseId">Base ID</Label>
          <Input id="baseId" required value={baseId} onChange={(e) => setBaseId(e.target.value)} />
        </div>
        <div className="space-y-1">
          <Label htmlFor="tableId">Table ID</Label>
          <Input id="tableId" required value={tableId} onChange={(e) => setTableId(e.target.value)} />
        </div>
      </div>
      <div className="space-y-1">
        <Label htmlFor="externalIdProperty">External-ID property</Label>
        <select id="externalIdProperty" value={externalIdProperty} onChange={(e) => setExternalIdProperty(e.target.value)} className="w-full rounded border px-2 py-1">
          {properties.map((p) => <option key={p.id} value={p.id}>{p.name}</option>)}
        </select>
      </div>
      <div className="space-y-2">
        <Label>Property → Airtable field name</Label>
        {properties.map((p) => (
          <div key={p.id} className="flex items-center gap-2">
            <span className="w-40 text-sm">{p.name}</span>
            <Input
              placeholder="Field name (case-sensitive)"
              value={fieldMap[p.id] ?? ''}
              onChange={(e) => setField(p.id, e.target.value)}
              className="flex-1"
            />
          </div>
        ))}
      </div>
      <Button type="submit" disabled={busy}>{busy ? 'Saving…' : 'Save connector'}</Button>
    </form>
  );
}
