# Cairn v0.7.0 — Plan P20: Google Sheets connector adapter

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the first concrete two-way DB connector adapter built on top of P19's `ConnectorAdapter` interface + sync engine + conflict inbox: a **Google Sheets** adapter. Implements the OAuth handshake (authorization-code flow → encrypted refresh token), Drive `files.watch` change-notification webhook for push-triggered syncs, and Sheets API `values.batchGet` / `values.batchUpdate` for `fetchAll` / `applyChanges`. Wires the adapter into the P19 connector registry and ships a config-form UI under the P19 connector shell so a user can pick a spreadsheet/sheet + map cairn properties → column letters.

**Architecture:** The adapter is one file (`src/lib/connectors/sheets/adapter.ts`) implementing `ConnectorAdapter` from P19; an `auth.ts` sibling owns the OAuth2 client + encrypted-refresh-token storage path (encryption reused from P19's `connectors/auth.ts` which itself wraps the v0.6 `secret-box`). Three API routes under `src/app/api/connectors/sheets/` cover the OAuth start, OAuth callback, and the Drive change-notification webhook — the webhook receives a `X-Goog-Channel-Token` (the per-connector signed token we hand Drive on subscribe) and dispatches `syncConnector(connectorId)` (the P19 orchestrator entrypoint). The Sheets API + Drive API talk through the official `googleapis` SDK. The UI form mirrors the P19 connector-shell pattern: pick spreadsheetId + sheetId (sheet tab GID), then a property-id → column-letter map.

**Tech Stack:** `googleapis` (Google's official Node SDK; latest stable, no version pin) for the Sheets v4 + Drive v3 clients and OAuth2 client. No DB schema changes — P19's `database_connectors` table holds `auth_config` (jsonb, encrypted) + `sync_config` (jsonb). All OAuth refresh tokens live inside `auth_config`.

**Spec:** `docs/superpowers/specs/2026-05-23-cairn-v0.7.0-design.md` §2.7 (hybrid push+poll, LWW per-cell, conflict-review inbox), §3 G7 "Adapter implementations / Sheets" (OAuth + Drive watches + Sheets API; mapping = spreadsheetId + sheetId + header-row + property → column-letter map), §5.1 (secret hygiene — OAuth refresh tokens are a secret class; encrypted at rest), §5.4 (`connector_sync_total{kind=google_sheets, outcome}` metric series — emitted from the P19 sync engine, not this plan).

```ts
import { google } from 'googleapis';
import { env } from '@/lib/env';
import {
  decryptAuthConfig,
  encryptAuthConfig,
} from '@/lib/connectors/auth';

const SCOPES = [
  'https://www.googleapis.com/auth/spreadsheets',
  'https://www.googleapis.com/auth/drive.readonly',
];

export function buildOAuthClient(redirectUri: string) {
  const clientId = env().CAIRN_GOOGLE_OAUTH_CLIENT_ID;
  const clientSecret = env().CAIRN_GOOGLE_OAUTH_CLIENT_SECRET;
  if (!clientId || !clientSecret) {
    throw new Error('Google OAuth client not configured');
  }
  return new google.auth.OAuth2(clientId, clientSecret, redirectUri);
}

export function buildAuthUrl(redirectUri: string, state: string) {
  const client = buildOAuthClient(redirectUri);
  return client.generateAuthUrl({
    access_type: 'offline',
    prompt: 'consent', // force refresh_token even on re-grant
    scope: SCOPES,
    state,
    include_granted_scopes: true,
  });
}

export async function exchangeCodeForTokens(code: string, redirectUri: string) {
  const client = buildOAuthClient(redirectUri);
  const { tokens } = await client.getToken(code);
  if (!tokens.refresh_token) {
    throw new Error('No refresh token returned (re-grant with prompt=consent)');
  }
  return tokens; // { refresh_token, access_token, expiry_date, ... }
}

export type SheetsAuthConfig = {
  refresh_token_encrypted: string;
};

export async function persistRefreshToken(refreshToken: string): Promise<SheetsAuthConfig> {
  return { refresh_token_encrypted: await encryptAuthConfig(refreshToken) };
}

export async function loadAuthorizedClient(
  authConfig: SheetsAuthConfig,
  redirectUri = 'urn:ietf:wg:oauth:2.0:oob',
) {
  const client = buildOAuthClient(redirectUri);
  const refreshToken = await decryptAuthConfig(authConfig.refresh_token_encrypted);
  client.setCredentials({ refresh_token: refreshToken });
  return client;
}
```

`encryptAuthConfig` / `decryptAuthConfig` are the P19-shipped wrappers that delegate to the v0.6 `secret-box` (key derived from `AUTH_SECRET` via HKDF; AES-256-GCM). The encrypted blob is a string the connector row can store inside its jsonb `auth_config`.

- [x] **Step 2: Implement the adapter**

```ts
import { google, type sheets_v4 } from 'googleapis';
import type {
  AckedChange,
  ConnectorAdapter,
  ConnectorState,
  Diff,
  ExternalRow,
} from '@/lib/connectors/adapter';
import { loadAuthorizedClient, type SheetsAuthConfig } from './auth';

type SheetsSyncConfig = {
  spreadsheetId: string;
  sheetTitle: string;          // human-readable tab name; A1-range source
  headerRow: number;           // first data row = headerRow + 1
  columnMap: Record<string, string>;        // cairn property id → A1 column letter
  externalIdProperty: string;  // which cairn property holds the external row id
};

async function sheetsClient(state: ConnectorState): Promise<sheets_v4.Sheets> {
  const oauth = await loadAuthorizedClient(state.authConfig as SheetsAuthConfig);
  return google.sheets({ version: 'v4', auth: oauth });
}

async function driveClient(state: ConnectorState) {
  const oauth = await loadAuthorizedClient(state.authConfig as SheetsAuthConfig);
  return google.drive({ version: 'v3', auth: oauth });
}

function columnsByProperty(syncConfig: SheetsSyncConfig): Array<[string, string]> {
  return Object.entries(syncConfig.columnMap);
}

function maxColumnLetter(syncConfig: SheetsSyncConfig): string {
  return columnsByProperty(syncConfig)
    .map(([, col]) => col)
    .sort()
    .at(-1) ?? 'A';
}

export const SheetsAdapter: ConnectorAdapter = {
  kind: 'google_sheets',

  authConfigSchema: undefined as never, // P19 registers via Zod elsewhere; placeholder

  async fetchAll(state) {
    const cfg = state.syncConfig as SheetsSyncConfig;
    const client = await sheetsClient(state);
    const firstDataRow = cfg.headerRow + 1;
    const range = `${cfg.sheetTitle}!A${firstDataRow}:${maxColumnLetter(cfg)}`;
    const { data } = await client.spreadsheets.values.batchGet({
      spreadsheetId: cfg.spreadsheetId,
      ranges: [range],
    });
    const rows = data.valueRanges?.[0]?.values ?? [];
    const props = columnsByProperty(cfg);
    const out: ExternalRow[] = [];
    rows.forEach((row, idx) => {
      const cells: Record<string, unknown> = {};
      for (const [propId, colLetter] of props) {
        const colIndex = colLetter.charCodeAt(0) - 'A'.charCodeAt(0);
        cells[propId] = row[colIndex] ?? null;
      }
      const externalId = String(cells[cfg.externalIdProperty] ?? `${firstDataRow + idx}`);
      out.push({ externalId, cells, sheetRowNumber: firstDataRow + idx });
    });
    return out;
  },

  async applyChanges(state, diff: Diff) {
    const cfg = state.syncConfig as SheetsSyncConfig;
    const client = await sheetsClient(state);
    const reqData: sheets_v4.Schema$ValueRange[] = [];
    const acked: AckedChange[] = [];

    for (const up of diff.upserts) {
      const rowNumber = up.sheetRowNumber as number | undefined; // P19 may carry it back via row_map
      if (!rowNumber) continue;
      const values = columnsByProperty(cfg).map(([propId]) => up.cells[propId] ?? '');
      reqData.push({
        range: `${cfg.sheetTitle}!A${rowNumber}:${maxColumnLetter(cfg)}${rowNumber}`,
        values: [values],
      });
      acked.push({ externalId: up.externalId });
    }
    if (reqData.length === 0) return { ack: acked };

    await client.spreadsheets.values.batchUpdate({
      spreadsheetId: cfg.spreadsheetId,
      requestBody: { valueInputOption: 'USER_ENTERED', data: reqData },
    });
    // Deletes are translated to a row clear (Sheets has no row-delete in values API;
    // the P19 sync engine surfaces deletes as a column wipe + drop from row_map).
    for (const del of diff.deletes) acked.push({ externalId: del.externalId });
    return { ack: acked };
  },

  async subscribe(state, _onChange) {
    const cfg = state.syncConfig as SheetsSyncConfig;
    const client = await driveClient(state);
    const channelId = `cairn-conn-${state.connectorId}-${Date.now()}`;
    const token = `${state.workspaceId}:${state.connectorId}`;
    const webhookUrl = `${process.env.PUBLIC_URL ?? ''}/api/connectors/sheets/drive-webhook`;
    const { data } = await client.files.watch({
      fileId: cfg.spreadsheetId,
      requestBody: {
        id: channelId,
        type: 'web_hook',
        address: webhookUrl,
        token,
      },
    });
    return async () => {
      if (!data.id || !data.resourceId) return;
      try {
        await client.channels.stop({ requestBody: { id: data.id, resourceId: data.resourceId } });
      } catch {
        // Channel may already be expired; ignore.
      }
    };
  },
};
```

`ConnectorState`, `Diff`, `ExternalRow`, `AckedChange`, `ConnectorAdapter` are the types P19 ships. The `sheetRowNumber` carried inside `ExternalRow` (and back through `Diff.upserts`) is how P19 round-trips an external row id to a writable Sheets row index without re-fetching headers.

```ts
import { requireRole } from '@/lib/auth/require-role';
import { buildAuthUrl } from '@/lib/connectors/sheets/auth';
import { signOAuthState } from '@/lib/connectors/oauth-state'; // P19 helper (HMAC of {workspaceId, databaseId, csrf})

export async function GET(req: NextRequest) {
  const { ctx } = await requireRole('admin');
  const url = new URL(req.url);
  const databaseId = url.searchParams.get('databaseId');
  if (!databaseId) return NextResponse.json({ error: 'databaseId required' }, { status: 400 });

  const redirectUri = new URL('/api/connectors/sheets/oauth/callback', url).toString();
  const state = signOAuthState({ workspaceId: ctx.workspaceId, databaseId, csrf: crypto.randomUUID() });
  const authUrl = buildAuthUrl(redirectUri, state);
  return NextResponse.redirect(authUrl);
}
```

- [x] **Step 2: `callback/route.ts`**

```ts
import { NextResponse, type NextRequest } from 'next/server';
import { db } from '@/db/client';
import { databaseConnectors } from '@/db/schema';
import { requireRole } from '@/lib/auth/require-role';
import { exchangeCodeForTokens, persistRefreshToken } from '@/lib/connectors/sheets/auth';
import { verifyOAuthState } from '@/lib/connectors/oauth-state';

export async function GET(req: NextRequest) {
  const { ctx } = await requireRole('admin');
  const url = new URL(req.url);
  const code = url.searchParams.get('code');
  const stateRaw = url.searchParams.get('state');
  if (!code || !stateRaw) return NextResponse.json({ error: 'missing code/state' }, { status: 400 });

  const state = verifyOAuthState(stateRaw);
  if (!state || state.workspaceId !== ctx.workspaceId) {
    return NextResponse.json({ error: 'invalid state' }, { status: 400 });
  }

  const redirectUri = new URL('/api/connectors/sheets/oauth/callback', url).toString();
  const tokens = await exchangeCodeForTokens(code, redirectUri);
  const authConfig = await persistRefreshToken(tokens.refresh_token!);

  await db
    .insert(databaseConnectors)
    .values({
      workspaceId: ctx.workspaceId,
      databaseId: state.databaseId,
      kind: 'google_sheets',
      authConfig,
      syncConfig: {}, // user fills in spreadsheetId + mapping in the config form next
      enabled: false,
      createdBy: ctx.userId,
    })
    .onConflictDoUpdate({
      target: databaseConnectors.databaseId,
      set: { authConfig, kind: 'google_sheets' },
    });

  return NextResponse.redirect(new URL(`/settings/connectors?databaseId=${state.databaseId}`, url));
}
```

`signOAuthState` / `verifyOAuthState` are P19-shipped helpers that HMAC-sign the state with the v0.6 `AUTH_SECRET`-derived key. They prevent cross-workspace CSRF + tampering.

```ts
import { and, eq } from 'drizzle-orm';
import { NextResponse, type NextRequest } from 'next/server';
import { db } from '@/db/client';
import { databaseConnectors } from '@/db/schema';
import { syncConnector } from '@/lib/connectors/sync';

export async function POST(req: NextRequest) {
  const token = req.headers.get('x-goog-channel-token');
  const resourceState = req.headers.get('x-goog-resource-state');
  if (!token) return NextResponse.json({ error: 'missing channel token' }, { status: 400 });

  const [workspaceId, connectorId] = token.split(':');
  if (!workspaceId || !connectorId) {
    return NextResponse.json({ error: 'malformed token' }, { status: 400 });
  }

  const [conn] = await db
    .select({ id: databaseConnectors.id })
    .from(databaseConnectors)
    .where(
      and(
        eq(databaseConnectors.id, connectorId),
        eq(databaseConnectors.workspaceId, workspaceId),
      ),
    );
  if (!conn) {
    // Existence-non-leak: cross-workspace receipts get 404, not 403.
    return NextResponse.json({ error: 'not found' }, { status: 404 });
  }

  // Drive sends an initial "sync" state on channel creation that carries no
  // change — drop it (per Google's webhook contract; otherwise we'd no-op fetch).
  if (resourceState === 'sync') {
    return NextResponse.json({ ok: true });
  }

  // Fire-and-forget — never block the webhook ack on adapter work.
  setImmediate(() => {
    syncConnector(connectorId).catch(() => {
      /* logged inside syncConnector */
    });
  });

  return NextResponse.json({ ok: true });
}
```

```tsx
    spreadsheetId?: string;

export function SheetsConfigForm({ connectorId, properties, initial }: Props) {
  const [spreadsheetId, setSpreadsheetId] = useState(initial?.spreadsheetId ?? '');
  const [sheetTitle, setSheetTitle] = useState(initial?.sheetTitle ?? 'Sheet1');
  const [headerRow, setHeaderRow] = useState(initial?.headerRow ?? 1);

        enabled: true,
      }),
    });
    setBusy(false);

      <div className="space-y-1">

      <div className="grid grid-cols-2 gap-3">
        <div className="space-y-1">

        </div>
        <div className="space-y-1">
          <Label htmlFor="headerRow">Header row (1-based)</Label>

        </div>
      </div>
      <div className="space-y-1">
        <Label htmlFor="externalIdProperty">External-ID property</Label>
        <select id="externalIdProperty" value={externalIdProperty} onChange={(e) => setExternalIdProperty(e.target.value)} className="w-full rounded border px-2 py-1">
          {properties.map((p) => <option key={p.id} value={p.id}>{p.name}</option>)}
        </select>
      </div>
      <div className="space-y-2">
```
