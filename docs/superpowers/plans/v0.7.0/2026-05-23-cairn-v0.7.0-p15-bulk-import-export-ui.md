# Cairn v0.7.0 — Plan P15: Bulk import/export UI (over v0.6 P21 libs) + SSE progress

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two new Settings pages — `/settings/import` and `/settings/export` — drive the v0.6 P21 import (`runImport`) and export (`runWorkspaceExport`) libraries from the workspace UI. The import page is a multipart-upload form (file + source select); on submit, `POST /api/imports` streams Server-Sent Events while the import runs, emitting progress + finally the import report. The export page kicks an export, mirrors the produced bundle to `FileStorage` (the v0.6 P21 `--target s3` path), and returns a signed download URL. Admin-gated (admin role required). No new library code — this plan is entirely UI + route handlers + tests over libs that already ship.

**Architecture:** v0.6 P21 already exports the four pieces this plan needs: `runImport({source, file, workspaceId})` (the dispatcher in `src/lib/import/run.ts`), `runWorkspaceExport({workspaceId, outDir})` (in `src/lib/export/workspace-archive.ts`), `FileStorage` (with `put` + `get`-style read), and the v0.5 P2 HMAC URL signer (for the temporary download link). The UI shell is a server component at `src/app/(app)/settings/import/page.tsx` mounting a client `ImportForm` component (form + SSE consumer). The `POST /api/imports` route reads the multipart body, persists the uploaded file to a temp location, opens an SSE response, then invokes `runImport` while emitting progress events. The export side is simpler: `POST /api/exports` runs `runWorkspaceExport` to a tmp dir, uploads the produced bundle to `FileStorage` under `backups/`, signs a short-TTL URL, returns JSON. Both routes go through `requireRole('admin')`.

**SSE progress events:** `runImport` already produces a structured `ImportReport` at the end. To get *progress* during the run (not just the final report), the import lib needs a small extension surface — the spec doesn't require this, so we keep the implementation pragmatic: emit `event: progress\ndata: {phase}` events at coarse checkpoints (`reading`, `parsing`, `rewriting`, `persisting`, `done`). If `runImport` doesn't expose a callback hook in v0.6, the route emits the `reading` event, awaits the full `runImport`, then emits `done` with the final report. The intermediate phases are best-effort — the route's responsibility is to keep the SSE channel alive (heartbeat every 10s) and emit at least `reading` + `done`.

**Tech Stack:** Next.js 16 (App Router, server + client components, Node runtime for route handlers), the existing v0.6 P21 import/export libs, the existing v0.6 P20 `requireRole` admin gate, the v0.5 P2 HMAC URL signer (`src/lib/files/signing.ts` per the repo layout), `archiver` (already a dep, used by export), Vitest 4 + Testcontainers Postgres. No new npm deps.

**Spec:** `docs/superpowers/specs/2026-05-23-cairn-v0.7.0-design.md` — §3 G5 "Bulk import/export UI" (the two bullets — `/settings/import` with SSE progress over `POST /api/imports`, `/settings/export` with the download-from-S3 link delta on top of P21's filesystem-only path), §5.1 (no new secrets surfaced — uploaded files go to a workspace-scoped temp area), §5.4 (no new metric series), §6 (no relevant risks).

```ts
import { mkdtemp, writeFile } from 'node:fs/promises';
import { tmpdir } from 'node:os';
import { join } from 'node:path';
import { auth } from '@/lib/auth/config';
import { runImport } from '@/lib/import/run';

export const runtime = 'nodejs';

type ImportSource = 'notion' | 'markdown-folder' | 'workspace-archive';
const VALID_SOURCES: ImportSource[] = ['notion', 'markdown-folder', 'workspace-archive'];

export async function POST(req: Request): Promise<Response> {
  const session = await auth();
  if (!session || !session.user?.id) {
    return new Response(JSON.stringify({ error: 'unauthenticated' }), {
      status: 401,
      headers: { 'content-type': 'application/json' },
    });
  }
  // Admin-only.
  if (session.role !== 'admin' && session.role !== 'owner') {
    return new Response(JSON.stringify({ error: 'forbidden' }), {
      status: 403,
      headers: { 'content-type': 'application/json' },
    });
  }

  let form: FormData;
  try {
    form = await req.formData();
  } catch {
    return new Response(JSON.stringify({ error: 'invalid multipart' }), {
      status: 400,
      headers: { 'content-type': 'application/json' },
    });
  }
  const file = form.get('file');
  const source = form.get('source');
  const workspaceId = form.get('workspaceId');
  if (!(file instanceof Blob) || typeof source !== 'string' || typeof workspaceId !== 'string') {
    return new Response(JSON.stringify({ error: 'missing fields' }), {
      status: 400,
      headers: { 'content-type': 'application/json' },
    });
  }
  if (!(VALID_SOURCES as string[]).includes(source)) {
    return new Response(JSON.stringify({ error: 'unknown source' }), {
      status: 400,
      headers: { 'content-type': 'application/json' },
    });
  }
  // Cross-workspace guard: an admin can only import INTO the workspace they're
  // currently signed into. The full ACL story is on the resolver in P3, but the
  // session-active-workspace check is sufficient for this surface.
  if (session.activeWorkspaceId !== workspaceId) {
    return new Response(JSON.stringify({ error: 'cannot import into a different workspace' }), {
      status: 403,
      headers: { 'content-type': 'application/json' },
    });
  }

  // Persist the upload to a temp file so runImport can read by path.
  const tmpDir = await mkdtemp(join(tmpdir(), 'cairn-import-'));
  const filePath = join(tmpDir, (file as File).name ?? 'upload.bin');
  const buf = Buffer.from(await file.arrayBuffer());
  await writeFile(filePath, buf);

  // Stream SSE.
  const encoder = new TextEncoder();
  const stream = new ReadableStream<Uint8Array>({
    async start(controller) {
      const emit = (event: string, data: unknown) => {
        const payload = `event: ${event}\ndata: ${JSON.stringify(data)}\n\n`;
        controller.enqueue(encoder.encode(payload));
      };
      // Heartbeat keeps the connection alive across proxies; one immediate, then every 10s.
      const hb = setInterval(() => controller.enqueue(encoder.encode(': hb\n\n')), 10_000);
      try {
        emit('progress', { phase: 'reading' });
        const report = await runImport({
          source: source as ImportSource,
          file: filePath,
          workspaceId,
        });
        emit('progress', { phase: 'done' });
        emit('done', report);
      } catch (err) {
        emit('error', { message: err instanceof Error ? err.message : 'unknown' });
      } finally {
        clearInterval(hb);
        controller.close();
      }
    },
  });

  return new Response(stream, {
    status: 200,
    headers: {
      'content-type': 'text/event-stream; charset=utf-8',
      'cache-control': 'no-cache, no-transform',
      connection: 'keep-alive',
    },
  });
}
```

```ts
import { readFile, mkdtemp } from 'node:fs/promises';
import { tmpdir } from 'node:os';
import { join, basename } from 'node:path';
import { auth } from '@/lib/auth/config';
import { runWorkspaceExport } from '@/lib/export/workspace-archive';
import { getStorage } from '@/lib/files/get-storage';
// The HMAC signer from v0.5 P2. Function name may be signFileUrl, signedUrlFor,
// or similar — match the existing import sites in src/app/api/files/*.
import { signFileUrl } from '@/lib/files/signing';

export const runtime = 'nodejs';

export async function POST(req: Request): Promise<Response> {
  const session = await auth();
  if (!session || !session.user?.id) {
    return new Response(JSON.stringify({ error: 'unauthenticated' }), {
      status: 401,
      headers: { 'content-type': 'application/json' },
    });
  }
  if (session.role !== 'admin' && session.role !== 'owner') {
    return new Response(JSON.stringify({ error: 'forbidden' }), {
      status: 403,
      headers: { 'content-type': 'application/json' },
    });
  }
  let body: { workspaceId?: string };
  try {
    body = (await req.json()) as { workspaceId?: string };
  } catch {
    return new Response(JSON.stringify({ error: 'invalid json' }), {
      status: 400,
      headers: { 'content-type': 'application/json' },
    });
  }
  const workspaceId = body.workspaceId;
  if (!workspaceId) {
    return new Response(JSON.stringify({ error: 'workspaceId required' }), {
      status: 400,
      headers: { 'content-type': 'application/json' },
    });
  }
  if (session.activeWorkspaceId !== workspaceId) {
    return new Response(JSON.stringify({ error: 'cannot export a different workspace' }), {
      status: 403,
      headers: { 'content-type': 'application/json' },
    });
  }

  const outDir = await mkdtemp(join(tmpdir(), 'cairn-export-'));
  const { archivePath, sizeBytes } = await runWorkspaceExport({ workspaceId, outDir });

  // Upload to FileStorage under backups/ — same convention as v0.6 P21's
  // backup --target s3 path.
  const key = `backups/${basename(archivePath)}`;
  const storage = getStorage();
  const blob = await readFile(archivePath);
  await storage.put(key, blob, 'application/zip');

  // Sign a short-TTL URL. The signer determines the URL shape; for the local
  // storage backend it's typically /api/files/<id>?sig=...&exp=...
  // For S3, this may be a presigned URL — match the existing v0.5 signer
  // contract (returns a string URL).
  const url = await signFileUrl({ key, ttlSeconds: 300 });

  return new Response(JSON.stringify({ url, key, sizeBytes }), {
    status: 200,
    headers: { 'content-type': 'application/json' },
  });
}
```

> The `signFileUrl({key, ttlSeconds})` call shape is the v0.5 P2 contract. The repo's actual function name may differ — check `src/lib/files/signing.ts` exports and adapt. The same applies to whether `runWorkspaceExport` returns `{archivePath, sizeBytes}` or just `archivePath` — adapt the destructuring to match v0.6 P21.

```tsx
// src/components/import/import-form.tsx
'use client';

import { useState } from 'react';
import { Button } from '@/components/ui/button';

type Phase = 'idle' | 'uploading' | 'running' | 'done' | 'error';

type Source = 'notion' | 'markdown-folder' | 'workspace-archive';
const SOURCES: { value: Source; label: string }[] = [
  { value: 'workspace-archive', label: 'Cairn workspace archive (.zip)' },
  { value: 'notion', label: 'Notion export (.zip)' },
  { value: 'markdown-folder', label: 'Markdown folder (.zip)' },
];

export function ImportForm({ workspaceId }: { workspaceId: string }): JSX.Element {
  const [file, setFile] = useState<File | null>(null);
  const [source, setSource] = useState<Source>('workspace-archive');
  const [phase, setPhase] = useState<Phase>('idle');
  const [log, setLog] = useState<string[]>([]);
  const [error, setError] = useState<string | null>(null);
  const [report, setReport] = useState<unknown>(null);

  const onSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    if (!file) return;
    setPhase('uploading');
    setLog([]);
    setError(null);
    setReport(null);
    const fd = new FormData();
    fd.set('file', file);
    fd.set('source', source);
    fd.set('workspaceId', workspaceId);

    const res = await fetch('/api/imports', { method: 'POST', body: fd });
    if (!res.ok || !res.body) {
      setPhase('error');
      setError(`HTTP ${res.status}`);
      return;
    }
    setPhase('running');
    // Consume the SSE stream.
    const reader = res.body.getReader();
    const decoder = new TextDecoder();
    let buffer = '';
    while (true) {
      const { value, done } = await reader.read();
      if (done) break;
      buffer += decoder.decode(value, { stream: true });
      // SSE messages are separated by a blank line.
      let idx: number;
      while ((idx = buffer.indexOf('\n\n')) !== -1) {
        const chunk = buffer.slice(0, idx);
        buffer = buffer.slice(idx + 2);
        const lines = chunk.split('\n');
        let event = 'message';
        let data = '';
        for (const line of lines) {
          if (line.startsWith('event: ')) event = line.slice(7).trim();
          else if (line.startsWith('data: ')) data += line.slice(6);
          else if (line.startsWith(':')) continue; // heartbeat
        }
        if (event === 'progress') {
          try { setLog((l) => [...l, JSON.parse(data).phase]); } catch { /* ignore */ }
        } else if (event === 'done') {
          try { setReport(JSON.parse(data)); } catch { /* ignore */ }
          setPhase('done');
        } else if (event === 'error') {
          try { setError(JSON.parse(data).message ?? 'unknown'); } catch { setError('unknown'); }
          setPhase('error');
        }
      }
    }
  };

  return (
    <form onSubmit={onSubmit} className="space-y-3">
      <div className="space-y-1">
        <label className="text-sm font-medium">Source</label>
        <select
          value={source}
          onChange={(e) => setSource(e.target.value as Source)}
          className="border rounded px-2 py-1"
        >
          {SOURCES.map((s) => (
            <option key={s.value} value={s.value}>{s.label}</option>
          ))}
        </select>
      </div>
      <div className="space-y-1">
        <label className="text-sm font-medium">File</label>
        <input
          type="file"
          accept=".zip,application/zip"
          onChange={(e) => setFile(e.target.files?.[0] ?? null)}
        />
      </div>
      <Button type="submit" disabled={!file || phase === 'uploading' || phase === 'running'}>
        {phase === 'idle' || phase === 'done' || phase === 'error' ? 'Import' : 'Working…'}
      </Button>
      {log.length > 0 && (
        <ul className="text-xs text-muted-foreground space-y-0.5">
          {log.map((l, i) => <li key={i}>· {l}</li>)}
        </ul>
      )}
      {error && <div className="text-sm text-destructive">Error: {error}</div>}
      {report !== null && (
        <pre className="text-xs bg-muted p-2 rounded overflow-auto">
          {JSON.stringify(report, null, 2)}
        </pre>
      )}
    </form>
  );
}
```

```tsx
// src/components/import/export-form.tsx
'use client';

import { useState } from 'react';
import { Button } from '@/components/ui/button';

export function ExportForm({ workspaceId }: { workspaceId: string }): JSX.Element {
  const [working, setWorking] = useState(false);
  const [downloadUrl, setDownloadUrl] = useState<string | null>(null);
  const [error, setError] = useState<string | null>(null);

  const onExport = async () => {
    setWorking(true);
    setDownloadUrl(null);
    setError(null);
    try {
      const res = await fetch('/api/exports', {
        method: 'POST',
        headers: { 'content-type': 'application/json' },
        body: JSON.stringify({ workspaceId }),
      });
      if (!res.ok) throw new Error(`HTTP ${res.status}`);
      const body = (await res.json()) as { url: string };
      setDownloadUrl(body.url);
    } catch (err) {
      setError(err instanceof Error ? err.message : 'unknown');
    } finally {
      setWorking(false);
    }
  };

  return (
    <div className="space-y-3">
      <Button onClick={onExport} disabled={working}>
        {working ? 'Generating…' : 'Generate export'}
      </Button>
      {downloadUrl && (
        <div className="text-sm">
          Ready —{' '}
          <a href={downloadUrl} className="underline text-primary">download archive</a>{' '}
          (link expires in 5 minutes).
        </div>
      )}
      {error && <div className="text-sm text-destructive">Error: {error}</div>}
    </div>
  );
}
```
