# Cairn v0.7.0 — Numbered Plans Index

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement these plans task-by-task. Each numbered plan below is its own `.md` doc; this index is the sequencing + dependency map.

**Spec:** `docs/superpowers/specs/2026-05-23-cairn-v0.7.0-design.md`

**Goal of v0.7.0:** open Cairn to agents (MCP) with the per-user authz primitives (PATs + page ACLs) those agents need; add depth to admin/observability; ship vector search, automation engine, and two-way DB connectors.

**Execution pattern:** subagent-driven (mirrors v0.6.0). Fresh subagent per plan with the plan's full task text + scene-setting context pasted in. Controller reviews + commits between plans. Each plan is bite-sized TDD: failing test → impl → gates (lint+typecheck+test+build) → commit.

**Conventions (carried from v0.6.0):**
- Prefix every shell command with `source ~/.zshenv && ` (PATH + DOCKER_HOST).
- Conventional Commits, no `Co-Authored-By` trailer.
- Do NOT push from subagents; controller/human pushes.
- Migration numbers shift if the next number is already taken — generate, accept whatever Drizzle emits, rename if needed, update meta journal.

## How to run a plan

For each numbered plan:

1. Open the plan's `.md` doc.
2. Dispatch a fresh subagent with the full task text + scene-setting context pasted in (per `superpowers:subagent-driven-development`).
3. Subagent executes tasks top-to-bottom: failing test → impl → green → gates → commit.
4. Controller reviews diff + commit, marks plan complete, dispatches next.
5. Between plans, run `pnpm lint && pnpm typecheck && pnpm test` to confirm baseline before the next dispatch.
6. After P23, human-run tag fires the existing GHA-hosted release workflow.

**Do NOT push from subagents.** The controller/human pushes (mirrors v0.6.0).
