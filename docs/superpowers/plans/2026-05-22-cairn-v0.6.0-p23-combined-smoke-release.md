# Cairn v0.6.0 Plan 23 — Combined cross-feature smoke & release

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tie off v0.6.0 after Plans 1–22 (P1–P22) have landed all five bands — content/database completeness, sharing/collaboration depth, mobile/a11y/i18n, admin/observability/ops, and import/export. This plan adds **no new feature code**. It ships: a combined cross-feature **docker-compose smoke** (`scripts/smoke-v0.6.0.sh`) that exercises every band against a live booted stack; **Lighthouse PWA + axe a11y** runs against that stack (the gates from P13/P14); the **README + CHANGELOG + SECURITY.md** updates documenting all v0.6.0 features and their security/ops caveats; the **version bump** to `0.6.0`; the pre-release gate run; and the (human-run) tag that fires the existing multi-arch release workflow.

**Architecture:** One new non-shipped artifact: `scripts/smoke-v0.6.0.sh`, a bash script that boots the full `docker compose` stack (Postgres + the Cairn container), waits for `/api/health` to report healthy, seeds a workspace, and walks the platform surface end-to-end with `curl` + `docker compose exec` against the *running* container (mirroring how the v0.5.0 cross-feature smoke walked key→page→webhook→version→template, but at the HTTP/CLI level against a real boot). It asserts exact responses and tears the stack down on exit (trap). The Lighthouse + axe runs target the same booted stack (Lighthouse against the PWA shell; `@axe-core/playwright`'s `pnpm test:a11y` from P14 against seeded screens). The release workflow `.github/workflows/release.yml` already exists (since v0.1.0) and is private-repo-safe — it gates `provenance`/`sbom`/the attestation step on `github.event.repository.visibility == 'public'`, so a private repo still builds + publishes. **Do NOT touch the workflow in this plan.** Tagging `v0.6.0` reuses it as-is: multi-arch (amd64+arm64) native-runner build, publishes `ghcr.io/jonathanmcohen/cairn:0.6.0` (+ `:0.6`, `:0`, `:latest`), and creates a GitHub Release.

**Tech Stack:** No new runtime deps. Bash + `curl` + `docker compose` for the smoke; `docker compose exec` to drive the in-image CLI (`node dist/server/cli.js` — backup/restore/export/import/reminders:scan from P21/P22). Lighthouse via `npx lighthouse` (or `@lhci/cli` if P13 wired it) against `http://localhost:3000`; `@axe-core/playwright` via the `pnpm test:a11y` script from P14. pnpm for the gates; git for the (human-run) tag.

**Spec:** `docs/superpowers/specs/2026-05-22-cairn-v0.6.0-design.md` (§7 P23, §6 "Build-verified" + "a11y", §8 risks — metrics token, 2FA secrets, single-instance scheduling ceiling, sharing/anon surfaces, offline scope limit, embed allowlist).

## Task 1: Combined cross-feature docker-compose smoke (`scripts/smoke-v0.6.0.sh`)

**Goal:** One bash script that boots the full stack live and walks every v0.6.0 band in sequence, asserting exact outputs, then tears down. Bands: **content/db** (a database with reverse relations + a list view + row hierarchy + a calc footer + new blocks on a page), **sharing** (publish a page with a password + expiry; reach the public site `/s/<slug>`; duplicate), **collab** (a comment on a row; a suggestion accepted), **mobile/offline** (PWA manifest served; `/metrics` reachable with the token), **admin/ops** (create an audit-log entry; a 2FA enroll; a quota check), **import/export** (export a workspace archive, re-import it). It is the integration backstop from §8 — not a substitute for the P1–P22 per-feature tests.

- [ ] **Step 1: Write the smoke script**

`scripts/smoke-v0.6.0.sh`:

```bash
#!/usr/bin/env bash
# Cairn v0.6.0 combined cross-feature smoke.
# Boots the full docker-compose stack, exercises all five bands of v0.6.0 against
# a live container, asserts exact outputs, and tears the stack down on exit.
# This is the integration backstop (spec §7 P23 / §8) — NOT a replacement for the
# per-feature Testcontainers tests in Plans 1–22.
#
# Usage: source ~/.zshenv && bash scripts/smoke-v0.6.0.sh
set -euo pipefail

BASE="http://localhost:3000"
METRICS_TOKEN="smoke-metrics-token-$$"
PUB_PASSWORD="smoke-pub-pw"
PASS=0
FAIL=0

note()  { printf '\n=== %s ===\n' "$1"; }
ok()    { printf '  PASS: %s\n' "$1"; PASS=$((PASS + 1)); }
bad()   { printf '  FAIL: %s\n' "$1"; FAIL=$((FAIL + 1)); }
# assert <description> <expected-substring> <actual>
assert() { case "$3" in *"$2"*) ok "$1" ;; *) bad "$1 (expected to contain: $2; got: $3)" ;; esac; }

cleanup() {
  note "Teardown"
  docker compose down -v >/dev/null 2>&1 || true
}
trap cleanup EXIT

note "Boot the stack (rebuild)"
# CAIRN_METRICS_TOKEN gates /metrics (off → 404 unless set; spec §2.32). Pass it through compose.
CAIRN_METRICS_TOKEN="$METRICS_TOKEN" docker compose up -d --build 2>&1 | tail -3

note "Wait for health"
healthy=""
for i in $(seq 1 24); do
  s=$(docker compose ps cairn --format '{{.Health}}' 2>/dev/null || echo unknown)
  printf '  attempt %s: %s\n' "$i" "$s"
  if [ "$s" = "healthy" ]; then healthy=1; break; fi
  sleep 5
done
[ -n "$healthy" ] || { bad "stack never became healthy"; exit 1; }
health=$(curl -fsS "$BASE/api/health")
assert "health reports version 0.6.0" '"version":"0.6.0"' "$health"

# Seed a workspace + owner + an API key for the editor role via the in-image seed/CLI helper.
# (P1–P22 expose a seed path used by the integration tests; the smoke reuses it via the CLI.
#  If the seed helper name differs, align it to what Plans 1–22 shipped — see NOTE in Step 2.)
note "Seed workspace + owner + editor API key"
SEED=$(docker compose exec -T cairn node dist/server/cli.js smoke:seed --slug smokews 2>/dev/null)
WS=$(printf '%s' "$SEED"  | sed -n 's/.*"workspaceId":"\([^"]*\)".*/\1/p')
KEY=$(printf '%s' "$SEED" | sed -n 's/.*"apiKey":"\([^"]*\)".*/\1/p')
USER=$(printf '%s' "$SEED" | sed -n 's/.*"userId":"\([^"]*\)".*/\1/p')
[ -n "$WS" ] && [ -n "$KEY" ] || { bad "seed did not return workspaceId + apiKey"; exit 1; }
AUTH=(-H "Authorization: Bearer $KEY")
J=(-H 'Content-Type: application/json')

# ----------------------------------------------------------------------------
note "BAND 1 — content & database"
# Create a page with new v0.6.0 blocks (toggle, columns, math, embed, bookmark).
PAGE=$(curl -fsS "${AUTH[@]}" "${J[@]}" -X POST "$BASE/api/v1/pages" \
  -d '{"title":"Smoke Content","content":{"type":"doc","content":[
    {"type":"toggle","content":[{"type":"paragraph"}]},
    {"type":"columnList","content":[{"type":"column","content":[{"type":"paragraph"}]},{"type":"column","content":[{"type":"paragraph"}]}]},
    {"type":"math","attrs":{"latex":"e^{i\\pi}+1=0"}},
    {"type":"embed","attrs":{"src":"https://www.youtube.com/embed/dQw4w9WgXcQ"}}
  ]}}')
PAGE_ID=$(printf '%s' "$PAGE" | sed -n 's/.*"id":"\([^"]*\)".*/\1/p')
assert "page created with new blocks" '"title":"Smoke Content"' "$PAGE"

# Two databases with a reverse relation, a list view, row hierarchy, a calc footer.
DBA=$(curl -fsS "${AUTH[@]}" "${J[@]}" -X POST "$BASE/api/v1/databases" -d '{"name":"Projects"}')
DBB=$(curl -fsS "${AUTH[@]}" "${J[@]}" -X POST "$BASE/api/v1/databases" -d '{"name":"Tasks"}')
DBA_ID=$(printf '%s' "$DBA" | sed -n 's/.*"id":"\([^"]*\)".*/\1/p')
DBB_ID=$(printf '%s' "$DBB" | sed -n 's/.*"id":"\([^"]*\)".*/\1/p')
# Reverse relation: Projects.tasks <-> Tasks.project (createReverse:true mirrors on write — §2.1).
REL=$(curl -fsS "${AUTH[@]}" "${J[@]}" -X POST "$BASE/api/v1/databases/$DBA_ID/properties" \
  -d "{\"type\":\"relation\",\"name\":\"tasks\",\"config\":{\"targetDatabaseId\":\"$DBB_ID\",\"createReverse\":true,\"reverseName\":\"project\"}}")
assert "reverse relation property created" '"reversePropertyId"' "$REL"
# A list view with a calc footer (config jsonb — §2.2 / §2.7).
LV=$(curl -fsS "${AUTH[@]}" "${J[@]}" -X POST "$BASE/api/v1/databases/$DBA_ID/views" \
  -d '{"type":"list","config":{"groupBy":null,"calcFooter":{"count":"filled"}}}')
assert "list view created" '"type":"list"' "$LV"
# Row hierarchy: parent row + child via parent_row_id (§2.3).
PARENT=$(curl -fsS "${AUTH[@]}" "${J[@]}" -X POST "$BASE/api/v1/databases/$DBA_ID/rows" -d '{"cells":{}}')
PARENT_ID=$(printf '%s' "$PARENT" | sed -n 's/.*"id":"\([^"]*\)".*/\1/p')
CHILD=$(curl -fsS "${AUTH[@]}" "${J[@]}" -X POST "$BASE/api/v1/databases/$DBA_ID/rows" \
  -d "{\"cells\":{},\"parentRowId\":\"$PARENT_ID\"}")
assert "child row records parentRowId" "\"parentRowId\":\"$PARENT_ID\"" "$CHILD"

# ----------------------------------------------------------------------------
note "BAND 2 — sharing"
# Publish the page with a password + a future expiry (§2.8 / §2.9).
EXP="2099-01-01T00:00:00.000Z"
SHARE=$(curl -fsS "${AUTH[@]}" "${J[@]}" -X POST "$BASE/api/v1/pages/$PAGE_ID/share" \
  -d "{\"password\":\"$PUB_PASSWORD\",\"expiresAt\":\"$EXP\",\"allowDuplication\":true}")
SLUG=$(printf '%s' "$SHARE" | sed -n 's/.*"slug":"\([^"]*\)".*/\1/p')
assert "page published with slug" '"slug"' "$SHARE"
# Wrong/absent password → the gate (NEVER the content). Existence-non-leak: a missing page is 404.
GATE=$(curl -fsS "$BASE/p/$SLUG" || true)
assert "protected page shows a password gate, not content" 'password' "$GATE"
case "$GATE" in *"Smoke Content"*) bad "protected page leaked content without password"; ;; *) ok "protected page did not leak content"; ;; esac
# Enable + reach the public site /s/<slug> (lists already-published pages — §2.11).
SITE=$(curl -fsS "${AUTH[@]}" "${J[@]}" -X POST "$BASE/api/v1/workspaces/$WS/public-site" -d '{"slug":"smokesite","enabled":true}')
assert "public site enabled" '"enabled":true' "$SITE"
SITE_HTML=$(curl -fsS "$BASE/s/smokesite" || true)
assert "public site /s/<slug> renders (HTTP 200 body)" 'html' "$SITE_HTML"
# Duplicate is allowed (allowDuplication:true) — assert the action endpoint accepts it.
DUP=$(curl -fsS "${AUTH[@]}" "${J[@]}" -X POST "$BASE/api/v1/pages/$PAGE_ID/duplicate" -d "{\"intoWorkspaceId\":\"$WS\"}")
assert "duplicate-to-workspace produces a fresh page id" '"id"' "$DUP"
DUP_ID=$(printf '%s' "$DUP" | sed -n 's/.*"id":"\([^"]*\)".*/\1/p')
[ "$DUP_ID" != "$PAGE_ID" ] && ok "duplicate has a distinct id" || bad "duplicate reused the source id"

# ----------------------------------------------------------------------------
note "BAND 3 — collaboration"
# A comment on a database row (polymorphic target_type=db_row — §2.12).
CMT=$(curl -fsS "${AUTH[@]}" "${J[@]}" -X POST "$BASE/api/v1/comments" \
  -d "{\"targetType\":\"db_row\",\"targetId\":\"$PARENT_ID\",\"body\":\"smoke comment\"}")
assert "row comment created on a db_row target" '"targetType":"db_row"' "$CMT"
# A suggestion proposed then accepted (Yjs-native marks + index — §2.13).
SUG=$(curl -fsS "${AUTH[@]}" "${J[@]}" -X POST "$BASE/api/v1/pages/$PAGE_ID/suggestions" \
  -d '{"kind":"insert","payload":{"text":"proposed"}}')
SUG_ID=$(printf '%s' "$SUG" | sed -n 's/.*"id":"\([^"]*\)".*/\1/p')
assert "suggestion opened" '"status":"open"' "$SUG"
ACC=$(curl -fsS "${AUTH[@]}" "${J[@]}" -X POST "$BASE/api/v1/pages/$PAGE_ID/suggestions/$SUG_ID/accept" -d '{}')
assert "suggestion accepted" '"status":"accepted"' "$ACC"

# ----------------------------------------------------------------------------
note "BAND 4 — mobile / offline / observability"
# PWA manifest served from the Next metadata route (§2.23 / P13).
MANIFEST=$(curl -fsS "$BASE/manifest.webmanifest" 2>/dev/null || curl -fsS "$BASE/manifest.json")
assert "PWA manifest is served with standalone display" '"display":"standalone"' "$MANIFEST"
# /metrics is token-gated: 404 unset path is exercised below; with the token → 200 prom text (§2.32).
M_NOAUTH=$(curl -s -o /dev/null -w '%{http_code}' "$BASE/metrics")
case "$M_NOAUTH" in 401|403) ok "/metrics rejects an unauthenticated request ($M_NOAUTH)" ;; *) bad "/metrics did not reject unauth (got $M_NOAUTH)" ;; esac
METRICS=$(curl -fsS -H "Authorization: Bearer $METRICS_TOKEN" "$BASE/metrics")
assert "/metrics returns prometheus text with the token" 'http_requests_total' "$METRICS"
# Aggregate-only: no workspace/page id should appear as a label (§2.31).
case "$METRICS" in *"$WS"*) bad "/metrics leaked a workspace id as a label"; ;; *) ok "/metrics carries no tenant identifiers"; ;; esac

# ----------------------------------------------------------------------------
note "BAND 5 — admin / ops"
# A 2FA enroll (TOTP secret encrypted at rest, recovery codes hashed — §2.29).
TOTP=$(curl -fsS "${AUTH[@]}" "${J[@]}" -X POST "$BASE/api/v1/settings/totp/enroll" -d '{}')
assert "2FA enroll returns a provisioning URI + recovery codes" 'otpauth://' "$TOTP"
# The raw secret must never be echoed back in plaintext beyond the provisioning URI's one-time setup.
# A quota check at the upload choke point (§2.33): set a tiny limit, then assert an over-limit upload is rejected.
QUOTA=$(curl -fsS "${AUTH[@]}" "${J[@]}" -X PUT "$BASE/api/v1/workspaces/$WS/quota" -d '{"storageBytesLimit":1}')
assert "quota set" '"storageBytesLimit":1' "$QUOTA"
UP=$(curl -s -o /dev/null -w '%{http_code}' "${AUTH[@]}" -X POST "$BASE/api/files" -F "file=@$0")
case "$UP" in 413|409|400) ok "over-quota upload rejected ($UP)" ;; *) bad "over-quota upload not rejected (got $UP)" ;; esac
# An audit-log entry was recorded for a sensitive action (the publish above — §2.27).
AUDIT=$(curl -fsS "${AUTH[@]}" "$BASE/api/v1/workspaces/$WS/audit")
assert "audit log recorded the publish action" 'page.published' "$AUDIT"
# Secrets must NOT appear in the audit log body (§6 security; §8 secret handling).
case "$AUDIT" in *"$PUB_PASSWORD"*) bad "audit log leaked the share password"; ;; *) ok "audit log carries no share password"; ;; esac

# ----------------------------------------------------------------------------
note "BAND 6 — import / export"
# Export the workspace as a re-importable archive (secrets excluded — §2.38).
docker compose exec -T cairn node dist/server/cli.js export --workspace "$WS" --out /data/exports >/dev/null
ARCHIVE=$(docker compose exec -T cairn sh -c 'ls -1 /data/exports/*.zip | head -1' | tr -d '\r')
[ -n "$ARCHIVE" ] && ok "workspace archive written ($ARCHIVE)" || bad "no workspace archive produced"
# Re-import the archive into a FRESH workspace (export/import are inverses — §2.38).
IMPORT=$(docker compose exec -T cairn node dist/server/cli.js import --source workspace-archive --file "$ARCHIVE" 2>&1)
assert "re-import completes" 'completed' "$IMPORT"
# The import must not carry secrets (API keys / hashes) into the fresh workspace.
case "$IMPORT" in *"$KEY"*) bad "import echoed the source API key"; ;; *) ok "import did not echo source secrets"; ;; esac

# ----------------------------------------------------------------------------
note "Summary"
printf 'PASS=%s FAIL=%s\n' "$PASS" "$FAIL"
[ "$FAIL" -eq 0 ] || exit 1
echo "v0.6.0 cross-feature smoke: ALL GREEN"
```

````markdown
### Security & operations caveats (v0.6.0)

- **`/metrics` is off by default.** The Prometheus endpoint returns **404**
  unless `CAIRN_METRICS_TOKEN` is set; when set, it requires
  `Authorization: Bearer <token>`. Metrics are aggregate-only — they carry **no**
  workspace, user, or page identifiers as labels (route templates only). Do not
  expose `/metrics` on an untrusted network without the token.
- **2FA secret handling.** TOTP shared secrets are **encrypted** at rest
  (AES-256-GCM, key derived from `AUTH_SECRET` via HKDF) because they must be
  reversible to verify codes; recovery codes are **hashed** (single-use). Rotating
  `AUTH_SECRET` invalidates stored TOTP secrets — re-enroll affected users. A
  workspace can *require* 2FA; the owner must enroll before enabling the
  requirement (no lockout). A documented CLI escape hatch disables TOTP for a
  locked-out user.
- **Single-instance scheduling ceiling.** Cairn does not host a cron daemon and
  has **no distributed lock**. Scheduled backups and reminder scans run via
  external cron (recommended) or an opt-in in-process interval ticker
  (`CAIRN_BACKUP_INTERVAL` / `CAIRN_REMINDER_INTERVAL`) that is **off by default
  and single-instance only** — two instances will double-fire. This matches the
  single-instance collab ceiling.
- **Sharing & anonymous surfaces.** Password-protected, expired, and unpublished
  pages all return **404** to anonymous visitors (never 403, never a partial
  render) so existence never leaks. Password access uses an HMAC-signed,
  expiring cookie (no new secret; reuses the signed-URL key) — wrong passwords
  leak nothing. The public site lists only already-published pages; enabling it
  does not bulk-publish, and per-page password/expiry still gate pages within it.
- **Offline scope limit.** Offline editing is supported **only** for pages
  already loaded into IndexedDB during the session, and only for Yjs document
  edits (CRDT-merged on reconnect). Creating pages, structural moves/deletes,
  database row mutations, and file uploads are **disabled** offline — Cairn is
  explicitly **not** full offline-first.
- **Embed allowlist.** Embeds are restricted to an allowlist
  (YouTube/Vimeo/Figma/GitHub-gist/CodeSandbox) and sandboxed under the CSP; no
  arbitrary iframes. The bookmark unfurl endpoint and outbound email links pass
  the SSRF guard.
````
