# Cairn v0.8.0 — Numbered Plans Index

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement these plans task-by-task. Each numbered plan is its own `.md`; this index is the sequencing + dependency map.

**Spec:** `docs/superpowers/specs/2026-05-24-cairn-v0.8.0-design.md`

**Goal of v0.8.0:** finish the experience strokes that get Cairn to 1.0 — full-doc offline editing, gesture-first mobile polish, native PDF, page covers + custom themes, command palette + settings hub, notification center, quick capture / first-run onboarding, performance pass, a11y sweep over v0.7 surfaces, and the small leftover block-type gaps.

**Execution pattern:** subagent-driven (mirrors v0.6.0 / v0.7.0). Fresh subagent per plan with the plan's full task text + scene-setting context. Controller reviews + commits + pushes between plans.

**Conventions (carried from v0.7.0):**
- Prefix every shell command with `source ~/.zshenv && `.
- Conventional Commits, no `Co-Authored-By` trailer.
- Workflow-wide `NODE_OPTIONS=--max-old-space-size=6144` in CI; Dockerfile builder stage also carries it. Honor this when adding new build steps.
- Migration numbers shift if the next is taken — generate, accept whatever Drizzle emits, rename if helpful, update meta journal.
- All P-plans land directly on `main` (no per-release feature branch — same as v0.7.0).
