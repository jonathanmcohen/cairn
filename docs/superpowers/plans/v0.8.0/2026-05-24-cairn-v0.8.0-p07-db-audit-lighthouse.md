# Cairn v0.8.0 — Plan P7: DB query audit (top-5 hot routes) + Lighthouse CI budget

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Drive the audit selection via the v0.6 P20 `db_query_duration_seconds` metric — pick the top 5 routes by p99 latency, run `EXPLAIN ANALYZE` against representative seed data, add the missing indexes (or rewrite the query), and document all five audits in `docs/operations.md`. Add a Lighthouse CI gate on the public `/p/<seed-slug>` route via `@lhci/cli` + a `.github/workflows/lighthouse.yml` workflow that runs after CI on `main`; budget is configured in `.lighthouserc.json` so a performance-score regression > 5 points (or LCP/FCP/TTI regression > 10%) fails the build.

**Architecture:** Two independent deliverables. (1) A migration `drizzle/migrations/<NEXT>_add_perf_indexes.sql` adds the indexes the audit identifies; the Drizzle schema files are updated in lockstep so the generator stays consistent (`(t) => ({ idx: index(...) })` per pattern in `src/db/schema/pages.ts`). (2) A Lighthouse CI workflow installs `@lhci/cli`, boots the prod build with a seeded public page, runs `lhci autorun --collect.numberOfRuns=3` (median of 3 to dampen LCP variance), and fails if the perf budget regresses. The seed slug is fixed (`v08-lhci-seed-slug`) and inserted by a `scripts/seed-lhci.ts` helper so the URL is reproducible across runs.

**Tech Stack:** Drizzle migrations (existing pattern), `@lhci/cli` (NEW dev dep), `lhci autorun` GitHub Action, `docs/operations.md` (existing — append a new section).

- [x] **Step 1: Write `scripts/seed-lhci.ts`**

```ts
/**
 * Seed a single published page with the fixed slug `v08-lhci-seed-slug` so
 * Lighthouse CI has a reproducible URL to scrape. Idempotent: if the page
 * already exists, only its publication state is refreshed.
 *
 * Invoked by `.github/workflows/lighthouse.yml` after migrations apply, but
 * before `lhci autorun` boots `pnpm start`.
 */
import { drizzle } from 'drizzle-orm/postgres-js';
import postgres from 'postgres';
import { eq } from 'drizzle-orm';
import * as schema from '@/db/schema';

const PUBLIC_SLUG = 'v08-lhci-seed-slug';

async function main(): Promise<void> {
  const url = process.env.DATABASE_URL;
  if (!url) throw new Error('DATABASE_URL is required to seed the LHCI page');
  const sql = postgres(url, { max: 1 });
  const db = drizzle(sql, { schema });

  // Ensure at least one user + workspace exist; the LHCI page belongs to the
  // first user / first workspace we find or create.
  const existingUsers = await db.select().from(schema.users).limit(1);
  let userId = existingUsers[0]?.id;
  if (!userId) {
    const [u] = await db
      .insert(schema.users)
      .values({ email: 'lhci@cairn.test', passwordHash: 'argon2$lhci-only-not-real' })
      .returning({ id: schema.users.id });
    userId = u!.id;
  }

  const existingWorkspaces = await db.select().from(schema.workspaces).limit(1);
  let workspaceId = existingWorkspaces[0]?.id;
  if (!workspaceId) {
    const [w] = await db
      .insert(schema.workspaces)
      .values({ name: 'LHCI', createdBy: userId })
      .returning({ id: schema.workspaces.id });
    workspaceId = w!.id;
  }

  // Upsert the public page.
  const existing = await db
    .select({ id: schema.pages.id })
    .from(schema.pages)
    .where(eq(schema.pages.publicSlug, PUBLIC_SLUG))
    .limit(1);

  if (existing[0]) {
    await db
      .update(schema.pages)
      .set({ published: true })
      .where(eq(schema.pages.id, existing[0].id));
    console.log(`[seed-lhci] refreshed published state on ${existing[0].id}`);
  } else {
    const [created] = await db
      .insert(schema.pages)
      .values({
        workspaceId,
        title: 'Cairn — Lighthouse CI fixture',
        published: true,
        publicSlug: PUBLIC_SLUG,
        createdBy: userId,
        content: {
          type: 'doc',
          content: [
            { type: 'heading', attrs: { level: 1 }, content: [{ type: 'text', text: 'Hello LHCI' }] },
            {
              type: 'paragraph',
              content: [
                { type: 'text', text: 'A small, deterministic published page used by Lighthouse CI.' },
              ],
            },
          ],
        },
      })
      .returning({ id: schema.pages.id });
    console.log(`[seed-lhci] created ${created!.id} with slug ${PUBLIC_SLUG}`);
  }

  await sql.end({ timeout: 5 });
}

main().catch((err) => {
  console.error('[seed-lhci] failed', err);
  process.exit(1);
});
```

> The seed runs at the same Node + tsx entry as the existing `src/server/entrypoint.ts` migrations bootstrap. Invoke via `pnpm exec tsx scripts/seed-lhci.ts` from the workflow.

        image: postgres:16

    env:
      DATABASE_URL: postgres://cairn:cairn@localhost:5432/cairn_lhci
      AUTH_SECRET: lhci-only-secret-padding-padding-padding
      NEXTAUTH_URL: http://localhost:3000

    steps:
      - uses: actions/checkout@v4
