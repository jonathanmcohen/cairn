# Cairn v0.8.0 — Plan P18: Inline transclusion preview + unlinked-mentions sidebar

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two backlinks-delta refinements on top of the v0.6 P10 backlinks surface:

1. **Inline transclusion preview** — hovering a `[[page-link]]` in the editor opens a popover showing the linked page's first paragraph + an outbound "open page" link. The hover-trigger is fired from the existing `page-link-extension.ts` via the tippy.js instance shared with v0.6 P10's mention popups (no new floating-UI dep).
2. **Unlinked-mentions sidebar section** — a new "Unlinked mentions" group inside the existing `<BacklinksPanel>`, populated by `findUnlinkedMentions(db, {pageId, workspaceId})`: a FTS search for the page's title across the workspace that excludes pages already linked via the `page_links` table.

**Architecture:** The transclusion popover is a **new** `<PageLinkPopover>` component fed by the page-link extension's `onHover` handler — when a `[[page-link]]` DOM node is hovered, the extension reads the target page id from the node attrs, fetches `GET /api/pages/[pageId]/preview` (a small new endpoint returning `{title, firstParagraph, emoji?}`), and renders the popover via the same tippy.js instance v0.6 P10 mentions already mount. The extension itself stays a TipTap Node (no rewrite); only an `onHover` plugin is added. The unlinked-mentions feature lives entirely server-side: `src/lib/pages/unlinked-mentions.ts` runs a Postgres FTS query against `pages.content_tsv` for the target page's title, scopes by workspace, EXCLUDES the page itself, and LEFT-ANTI-JOINs `page_links` to remove already-linked pages (because if the page is already linked via `[[…]]`, it's a *linked* reference, not an unlinked mention). The backlinks panel gets a second section beneath the existing linked-references list. The `<BacklinksPanel>` is a server component (confirm in Step 0); the new section reuses its data-fetching pattern.

**Tech Stack:** No new runtime deps. tippy.js is already pulled in by v0.6 P10 (mentions popup) — the page-link extension imports the existing instance. Drizzle SQL for the FTS query (`to_tsquery` on the existing `pages.content_tsv` generated column), Zod v4 for the preview route, Vitest 4 + Testcontainers for the unlinked-mentions helper test.

**Spec:** `docs/superpowers/specs/2026-05-24-cairn-v0.8.0-design.md` — §3 G6 P18 (backlinks delta: inline transclusion preview — hovering a `[[page-link]]` in the editor opens a popover with the first paragraph of the linked page + outbound link; unlinked-mentions sidebar section in the existing linked-references panel — FTS for page title across the workspace, deduped against existing linked references).

```ts
import { sql } from 'drizzle-orm';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import * as schema from '@/db/schema';

type Db = PostgresJsDatabase<typeof schema>;

export type UnlinkedMention = {
  id: string;
  title: string;
  snippet: string; // short body fragment showing the mention context
};

const MAX_RESULTS = 20;

/**
 * Find pages in the same workspace that mention the target page's title in
 * their content (full-text search over `pages.content_tsv`) and are NOT
 * already linked to the target page via `page_links` (any kind). Excludes
 * the target page itself and any soft-deleted page. Capped at MAX_RESULTS.
 */
export async function findUnlinkedMentions(
  db: Db,
  input: { pageId: string; workspaceId: string },
): Promise<UnlinkedMention[]> {
  // Fetch the target's title for the FTS query.
  const target = await db
    .select({ title: schema.pages.title })
    .from(schema.pages)
    .where(sql`${schema.pages.id} = ${input.pageId}`)
    .limit(1);
  const title = target[0]?.title;
  if (!title || title.trim().length === 0) return [];

  // Build the tsquery: plainto_tsquery handles tokenization safely (no
  // user-controlled SQL operators reach the parser). The generated column
  // `content_tsv` already exists on `pages` (project-wide FTS convention).
  // We anti-join page_links to drop already-linked pages.
  //
  // ts_headline produces a short snippet centered on the match — capped to
  // keep the panel snappy.
  const rows = (await db.execute(sql`
    SELECT
      p.id            AS id,
      p.title         AS title,
      ts_headline(
        'english',
        p.content_text,
        plainto_tsquery('english', ${title}),
        'MaxFragments=1, MaxWords=20, MinWords=5'
      )               AS snippet
    FROM pages p
    LEFT JOIN page_links l
      ON l.source_page_id = p.id AND l.target_page_id = ${input.pageId}
    WHERE p.workspace_id = ${input.workspaceId}
      AND p.id <> ${input.pageId}
      AND p.deleted_at IS NULL
      AND p.content_tsv @@ plainto_tsquery('english', ${title})
      AND l.source_page_id IS NULL
    ORDER BY p.updated_at DESC
    LIMIT ${MAX_RESULTS}
  `)) as unknown as Array<{ id: string; title: string; snippet: string }>;

  return rows.map((r) => ({ id: r.id, title: r.title, snippet: r.snippet ?? '' }));
}
```

## Task 2: `/api/pages/[pageId]/preview` endpoint (powers the popover)

**Goal:** A tiny GET endpoint returning `{title, emoji?, firstParagraph}` for the popover to render.
```ts
import { NextResponse } from 'next/server';
import { z } from 'zod';
import { HttpError } from '@/lib/auth/require-role';
import { requirePageAccess } from '@/lib/pages/access';

const Params = z.object({ pageId: z.uuid() });

function firstParagraphFromContent(content: unknown): string {
  if (!content || typeof content !== 'object' || !('content' in content)) return '';
  const top = (content as { content: unknown }).content;
  if (!Array.isArray(top)) return '';
  for (const node of top) {
    if (!node || typeof node !== 'object') continue;
    if ((node as { type?: string }).type !== 'paragraph') continue;
    const inner = (node as { content?: unknown }).content;
    if (!Array.isArray(inner)) return '';
    const text = inner
      .map((leaf) => (leaf && typeof leaf === 'object' && 'text' in leaf ? String((leaf as { text: unknown }).text) : ''))
      .join('');
    return text.slice(0, 280);
  }
  return '';
}

export async function GET(
  _req: Request,
  { params }: { params: Promise<{ pageId: string }> },
): Promise<Response> {
  try {
    const { pageId } = Params.parse(await params);
    const { page } = await requirePageAccess(pageId, 'viewer');
    return NextResponse.json({
      title: page.title,
      emoji: (page as { emoji?: string | null }).emoji ?? null,
      firstParagraph: firstParagraphFromContent(page.content),
    });
  } catch (err) {
    if (err instanceof HttpError) {
      return NextResponse.json({ error: err.message }, { status: err.status });
    }
    if (err instanceof z.ZodError) {
      return NextResponse.json({ error: 'validation', issues: err.issues }, { status: 400 });
    }
    return NextResponse.json(
      { error: err instanceof Error ? err.message : 'unknown' },
      { status: 500 },
    );
  }
}
```

```tsx
'use client';

import type { Route } from 'next';
import Link from 'next/link';
import { useEffect, useState } from 'react';

type Preview = {
  title: string;
  emoji: string | null;
  firstParagraph: string;
};

type State =
  | { kind: 'loading' }
  | { kind: 'ok'; preview: Preview }
  | { kind: 'error' };

export function PageLinkPopover({ pageId }: { pageId: string }): React.ReactNode {
  const [state, setState] = useState<State>({ kind: 'loading' });

  useEffect(() => {
    let cancelled = false;
    (async () => {
      try {
        const res = await fetch(`/api/pages/${pageId}/preview`, { credentials: 'include' });
        if (!res.ok) throw new Error(`preview: ${res.status}`);
        const preview = (await res.json()) as Preview;
        if (!cancelled) setState({ kind: 'ok', preview });
      } catch {
        if (!cancelled) setState({ kind: 'error' });
      }
    })();
    return () => {
      cancelled = true;
    };
  }, [pageId]);

  return (
    <div
      role="tooltip"
      className="max-w-sm rounded-md border bg-popover p-3 text-sm shadow-md"
    >
      {state.kind === 'loading' && <p className="text-muted-foreground">Loading preview…</p>}
      {state.kind === 'error' && (
        <p className="text-muted-foreground">Couldn't load preview.</p>
      )}
      {state.kind === 'ok' && (
        <>
          <p className="mb-1 font-medium">
            {state.preview.emoji && <span aria-hidden className="mr-1">{state.preview.emoji}</span>}
            {state.preview.title}
          </p>
          {state.preview.firstParagraph && (
            <p className="mb-2 text-muted-foreground">{state.preview.firstParagraph}</p>
          )}
          <Link
            href={`/pages/${pageId}` as Route}
            className="text-primary underline-offset-4 hover:underline"
          >
            Open page
          </Link>
        </>
      )}
    </div>
  );
```

The exact integration depends on the existing extension shape; the pattern below assumes a TipTap Node with a `addProseMirrorPlugins()` hook (the v0.6 P10 mentions used the same pattern). Insert a hover-listener plugin that mounts/unmounts the popover through the shared tippy.js factory.

```ts
import type { Editor } from '@tiptap/core';
import { Plugin, PluginKey } from '@tiptap/pm/state';
import { createRoot, type Root } from 'react-dom/client';
import tippy, { type Instance as TippyInstance } from 'tippy.js';
import { PageLinkPopover } from './page-link-popover';

// Reuse v0.6 P10's tippy options factory if it exists; the inline options
// below are the minimal set needed for the popover hover behaviour.
const TIPPY_OPTIONS = {
  appendTo: () => document.body,
  trigger: 'manual' as const,
  placement: 'top' as const,
  interactive: true,
  arrow: true,
  delay: [300, 0] as [number, number], // hover-intent: 300ms open, instant close
};

/** A unique key for the hover plugin so multiple page-link nodes share state. */
export const pageLinkHoverPluginKey = new PluginKey('pageLinkHover');

export function pageLinkHoverPlugin(_editor: Editor): Plugin {
  let activeTippy: TippyInstance | null = null;
  let activeRoot: Root | null = null;

  const close = (): void => {
    activeTippy?.destroy();
    activeRoot?.unmount();
    activeTippy = null;
    activeRoot = null;
  };

  const openFor = (target: HTMLElement, pageId: string): void => {
    close();
    const container = document.createElement('div');
    activeRoot = createRoot(container);
    activeRoot.render(<PageLinkPopover pageId={pageId} />);
    activeTippy = tippy(target, {
      ...TIPPY_OPTIONS,
      content: container,
      onHidden: close,
    });
    activeTippy.show();
  };

  return new Plugin({
    key: pageLinkHoverPluginKey,
    view() {
      // Listen at the document level so we catch enter/leave on rendered
      // `[data-page-link]` nodes regardless of which editor instance owns
      // them (matches v0.6 P10 mentions pattern).
      const onMouseEnter = (e: Event) => {
        const target = e.target;
        if (!(target instanceof HTMLElement)) return;
        const node = target.closest<HTMLElement>('[data-page-link]');
        if (!node) return;
        const pageId = node.getAttribute('data-page-id');
        if (!pageId) return;
        openFor(node, pageId);
      };
      const onMouseLeave = (e: Event) => {
        const target = e.target;
        if (!(target instanceof HTMLElement)) return;
        const node = target.closest<HTMLElement>('[data-page-link]');
        if (!node) return;
        // Tippy's delay handles brief mouse jumps; explicit close on leave is
        // handled by the leave-out-of-popover behaviour built into tippy
        // (interactive=true keeps the popover open while the mouse is over it).
      };
      const onKeyDown = (e: KeyboardEvent) => {
        if (e.key === 'Escape') close();
      };
      document.addEventListener('mouseenter', onMouseEnter, true);
      document.addEventListener('mouseleave', onMouseLeave, true);
      document.addEventListener('keydown', onKeyDown);
      return {
        destroy() {
          document.removeEventListener('mouseenter', onMouseEnter, true);
          document.removeEventListener('mouseleave', onMouseLeave, true);
          document.removeEventListener('keydown', onKeyDown);
          close();
        },
      };
    },
  });
}
```

```ts
import { NextResponse } from 'next/server';
import { z } from 'zod';
import { getDb } from '@/db/client';
import { HttpError } from '@/lib/auth/require-role';
import { requirePageAccess } from '@/lib/pages/access';
import { findUnlinkedMentions } from '@/lib/pages/unlinked-mentions';

const Params = z.object({ pageId: z.uuid() });

export async function GET(
  _req: Request,
  { params }: { params: Promise<{ pageId: string }> },
): Promise<Response> {
  try {
    const { pageId } = Params.parse(await params);
    const { ctx } = await requirePageAccess(pageId, 'viewer');
    const mentions = await findUnlinkedMentions(getDb(), {
      pageId,
      workspaceId: ctx.workspaceId,
    });
    return NextResponse.json({ mentions });
  } catch (err) {
    if (err instanceof HttpError) {
      return NextResponse.json({ error: err.message }, { status: err.status });
    }
    if (err instanceof z.ZodError) {
      return NextResponse.json({ error: 'validation', issues: err.issues }, { status: 400 });
    }
    return NextResponse.json(
      { error: err instanceof Error ? err.message : 'unknown' },
      { status: 500 },
    );
  }
}
```
