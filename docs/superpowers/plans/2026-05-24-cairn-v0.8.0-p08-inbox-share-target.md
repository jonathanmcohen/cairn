# Cairn v0.8.0 — Plan P8: Inbox page + PWA share_target + `/api/inbox` + triage UI

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land the load-bearing pieces that the rest of G3 builds on. (1) Migration `0029` adds `workspaces.inbox_page_id uuid REFERENCES pages(id) ON DELETE SET NULL` — a per-workspace pointer to a lazily-created "Inbox" page. (2) The PWA manifest registers Cairn as an OS-level share target. (3) `POST /api/inbox` accepts both JSON and `multipart/form-data` payloads from the share-sheet, lazily creates the inbox page on first capture, then inserts a child page tagged `{inbox: true, capturedAt}` in the page metadata. (4) `/inbox` triage UI lists inbox children with drag-to-folder + "mark done" actions. P9 (in-tab hotkey) and P10 (onboarding wizard) both depend on this surface.

**Architecture:** A single new migration owned by this plan (`0029`). The inbox page lives in the normal `pages` table — nothing new schema-wise except the workspace pointer. Captured items are also normal `pages` rows: their parent is the inbox page, their metadata jsonb carries `{inbox: true, capturedAt}` until triaged. "Triage" = either move the page (clears the parent and the inbox flag), or "mark done" (clears the inbox flag in place). The share-target endpoint accepts both content types so the same route handles in-app POSTs (P9 hotkey) and OS share-sheet POSTs (PWA `share_target` POSTs `multipart/form-data` with the configured fields). Cross-workspace access returns 404 (existing project convention — never 403 — see `src/lib/pages/access.ts`).

**Tech Stack:** Drizzle (`workspaces` table modify; `pages.metadata` jsonb already exists per v0.5 schema), Next.js 16 App Router POST route + a thin server-component page for triage + a client component for the draggable list (uses native HTML5 drag-and-drop — no new dep), Zod v4 for the JSON body shape, Vitest 4 + Testcontainers v12 for the round-trip + lazy-create + cross-workspace tests.

**Spec:** `docs/superpowers/specs/2026-05-24-cairn-v0.8.0-design.md` — §2.4 (quick capture: in-tab hotkey + share_target + inbox page); §3 G3 P8 row; §4 migration `0029`; §5.5 audit-log additions (`inbox.captured` / `inbox.triaged`).

- [ ] **Step 3: Implement `src/lib/inbox/lazy-page.ts`**

```ts
import { eq } from 'drizzle-orm';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import * as schema from '@/db/schema';

type Db = PostgresJsDatabase<typeof schema>;

/**
 * Returns the workspace's inbox page id, lazily creating it (and recording
 * the pointer in `workspaces.inbox_page_id`) on first call. Idempotent: a
 * second call within the same transaction returns the existing id.
 *
 * The inbox page is a normal `pages` row with title "Inbox", no parent, and
 * empty ProseMirror content — readers and editors render it the same way as
 * any other page.
 */
export async function ensureInboxPage(
  db: Db,
  input: { workspaceId: string; userId: string },
): Promise<string> {
  const [ws] = await db
    .select({ inboxPageId: schema.workspaces.inboxPageId })
    .from(schema.workspaces)
    .where(eq(schema.workspaces.id, input.workspaceId))
    .limit(1);
  if (!ws) throw new Error('workspace not found');
  if (ws.inboxPageId) return ws.inboxPageId;

  return db.transaction(async (tx) => {
    // Re-check inside the tx to avoid a double-create race.
    const [pinned] = await tx
      .select({ inboxPageId: schema.workspaces.inboxPageId })
      .from(schema.workspaces)
      .where(eq(schema.workspaces.id, input.workspaceId))
      .for('update');
    if (pinned?.inboxPageId) return pinned.inboxPageId;

    const [page] = await tx
      .insert(schema.pages)
      .values({
        workspaceId: input.workspaceId,
        parentId: null,
        title: 'Inbox',
        icon: null,
        content: { type: 'doc', content: [] } as never,
        metadata: { systemPage: 'inbox' } as never,
        createdBy: input.userId,
      } as never)
      .returning({ id: schema.pages.id });
    const pageId = page!.id;

    await tx
      .update(schema.workspaces)
      .set({ inboxPageId: pageId })
      .where(eq(schema.workspaces.id, input.workspaceId));

    return pageId;
  });
}
```

- [ ] **Step 4: Implement `src/lib/inbox/capture.ts`**

```ts
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import { writeAuditLog } from '@/lib/audit/log';
import * as schema from '@/db/schema';
import { ensureInboxPage } from './lazy-page';

type Db = PostgresJsDatabase<typeof schema>;

export type InboxCapturePayload = {
  title: string;
  body: string;
  url: string | null;
};

export type InboxCaptureResult = {
  capturedPageId: string;
  inboxPageId: string;
};

/**
 * Append a captured page under the workspace's inbox page. Tags the child's
 * metadata with `{inbox: true, capturedAt}` so the triage UI can surface it
 * and the "mark done" action can flip the flag without moving the page.
 *
 * `body` becomes a single paragraph block; `url` (if present) becomes a
 * second paragraph holding a bookmark-style link plus is recorded on the
 * metadata as `sourceUrl` for later round-trips.
 */
export async function captureInbox(
  db: Db,
  input: { workspaceId: string; userId: string; payload: InboxCapturePayload },
): Promise<InboxCaptureResult> {
  const inboxPageId = await ensureInboxPage(db, {
    workspaceId: input.workspaceId,
    userId: input.userId,
  });

  const title = input.payload.title.trim() || 'Untitled capture';
  const bodyTrim = input.payload.body.trim();
  const blocks: Array<Record<string, unknown>> = [];
  if (bodyTrim.length > 0) {
    blocks.push({ type: 'paragraph', content: [{ type: 'text', text: bodyTrim }] });
  }
  if (input.payload.url) {
    blocks.push({
      type: 'paragraph',
      content: [
        {
          type: 'text',
          text: input.payload.url,
          marks: [{ type: 'link', attrs: { href: input.payload.url } }],
        },
      ],
    });
  }

  const capturedAt = new Date().toISOString();
  const metadata: Record<string, unknown> = {
    inbox: true,
    capturedAt,
  };
  if (input.payload.url) metadata.sourceUrl = input.payload.url;

  const [row] = await db
    .insert(schema.pages)
    .values({
      workspaceId: input.workspaceId,
      parentId: inboxPageId,
      title,
      icon: null,
      content: { type: 'doc', content: blocks } as never,
      metadata: metadata as never,
      createdBy: input.userId,
    } as never)
    .returning({ id: schema.pages.id });
  const capturedPageId = row!.id;

  await writeAuditLog(db, {
    workspaceId: input.workspaceId,
    actorId: input.userId,
    action: 'inbox.captured',
    targetId: capturedPageId,
    metadata: { hasUrl: input.payload.url !== null, hasBody: bodyTrim.length > 0 },
  });

  return { capturedPageId, inboxPageId };
}
```

> If the existing audit helper has a different signature (e.g. takes positional args, or is named `appendAuditLog`), match it exactly — Step 1 noted the canonical name. The contract is: write one row with `workspaceId`, `actorId = userId`, `action = 'inbox.captured'`, `targetId = capturedPageId`, the rest free-form metadata.

```ts
import { and, eq } from 'drizzle-orm';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import { writeAuditLog } from '@/lib/audit/log';
import * as schema from '@/db/schema';

type Db = PostgresJsDatabase<typeof schema>;

/**
 * Mark a captured inbox child as triaged-in-place: set metadata.inbox = false
 * without moving the page. The page stays under the inbox parent unless the
 * caller separately moves it via the existing page-move API.
 *
 * Cross-workspace pages throw a "Page not found" error — the route handler
 * translates that to a 404 response, matching the project's never-leak-
 * existence convention (see src/lib/pages/access.ts).
 */
export async function markInboxDone(
  db: Db,
  input: { pageId: string; workspaceId: string; userId: string },
): Promise<void> {
  const [page] = await db
    .select({ metadata: schema.pages.metadata })
    .from(schema.pages)
    .where(and(eq(schema.pages.id, input.pageId), eq(schema.pages.workspaceId, input.workspaceId)))
    .limit(1);
  if (!page) throw new Error('Page not found');

  const meta = (page.metadata ?? {}) as Record<string, unknown>;
  const updated = { ...meta, inbox: false };

  await db
    .update(schema.pages)
    .set({ metadata: updated as never })
    .where(and(eq(schema.pages.id, input.pageId), eq(schema.pages.workspaceId, input.workspaceId)));

  await writeAuditLog(db, {
    workspaceId: input.workspaceId,
    actorId: input.userId,
    action: 'inbox.triaged',
    targetId: input.pageId,
    metadata: { kind: 'mark-done' },
  });
}
```

```ts
import { NextResponse } from 'next/server';
import { z } from 'zod';
import { getDb } from '@/db/client';
import { captureInbox, type InboxCapturePayload } from '@/lib/inbox/capture';
import { getAuthContext } from '@/lib/auth/require-role';

export const dynamic = 'force-dynamic';

const JsonBody = z.object({
  title: z.string().max(500).optional().default(''),
  body: z.string().max(50_000).optional().default(''),
  url: z.string().url().nullable().optional().default(null),
});

async function readPayload(req: Request): Promise<InboxCapturePayload> {
  const contentType = req.headers.get('content-type') ?? '';
  if (contentType.includes('multipart/form-data') || contentType.includes('application/x-www-form-urlencoded')) {
    // Share-sheet POST: PWA manifest's share_target.params keys are
    // `title` / `text` / `url`. Map `text` → body so the same downstream
    // schema applies.
    const form = await req.formData();
    const url = (form.get('url') as string | null) ?? null;
    return {
      title: ((form.get('title') as string | null) ?? '').slice(0, 500),
      body: ((form.get('text') as string | null) ?? '').slice(0, 50_000),
      url: url && /^https?:\/\//i.test(url) ? url : null,
    };
  }

  const json = (await req.json().catch(() => ({}))) as unknown;
  const parsed = JsonBody.safeParse(json);
  if (!parsed.success) {
    const err = new Error('Invalid request body');
    (err as { status?: number }).status = 400;
    throw err;
  }
  return {
    title: parsed.data.title,
    body: parsed.data.body,
    url: parsed.data.url ?? null,
  };
}

export async function POST(req: Request): Promise<Response> {
  const ctx = await getAuthContext();
  if (!ctx?.userId || !ctx.workspaceId) {
    return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
  }

  let payload: InboxCapturePayload;
  try {
    payload = await readPayload(req);
  } catch (err) {
    const status = (err as { status?: number }).status ?? 400;
    return NextResponse.json({ error: 'Invalid request body' }, { status });
  }

  const result = await captureInbox(getDb(), {
    workspaceId: ctx.workspaceId,
    userId: ctx.userId,
    payload,
  });
  return NextResponse.json(result, { status: 201 });
}
```
