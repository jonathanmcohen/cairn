# G17 — Search Reachability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Make the search backend's already-shipped capabilities reachable from the UI. Three gaps close here, all resolving **#164**: (1) the `SearchPalette` (`src/components/search-palette.tsx`) hard-codes FTS — add a **fts / semantic / hybrid** mode toggle that appends `&mode=` to the `/api/search` request; (2) there is **no `/search` results page** — build one that reuses the existing `SearchChipInput` operator UI (`src/components/search/search-chip-input.tsx`) to drive a full-page result list; (3) admins cannot trigger the route's federated cross-workspace path from the UI — add an **"All workspaces"** toggle (admin/owner only) that sends `&include_all_workspaces=true`, which `/api/search` already reads.

**Architecture:** Pure UI-layer work — **no schema, no migration, no new API route, no backend change**. The `GET /api/search` route (`src/app/api/search/route.ts`) already (a) parses `mode` via `SearchModeSchema = z.enum(['fts','semantic','hybrid'])` and forwards it to `searchPages(...{ mode })`, (b) reads `include_all_workspaces === 'true'` and routes to `federatedSearch(...{ includeAllWorkspaces })` (returning `{ results, peer_results, warnings }`) when `mode === 'fts'`, and (c) returns `{ results, warnings }` otherwise. `searchPages` (`src/lib/pages/search.ts`) types `SearchMode = 'fts' | 'semantic' | 'hybrid'`. `SearchChipInput` is a controlled component: `{ initialValue, onChange }` where `onChange` receives `ParseResult & { raw: string }` (`ops`, `free`, `warnings`, `raw`). The new `/search` page is a server component under `src/app/(app)/search/page.tsx` (the `(app)` group provides the authenticated shell, sidebar, and the existing `<I18nProvider>` that `useT()` relies on) that reads `getAuthContext()` for `role` (to gate the federated toggle to `admin`/`owner`) and renders a client `SearchResults` component. The palette gets a small inline segmented control persisting the chosen mode to `localStorage` so it survives reopen.

**Tech Stack:** React 19 / Next 16 App Router (server `page.tsx` + `'use client'` children), `cmdk` palette, shadcn/ui (`Button`, `Input`), lucide-react icons, the in-repo i18n `useT()` (`src/lib/i18n/provider`) backed by `messages/{en,es,ar}.json`, Vitest 4 + `@testing-library/react` under jsdom for components (`// @vitest-environment jsdom`) and Testcontainers Postgres for the `/api/search` route test.

**Closes:** #164

  ```ts
  'use client';

  import { useCallback, useEffect, useState } from 'react';
  import type { SearchMode } from '@/lib/pages/search';

  /** The backend's three retrieval strategies, in display order. Mirrors
   * `SearchModeSchema` in src/app/api/search/route.ts. */
  export const SEARCH_MODES = ['fts', 'semantic', 'hybrid'] as const satisfies readonly SearchMode[];

  const STORAGE_KEY = 'cairn:search-mode';

  function isMode(v: string | null): v is SearchMode {
    return v === 'fts' || v === 'semantic' || v === 'hybrid';
  }

  /**
   * Read/write the user's preferred search mode, persisted to localStorage so
   * it survives palette reopen and full-page reloads. SSR-safe: the initial
   * render is always `'fts'` (server + first client render match), then an
   * effect hydrates the stored value to avoid a hydration mismatch.
   */
  export function useSearchMode(): { mode: SearchMode; setMode: (m: SearchMode) => void } {
    const [mode, setModeState] = useState<SearchMode>('fts');

    useEffect(() => {
      try {
        const stored = window.localStorage.getItem(STORAGE_KEY);
        if (isMode(stored)) setModeState(stored);
      } catch {
        // localStorage unavailable (private mode / SSR) — keep the default.
      }
    }, []);

    const setMode = useCallback((m: SearchMode) => {
      setModeState(m);
      try {
        window.localStorage.setItem(STORAGE_KEY, m);
      } catch {
        // ignore write failures
      }
    }, []);

    return { mode, setMode };
  }
  ```

  Note: import is `import { useCallback, useEffect, useState } from 'react';` — fix the casing if Biome flags it (the snippet above intentionally matches React's exports `useCallback`/`useEffect`/`useState`).

  ```tsx
    title: string;
    snippet: string | null;
    breadcrumb: { id: string; title: string }[];
  };

  type SearchResponse = {
    results: ResultRow[];
    peer_results?: { workspaceName?: string; results: ResultRow[] }[];
    warnings?: unknown[];
  };

  export function SearchResults({
    initialQuery,
    canFederate,
  }: {
    initialQuery: string;
    /** True for admin/owner — gates the cross-workspace federated toggle. */
    canFederate: boolean;
  }) {
    const t = useT();
    const router = useRouter();
    const { mode, setMode } = useSearchMode();
    const [raw, setRaw] = useState(initialQuery);
    const [includeAll, setIncludeAll] = useState(false);
    const [results, setResults] = useState<ResultRow[]>([]);
    const [peers, setPeers] = useState<{ workspaceName?: string; results: ResultRow[] }[]>([]);
    const [loading, setLoading] = useState(false);
    const [searched, setSearched] = useState(false);

    const run = useCallback(async () => {
      const q = raw.trim();
      if (!q) return;
      setLoading(true);
      setSearched(true);
      try {
        const params = new URLSearchParams({ q, mode });
        if (canFederate && includeAll) params.set('include_all_workspaces', 'true');
        const res = await fetch(`/api/search?${params.toString()}`);
        if (res.ok) {
          const body = (await res.json()) as SearchResponse;
          setResults(body.results);
          setPeers(body.peer_results ?? []);
        }
      } catch {
        // network/abort — leave prior results in place
      } finally {
        setLoading(false);
      }
    }, [raw, mode, canFederate, includeAll]);

    return (
      <div className="mx-auto w-full max-w-3xl space-y-4 p-4">
        <h1 className="text-xl font-semibold">{t('search.page.title')}</h1>

        <SearchChipInput initialValue={initialQuery} onChange={(r) => setRaw(r.raw)} />

        <div
          className="flex flex-wrap items-center gap-2"
          role="group"
          aria-label={t('search.mode.label')}
        >
          <span className="text-xs text-muted-foreground">{t('search.mode.label')}</span>
          {SEARCH_MODES.map((m) => (
            <button
              key={m}
              type="button"
              aria-pressed={mode === m}
              onClick={() => setMode(m)}
              className={`rounded px-2 py-1 text-xs ${
                mode === m
                  ? 'bg-accent font-medium text-accent-foreground'
                  : 'text-muted-foreground hover:bg-accent/50'
              }`}
            >
              {t(`search.mode.${m}` as 'search.mode.fts')}
            </button>
          ))}
          <Button type="button" size="sm" onClick={() => void run()}>
            {t('search.page.submit')}
          </Button>
        </div>

        <p className="text-xs text-muted-foreground">{t('search.mode.hint')}</p>

        {canFederate ? (
          <label className="flex items-center gap-2 text-sm">
            <input
              type="checkbox"
              checked={includeAll}
              aria-label={t('search.federated.toggle')}
              onChange={(e) => setIncludeAll(e.target.checked)}
            />
            <span>{t('search.federated.toggle')}</span>
            <span className="text-xs text-muted-foreground">{t('search.federated.hint')}</span>
          </label>
        ) : null}

        {loading ? <div className="text-sm text-muted-foreground">…</div> : null}

        {!loading && searched && results.length === 0 && peers.length === 0 ? (
          <div className="rounded-md border p-4 text-sm">
            <div className="font-medium">{t('search.page.empty.headline')}</div>
            <div className="mt-1 text-muted-foreground">{t('search.page.empty.guidance')}</div>
          </div>
        ) : null}

        {results.length > 0 ? (
          <section aria-label={t('search.page.localHeading')} className="space-y-1">
            {peers.length > 0 ? (
              <h2 className="text-xs font-medium text-muted-foreground">
                {t('search.page.localHeading')}
              </h2>
            ) : null}
            <ul className="divide-y rounded-md border">
              {results.map((r) => (
                <li key={r.id}>
                  <button
                    type="button"
                    onClick={() => router.push(`/pages/${r.id}` as Route)}
                    className="block w-full px-4 py-2 text-left hover:bg-accent/50"
                  >
                    <div className="font-medium">{r.title}</div>
                    {r.breadcrumb.length > 1 ? (
                      <div className="text-xs text-muted-foreground">
                        {r.breadcrumb
                          .slice(0, -1)
                          .map((b) => b.title)
                          .join(' / ')}
                      </div>
                    ) : null}
                    {r.snippet ? (
                      <div
                        className="palette-snippet mt-1 text-xs text-muted-foreground"
                        // biome-ignore lint/security/noDangerouslySetInnerHtml: ts_headline returns sanitized <b> markup; same trust boundary as the palette.
                        dangerouslySetInnerHTML={{ __html: r.snippet }}
                      />
                    ) : null}
                  </button>
                </li>
              ))}
            </ul>
          </section>
        ) : null}

        {peers.length > 0 ? (
          <section aria-label={t('search.page.peerHeading')} className="space-y-1">
            <h2 className="text-xs font-medium text-muted-foreground">
              {t('search.page.peerHeading')}
            </h2>
            <ul className="divide-y rounded-md border">
              {peers.flatMap((p) =>
                p.results.map((r) => (
                  <li key={`${p.workspaceName ?? 'peer'}-${r.id}`} className="px-4 py-2">
                    <div className="font-medium">{r.title}</div>
                    {p.workspaceName ? (
                      <div className="text-xs text-muted-foreground">{p.workspaceName}</div>
                    ) : null}
                  </li>
                )),
              )}
            </ul>
          </section>
        ) : null}
      </div>
    );
  }
  ```
